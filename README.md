# Helix

**简体中文** | [English](README.en.md)

**开源 Android AI Agent，让一句话变成手机上的实际行动。**

Helix 在 Android 本机执行任务：操作支持的应用界面、浏览网页、处理文件和运行工具。你选择模型与访问范围，Helix 展示执行过程，并把结果留在可查看、可继续使用的会话和文件中。

如果你在寻找**豆包手机助手式体验的开源替代方案**，Helix 正在探索这条路：以 Mobile Use 插件为核心场景，把手机操作、网页和文件工作流交给你选择的模型。Helix 是独立的 Apache-2.0 开源项目，与豆包及其开发方没有官方关联；不依赖 OEM 预装集成，也不宣称具备相同的系统权限或全部能力。

[下载预览版](https://github.com/dollarser/helix-agent/releases) · [使用入门](#开始第一个任务) · [文档](docs/README.md) · [反馈](https://github.com/dollarser/helix-agent/issues) · [参与贡献](CONTRIBUTING.md)

> **开发预览阶段，需要 Android 10+，不承诺保留旧数据。** 当前发布包使用 debug 签名。数据库结构不兼容时，启动会要求确认清空数据库中的会话、任务、配置和授权记录；取消会保留旧数据并退出，确认后才重建，数据库外文件保留；重要内容请另行保存，诊断导出不是可恢复的全量备份。`main` 中的新功能不一定已包含在发布 APK 中。

## 可以做什么

| 能力 | 使用方式 |
| --- | --- |
| **手机操作 · Mobile Use** | 观察屏幕、查找元素、点击、滚动和输入；根据可用能力使用无障碍、Shizuku 或 Root |
| **文件与成果** | 独立文件管理器；读取、整理、创建和修改已授权文件，预览、定位和分享结果 |
| **网页与工具** | 浏览网页、收集资料、调用工具；Developer 构建还包含进阶终端与运行环境 |
| **会话与项目** | 围绕同一项目组织会话、文件、指令和记忆；执行中可排队、调整或停止任务 |
| **模型选择** | API 服务、自建兼容服务和设备内模型；Developer 额外提供实验性第三方订阅接入 |
| **插件** | 通过插件、技能和连接器组织能力，支持 MCP；按会话选择需要的插件 |

这些能力的完成质量取决于模型、设备、授权和目标应用。当前不是 OEM 系统镜像，也不承诺兼容所有应用、网站或文件格式。实际交付与验证范围见[当前状态](docs/development/status.md)。

### 从聊天走向实际任务

- **让模型操作手机**：在你授权的应用中查找内容、填写信息、完成多步操作；你可以观察过程并随时追加要求。
- **把网页信息变成成果**：浏览公开页面、对照资料，把结论整理到文件中，随后预览或分享。
- **带着上下文继续工作**：会话、项目目录和可选记忆保留任务线索；接入自己的 API 或设备内模型，按任务选择插件。

Mobile Use 是可选插件，浏览器、文件和工具各有自己的授权边界。涉及账号、付费或重要外部操作时，请按实际任务检查范围与结果。

## 开始第一个任务

1. 从 [Releases](https://github.com/dollarser/helix-agent/releases) 下载 APK，按 Android 提示安装。版本说明和校验文件以对应发布页为准。
2. v0.0.6 重发版会在对话模型选择中动态获取 **Helix 内置模型**目录，无需填写 Key；目录列出不代表推理连接已通过。它使用项目云端服务，共享额度，消息、上下文、工具结果及所选图片会发送至服务端。也可在**模型**中添加自己的 API 服务或设备内模型；已有选择不会覆盖。本轮已验证内置文字、图片和有界文件任务；共享服务的实时状态仍以实际请求为准。内置服务的验收范围见[HXA-307](docs/development/tasks/HXA-307.md)。
3. 新建会话并选择模型，从一个简单文件任务开始：

```text
帮我整理明天的待办：上午十点开会，下午寄快递，晚上买牛奶。
按上午、下午、晚上分组，保存为“明日待办.md”。
不要补充我没说过的时间。保存后读回文件，确认内容一致。
```

4. 查看执行状态并打开生成文件，核对结果。再尝试整理 CSV、汇总网页或操作测试应用。

网络模型可能产生服务方费用；本地模型需要额外下载权重并占用内存和存储。没有配置好的模型时，需要先完成模型设置。

### 操作手机应用

在插件中配置 **Mobile Use**，连接至少一个可用的屏幕操作后端，再在会话中选用。缺少配置或连接时，点击勾选会进入对应设置，完成后再明确勾选。无障碍、Shizuku、Root 等系统授权由 Helix 统一管理，插件使用宿主已获得的能力。无需同时获得全部权限；具体动作仍需满足相应条件。

支持的操作按实际就绪能力优先使用 **Root → Shizuku → 无障碍**。不同后端的能力并不完全相同，高权限也不能保证读取或操作所有安全窗口。遇到不确定结果时应先核查，不盲目重复可能已经完成的操作。

## 选择安装包

| 构建渠道 | 包含的能力 |
| --- | --- |
| **Standard / consumer** | 完整基础产品：会话、API/本地模型及渠道允许的工具；不包含第三方订阅 Runtime 和 PRoot 终端 |
| **Advanced / developer** | 在基础产品上增加平台或渠道允许的进阶能力，包括订阅适配、终端和内置 Linux 运行环境；适合开发与进阶体验 |

安装包渠道与会话权限模式是不同概念。第三方订阅适配需要对应账号权益，兼容性逐服务验证，不代表服务提供商官方授权。使用 API 地址与 Key 的套餐仍属于 API 配置。

**[v0.0.6 开发预览版](https://github.com/dollarser/helix-agent/releases/tag/v0.0.6)** 面向 ARM64，采用 R8 优化、不可调试构建，2026-10-18 重发版保持内部 `versionCode=1` 和相同开发签名。已安装原版的用户需手动下载同渠道 APK 覆盖安装；相同编号不会提供新的版本号提示：

| 渠道 | 安装包 |
| --- | --- |
| Standard | `helix-v0.0.6-consumer-arm64-v8a.apk` |
| Advanced | `helix-v0.0.6-developer-arm64-v8a.apk` |

本版重点是插件与会话交互、文件路径展示、任务结果与恢复可靠性，以及 Advanced 的 Linux 环境按需准备：首次获准的 Linux 任务或手动终端自动准备内置资源，正常使用无需先到设置中验证。实际执行仍遵守当前模式和授权范围。

本次还修复内置浏览器的页面布局与快照、通知栏手势被正常窗口切换取消、空白过程说明和会话自动标题，保留紧凑的同排输入布局。

详见 [v0.0.6 版本说明与验证边界](docs/product/releases/v0.0.6.md)。下载以 Release 中实际存在的附件为准，安装前核对 `BUILDINFO.json` 与 `SHA256SUMS`。当前验证以 API36 ARM64 模拟器为主，未验真机/OEM；浏览器资源检查仅 15 分钟，抖音任务是在提供下载事实和菜单入口后续测成功，模型仍会冗余检索或重复操作。签名冲突、已装版本编号高于 1 或旧库不兼容时，先保留数据，不直接卸载或清空。

## 隐私与控制

- **本机执行不等于数据完全离线。** 使用远程模型时，对话和任务所需的文件片段、工具结果或图像可能发送给所选模型服务。
- 设备内模型在本地推理，但下载、网页和联网工具仍可能访问网络；APK 不包含模型权重。
- 系统权限与工具授权分别管理。按需开放访问范围，并查看实际执行状态；模型说“完成”不等于操作已被验证。
- 停止任务不会撤销已经发生的外部操作。首次体验请使用测试资料或副本。

## 从源码构建

准备 **JDK 17、Android SDK 和 Python 3**，按照[开发环境说明](docs/development/environment.md)配置 SDK/NDK 与依赖。版本以仓库锁定配置为准。

```sh
git clone https://github.com/dollarser/helix-agent.git
cd helix-agent
./gradlew :app:assembleConsumerDebug
# 需要进阶构建时：
./gradlew :app:assembleDeveloperDebug
```

APK 位于 `app/build/outputs/apk/`。主机源码门禁为 `./scripts/check-all.sh --source`；构建成功不等于设备、真实模型或正式发行验收通过。贡献流程与测试要求见[贡献指南](CONTRIBUTING.md)。
