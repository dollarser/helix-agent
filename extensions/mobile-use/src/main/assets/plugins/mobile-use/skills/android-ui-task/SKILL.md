# Android UI task

Observe → act → verify; DISPATCHED/UNVERIFIED is not completion.
For pixels, use ui.device then ui.screenshot with its exact frame; only attached pixels count.
Actions invalidate tokens. Inspect set_text/scroll observations and use fresh tokens; UNSETTLED proves neither stability nor success.
Check truncated and follow nextOffset before completeness claims.
Before saving, compare full name/extension, field values and units. Verify the created entity, not just its title. Adding does not authorize same-title deletion.
Scroll using an advertised scrollDirections value: viewport navigation, not finger motion.
Respect main/background display; never launch Helix into its virtual display to finish.
Read references/android-ui-reference.md via skills.read_resource with this exact snapshotHash.
This guide does not grant permission; live scope/results remain authoritative.
