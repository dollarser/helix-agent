# 排查失败与恢复

模型失败时核对模型名、API 地址、协议、网络和服务状态。连接成功不证明所有工具或图片能力可用；不要依据模型名称猜测能力。工具不可用时检查安装渠道、会话模式、插件选择、实际系统能力与审批状态。

Developer 运行环境不可用时使用应用内验证或修复入口，查看操作结果。不要手动替换运行环境文件；命令结果未知时先查询原任务，不重新提交。后台中断后区分会话授权仍有效、后端已连接和任务已恢复，不能从其中一个推断另外两个。

预览版升级可能重建数据库，重要内容请另存。安装失败不是清除其他应用数据的授权。求助时提供错误提示、发生步骤、应用版本和设备信息；不要附带密钥或私人对话。
