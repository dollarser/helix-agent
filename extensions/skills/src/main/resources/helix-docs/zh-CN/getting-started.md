# 开始第一个任务

Helix 是运行在 Android 手机上的 AI Agent，需要 Android 10 或更新版本。在“模型”中添加服务，填写 API 地址、协议和密钥，添加服务支持的模型并测试连接。密钥只填在原生配置表单，不要发送到对话。设备内模型需要另外下载权重，并占用存储与内存；网络模型可能产生服务方费用。

新建会话，选择模型后输入任务。可以先让 Helix 创建一份简单待办文件，再打开或读回成果，核对是否符合要求。任务显示结束不代表内容一定正确。配置推理强度时，重新打开模型选择，在当前模型旁操作；可用选项由实际 Provider 能力决定。

会话列表支持搜索、重命名、归档和恢复；已完成的回答可以新建分支。也可以直接说“查一下这个对话里我之前提出的限制”或“把这个对话改名为出行计划”。模型可按需查询当前对话保存的文字及你分享过的其他对话引用；很长或不可读的内容会说明范围。引用是分享时保存的内容，不开放源对话后续消息，也不允许模型操作那个对话。标题修改仍遵守当前权限和模式。
