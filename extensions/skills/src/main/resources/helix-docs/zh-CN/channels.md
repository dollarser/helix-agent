# 渠道、预览版与升级

Standard 是完整产品的默认方向。consumer/developer 是当前构建能力集合，不等同于会话审批模式，也不代表商店最终分发方案。Developer 额外提供 PRoot 终端和实验性订阅等能力；具体可用性仍取决于安装包和设备。

预览版不承诺保留旧数据。不兼容的数据库结构会重建，清除会话、配置及其他数据库记录；数据库外文件由现行实现保留。重要内容请另行保存，诊断导出不是可恢复的全量备份。帮助 manifest 不证明签名身份或正式发布状态，应以实际分发记录为准。

Developer 运行环境与主应用共享 UID、数据和网络权限，不是安全沙箱。删除运行环境会移除其软件和任务记录，工作区文件不在该删除范围内。
