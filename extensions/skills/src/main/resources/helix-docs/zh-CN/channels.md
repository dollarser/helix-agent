# 渠道、预览版与升级

Consumer 固定提供 Standard 的完整渠道能力；Developer 固定提供 Advanced 的全部渠道能力，包括 PRoot 终端和实验性订阅等，无需在应用内选择或切换档位。渠道能力不等同于会话审批模式，也不代表商店最终分发方案。系统权限、目录范围、Root/Shizuku 和服务账号仍按需单独授权，运行环境按首次使用流程准备；可用性取决于安装包、设备和实际授权。

预览版不承诺保留旧数据。不兼容的数据库结构会重建，清除会话、配置及其他数据库记录；数据库外文件由现行实现保留。重要内容请另行保存，诊断导出不是可恢复的全量备份。帮助 manifest 不证明签名身份或正式发布状态，应以实际分发记录为准。

Developer 运行环境与主应用共享 UID、数据和网络权限，不是安全沙箱。删除运行环境会移除其软件和任务记录，工作区文件不在该删除范围内。
