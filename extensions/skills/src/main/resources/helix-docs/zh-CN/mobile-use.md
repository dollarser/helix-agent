# Mobile Use 手机操作

Mobile Use 是插件。在“扩展”中配置至少一种支持的后端，再在需要的会话中选用。可用后端包括无障碍、Shizuku 和 Root；能力及安全窗口限制不同，不需要全部授权。配置完成不等于自动选用，也不代替会话操作授权。

授权仅属于当前 Helix 对话。授权范围内截图无需每次重复确认；只有手动撤销结束授权。锁屏、进程死亡、重启、断连或模型失败不会撤销该授权，但恢复执行仍需系统后端重新就绪并取得新的观察/动作凭据。授权还在不等于任务一直在后台运行，系统仍可能终止进程。

悬浮界面用于查看状态和控制任务，不是目标应用完成操作的证据。点击或输入注入成功后，还要观察真实界面结果。遇到断连、过期目标或未知结果，应重新观察；不要跨后端重复可能已经完成的提交。停止、返回会话和撤销授权是不同操作。

可在 Mobile Use 设置选择主屏或后台屏。后台屏复用已连接、已授权的 Shizuku，应用没有就绪时会明确报告，不会偷偷改点主屏；配对仍由 Shizuku 管理。后台屏不是应用分身，账号和文件共享；同一应用正在主屏使用时，由用户选择是否允许移动。Android/OEM 的独立焦点支持会如实显示；锁屏认证不能绕过。停止原任务会释放其后台显示，恢复时须重新观察，旧截图和节点编号不可跨屏使用。
