# Summarize supplied text

Use only the text supplied for this task. Identify the main facts, open questions and suggested next actions. Clearly mark suggestions and uncertainty. Produce a draft for the user to review.

For requested local-file work, use the existing authorized read tool and verify the target. This Skill does not grant access, add tools, send messages, monitor chats or run bundled scripts.
