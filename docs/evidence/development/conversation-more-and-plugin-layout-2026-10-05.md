# 会话更多菜单与插件详情整理

Date: 2026-10-05
Scope: 所有者要求会话成果进入上下文占用右侧的更多菜单，整理附属内容及 Mobile Use 详情。

## 交互

- 上下文占用右侧及会话标题栏使用独立的竖向三点资源，输入区菜单标题为“更多”。不改变文件管理器及思考内容使用的其他图标。
- 本会话成果、任务清单、Goal 管理和分支会话说明在更多菜单内显示，保留原有按会话/模式显示条件。
- 排队消息、待发送附件、审批/阻塞/失败、草稿保存失败与目录恢复提示仍就地显示。它们影响下一步操作，不作为普通资料入口隐藏。
- 后续新增会话资料、查询或管理入口优先进入更多菜单；即时操作和需要处理的异常留在原位置，避免附属入口持续挤占消息空间。
- Mobile Use 按名称、描述、是否启用、插件设置、技能列表、工具列表排序。点击卡片展开技能与工具，点击各条目查看内容。

## 注册修复

`PluginRegistry.repair` 根据内置插件工厂重建工具注册，保留持久化启用状态，不申请无障碍、Root 或 Shizuku 权限，也不是下载安装更新。注册丢失或与当前版本不一致时仍有恢复价值；正常使用不需要反复执行。

界面改为“修复插件”，仅在内置插件已启用且组件未就绪时显示；关闭插件不会因为 ready 为 false 而错误提示修复。服务端保留原修复与授权边界。
