# HXA-211 原任务规格：按会话导出 JSONL 执行记录

历史规格：2026-09-20 交付后归档，实际验证见[完成记录](../../completion-records/HXA-211.md)。2026-09-18 所有者授权在当前会话推进；实施顺序为 196 → 197 → 211，外部设备阻塞独立记账。

前置条件：[ADR-AGENT-005](../../adr/agent/005-session-jsonl-export.md) 已接受；不依赖 191/207/206、PRoot 或真实模型账号。

## 范围与验收要求

- 应用能力：用户在会话中发起，通过应用服务导出；不注册 Agent 工具，不调用模型，不重放工具。
- 允许 core/storage 的只读快照与来源映射、应用服务、会话导出入口与系统文档输出、合成格式样例和独立校验器、测试/docs。避免修改 191 主题和 207 扩展文件；共享入口改动在集成时单独核对。
- 格式遵循 ADR：消息、Turn、模型调用、工具调用/结果、压缩边界、用量/终止原因、稳定 ID、大内容引用、版本、完成尾。历史缺失显式 unknown，不推测补值。
- 首版固定上限：内联文本最多 32 KiB UTF-8；单行最多 256 KiB；关系快照暂存和最终 JSONL 各最多 128 MiB；流式交付缓冲 32 KiB。阈值超限按 ADR 显式引用/省略或失败，不能静默截断后显示完整。
- 选定单会话的一致关系快照先落本地有界暂存；不在数据库事务中等待 SAF 输出。内容在事务外按稳定引用校验；并发删除或变更显式可见。
- 首版为单个 JSONL，大内容 reference_only 可能需要原设备，不承诺自包含备份。字段排除与自由正文脱敏边界按 ADR；不导出凭据配置、Secret、认证 header/cookie 或可复用授权证明。
- 取消、磁盘满、目标撤权、写入/关闭失败、进程死亡不能报告成功；仅清理本次暂存和新建的不完整目标。
