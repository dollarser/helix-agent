## 采用原则与边界

插件仍遵循所有者指定的每会话选择与“默认新会话启用”，不恢复全局启用开关。当前单独页面只列自己的插件；系统授权、操作范围、会话选择和保存分开呈现。参考 Claude Code 的插件组件与作用域组织，结合 Android 的显式系统授权与 Helix 原权限链，不从安装事实授予执行权限。启动异步准备和前台刷新停止后台轮询，不以一次首屏或有界检查宣称解决实体手机卡顿/黑屏。

本轮不是全 OEM、Doze、长稳、实际拼音 IME、窄屏大字体、所有插件更新失败矩阵或完整真实模型验收。J2、项目/Memory 完整 UI/进程死亡与 R2-B 各自继续，不由这些绿色关闭。
