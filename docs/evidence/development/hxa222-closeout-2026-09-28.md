## 实现修正

- 输出预算耗尽时 native 不解析残缺工具语法；codec 保留 measured usage 并返回 `LOCAL_OUTPUT_LIMIT`，不向 Dispatcher 交付部分调用。覆盖文本截断和不完整 calls payload。旧 `PROTOCOL` 没有保留原始 native reply，不能声称已唯一定位历史失败原因。
- 接入 pinned llama.cpp chat template 提供的 grammar/triggers/preserved tokens；最终 schema、权限、审批和 durable settlement 不变。grammar 仅辅助语法，不证明计算或任务成功。
- 明确 text-only runtime 的真实能力探测：执行连接、目录、文本和工具阶段，`PROBED` 的 vision=false；网络 Provider 仍执行既有五阶段。
- 默认 context 4096；已有上下文 UI 可设置 1024–32768，metadata 与生成共享配置。加载失败仍能在设置框修正。按可用内存、权重、F16 KV 估算及保留空间拒绝超预算加载，允许降低 context 重试；不静默改小配置。
- JNI load 的分配异常归一化；失败尝试清理资源，runtime restart 不复活旧 generation。模型管理失败保留用户输入并可退出。
- 下载续传协议提取为可测试的纯边界：200 从头重写；206 必须精确匹配 offset/end/total；重定向、认证错误与错位区间不能发布为已验证资产。对应三项 host 测试通过；本轮真实模型通过 host 下载和 ADB fixture 注入，没有把它记作 Android HTTP 下载端到端验收。
