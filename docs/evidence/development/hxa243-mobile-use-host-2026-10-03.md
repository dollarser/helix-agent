# HXA-243：Mobile Use 全机许可、原生操作与主机验收

日期：2026-10-03。前置 HXA-242 已提交 `ed5e1ef3848afa15de3d8427c26fcc92d8bd6bf0`；本轮由所有者授权在 main 收敛及本地提交，不推送。设备、真实账号及外部操作均未请求，不继承此前模拟器证据。

## 交付结论

Mobile Use `0.2.0` 已在 Advanced/developer 接入全机/指定应用许可、原生系统动作、应用启动、物理手势和无障碍截图。保留原10个语义工具，增加6个手机工具，共16个；不是创建第二套 Agent/任务运行时。当前完成主机与 Debug 制品验收，尚无本轮模拟器/真机验收。

### 授权和限制收敛

- 用户主动选择本次全手机范围或指定应用；全机包含系统界面，指定范围可额外纳入系统设置。工具输入不能授予新权限。
- 默认直到停止且不设动作次数；分钟/次数填0表示不限。明确的有限预算仍生效，尝试次数不冒充成功次数。
- 移除5分钟/30动作硬上限、每10次确认的死代码，以及以包名类别或“发送/支付/安装”等文字猜测的永久拒绝；实际外部动作走已有工具权限及审批策略。
- 许可绑定独立 grantId 和完整到期精度；有限到期计时向上取整，极长许可分段重查而非修改期限。旧定时回调不停止新许可。
- 取消任意30秒节点token期限；新快照/动作/授权变化仍废止旧token，包名/窗口/指纹/代际继续校验。包名支持平台允许的大小写并保持精确身份。
- 停止、熄屏/锁屏、服务断开结束许可；不提供自动解锁/认证绕过。停止不等于撤回已发出的 Android 动作。

### 能力入口

| 接口 | 本轮能力 |
| --- | --- |
| `ui.device` | 当前目标、display/window/旋转/尺寸、物理像素范围、frame和设备实际支持的系统动作 |

| `ui.gesture` | 点按/长按、路径滑动/拖动、多指缩放；frame绑定本次许可及实际坐标系，指定应用范围检查覆盖窗口 |

原有 `ui.snapshot/find/click/long_click/set_text/set_progress/scroll/back/home` 保留。系统动作枚举不代表每台设备都支持；耳机动作可能接听/挂断通话，锁屏会结束当前许可。密码及Android标记的敏感节点保留脱敏占位，不再让一个受保护字段导致整个页面不可用。

### 结果与资源真实性

截图复用 `WorkspaceToolImagePublisher` 和既有 `ToolVisualPreparation`，先发布到原 session/turn，再准备模型像素；没有视觉能力时保留文件并说明未回填，不塞Base64字符串、不伪造模型已看图。返回PNG宽高、实际回填图像宽高、screenBounds及pixelsAttached，避免缩放图导致坐标误算。截图遵守原有产物保留/删除机制，不承诺未存储。

修复新截图发布在输出目录不存在时失败的问题：安全创建固定output目录，不覆盖用户同名文件或绕过路径包含检查；回归验证连续两次输出均保留。等待会观察全部有界匹配项后再截断返回结果，避免maxResults掩盖页面变化；迟到快照不把超时改成成功，截断快照不能证明元素消失或界面稳定。

手势与截图各自只有真实物理回调执行槽，没有全局工具/终端锁。取消等待后仍等待真实回调释放物理槽，旧回调不能释放新操作的槽；进入平台后异常或结果不确定不标成无副作用，不自动重放。SDK-only媒体采集适配使用平台注解与明确API入口检查；局部UseRequiresApi风格提示有注释说明，不关闭NewApi或其他功能校验。
