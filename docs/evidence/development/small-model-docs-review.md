## 第二部分：面向用户的终端帮助草稿（Terminal User Guide Draft）

> [!NOTE]
> **版本与可用性说明**：
> 1. 本功能仅在 Helix **Developer 变体**中提供，需在设置中启用 **Advanced** 安全配置。
> 2. **已支持双终端并发会话（Multi-Session Terminal，最多 2 个）**。
> 3. 提供顶部标签栏快速切换会话，切换时后台 Shell 持续运行零重开。
> 4. 支持单写者与只读观察端隔离保护。

### 1. 终端环境与权限

- **运行位置**：终端运行在独立且私有的 `:proot` 进程中，与主应用进程隔离。
- **文件系统**：
  - 系统根目录（RootFS）以受保护方式挂载。
  - 工作目录映射到应用的沙盒工作区路径（`/workspaces/app/<relative>`），终端在该工作区内具备标准 Linux 命令执行能力。
- **无模型注入**：手动终端是纯人工开发者操作界面，模型（AI Agent）无法直接向当前终端注入输入或窃取屏幕输出。

### 2. 进入与启动终端

- **启动入口**：在文件管理页面中，选择目标工作目录，点击“打开终端”进入终端界面。
- **启动 Shell**：
  - 若当前工作目录尚无活跃终端，界面显示 **启动（Start）** 按钮。
  - 点击“启动”后，后台将创建基于 PTY 的交互式 Shell 进程，默认租期为 2 小时（最长可支持 8 小时）。
  - 启动成功后，屏幕上方显示会话工作目录、运行状态（RUNNING）及终端视口。

### 2.1 多会话管理与只读观察模式

- **多标签切换（Tab Bar）**：
  - 顶部导航栏展示当前活跃的终端标签（例如“终端 1”与“终端 2”）。
  - 点击相应标签可快速切换当前视口，**切换操作仅断开前端订阅并挂载目标视口，绝不重启或杀死后台 Shell 进程**。
- **新建终端标签（+）**：
  - 当活跃会话数少于 2 时，标签栏右侧显示“+”按钮，点击可开启第 2 个独立工作区终端。
  - 最多同时支持 2 个 live 会话。达到上限后，新建操作将被明确拒绝并弹出“已达到最大并发终端数（最多 2 个）”提示。
- **单写连接与只读观察模式**：
  - 同一终端会话仅允许一个主写连接获取输入控制权。
  - 当次要视口或重复连接接入同一会话时，自动降级为“只读观察模式”，顶部显示黄色警告横幅并禁用键盘输入与虚拟按键。
  - 当原主写连接断开（Detach）后，新接入的连接可自动晋升为写入者。

### 3. 退出与后台保活

- **离开页面（Detach）**：
  - 点击左上角“返回”按钮或使用系统返回手势离开终端页面时，仅断开界面与终端的连接（Detach），**不会终止后台正在运行的 Shell 或进程**。
  - 用户可以自由切换到 Helix 的其他页面（如对话、任务或文件）查看进展。
- **空闲超时（Detach Idle）**：
  - 终端在无前端连接的情况下，后台保留最长 30 分钟的空闲保持期；超过空闲期限且无活跃子进程时，后台服务将执行有界回收。

### 4. 重新连接与重新创建

- **重新连接（Re-attach）**：
  - 当后台存在已启动的终端时，再次进入终端页面将显示 **连接（Connect）** 按钮或自动恢复连接。
  - 点击“连接”即可重新接入正在运行的 Shell，终端将自动同步最新的屏幕输出。
- **重新创建（Recreate）**：
  - 当 Shell 进程已经退出（例如输入了 `exit` 或被主动停止，状态显示 STOPPED 且附带 exitStatus）时，界面提供 **清理结算（Settle）** 按钮。
  - 点击“清理结算”后，旧会话占用的席位和持久化记录将被彻底释放，界面恢复为“启动（Start）”按钮，允许在当前或新目录下启动全新会话。
- **异常恢复**：
  - 若应用主进程或后台 Runtime 发生异常退出，再次进入终端将呈现对账后的真实状态。若进程已无法恢复，状态将标记为可结算，用户可点击“清理结算”后重新启动，绝不会发生盲目重放或破坏工作区文件。

### 5. 停止与结算

- **停止终端（Stop）**：
  - 在终端运行期间，可点击操作栏的 **停止（Stop）** 按钮，系统将向后台会话发送终止信号以优雅关闭 Shell 及其衍生进程。
- **清理结算（Settle）**：
  - 只有在会话已停止或进入终态（`canSettle == true`）时方可执行。
  - 结算将解除所有与该会话相关的资源引用和持久记录。

### 6. 输出缺口与屏幕显示

- **屏幕视口**：终端视口提供 ANSI/xterm 兼容的虚拟终端仿真，支持常见终端文本修饰与光标移动。
- **输出缺口提示（Output Gap Detected）**：
  - 当终端产生极高速度的大吞吐量输出（例如执行无节制的日志打印或遍历），或者断开重连期间产生的输出超出了有界环形缓冲区容量时，终端将在顶部显示“检测到输出缺口（Output gap detected）”横幅。
  - 此时终端模拟器会自动进行新纪元（Epoch）重置，确保后续输出不会因缺失 ANSI 转义序列而出现花屏乱码。

### 7. 控制按键与虚拟键盘

- **快捷控制键**：
  - 终端上方提供了移动端常用控制按钮：`Ctrl-C`（中断当前命令）、`Tab`（命令补全）、`Esc`（退出/Vi 模式）、`Ctrl-D`（EOF / 退出 Shell）。
  - 点击相应按键即可直接向 Shell 发送对应的控制字符，无需外接物理键盘。
- **软键盘切换**：
  - 点击“键盘”按钮可主动拉起或收起系统输入法软键盘。

### 8. 租期与 Android 后台限制

- **租期约束**：每次启动终端的默认生命周期租期为 2 小时。租期到期后，系统将终止会话以保护移动设备电池和系统资源。
- **系统节电与限制**：
  - 移动设备受 Android 系统 Doze 模式、OEM 定制后台省电策略及内存压力（Low Memory Killer）影响。
  - 建议避免在移动端终端中执行耗时数小时的重型编译或网络下载任务；如果应用在后台被系统彻底回收，请在重新打开应用后查看会话结算提示。
