# HXA-197 私有 Runtime 原生 PTY I/O

日期：2026-09-20。范围为生产 proot-app 的原生 I/O 基础、实际 PRoot 设备旅程及变体边界；尚未接入产品终端页面、持久会话 owner 或 Binder 传输，不关闭 197。

## 实现与生命周期

`ProotPtyProcess` 只允许在私有 `:proot` 进程的非主线程创建。应用进程不执行生成代码；此进程共享应用 UID，不构成文件或凭据隔离。JNI 使用新建 PTY、controlling TTY、独立初始进程组及显式 argv/env；子进程在 fork 后只执行系统调用和 exec，不进入 JVM、分配器或日志框架，并恢复继承的信号处理与 mask。

- 参数使用标准 UTF-8 字节数组，保留中文和非 BMP 字符；拒绝 NUL。argv/env 各最多 128 项、单项 4096 字节、每个向量总计 65536 字节。Kotlin 在编码前限制字符串长度和环境变量数量，编码时累计检查；JNI 独立检查且先校验再累加，避免整数溢出。
- 主端非阻塞，单次读写最多 8 KiB，读 poll 最多 20 ms，resize 限制 1～512 行列。返回 0 表示暂不可读/写，部分写入由调用方保留未写偏移；EOF 返回 -1，不把它当作进程结算。
- slave 在 fork 前打开，避免子进程尚未打开它时主端出现瞬时 EOF。fork 成功只返回 PID/FD；exec 失败通过固定输出与退出 127 观察，不伪造 shell ready。
- `pollExit` 使用 `waitid(...WNOWAIT)` 观察但不回收，保留原 PID；`reap` 单独、幂等执行。描述符使用/关闭及 wait/signal 串行化；关闭后拒绝 I/O，回收后拒绝向初始组发信号。
- `killInitialGroup` 只终止原初始组与未回收 leader，**不代表交互 shell 的所有后台作业已停止**。关闭 master、EOF、leader 退出均不能直接释放持久执行占用。会话层仍需实现后台作业清理、身份校验与未知结果对账。

诊断 `PtyNativeProbeService` 仅位于 developer debug，非导出、运行于 `:proot`，只接受四个固定旅程编号，不提供任意命令、路径或环境变量 IPC。release 与 consumer 中没有该服务或诊断类。正式 native I/O 仍为内部组件，未增加 Agent/MCP/Skill 输入工具。

## 新增设备覆盖

`ProotPtyNativeDeviceTest` 四项均通过实际私有 Runtime PID 执行：

1. 锁定 PRoot/Alpine 的真实交互 TTY，UTF-8 argv/env、跨命令 cwd/env、resize、Ctrl-C 后退出 130 且前台命令消失、真实 Python REPL 与 Ctrl-D 返回/退出。诊断通道将既有 `PtyInputBuffer`/`PtyOutputBuffer` 接到 native 部分写入和读取。
2. 不存在的 executable 返回诊断输出、退出 127，输出最终 EOF。
3. 预热后连续创建/退出/回收/关闭 20 个进程，检查 FD 不增长；重复回收/关闭幂等，关闭后 I/O 与回收后 signal 被拒绝。
4. NUL、单项/总量/数量超限的 argv、超限环境变量、读取/写入/resize 边界拒绝；有效 I/O 仍可继续，SIGKILL 报告信号终态。

这些是 native 基础旅程，不是待实现的 `ProotTerminalSessionDeviceTest` 产品验收。诊断中有界通道已经使用生产缓冲；生产会话服务、IPC 与 Compose 渲染还未接线。

## 单写连接更新

随后增加生产核心 `PtyInputConnection`，把连接撤销与队列准入放在同一把锁下。第二个 attach 不抢占当前连接；detach 不丢弃已接收内容，新连接使用新标识。旧连接的延迟 detach 不影响继任者，旧输入返回 DETACHED；重连不重置队列，不能绕过 32 KiB/64 块限制。close 撤销全部连接并返回待写丢弃量，不宣称在途输入或进程已停止。连接标识不是权限来源，可信 USER/Session 校验仍由后续应用服务承担。

`PtyInputConnectionTest` **4/4**：撤销与已接收顺序、跨实例连接/关闭、重连后的预算与队列顺序、并发 attach 唯一成功及并发旧输入拒绝。原生旅程的诊断通道改用此组件，在真实 shell 已设置 cwd/env 后断开并重连，旧连接尝试写 `exit` 被拒绝，新连接继续验证原 cwd/env 与 REPL；这不是 Activity 或 Binder 死亡测试。
