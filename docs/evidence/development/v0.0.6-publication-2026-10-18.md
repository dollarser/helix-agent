## 审查与发布材料

起点 main `998bfc96`，远端 main `a9571a59`；待推送的五个既有提交覆盖浏览器、会话标题、紧凑交互及验收文档，工作区另有通知栏/过程说明修复。全部保留并审查，后者提交为 `0a6e1a10`。未改依赖版本、权限范围、内部版本编号或签名。全部待推送提交的变更 blob 使用原秘密规则扫描，并检查机器路径/签名材料；不上传模拟器数据库、Provider 配置、模型会话或内部日志。

双语 README 和版本说明改为实际 ARM64 分发、旧库确认、Standard/Advanced、开发签名与实际测试边界。当前预览没有旧库迁移承诺；不兼容时必须先在前台确认数据库删除范围，取消保留数据。既往一次清库授权没有用于本轮日常安装。

发行审查发现 Alpine 说明把通用仓库链接描述为足够的源码提供方式，缺少精确包对应材料。本轮从锁定 RootFS 的 apk 数据库提取 53 个包/38 个 origin 的实际 aports commit，归档原配方、本地补丁/材料和上游源码；每个下载输入对照 APKBUILD SHA-512 校验。`alpine-release` 由已审查配方生成文本，没有外部源码。没有执行下载配方或重编译第三方包。依据 [GPL 源码分发说明](https://www.gnu.org/licenses/gpl-faq.en.html#SourceAndBinaryOnDifferentSites)纠正文案，发布同页提供源码附件，不以“未修改”免除再分发要求。既有 `runtime-assets-20260917` 不变。

同时保存两个 Release RuntimeClasspath 的已解析 Maven 输入、POM 和原始 license/notice；单独保留原生组件、PRoot/RootFS、字体与订阅组件许可。解析输入清单不是 R8 后每个类的存活清单，也不将约束 BOM 当作二进制。公开附件与原 APK 内容核对，Helix 的 Apache-2.0 不覆盖第三方各自许可。

## 验证与制品绑定

生产实现沿 [HXA-306 最新修复](daily-interaction-closeout-2026-10-17.md#通知栏与过程说明修复)：完整主机门禁 Python 276、JVM 6093 通过/8 条件跳过，Mobile Use 311/311，日常 API36 Consumer Debug 会话 UI 9/9；Developer R8/Shizuku/真实 Qwen 的同一手势及系统通知栏入口各 1/1。前序源码完整主机、设备 UI、浏览器/文件与辅助抖音任务分别保留原来源，不将多轮验收表述为一次无辅助全量通过。

最终发布从干净提交运行 `./scripts/build-release-apks.sh arm64-v8a`，核对版本、ARM64、R8、non-debuggable、既有证书和双渠道边界，保存 matching mapping。精确源码、APK 字节/大小/签名、CI URL、最终制品比较及有界设备验证写入 Release 的 `BUILDINFO.json`；校验文件涵盖公开附件。仅当同一实现输入及实际 APK 内容对比支持时继承上述证据，不把旧包测试改成最终包重新运行。

GitHub 仅运行 source、锁定运行时资产、JVM、lint/静态、APK 和测试 APK 编译；发布以前必须等待最终提交所需作业成功。公开可用性、tag 对应提交与下载哈希另行核验，不由 CI 或上传成功推导。详细本地操作记录位于 ignored `build/v006-publication-2026-10-18/`；对外以 [v0.0.6 Release](https://github.com/dollarser/helix-agent/releases/tag/v0.0.6) 的真实状态和附件为准。

## 保留边界

- 实体手机、其他 API/OEM、Root/普通无障碍的新增手势设备矩阵、x86 设备、其他 Provider/账号没有本轮验收。
- 浏览器资源检查只有 15 分钟/122 循环的独立 Debug 宿主，不是生产 R8 的 2 小时或 24 小时长稳；完整 FFmpeg/PRoot 媒体端到端未重测。
- 抖音首次下载后导航失败、重复下载及未知回执保留；提供下载事实和菜单入口后的安装、66 秒独立视频采样、卸载/返回属于辅助续测成功。手势修复后的通知栏定向通过不替代全业务链重跑。
- 模型仍可能冗余检索、重复操作、误读图像或错误推断经过时间；发布说明保留这些质量限制，不削弱授权/UNKNOWN 边界掩盖它们。
- 预览仍用开发证书和 code 1；这不是正式签名、应用商店准入或长期数据升级承诺。
