## 重点字段与校验

| 领域 | 字段 / 规则 | 取消、失败与结果 |
| --- | --- | --- |
| 来源模板 | 当前源码 18 API 模板；OpenAI Responses / Chat Completions / Anthropic Messages | 模板只预填协议与地址，不内置真实模型或密钥；示例地址不会被访问 |
| 来源名称 | 1–128 字符 | 错误定位并保留表单 |
| Endpoint | http/https、合法 IPv4/IPv6/ASCII host、端口 1–65535；禁止 userinfo/query/fragment/空白/反斜线/IDN | HTTP 显示警告但可保存；从实际地址区分 loopback/LAN/public/unknown；10.0.2.2 是 LAN |
| API Key | 可选、编辑来源留空保留已有凭据的示例语义 | 原型只保存“已有示例凭据”标志，不保存输入值、不发请求 |
| 高级 Header | 名称最多 128；值最多 512；必须成对；合法 token；禁止控制字符、凭据关键词、proxy-*、传输/追踪保留名 | OpenRouter X-Title 大小写冲突拒绝；凭据必须走独立入口 |
| 模型 | 精确 ID 1–256、不含控制字符；显示名最多 256 | 创建可添加模型；编辑连接不覆盖模型偏好；目录发现失败/取消保留字段 |
| 模型目录 | 自定义 ID、可见性、空可见列表、顺序、显示名、搜索 | 明确保存空选择；取消回滚；上下文/能力子面板返回原目录 |
| 上下文 | endpoint/精确模型独立；自动窗口/手动窗口、自动压缩、触发百分比 | 手动 1024–10000000，本地来源上限 32768；比例 10–95；自动禁用手动输入；失败重试不报假成功 |
| 推理 | 演示精确目录 OFF/none/low/medium/high | OFF 不发送 effort，与服务端 none 分开；不按名字猜支持项 |
| 全局默认 | 单次输出 1–128000，Goal 自动轮数正 Int | 恢复默认 2048/256 需确认；不清零旧 Goal 累计或自动恢复 |
| CUSTOM | 从一个预设固定复制；七类效应 ALLOW/ASK/DENY，缺失 ASK | 当前会话规则与新会话默认分开；全局工具仅启用/禁用，预设不复活禁用工具 |
| LAN | 精确私网 origin，显式端口规范化；禁止 CIDR、公网、loopback、路径 | 添加、去重、移除；不是第一版的“网段”输入 |
| 出站 | Provider/MCP 精确 ID、canonical origin、固定 1h/24h/7d/30d TTL | Advanced gate、禁止通配符；撤销、过期、存储损坏 fail closed；不改变逐次审批 |
| hosts | 128 KiB；每行 IP+别名；IPv4/IPv6；注释、IDN、去重；每 host ≤16 地址 | 行号错误、全量校验后保存、恢复已保存；没有代理伪字段、DNS 查询或真实文件写入 |
| 云端语音 | HTTP/WS、启用云端输入、ASR/TTS、账号登录 | HTTPS/loopback HTTP；WS 固定演示目标与账号；改错失败、取消回滚；从不上传 |
| 本地资产 | 名称、HTTPS URL、SHA-256、字节数、推荐/高级、镜像 | 下载→校验→就绪；取消/哈希失败不可加载；就绪不自动加载 |
| PRoot/QuickJS | 非凭据环境行、默认允许列表；原生访问开关 | 拒绝凭据名/结构/未知变量；原生访问需独立确认，显示共享 UID 与 isolated UID 的差别 |
| 设备自动化 | 整机/所选应用、保存、后端状态、系统权限链接 | 空范围拒绝，整机时不同时编辑单独列表；只保存全局范围，不批准具体调用 |
| 提醒 | 标题 ≤160、正文 ≤20000、启用定时、精确通知请求、日期、时间、时区、ONCE/DAILY/WEEKLY/MONTHLY | 解释→真实字段→三次日历预览→确认；月末锚点保留、DST 间隙前移/重复较早；只保存模拟规则 |
| 定时 PLAN | 标题 ≤160、任务 ≤6000、首日、时间、IANA zone、会话、模型、目录、工具、时长、启用 | 每次范围变化使确认失效；UNKNOWN 不重试；无未决效果才显式新 attempt |
| 扩展导入 | MCP JSON、transport、endpoint；OAuth client/scope/redirect/document；设备码；来源包/目标 | 无效 JSON/凭据/command 拒绝；预览后导入默认不启用；签名失败禁止安装；设备码过期与取消 |
| 技能 | 名称、描述、指令、SKILL.md、相对路径、包来源 | 结构化字段生成正文、编辑保存、导入预览、导出预览；拒绝 .. 路径，不执行脚本 |

网络/Provider 参数取自当前 Kotlin 类型和校验源码；生产实现应继续使用现有校验服务，不能把本 HTML 的模拟校验代码复制为另一套权威实现。固定示例数据和 .invalid 地址仅供评审。时区在浏览器 Intl 中计算，Android ReminderTime 仍是生产日历所有者。

## 从入口走完整流程

- 模型 → 自配 API → 填完整字段 → 高级 Header → 发现模型 → 选择候选 → 保存 → 管理模型 → 可见性/显示名/顺序 → 上下文/压缩 → 模拟保存失败 → 重试。
- 设置 → 权限 → 新会话默认、全局禁用工具 → 当前会话 CUSTOM → 复制预设 → 七类规则 → 保存；再切预设，禁用工具保持禁用。
- 设置 → 网络 → 粘贴 hosts → 行号错误 → 修正 → 保存；权限 → LAN origin → 添加/去重/移除；Advanced 出站规则 → TTL → 到期/撤销。
- 设置 → 语音 → 云端配置 → HTTP/WS/账号范围 → 校验失败/取消/保存；模型 → 本地 → 高级字段 → 哈希失败/取消/成功 → 主动加载。
- 项目新建/编辑独立目录；历史 9 条分页/筛选；消息分支保存/切换/逐消息引用；文件嵌套目录/图片/PDF 页引用/多选移动/重名拒绝/恢复副本。
- 知识库 → 提取失败 → 保留原件 → 重试 → 引用 v1 → 来源更新 v2 → 冻结片段仍 v1；问答必须有明确选定来源。
- 提醒 → 标题/正文/日期/时区/重复 → 未来三次预览 → 保存 → 启停/编辑/删除；定时 Agent → 范围确认 → 修改目录使确认失效 → 再确认保存 → 启用。
- 插件 → MCP JSON → 校验 → 预览 → 导入未启用 → 连接/OAuth 高级字段/设备码；市场签名失败→禁止安装→刷新验证→审阅目标→确认。
- 浏览器多标签独立历史；终端多会话保留命令草稿与输出；存储分类清理前确认；诊断正文/路径默认不选、脱敏预览不分享。

## 模拟与提案标记

系统选择器使用单独“模拟”标题，提供合法/非法 URI、类型和大小，用户不会误认为正在访问设备。图片/PDF 预览为本地示意内容；模型/目录/签名/提取/认证/工具/下载结果是演示状态。额外筛选、目录内上下文返回、独立详情页、错过展示策略及系统页容器是视觉/交互提案；没有改变实际 Android 能力契约。

真实浏览器截图、真实 Android/Room/进程/音频/系统选择器/网络与账号仍未验收，详见 COVERAGE 与 VALIDATION。本次没有设置新的真实服务、安装依赖或开启转发。
