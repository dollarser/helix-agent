页面与交互

  1. 首页只保留资料头与通知、额度、账号三个统一入口；详情各自进入子页，避免首屏堆叠。
  2. 个人资料是本机展示设置，未登录也能编辑；退出或切换云端账号不会将资料上传。
  3. 编辑时保留草稿，保存才生效。头像经系统选择器导入；失败保留旧头像。
  4. 账号权限、云端额度与通知仍来自当前账号；未登录不展示虚构余额。
  5. 返回回到原入口，保留会话与输入草稿。退出账号需要确认。

原型不持久化文件、不发网络请求。演示数值仅供布局评审，正式产品必须显示真实结果及加载/错误状态。
