# 知识库与对话引用原型

2026-10-25。打开 [index.html](index.html)，完整设计、竞品官方依据和能力映射见 [DESIGN.md](DESIGN.md)。这是离线可操作提案，演示不等于 Android 功能已验收；实际接入与测试状态见[接入记录](../../development/knowledge-conversation-integration.md)。已发布 v0.0.7 不变。

## 方案

- 知识、笔记、资料是三个内容分类；问答保留为会话记录入口，不另建全应用导航。
- 随手记保存后就是笔记；知识是主动整理或直接写出的可复用内容。内容类型、保存、核对与提取状态分开，不把“草稿”当笔记类型。
- 从输入框＋或阅读页添加同一种引用；选择器支持分类、搜索、多选、预览与取消。取消不丢已有问题/引用，添加不发送。
- 引用条可预览实际全文/片段、版本与字符数；长文明确默认片段，超限阻止发送，不静默截断。关联来源不会递归发送。
- 来源更新需明确保留版本或刷新；不可用引用阻止发送，可移除后继续。历史保留实际当时内容，不随原文修改。
- “本条附带”只表示不自动附加到下一条输入，不承诺已发文字会从会话历史消失。
- 笔记整理为知识先得到可编辑候选，显式保存独立新内容；原笔记保留、默认未核对。回答保存为笔记，不自动升级。

## 使用

页面顶部是评审控制区，不是拟加入产品的功能栏。可切知识库、对话引用、整理知识、历史引用、来源更新、来源不可用，以及宽屏、大字体、暗色与复位。App 内可操作添加/编辑/保存/放弃、引用选择和预览、范围/版本操作、演示发送、历史引用、保存回答、核对和删除确认。

所有样本为合成内容，只存在内存，刷新/复位还原。回答及整理草案明确使用演示数据，不接模型；导入/导出只解释已有 Android 入口，不伪造文件处理成功。没有网络、文件访问、账号、麦克风或长期存储。用户可手动打开本地单文件，不需要启动服务或安装依赖。

## 验证与边界

- JavaScript 语法与 21 项离线 DOM 交互检查通过，覆盖编辑/取消与导航、引用取消及草稿、分类搜索、长文预算、版本和不可用、冻结历史、知识候选保存、来源保留、删除确认及 HTML 转义。
- 使用独立 headless 浏览器配置从生成内容直接渲染，未访问被拒绝的 file:// URL，也未架设转发服务。已检查窄屏列表、大字体选择器、宽屏暗色历史引用和版本面板的实际截图及横向溢出。浏览器检查和 Android 设备验收分开。
- 首次普通 Chromium 命令在产生图片后未正常结束，按 60 秒上限终止；原始失败保留。后改用已有 headless shell，检查正常结束，不将超时当通过。
- 测试脚本在忽略的 `scripts/local/debug/2026-10-25/knowledge-design/`，截图/几何与失败证据在忽略的 `build/knowledge-design-2026-10-25/`。没有增加生产依赖。
- 此节仅记录原型阶段：原型自身没有运行 Gradle、模拟器、真机或真实模型。后续 Android 已增加内容用途和结构化引用，真实验收另见接入记录；不能将浏览器通过冒充 Android 通过。原始 untracked 提案已先备份到本地证据目录，再按本次设计更新，未丢弃旧内容。

## 融合现有会话 UI

原型对话部分按当前 `AdaptiveConversationHeader`、`ConversationComposer`、`ComposerToolbar` 和 `ComposerAddSheet` 重排：会话标题栏保留导航、搜索、新会话和更多；输入框上方一条紧凑工具栏展示模式/会话权限/上下文/更多，输入框内下方保留＋、模型、语音与发送。知识引用是输入正文上方的增量区域，不新造模型/权限底栏。＋菜单保留原有会话引用，另增知识库引用；原型中的其他既有功能只解释其真实入口，不复制业务实现。

首屏文案沿用当前“今天想让我做什么？”及附件提示；用户任务建议追加到已有草稿，不覆盖问题、不发送。原型阶段的浏览器几何检查覆盖 320px 大字体、窄屏和宽屏暗色，21 项交互检查通过；证据为 `build/knowledge-fusion-2026-10-25/`。融合不等于像素级原生截图复刻；Android 构建和设备验证单独记在接入记录中。
