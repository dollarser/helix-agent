# ADR-0042: 手动文件传输中断恢复日志

Status: accepted
Date: 2026-09-09
HXA: HXA-182
Deciders: Project owner（明确要求文件传输中断恢复，授权持久操作记录与重启恢复入口）
Supersedes: none
Superseded by: none

## Context

ADR-0041 的复制暂存、覆盖备份和移动源删除阶段原来只存在内存。进程死亡后无法定位操作阶段。所有者明确选择补充持久恢复；不新增后台执行或 Agent 权限。

## Decision

部分扩展 ADR-0041：在 app 私有 noBackup 目录使用版本化、文件同步后原子替换的操作日志。记录 scoped 路径、操作 ID、阶段及发布前内容指纹。恢复入口显式执行，重验当前权限、目标和备份，不在启动时自动写外部存储。

发布前恢复旧目标并清理本操作的暂存节点，用户可重新发起传输；发布后重验目标内容，清理可验证备份，保留源端剩余内容，明确提示检查源目录。绝不盲目重放移动源删除。未知版本、目标冲突或内容改变保留记录和文件供人工检查。操作和恢复在组件内串行，不能清理正在执行的操作。

现有 SAF picker 导入/导出管线不改变；本记录覆盖独立文件管理的复制/移动/改名管线。不承诺字节偏移续传、断电事务或持久后台传输队列。

## Alternatives considered

- 自动重放整个移动：可能覆盖新增目标或删除用户修改，未采用。
- Room 保存单项状态：仍无法与外部文件系统形成事务；本轮独立小日志无需修改聊天数据库。
- 只留下临时文件：缺少可发现的恢复入口，不能满足需求。

## Consequences

普通进程终止后可定位并恢复文件操作。外部 Provider 与日志不构成原子事务，内容或授权变化时必须保留并报告。恢复完成的移动可能保留源副本；用户可确认后另行删除。旧版无日志的暂存文件不会猜测归属或自动清理。

## Verification

HXA-182 已完成阶段注入、重建日志实例、权限撤销、备份与目标修改、目录移动部分删除、重复恢复；双版本主机和独占 API29/36 各47项含真实进程死亡与原生恢复通过。精确范围与限制见 [完成记录](../completion-records/HXA-182.md)。

## Reconsider when

需要字节续传、跨来源统一任务队列、自动恢复或断电强一致保证时重新评估。
