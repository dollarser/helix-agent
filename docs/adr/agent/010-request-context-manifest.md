# ADR-AGENT-010: 模型请求上下文清单

Status: proposed
Date: 2026-09-22
HXA: HXA-217
Deciders: Project owner（授权收敛轻量版需求设计，未授权本轮实现）

## Context

聊天气泡、持久历史和模型请求不等价。压缩、修订、fork 和后续 Queue/Steer 会改变一次请求使用的来源。当前 ModelCall 已保存部分配置、用量和请求身份，但仅凭会话历史不能准确判断某条输入是否进入了某次请求。

需要的是最小来源记录，不是完整请求取证系统。重复存储正文会增加手机存储与敏感数据副本；即使只保存 ID，长任务逐次重复历史来源列表也有累计成本，应测量后确定边界。

## Decision

### 请求时保存依据，读取时组合展示

最终上下文组装、压缩、附件物化和容量准入完成后，在调用 Provider 之前，采集本次逻辑请求实际选用的最小来源记录。覆盖普通生成和压缩摘要请求，明确请求用途。不得在查看或导出时根据当前数据库倒推历史清单。

读取或导出时按稳定引用解析现有内容，不另存展示文本。记录表示来源被选入逻辑请求，不证明服务端收到、模型理解或执行，也不等同最终 HTTP 字节。经过裁剪的工具结果不能显示为原文完整发送；无法表达的转换应明确来源级证据边界，不伪造逐段映射。

### 首期最小数据

- 格式版本及 sessionId、turnId、modelCallId 关联；能从关联记录可靠取得的字段不重复保存。
- 请求用途、按实际请求顺序选用的消息 ID 和角色，以及请求使用的 input IDs。采用不可变消息身份；修订需指向具体版本，不能引用可变的“最新消息”。
- 使用的压缩 checkpoint ID、覆盖与保留历史边界。输入若被本次摘要吸收，区分摘要来源与直接消息来源；沿现有检查点来源关系追踪，不新增逐段映射引擎。
- 请求独有且既有 ModelCall 未保存的必要非机密配置。模型身份、输入 token 估算、输出上限和实际用量优先复用既有调用记录；实际用量随既有结算产生，不在请求前伪造。
- 附件复用所选消息上的不可变附件引用，不复制字节、不默认新增哈希。无法解析时明确不可用；不把原始附件等同 Provider 物化后的字节。

同一输入可被后续多次请求引用；清单不负责输入消费或首次交付记账，复用 HXA-216 的权威状态。未纳入请求的 pending 输入不能标成已使用。不默认增加 adapter 版本、工具 schema 全面指纹、生成段内容哈希或完整转换映射；已有指纹可通过 ModelCall 关联读取。此最小范围不能证明当时的完整工具目录或系统提示正文。

### 存储与资源边界

优先随既有 ModelCall 保存紧凑的来源元数据或关联记录，具体存储形式由实施切片验证决定。不强制独立 ContentRef 制品，不另建执行状态机、配额服务或后台淘汰任务。审计只引用调用 ID 和有界状态，不塞入完整来源列表。

首期实施前测量普通会话、反复工具调用、压缩和最大合法来源数量下的编码字节、读写耗时及累计增长，包括长任务至少 100 次调用重复历史 ID 的成本。根据测量在实施记录中确定并测试单条记录的字节/条目上限；删除原先未经测量的 1 MiB/64 MiB 固定指标。不得无界构造清单或默认无限增长可接受；若最小记录的累计开销仍不合理，先收缩采集范围或另行评审简单保留策略，不隐式引入复杂淘汰系统。

超限时保留可写入的有界状态、原因和来源数量，标为 incomplete/omitted，不静默截断后宣称完整。诊断写失败不单独阻断合法模型调用，既有强制审计和准入仍生效；磁盘完全不可写时不承诺能保存失败原因。清单失败不改变输入消费或执行结算。

记录随会话删除。引用不延长消息、检查点或附件原有保留期，不复制已删除正文。源内容缺失时返回“原内容不可用”；保留来源 ID 不等于能永久还原请求。

### 读取、导出与缺失语义

首期提供内部只读查询和 HXA-211 JSONL 导出，不新增调用详情页面或正常聊天气泡。将来详情页按引用组合展示即可，不回写一份展示快照。JSONL 定义新增记录/字段的格式版本和兼容规则，同一会话正文仍由既有记录导出，清单仅给出来源引用。

区分来源记录完整、不完整/省略、旧版本未采集，以及源内容已不可用。来源列表完整不表示正文仍可读取或完整请求可重建。进程在采集与调用之间死亡时，依据既有 ModelCall 生命周期解释：清单落盘不证明调用启动，调用启动不证明服务端收到，未知终局不伪装完成或触发重放。不建立第二套 prepared/started/finished 持久状态。

禁止保存认证头、token、Secret、含凭据 URL，以及重复提示词/工具结果/图片正文；不上传遥测、不新增 Agent 调试工具。详细诊断仅在出现具体排错需求后另行设计用户主动启用的范围、脱敏与保留期限，本期不实现诊断开关。

## Alternatives considered

- 查看时重建清单：当前状态可能变化，不能充当原请求事实；只用于解析已保存引用的展示。
- 每次保存完整 HTTP 请求或正文：重复量与隐私成本过高，不采用。
- 独立大清单制品、固定全局配额与淘汰系统：当前无测量证据支持复杂度，先做最小记录并验证成本。
- 观测缺失就拒绝模型调用：将诊断故障变成任务故障，不采用。

## Consequences

可以核查消息修订是否生效、输入关联和压缩来源，提升 JSONL 排错价值；不能提供完整请求重放、逐段内容证明或永久原文存档。新增少量但仍随调用增长的元数据，必须有实测边界。保持 P2，先完成输入语义与稳定性工作。

## Verification

[HXA-217](../../development/tasks/HXA-217.md) 要求来源与 loopback 请求核对、修订/压缩/真实输入交付、存储测量、JSONL 兼容、内容缺失、写失败与进程中断验证。本轮只修改设计，未实施或执行新功能验收。

## Reconsider when

有实际案例需要工具目录变化对比、精确生成段映射、附件物化指纹或 wire 排错时，再独立评估详细诊断；实测累计来源记录成本不适合端侧时重新评审保留策略。
