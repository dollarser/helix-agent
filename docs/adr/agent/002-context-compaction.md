# ADR-AGENT-002: 模型请求上下文与步骤边界压缩

Status: accepted
Date: 2026-09-16
HXA: HXA-174, HXA-176
Deciders: Project owner（当前有效决定；授权按需求合并重编，不新增功能接受范围）

## Context

长任务需要在执行步骤之间控制上下文大小，同时保持协议完整性、附件绑定和可恢复原历史。

## Decision

- 以持久历史、摘要、附件和工具调用配对构建模型请求。压缩不删除原历史，不建立另一个与生产请求组装竞争的 Context Builder。
- R2-A 将现有选择与容量算法迁入唯一纯 `ContextCompiler`；宿主先读取有界、带来源身份的快照，Core 决定保留与压缩，原日志事务发布摘要。正常请求的存储/附件/权限适配仍由宿主完成。摘要编排和材料化分开，但不改变原提示词、保留顺序、预算或收益阈值。选中的损坏历史继续拒绝；恢复规则明确排除的历史行不因提前解码而阻断有效请求。
- 每次模型请求前检查实际输入用量与增量估算，受 Provider 上下文窗口、用户上限、输出预算和协议/图片余量共同约束。模型窗口未知时不猜无限容量。
- 仅压缩已完成的历史或当前 Turn 较早完整工具步骤；工具调用与全部结果整组保留/压缩，保留当前用户原文与最新完整步骤。无当前可压缩步骤时可处理上一轮较早已结算部分。
- 摘要使用无工具调用，生成结构化连续工作笔记；摘要也计入模型/token/时间预算，不授予新权限。摘要正文目标按本次可移除历史的估算量取八分之一，范围 128～4096 tokens，并受用户输出额度约束；包含服务端推理的请求输出额度最多 16384，仍取用户配置与窗口四分之一的较小值，并由原 Turn 总预算继续约束。请求使用 OFF；通用兼容协议省略推理字段不保证服务端关闭默认推理，因此正文目标不能充当计费输出硬上限。
- 用户单独发送 `/compact` 属于维护请求：不创建或绑定 Goal，不携带目标生命周期工具或目标编辑授权，不恢复旧的自动续跑资格；成功、失败、取消和重试均保留既有 Goal 状态与用量、会话所选模式。维护摘要计入其独立 Turn 的模型/token 预算。任务内部的自动压缩仍计入原 Turn/Goal，原任务可继续。
- 发布 checkpoint 原子化，保留必要 message IDs/覆盖边界与来源。发布前检查收益，每个原任务调用间限制次数，无收益不循环摘要。
- 失败保留原历史并结算摘要调用；仅无副作用的可恢复摘要失败允许一次预算内重试。原上下文仍在硬限制内可跳过，否则报告可恢复容量限制。取消、拒绝、预算不足不重试。压缩不触发 Goal 激活或自动扩大预算。
- 手动摘要合法但不足以减少上下文时，维护 Turn 正常结束并提示原上下文未改变，不生成 checkpoint、不宣称压缩成功、不重放摘要正文；实际模型调用仍计费记账。无收益不是协议或执行失败，真实错误继续如实呈现。
- 上下文圆环以当前会话为边界，从该会话读取匹配模型与接入配置的已确认用量。每个 ModelCall 完成并落库后更新，不等 Turn 最终结束；包含转入工具执行的中间调用，并在工具启动前发布。单次调用仍在流式输出、失败及未生效压缩保留上次有效值；只有已提交 checkpoint 可替换为压缩后估算。摘要请求的输入用量不是会话上下文用量，不进入圆环或普通输入用量下限。窗口上限为 fallback 时标注估算，不冒充官方容量。

## Alternatives considered

仅保留最近 N 条会破坏工具配对和用户意图；只在 Turn 结束压缩无法支持长工具循环；把摘要当可信系统指令会提升外部内容权限。

## Consequences

同一主题使用一份有效契约，避免并行实现各自解释权限和生命周期。代价是实现、UI、数据与恢复需要一起验证；accepted 表示决定，不代表相关任务全部完成。

## Verification

本次为现行决策整理，不新增功能通过结论。实现范围与实际命令结果以[实施状态](../../development/status.md)、对应 HXA 及完成记录为准；修改本契约后须覆盖成功、失败、取消、边界和恢复，不能用文档门禁代替设备/功能验收。

## Reconsider when

产品所需能力超出本决定边界，或平台、依赖、资源和设备证据证明当前方案不可行时重新评审；普通实现修复不另造一套决策。

## Decision history

- 2026-10-04：所有者报告长任务直到最终回复才更新占用。取消投影的 Turn 终态过滤，并在已提交模型工具步骤后发出刷新；精度仍是服务端报告的单次请求输入用量，不是流式 token 计费累计或未发送草稿估算。
- 2026-10-01：HXA-236 将宿主验证的 Job 观察事实接入同一请求装配与纯 ContextCompiler。原 audit journal 保存状态变化，不新增聊天历史或任务数据库；当前绑定/权限筛选后最多 8 项/8 KiB，并受输入预算与消息数限制。时间是已记录观察，不保证实时；旧非终态标 stale。resultRef 指向审计事实而非产物，已结束不等于已收取或任务成功；自动纳入不启动新推理、不做 Runtime 查询。ModelCall 只保存有界严格格式的原快照引用。

- 2026-10-01：HXA-234 接入有界 `ContextSourceSnapshot`、纯编译器和 Core 压缩周期，删除原 App 选择算法。复用历史映射、恢复过滤与原子 checkpoint；真实存储集成与纯算法测试分别验收，不把本轮结构迁移宣称为模型效果或上下文成本优化。
- 2026-10-01：手动压缩无收益时正常结束并保留原历史，不写 checkpoint；圆环按当前会话已确认的普通请求用量或已提交的压缩估计投影，发送中保留上次值。失败或未提交的摘要调用不替代会话用量；服务未提供窗口时明确标注估算。
- 2026-09-29：修正手动压缩误入 Goal 准入的实现边界，明确维护 Turn 与目标自动执行隔离；不改变任务内自动压缩契约。

## Decision history — 2026-09-30：重复压缩输出余量

API36 真实 SGLang 的重复压缩在 4096 输出 tokens 处触发 OUTPUT_TOKEN_LIMIT。移除低于用户配置的 4096 固定摘要请求上限，改为最多 16384；正文目标、摘要字符上限、窗口与用户预算仍生效。截断不落为 checkpoint，原历史保留。不为所有 OpenAI-compatible 服务盲目注入厂商特有的 thinking 字段。

## Decision history — 2026-09-30：摘要事实归属

针对真实服务在重复压缩后误答 UNKNOWN，摘要生成与回填提示明确区分用户提供的标识/约束、独立验证结果和权限。复述用户提供的事实不要求工具重新验证；不能把验证码存在误解为验证已经成功。摘要继续作为不可信历史数据，不提升为系统指令或授权。提示保存在 prompts 资源中，模型偶发行为的改善由定向实测记录，不承诺消除所有遗忘。
