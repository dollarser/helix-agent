# ADR-AGENT-002: 模型请求上下文与步骤边界压缩

Status: accepted
Date: 2026-09-16; revised 2026-10-16
HXA: HXA-174, HXA-176, HXA-286, HXA-287, HXA-293
Deciders: Project owner（2026-10-15 要求按评审更新目标设计和任务；接受范围见 Decision，实施另计）

## Context

长任务需要在执行步骤之间控制上下文大小，同时保持协议完整性、附件绑定和可恢复原历史。

## Decision

- 以持久历史、摘要、附件和工具调用配对构建模型请求。压缩不删除原历史，不建立另一个与生产请求组装竞争的 Context Builder。
- R2-A 将现有选择与容量算法迁入唯一纯 `ContextCompiler`；宿主先读取有界、带来源身份的快照，Core 决定保留与压缩，原日志事务发布摘要。正常请求的存储/附件/权限适配仍由宿主完成。摘要编排和材料化分开，但不改变原提示词、保留顺序、预算或收益阈值。选中的损坏历史继续拒绝；恢复规则明确排除的历史行不因提前解码而阻断有效请求。
- 每次模型请求前检查实际输入用量与增量估算，受 Provider 上下文窗口、用户上限、输出预算和协议/图片余量共同约束。模型窗口未知时不猜无限容量。
- 仅压缩已完成的历史或当前 Turn 较早完整工具步骤；工具调用与全部结果整组保留/压缩，保留当前用户原文与最新完整步骤。无当前可压缩步骤时可处理上一轮较早已结算部分。
- 摘要使用无工具调用，生成结构化连续工作笔记；摘要模型/token/时间用量也记录为统计，不授予新权限。摘要正文目标按本次可移除历史的估算量取八分之一，范围 128～4096 tokens；包含服务端推理的请求输出额度按完整摘要请求的校准输入估计从当前有效窗口扣除，并保留 min(window/4, max(2048, ceil(window/10))) 协议与估算安全余量，再取服务明确声明的单次输出上限。摘要不受普通回复输出配置或旧 16384 上限裁剪；普通回复额度不变，现有 Goal 准入与用量核算不放宽。请求使用 OFF；通用兼容协议省略推理字段不保证服务端关闭默认推理，因此正文目标不能充当计费输出硬上限。
- 用户发送 `/compact [可选重点]` 属于维护请求：不创建或绑定 Goal，不携带目标生命周期工具或目标编辑授权，不恢复旧的自动续跑资格；成功、失败、取消和重试均保留既有 Goal 状态与用量、会话所选模式。维护摘要统计于其独立 Turn。任务内部的自动压缩用量统计于原 Turn/Goal，原任务可继续。
- 发布 checkpoint 原子化，保留必要 message IDs/覆盖边界与来源。发布前检查收益，每个原任务调用间限制次数，无收益不循环摘要。
- 压缩触发后必须成功发布有效 checkpoint 才继续任务；失败保留原历史并结算摘要调用，摘要无效、无收益、输出截断或未收到任何内容的可重试服务错误最多尝试三次（首次加两次重试），不叠加普通推理空响应重试。次数耗尽、无法选段或容量不足均明确失败，不能因原上下文仍可放入而跳过。取消、拒绝及结构化工具片段不重试。压缩不触发 Goal 激活或自动扩大预算。
- 手动压缩采用相同成功与有限重试规则；最终无收益或其他失败以维护 Turn 失败状态与明确原因提示用户，保留原历史、既有 checkpoint 和模型用量，不伪称压缩完成。
- 上下文圆环以当前会话为边界，从该会话读取匹配模型与接入配置的已确认用量。每个 ModelCall 完成并落库后更新，不等 Turn 最终结束；包含转入工具执行的中间调用，并在工具启动前发布。单次调用仍在流式输出、失败及未生效压缩保留上次有效值；只有已提交 checkpoint 可替换为压缩后估算。摘要请求的输入用量不是会话上下文用量，不进入圆环或普通输入用量下限。窗口上限为 fallback 时标注估算，不冒充官方容量。

### 内容快照与策略分期（HXA-286/293）

上下文来源、内容版本/身份、信任、当前资格和成本口径在 HXA-286 共同契约阶段固定，沿现有 ContextSourceSnapshot/ContextCompiler 收敛，不新增竞争的历史构建器。Memory、Skill、资源及工具结果都以有界输入参与；原持久历史/引用/checkpoint 仍为事实来源，复用 HXA-285 的一致性修复。

正确性继承 HXA-285 和现行上下文证据，在 HXA-287/286 每个变化的接缝上继续验证：不可变模型输入、授权投影、call/result 成组及原调用顺序，在取消/迟到回调和 crash/reload 后仍按同一持久身份重建；不能依赖当前页面或另一运行快照。先用受控 executor/可重载事实夹具，再以真实 Room/执行集成举证。检索、排序、摘要质量等策略后置，不代表协议与来源正确性可以等到 293 或 294 才验证。

HXA-293-A 从 285 的同源物化和 299 已交付诊断继续，完善最小内容端口与统一可选预算；必要指令、当前输入、完整 call/result 组及输出余量优先，目录/近期工具/Skill/Memory/资源在剩余窗口分配，并解释省略和重读路径。293-B 再以冻结样本分别比较 Memory 检索、选择和排序。Schema 字节估算、实际模型 token 和图片/协议成本不能混用，不能截半个调用组或以静默丢弃掩盖硬超窗；诊断不扩大权限或自动启动推理。无稳定收益保留默认，不恢复累计任务 token 阻断、固定工具数量或未经验证的全量常驻。

结构改造不能破坏工具调用配对、用户当前输入、来源身份、Memory 开关及摘要原子发布；新的选择策略不继承旧 R2-B 对照收益，也不重开暂停的提前结束专项。

### 多运行内容隔离

唯一 ContextCompiler 是同一套编译实现，不是共享的可变当前上下文。HXA-287/293 的快照、模型配置、可用工具和 Memory scope 按显式运行身份输入；两次编译/取消互不污染，父子用量归集不能把两个独立上下文窗口合并或继承审批。

内容源引用沿 [Workspace 契约](../workspace/001-session-paths.md)保留可确认版本，过期后台结果不得覆盖更新快照。当前用普通会话的交错请求与文件变化验证，不为未来 child 预建新历史库、上下文管理平台或生产调度器。

## Alternatives considered

仅保留最近 N 条会破坏工具配对和用户意图；只在 Turn 结束压缩无法支持长工具循环；把摘要当可信系统指令会提升外部内容权限。

## Consequences

同一主题使用一份有效契约，避免并行实现各自解释权限和生命周期。代价是实现、UI、数据与恢复需要一起验证；accepted 表示决定，不代表相关任务全部完成。

## Verification

本次为现行决策整理，不新增功能通过结论。实现范围与实际命令结果以[实施状态](../../development/status.md)、对应 HXA 及完成记录为准；修改本契约后须覆盖成功、失败、取消、边界和恢复，不能用文档门禁代替设备/功能验收。

## Reconsider when

产品所需能力超出本决定边界，或平台、依赖、资源和设备证据证明当前方案不可行时重新评审；普通实现修复不另造一套决策。

## Decision history — 2026-09-30：重复压缩输出余量

API36 真实 SGLang 的重复压缩在 4096 输出 tokens 处触发 OUTPUT_TOKEN_LIMIT。移除低于用户配置的 4096 固定摘要请求上限，改为最多 16384；正文目标、摘要字符上限、窗口与用户预算仍生效。截断不落为 checkpoint，原历史保留。不为所有 OpenAI-compatible 服务盲目注入厂商特有的 thinking 字段。

## Decision history — 2026-09-30：摘要事实归属

针对真实服务在重复压缩后误答 UNKNOWN，摘要生成与回填提示明确区分用户提供的标识/约束、独立验证结果和权限。复述用户提供的事实不要求工具重新验证；不能把验证码存在误解为验证已经成功。摘要继续作为不可信历史数据，不提升为系统指令或授权。提示保存在 prompts 资源中，模型偶发行为的改善由定向实测记录，不承诺消除所有遗忘。

## Decision history — 2026-11-10：原文缺失与接受声明的来源保真

长任务证据暴露了摘要遗漏待录入原文、又把助手重建内容描述为用户已接受的问题。沿现有文本摘要链修复：编译输入增加原消息 sequence；有附件的行显式标记 attachmentContent=not_included_in_summary_request。原消息 id、role 与正文保持，附件像素并未发送给摘要模型，不因早期任务模型看过截图而假定摘要模型也看过。回填用持久 checkpoint 的 coveredThrough 标示检索边界，不声称边界内全部细节都已保留；不改变 checkpoint 格式版本、选择/原子发布/取消恢复规则，也不增加未经授权的图片披露。

摘要优先保留未完成抄录的准确原值、单位和来源；缺失原文显式留为待检索，不能补写合理内容。用户接受替代/近似方案的声明须归属原用户消息，助手建议、旧摘要和沉默不构成接受。恢复指引要求在缺失内容影响后续填写时重读原消息/结果/附件；改变保真要求的“已接受”声明需查原用户表述。已有足够原文与授权则复用，不增加例行审批或一律重读。

回归覆盖源身份、附件省略标记、请求不夹带图片、当前输入保留、摘要仍为不可信 assistant 历史及打包提示契约。它们证明传递信息和指引正确，不证明任意模型绝不会虚构；原任务事实正确性仍需独立模型任务验收，不在夹具中裁剪答案或伪造结果。

## Decision history — 2026-11-11：拒绝纯工具标记摘要

摘要调用仅返回完整 `<tool_call>…</tool_call>` 文本（一个或多个包裹，包裹之间及之外只有空白）时，即使没有结构化 tool call 且具备 token 收益，也不能发布为连续工作笔记。按既有 `CONTEXT_SUMMARY_INVALID` 结算并走原有有界重试/保留历史路径，不执行标记内容，不升级权限，不删除或覆盖旧 checkpoint。带有正常正文的字面标记不因此拒绝；不强制新的摘要 schema，也不把语义错误判断扩展成通用真实性判定。
