# ADR-AGENT-006: 模型结果投影与预算恢复体验

Status: accepted
Date: 2026-09-17
HXA: HXA-099, HXA-174, HXA-176
Deciders: Project owner（授权在独立 worktree 优化工具回显、模型输入与预算问题）

## Context

工具协议、模型上下文、用户聊天和审计记录服务不同目的。把 TOOL 记录显示成普通回复会造成重复大段 JSON；将完整大结果反复带入模型上下文会增加端侧内存、传输与推理费用。预算仍有必要，但多个入口使用不同估算、所有超限共享一个错误、重试重新裁切历史，会让用户误以为任务或已完成工具结果丢失。

## Decision

- 聊天气泡只投影用户与助手正文。工具调用、结果、压缩 checkpoint 保留持久记录和协议配对，工具过程从现有可展开工具时间线查看；不按内容是否像 JSON 删除真实用户/助手正文。
- 模型仍收到 TOOL 结果。已知 QuickJS 包装中的 JSON 字符串可解码一层，保留业务字段；未知格式原样保留，不递归删用户字段。
- 大于 16 KiB 的成功结果，在 `tool.result.read` 已注册且该会话启用时，模型投影为明确标注截断的 JSON，含 `resultRef`、前 2048 个 Unicode code point、`nextOffset` 和总字符数。完整已验证输出仍在 `tool_results`/内容存储。读取工具被禁用时不生成无法读取的新投影。
- `tool.result.read` 是本地只读工具，走既有 schema、授权、执行限制和审计管线。引用包含本地 Turn/ToolCall ID；执行器以 Dispatcher 注入的会话与 Turn 验证归属，仅返回同一会话已完成且验证通过的成功结果。每页最多 2048 个 code point，输出最多 16 KiB，期限 5 秒；取消、过期、缺失、未结算或校验失败返回相应结果，不执行原工具、不读取任意路径、不扩大授权。原工具输出受框架 8 MiB 硬上限约束；此实现按页输出但每次读取会校验完整原内容，不承诺文件流式随机访问。
- 上下文预检、Turn 准入和 Goal 预留共用输入估算，包括指令、历史/工具参数、工具 schema、消息协议开销和图片余量。Provider 报告用量优先；缺失时保守估算，部分输出工具参数也计费。估算不是模型 tokenizer 的精确计数；已有实际输入校准仍保留。
- 输入上限、输出上限、Turn 总量、消息数量、模型调用/工具轮上限、Provider 窗口和压缩失败分别诊断。每次调用通过 `budget.request` 保存压缩前上下文与预算快照，`budget.admitted` 保存实际获准任务/摘要请求的估算与输出上限，`budget.result` 保存结算与用量来源，`context.compaction` 保存摘要结果。元数据带格式版本，单条不超过 512 字符，不含正文、凭据或外部地址。
- 设置突出总 token 额度；输入自动容量、单次输出、调用数和工具轮放入高级选项。自动输入沿用产品输入上界，并仍受已知 Provider 窗口/回退窗口约束，不代表无限。恢复推荐值由用户操作触发；已有自定义配置不静默重置。保存对新 Turn 生效，不扩大运行中 Turn 或已有 Goal 预算。
- 普通会话最近 Turn 因预算/容量停止且所有相关工具已结算时，用户可明确“从已有结果继续”。新建有界 Turn，保留已有对话与完整工具配对，使用明确的继续提示，不通过原始输入重试裁切历史。该生成提示不能登记为用户新授权 Goal 的原始请求；附件仍复核，未知副作用阻止此入口。Goal 保留其独立激活、预算与恢复路径。

## Alternatives considered

- 删除模型工具结果只保留聊天摘要：模型无法核对事实和继续工作，不采用。
- 直接截断序列化 JSON：产生不合法 JSON 且不可恢复完整内容，不采用。
- 自动扩大预算或无限自动新建 Turn：使额度失去约束、可能重复副作用，不采用。
- 把每个细分预算都放在主设置页：增加误配概率，保留高级覆盖即可。
- 为手机复制桌面完整执行生态：此改动不引入子 Agent、远端 Worker、CLI hooks 或持续存活保证。

## Consequences

沿用 Room 与内容存储，不新增会话权威日志或数据库迁移。额外的只读工具 schema 和分页调用占用少量上下文/轮数；模型仍需判断哪些页值得读取。明确继续是新 Turn，不是进程指令 checkpoint，也不保证模型在语义层绝不重复调用。输出执行成功仍不能代替业务结果验证。

## Verification

覆盖 UI/模型投影分离、Unicode 分页完整性、未知格式保留、会话归属、取消/期限/缺失结果、重开数据库、预算维度、估算一致性、真实 ChatService 继续后的出站请求和高级设置保存。实际结果见[修复记录](../../bug-fixes/2026-09-17-context-budget-tool-projection.md)；专项通过不替代完整真机 P0、OEM/Doze 或付费模型验收。

## Reconsider when

端侧测量证明逐页整块校验带来不可接受成本、需要多模态工具原生结果，或需要按需工具 schema 路由时，另以明确资源和兼容性证据调整；不提前引入第二套执行引擎。

## Decision history

- 2026-09-28：计划审阅页执行计划时采用当前会话配置的Goal预算，不维护第二份低额度常量；持久化后的Goal继续遵循原有累计及用户限额契约。
- 2026-09-28：owner 明确要求长程任务预算达到数百/上千次，避免短程默认额度阻断任务。普通新 Turn 推荐值为512工具轮、1024模型调用、3200万累计token；高级配置上界为10000工具轮、20000模型调用、10亿累计token。工具轮是一次模型响应的一批调用，不等于单个工具。单次输入100万/默认输出16384及Provider窗口约束不变，累计额度不是上下文窗口。Goal既有默认512模型调用/2048工具调用/3200万累计token保留其独立累计契约。已有v3预算/自定义值、运行中Turn和已有Goal不被静默扩大；只有未配置、既有历史模板迁移或用户主动恢复推荐值采用新默认。新预算不能替代审批、敏感目标、执行期限或未知副作用恢复，不做无限自动重试。

## Decision history — 2026-09-28 no-progress protection

所有者要求长任务保留较大调用预算，并用进展证据识别循环。Harness 从当前 Turn 最近 12 条持久化工具调用/结果重建签名，包含规范业务参数 hash、完整内容引用、状态及结果摘要，不使用 modelIntent。相同序列长度 1 或 2 连续重复 3 次先反馈固定系统警告，6 次停止并保留真实结果；变更参数/结果、成功写入、不确定执行或显式用户 steering 打断计数。成功的 Accessibility、Goal 状态、时间及后台 Job 观察不参与稳定读取判重。未验证结果不当作重复成功。

此保护不缓存成功、不禁止一般重复参数、不声称识别任意循环。普通 Turn 可从既有结果继续；Goal 转 INPUT_REQUIRED，避免自动续跑同一循环。UNKNOWN/review 优先于循环判断。阈值是初始保守策略，不能替代长程模型及设备轨迹验证。
