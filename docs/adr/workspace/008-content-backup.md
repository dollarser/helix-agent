# ADR-WORKSPACE-008: 本地应用备份与恢复

Status: accepted
Date: 2026-10-30
HXA: owner-authorized local backup task (2026-10-30)
Deciders: project owner；实现 Agent

## Context

换手机、重装应用需要恢复会话、个人配置和 Agent 记忆。仅打包公共目录的知识文档不能满足此用途；直接复制整个 App 目录又会夹带登录会话、授权、缓存和不可恢复的进程状态。

## Decision

使用用户主动选择的本地 ZIP，按当前领域记录白名单序列化，不复制外来数据库或整目录。默认包含聊天与分支、必要附件及引用关系、长期记忆、专家、用户 Skills、自定义指令、模型服务商及参数、插件与连接器配置、应用设置、定时定义及必要执行历史。公共知识库、笔记、资料原件与工作区文件单独可选；原件缺失必须显示不可用，不能把旧设备路径当成新设备权限。

可重新下载的模型、RootFS 和插件运行包、可重建索引和缓存不打包。保留用户创建且无法重新下载的配置与内容。公共资料不因恢复而整体替换或删除；已经存在但内容冲突时预检拒绝。新发布的公共文件具有独立恢复日志，失败只撤回该操作拥有且哈希匹配的新增文件。

API 密钥及静态连接器凭据是独立且默认关闭的选项。使用 JCA PBKDF2-HMAC-SHA256（随机盐，600000 次）派生 AES-256-GCM 密钥；随机 IV、认证标签和闭合加密信封，不记录密码，不把明文凭据写入暂存文件。认证数据绑定完整状态清单摘要，防止保留加密密钥却篡改服务地址或凭据归属。普通哈希清单只证明完整性，不证明来源可信。聊天与普通配置本身没有因此加密，导出界面须说明。账号登录/刷新会话、OAuth 会话、设备 Keystore 密钥、系统权限、临时审批和能力授权不转移；恢复后重新登录或授权。凭据恢复使用新本机别名并由本机 Keystore 重新加密，不恢复保留账号别名。

归档格式保持 1。只接受 `state.json`、可选 `credentials.enc` 和按 SHA256 命名的 `blobs/`；压缩包路径不决定目标文件路径。正文负载总量最多 2 GiB，单文件 512 MiB，状态与加密信封合计 64 MiB，清单单独 4 MiB，最多 20000 项；压缩输入另有容器上限。可选公共资料沿现有文档导入边界，单件 16 MiB、合计 64 MiB、最多 1024 件；大资料库不会阻塞默认会话与配置备份。实际解压计数、闭合清单、重复项、路径、内容哈希、字段类型和领域关联必须先验证。文件暂存去重，不递归解包附件。

恢复采用明确的私有配置替换策略，而不是无提示的逐项合并。先在私有暂存目录重建当前 Room 数据库、配置和文件，校验全部引用、外键与内容；预览范围、缺失内容和替换影响，确认后在无运行执行者时排队。新进程在账号、数据库和任务消费者初始化之前执行持久替换日志；中断或失败回滚旧根，不能将部分恢复当成成功。初始化成功后才清理回滚副本。取消、预检失败或重复点击不能发布内容。

保持会话、消息、分支和历史执行 ID。跨设备工作区创建新的当前绑定，历史请求映射仍指向原身份且不可用，不改写为新目录。外部路径必须重新绑定；恢复附件使用新私有路径。按内容身份而非物理 URI 计算资料修订。不能提供的来源或原件明确不可用，不静默改读其他文件。

定时与提醒恢复后暂停；运行中的模型请求中断，未开始的工具调用取消，结果不明的工具保留待审阅，关联 Goal 阻塞。批准的计划失去批准权限并回到待审阅状态。进程、终端连接、运行队列、临时票据及外部副作用不会恢复或自动重放。模型、工具及系统授权仍走现有权限路径。

## Decision history

- 2026-10-30：最初采用知识/专家内容包与非覆盖增量导入，随后修正内容、清单及容器的独立大小边界。
- 2026-10-30：所有者明确以换手机和重装为目标，替换窄内容包方案：默认领域数据与配置、原件/工作区可选、凭据独立加密、无活动执行时的持久替换及回滚。移除旧内部格式读写，不增加兼容链或内部版本号。

## Verification

以合成数据验证密码、哈希损坏、限额、路径、取消、重复操作、引用关联、冲突、进程中断及回滚。设备恢复仅限隔离数据；不导出或恢复真实凭据，不覆盖日常数据。设计接受不代表实现、真实迁移或设备恢复已经验收。

## Alternatives considered

不采用整 App 目录复制：其中包含不可跨设备转移的密钥、授权与进程事实。原内容增量包不足以迁移会话和配置，改为当前领域白名单与显式私有替换；公共文档仍采用可核验的独立新增日志，不宣称跨 Provider ACID。

## Consequences

恢复会关闭应用并要求重新登录、授权和绑定外部目录。未包含或不可用的文件必须在预览中说明；原始目录和历史执行身份不能被新设备路径冒充。私有替换保留回滚副本直到消费者初始化成功，旧副本清理失败另留本机清理收据。

## Reconsider when

正式发布后的数据政策、跨平台迁移或云同步另行获准时重新评估；本决策不授权自动上传、持续访问凭据或在设备上执行真实迁移验收。
