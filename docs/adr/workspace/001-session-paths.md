# ADR-WORKSPACE-001: 会话目录、相对路径与内容身份

Status: accepted
Date: 2026-09-16; revised 2026-10-17
HXA: HXA-163, HXA-190, HXA-191, HXA-286, HXA-288, HXA-289, HXA-293, HXA-296
Deciders: Project owner（2026-10-15 接受内容版本与后续扩展边界；未启用 LSP）

## Context

会话组织、路径解析、权限和文件身份是不同职责。文件工具需要可预测的相对路径，同时保留稳定的产物来源。

## Decision

- 新建会话先是内存草稿，首次有效发送才落库；空白退出不保留。默认标题压缩空白并取前 20 个 Unicode code point，用户可改名。草稿附件不自动发送。
- 保存的 directoryRef 是模型安全的 scoped 引用；选择目录仅建立归属，不授予能力、不移动文件、不创建 worktree。目录失效仍可查看会话历史并显式重新选择。
- 内置文件工具在应用边界按会话目录解析相对路径；显式 scope 引用保持原锚点，MCP 参数不由宿主擅自改写。归一化在参数哈希、scope/policy、审批、调度之前完成。已选择目录无效时不静默回退其他根。
- 工作目录接受普通用户文件，不强制 input/work/output；这些仅是约定目录。内部控制元数据与根级破坏操作仍受保护，保留符号链接/越界、quota、原子写和哈希检查。归档/解压需遵守各自目标契约。
- Artifact 保存真实 scope 与路径身份，不因会话切换目录重解释同名文件。项目材料保留来源和信任级别；内置系统段由固定代码 allowlist 选择，Workspace/MCP 内容不能替换系统指令。
- 模型请求中的已知文件参数/结果按该请求捕获的工作目录投影：目录内使用相对路径，目录外保留稳定 scope 引用；路径段边界、同名跨根与保留前缀必须准确往返。持久参数、授权哈希、审计、产物及摘要生成源保留完整资源身份；回放与压缩匹配共用同一投影，不能通过弱化一致性检查来缩短路径。只改已知结构字段，不替换文件正文、任意模型文本、MCP 参数或脚本输出。
- 文件工具标题只显示操作与文件名，长名称按布局截短；模型意图、目录及完整参数放展开详情。目录选择显示来源名称，完整引用可在详情查看/复制。显示名、缩略文本与路径标签都不参与定位、权限或持久关联。重名来源保留辨认信息，不创建短 ID 别名表，也不为显示效果搬移文件或重命名稳定 Workspace ID。
- 默认会话独立目录与外部目录直连由已接受的 [ADR-WORKSPACE-004](004-workspace-binding.md) 定义；具体可用性与恢复按该契约及当前实现验证。

### 内容版本与运行环境映射

HXA-296 在现有读取路径补齐显式完整哈希：普通窗口不扫描全文；请求版本凭据时，同一条有界、可取消的流提供窗口与完整文件 SHA-256。它不是窗口/工具结果哈希，不构成文件锁或跨多次读取的快照。编辑在计算替换前核对实际加载字节，再于发布时沿原版本检查；发布后异常不能宣称文件未改变。系统提示和 Schema 必须与此能力一致。

HXA-289/293 分别保留资源身份、内容版本/已验证指纹、定位范围和快照来源。相同路径不证明内容相同；搜索、分析或异步结果绑定请求时可确认的版本，无法确认则明示未知，修改前按现有 hash/scope 规则重读或拒绝过期引用。版本校验是冲突检测，不承诺跨进程文件锁或全目录原子快照，也不要求为搜索预先哈希整个目录。

宿主 Workspace 引用与 Runtime 内路径/URI 由可信适配器映射，保留原根/实例身份，不能靠模型参数更换目录或读写范围。行号/字符/字节位置及其单位明确；未来 LSP 位置编码、未保存缓冲版本与协议同步留在其适配器，不能把服务端文档版本、mtime 和内容 hash 当同一事实。

当前只用已有文件、快照和 Runtime 映射验证陈旧结果与跨 scope 反例，不安装语言服务器或新增通用编辑器。以后 LSP 返回的修改建议仍走文件治理与冲突检查，诊断/编辑建议不授予写权限。

### 资源引用与执行路径（2026-10-17 目标契约）

资源引用表达 provider、稳定身份及可确认版本；执行路径表达 environment/实例 generation 中的路径与规则；展示文本只供阅读。相同 basename、URI 或 `/workspace` 不能证明同一资源。来源到 guest 相对目标的映射保留层级、版本和物化模式，拒绝目标冲突/越界；不可确认版本明确未知，输入复制不冒充全目录原子快照。

同一绑定的文件、exec、终端访问同一工作副本，显式 snapshot 例外可见；cwd 是起点，不是授权根。当前 Job 仍使用快照，后续由 HXA-286/288 完整替换，不为显示简化加入第二解析器或路径别名表。产物引用与回写源文件分别留事实；版本检查不承诺 Provider 未提供的原子 CAS。责任、流程和边界见 [Harness §23.3.1](../../architecture/harness-refactor-plan.md#2331-目录资源与执行环境)。

## Alternatives considered

全局 cwd 会使会话串扰；先哈希再解析相对路径不能绑定实际目标；目录失效时回退会写错资源。均不采用。

## Consequences

同一主题使用一份有效契约，避免并行实现各自解释权限和生命周期。代价是实现、UI、数据与恢复需要一起验证；accepted 表示决定，不代表相关任务全部完成。

## Verification

本次为现行决策整理，不新增功能通过结论。实现范围与实际命令结果以[实施状态](../../development/status.md)、对应 HXA 及完成记录为准；修改本契约后须覆盖成功、失败、取消、边界和恢复，不能用文档门禁代替设备/功能验收。
