# ADR-WORKSPACE-007: 系统分享收集与本机知识库

Status: accepted
Date: 2026-10-19; revised 2026-10-25
HXA: HXA-308, HXA-311
Deciders: project owner（开始执行收集/知识库第一阶段）；实现 Agent（有界实现取舍）

## Context

旧系统分享入口仅将材料放入会话草稿，没有独立知识管理。Owner 要求从 X、微信及其他应用收集文字、链接、图片/文件，先保存原件与来源，再提取、检索、选择引用和可选分析。此领域不同于人格 Memory，也不以 HXA-286～294 的整体重构为前置。

## Decision

收集记录明确是 **原始来源资产**，并非已经确认的知识。`CollectedSource` 保存原文/原件、提取正文和来源附属笔记；`KnowledgeNote.kind` 区分笔记与知识，保存状态及核对状态不决定内容类型；`KnowledgeNoteSource` 保存用户选择的多对多引用快照。来源库长期保留材料，提炼后不搬走或清空，不强制走“清空收集箱”流程。不将每次分享或自动摘要固化为一个知识，不按语义相似自动合并。

### 笔记、知识与会话引用

- 随手记保存后是笔记；新建编辑器未保存的内容不入库。知识由用户直接创建，或将已保存笔记整理为可编辑候选，再明确保存为独立、未核对的知识。原笔记和资料保留；不是改一个审核标签就升级类型，也不要求调用模型才可整理。
- 知识库展示知识、笔记、资料；新问答统一使用现有会话；旧资料问答仅保留只读历史和明确保存为笔记，不再提供独立模型调用入口。不新建聊天引擎，不将人格 Memory 与知识存储合并。
- 输入框原有＋菜单新增知识库引用，保留独立的会话引用。选择、预览、取消、添加与移除不发送、不清草稿、不改变知识工具开关或权限。资料阅读页使用相同结构化引用进入原会话草稿。
- 每条引用固定类型、资源身份、标题、完整正文摘要、实际选中正文及 FULL/EXCERPT 范围；当前片段是开头最多 1800 字符，不声称命中位置检索或任意文本选区。最多八条、总正文 24000 字符；字符数不是 token 保证。超限拒绝，不静默缩短用户明确选择的全文，不递归附带关联原件。
- 发送前与发送确认时核对来源；变化须明确保留所选版本或重新选择，不可用须移除。输入一经原准入链路接纳，引用作为 `SessionInput` 固定事实随队列及恢复交付，不再重读来源替换已确认内容；历史展示实际当时内容。仅编辑用户正文不修改固定引用、不发送、不建分支。
- 引用复用现有敏感文件文本披露与凭据扫描，原有 Provider、权限、取消与执行身份不变。模型接收明确标记的不可信引用正文；不能由引用内容授权工具。“本条附带”不承诺会话历史中的已发送内容自动遗忘。
- 上线前主库和当前文档格式固定内部版本 1；资料正文不再使用独立 Room 库，不保留 App 内历史迁移链。来源、类型、引用和正文结构仍严格校验；旧测试库不冒充当前身份，按外部一次性处理或明确目标后干净安装处理，不自动清库。

- Standard 与 Advanced 提供相同的独立收集页；系统分享使用明确的“收集到 Helix / Helix Advanced”目标标签，Advanced 应用名也区分渠道，避免同机安装时误投。Android SEND/SEND_MULTIPLE 指向收集 Activity，不自动创建 Turn。微信内部转发不等于系统分享；没有入口时提示复制文字/链接或保存文件后分享。
- 当前 Owner 决定采用文档优先：资料原件、笔记和知识固定共享保存，不提供私有／共享切换，不首次强制 SAF，不逐次询问；正文不再以 `library.db` 为权威。应用自有 MediaStore.Files 文件固定放在 `Documents/Helix/library/`，使用开放 Markdown／原格式，目录和搜索可重建；回答历史、会话来源身份及内部快照保持私有。目录授权和共享位置不自动授予模型权限。此替换已接通并完成当前主机及有界模拟器验收，其他设备和真实授权边界见[存储记录](../../development/document-first-storage.md)；不得用设计 accepted 宣称完整交付。不引入向量服务、账号、同步或新依赖。
- 收集 Activity 在临时 URI 授权有效期间保持存活，应用作用域进行有界物化：最多八文件、单文件 16 MiB、文字 200000 字符。只接收 content URI，不让外部调用者借用本应用 FileProvider 路径。文件名仅展示，不参与存储路径。按文字和实际文件字节摘要去重；相同材料保留首次来源/时间。
- IMPORTING/QUEUED/EXTRACTING 是持久状态。每个完成文件登记后再继续；进程中断后 IMPORTING 明确标不完整并要求重分享，排队/提取项从本机原件重试。不宣称临时 URI 可永久恢复或断电事务。失败不得显示完成，已接收资料不丢弃。
- 本机 PDF/DOCX/HTML 提取复用现有有界文本提取器；图片及未知文件只保存原件，不冒充 OCR 或完整 PDF 理解。用户需要视觉识别时，复用会话图片及文档逐页查看功能，经原披露与权限边界交给当前视觉模型；不新增本地 OCR，不自动上传或把结果当作已审核知识。链接只通过现有公开网络 SSRF/TLS/重定向防护 transport 抓取，不携带浏览器 Cookie/登录态、不执行脚本、不绕过登录。保留分享 URL 与公开页面原始快照；通用可见文字提取不能证明正文完整，页面明确标注未核验，失败/登录/超限均标不完整。
- 原始资料、提取内容和来源附属摘要独立，来源附属摘要不是已确认知识。用户可直接写知识笔记，从单源提炼，或选择最多八份来源综合。笔记引用保存有界片段、来源身份/时间/完整性与内容摘要；来源重新提取不静默更新笔记或引用。
- 模型处理统一进入既有会话：用户选择引用，确认实际发送内容与目标后提问。知识库不持有第二套模型配置、生成确认或请求状态机。普通回复可显式保存为笔记，绑定会话/消息/正文摘要和当时引用；重复保存不重复创建，也不覆盖后续用户编辑。保存不等于核对或知识提炼。
- 旧记录中的模型建议仍可查看并明确载入编辑器，旧问答的冻结来源、正文及状态保留；中断恢复只标 INTERRUPTED，不重放模型请求。旧 READY 问答可原子保存为笔记并登记 savedNoteId，失败记录不得伪装可保存成功。删除被替代的独立问答/笔记生成 transport 与旧 UI，而非只隐藏入口。
- 来源选择、候选编辑与明确保存相互分开：打开候选和取消不写入空笔记；保存时重核所选来源版本，来源变化拒绝静默替换。多源候选为本机可编辑整理内容，不伪称已经模型综合；需要模型总结时使用正常会话。
- 普通笔记编辑使用整页无边框标题与 Markdown 正文画布，正文单页滚动，保存保持显式。标题可留空并在保存时使用本地化未命名标题；标题与正文都为空不能保存。未保存文字与光标/选择可恢复，失败不离开编辑页；不引入富文本往返、自动保存或隐式模型请求。
- 知识库主界面复用 Shell 的唯一标题，内容依次为搜索、知识/笔记/资料分类、数量与问答记录、平面列表、底部当前分类主动作。笔记提供写笔记，知识提供直接写知识，资料提供导入；不在其他分类复用笔记空态或主按钮。管理及恢复在更多，资料多选仅在资料类提供。搜索无匹配与分类无内容分开，清除搜索不改变分类。阅读正文优先，编辑为独立状态，保存仅明确动作；必要来源管理、核对和删除确认在二级入口。新问答不再要求先走一个重复的知识库向导。
- Agent 默认关闭的 `knowledge.search/read` 继续有界词法检索与受控读取；移除的是独立问答专用的片段窗口拼装，不是现有 Agent 搜索能力。不自动注入全库或写入人格记忆。

### 管理与 Agent 只读访问

来源删除仅由当前明确用户动作清理所选资料及所属共享原件。共享 `DELETING`／`QUEUED` 等状态不是授权，启动时仅标为未完成，不自动续跑删除或提取；用户明确重试需重新核对内容身份和版本。固定引用不级联删除。笔记删除原子清理索引/引用并解除问答 savedNoteId；保留问答及其他资料。来源更新不改写笔记正文，用户明确刷新引用时核对版本、清除旧生成建议并改回草稿。Markdown 导出仅含已保存正文和固定引用，不是整库原件备份。

`knowledge.search/read` 默认关闭，用户在知识库中明确开启后才返回有界资料；执行前后重核开关与取消，继续服从工具权限链路。结果可能送往当前会话模型，资料永远是不可信引用，不能授权后续操作。不自动注入全库，不开放原始路径/SQL/任意 URI 或模型写删接口。

## Alternatives considered

不沿用只填聊天草稿作为收藏：其会话生命周期和来源/原件管理不能满足知识库要求。不引入向量库、自托管爬虫或新 Provider 调用栈：现有 Room、文本提取和聊天足够覆盖此阶段，也减少权限和数据副本。单独新增知识数据库避免将新领域强耦合到历史会话 schema；后续仍由同一应用服务维护一致性。

## Consequences

原件先落地，网络/模型失败不丢掉资料；分析有明确的内容发送边界。通用网页提取不能保证文章完整，扫描 PDF、图片及任意二进制也不因文件已收藏而变成可读文本。模型建议与已核对笔记分离，保留可编辑保存和引用追溯；没有自动知识确认。
