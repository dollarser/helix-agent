# ADR-0046: 订阅连接检查与模型生成验证分离

Status: accepted
Date: 2026-09-10
HXA: HXA-190, HXA-191
Deciders: Project owner（明确要求连接测试验证订阅本身，不绑定最贵或特定模型）
Supersedes: none
Superseded by: none

## Context

所有者确认此前中断是网络问题，并要求优化两处订阅连接测试的成本及语义。Subscriptions 旧极小测试取目录首个可见模型，主应用使用配置中的模型；两者均发送生成请求，未按价格选择。目录顺序不是价格证明，模型名称也不足以推断当前订阅成本。

## Decision

本决定部分替代 ADR-0044 中 Codex 连接测试必须完成简短生成的要求，其余流式、能力检测、取消及恢复规则保留。

- 有真实认证模型目录的订阅适配器，以当前认证目录请求成功且目录有效为连接成功，不选择模型、不发送生成请求、不修改用户模型选择。
- Codex 在 Subscriptions 与主应用采用此路径；401 按原机制最多刷新一次，失败不能用缓存目录冒充成功。
- 本地合成目录不构成认证证据。不支持认证目录检查的其他适配器保留原验证方式，不能因实现同一类接口便自动跳过验证。
- 成功仅声明订阅认证及目录可用，不声明任何特定模型可推理、剩余额度充足、视觉/工具能力可用。具体生成验证由显式能力检测或实际对话完成。
- 不以模型名字猜价格、不建立硬编码便宜模型列表；此路径无生成请求。

## Alternatives considered

选择目录第一项不能保证便宜。按照名字猜测 mini/nano/spark 等价格会固化易变假设；按真实定价元数据排序适合用户明确要求生成测试且服务端提供可信成本信息的场景。仅检查本地 token 存在无法验证服务端是否接受，因此不采用。

## Consequences

连接测试更快且没有生成请求，和当前聊天模型解耦。代价是目录成功不保证模型服务生成正常，UI 必须如实区分连接和能力。保持 Runtime 凭据隔离、持久配置及 IPC 不变。

## Verification

本轮主机回归覆盖：认证目录通过不调用生成、当前配置模型不在目录也不影响账号连接、认证失败不回退本地目录、没有账号检查的适配器仍验证真实连接、401 单次刷新且仅有 GET 请求。两种 app flavor 与 Subscriptions 构建通过；设备验收由所有者后续执行，不以 ADR accepted 代替实现或真机证据。

## Reconsider when

服务端不再提供认证目录，或目录接口无法反映账号访问状态；此时评估账户状态接口或显式选择的低成本生成检查，不能静默以本地目录判成功。
