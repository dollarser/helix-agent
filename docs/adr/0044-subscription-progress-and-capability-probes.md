# ADR-0044: 订阅增量预览与真实能力探测

Status: accepted
Date: 2026-09-10
HXA: HXA-190
Deciders: Project owner（要求修复订阅并先验证流式、工具、视觉与推理，再做对话验收）
Supersedes: none
Superseded by: none

## Context

原 Codex Provider 等待 Runtime 完整 Job 返回后才发出事件；连接测试只发一个简单文本请求，并把服务端元数据写为已探测能力。这不能证明跨进程流式、工具结果回填或图片理解。网络读异常还会被 Job 的通用失败映射成协议错误。

## Decision

在现有签名验证和按需绑定内，增加可选、有界的 Job 增量读取事务。主 App 按事件偏移读取当前 Job 的非终态预览，Runtime 使用有界 PFD 传输并附哈希。旧 Runtime 不支持该事务时保留完整结果兼容路径，但不能通过真实流式验收。

预览不是完成证据：终态仍以原 journal 的持久结果及哈希为准，成功结果必须匹配已交付前缀；Binder 丢失不能自动重发模型请求。取消、超时与旧 Job 隔离保持原契约。凭据不离开 Runtime，工具预览不创建授权，真实工具执行仍等待完整协议结果。

2026-09-10 所有者要求拆分：连接测试仅查询目录并完成一次无工具、无图片、默认推理的简短文本请求；能力检测由独立按钮触发，验证完成前增量、合成 echo 调用与结果回填、内置色块图片理解，以及目录声明的首个显式推理强度。连接通过不冒充全部能力通过，尚未检测标记为 CONNECTION_ONLY；能力检测失败不撤销已通过的连接状态。2026-09-10 所有者要求优先修 bug、停止不必要测试：完整推理档位矩阵保留为独立诊断，不再作为 Provider 可用门槛。推理能力通过不表示每个可选强度均已验证；服务端选项继续动态获取，不静默降档。合成工具不进入设备 Dispatcher，不访问用户文件。明确声明无视觉/推理的模型保留不支持状态；JSON Schema 和并行工具未测时不声明通过。服务端目录用于生成选项，不替代实测结论。

订阅组件仅在用户触发的目录/模型网络请求期间使用自身 UID 的 dataSync 前台服务；握手、被动刷新和本地 fixture 不启动它。绑定覆盖请求及结果传输，解绑即停止；通知提供停止动作，系统 onTimeout 仍取消并释放。不自动重启、不申请唤醒锁、不修改系统冻结策略。

2026-09-10 所有者报告长回复截断并明确要求两 App 之间不设时长/长度上限：移除 120 秒等待、150 秒租约、网络响应总时长/读取超时，以及响应的累计字节/事件阈值；传输与结果存储不再额外限制正文长度。分批传输不丢弃后续批次；显式取消、协议终态、真实 I/O 失败、系统服务终止和完整性验证仍生效。该授权覆盖此前的应用固定 deadline/累计长度条款；不承诺消除服务器上下文限制或设备内存/存储及系统后台时限。

## Alternatives considered

- 仅把服务端 SSE 接受视为流式通过：无法验证主 App 是否及时收到增量，未选择。
- 新增常驻 Service 或把凭据移入主 App：改变生命周期及隔离边界，未选择。
- 只依赖实时回调、不保留完整结果：进程死亡后无法按既有协议对账，未选择。

## Consequences

增加可选 IPC 和预览缓冲测试面；连接测试只生成一次简短回复；独立能力检测需要多次合成模型请求。未通过任一要求的阶段不能宣布全部能力通过。旧持久记录格式不变，运行状态继续遵循 ADR-0007。

## Verification

当前真机已复现冷绑定被拒绝、SocketException 与原有能力显示失真。实现后的取消、缓冲边界、前缀核对、真实 Provider 全阶段与对话回归结果继续记录在 HXA-190；此决定不代表这些验收已通过。

## Reconsider when

需要完整跨进程实时背压、多个同时运行的模型 Job，或更长的恢复窗口时重新评估事件日志与传输协议。
