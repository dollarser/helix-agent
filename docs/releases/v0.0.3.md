# Helix v0.0.3（更新版开发预览）

基于 main `7480141b`，包含最新交互修复和文档整理。APK versionName 为 0.0.3、versionCode 为 4，可在签名一致时覆盖旧版 v0.0.3（versionCode 3）。

## 下载选择

- **developer-debug.apk**：推荐直接安装体验，包含订阅与 PRoot Runtime；高级能力需要显式开启和授权。
- **consumer-debug.apk**：不包含订阅与 PRoot Runtime 的渠道测试包。
- **SHA256SUMS**：用于核对下载完整性。GitHub Source code 压缩包对应更新后的 v0.0.3 标签。

要求 Android 10 / API29 及以上；PRoot 运行范围以现有 arm64 支持为准。两个包均为 debug 签名开发制品，并非商店正式发行。

## 本次更新

- 新会话默认 Act；模式统一用斜杠命令，选择后先进入输入框，点击发送才执行。
- 修复设置返回、输入布局、重新生成、语音及附件回填中的会话归属问题。
- Runtime 页面适配系统栏，删除入口与状态提示更清楚；许可证正文可滚动，大字体下关闭按钮保持可见。
- 分享、文件/照片选择和导出失败时显示提示，保留内容供重试。
- 整理当前计划、研究和发行边界文档。

## 验证边界

功能提交已通过双渠道 app 单元测试、lint、Debug APK/AndroidTest APK、格式及静态检查。API36 为多轮定向验证，最近一轮 consumer 3/3、developer 4/4，另有 320dp 大字体 1/1；完整记录见 docs/bug-fixes/2026-09-29-external-ui-recovery.md 及其引用记录。语音/选择器异常由夹具注入，不代表真实语音识别或第三方接收应用验收。本次发布重编译验证另行核对 APK 版本、签名和校验和，不新增真机或真实账号测试。

## 升级与已知边界

**开发期覆盖升级遇数据库结构不兼容时会清空会话、配置及数据库记录，保留数据库外文件。升级前请导出重要内容。** 同包名覆盖安装要求签名一致；这不是正式数据迁移承诺。

历史输出截断、模型偶发多余调用、OEM/真机长稳和真实账号仍有未完全解决的边界。公开 benchmark 仅有历史小样本诊断，不能作为完整榜单成绩。旧 v0.0.3 源码保留在 codex/release-v0.0.3 分支。
