# Helix v0.0.3（开发预发布）

本版本基于 main 的 `70456eb5`，增加版本标识及 Plugin/Mobile Use 的依赖锁；不包含主工作区尚未提交的重构方案或其他并行改动。

## 下载选择

- `helix-v0.0.3-developer-debug.apk`：推荐的直接分发测试包，默认 Standard，内置订阅与 PRoot Runtime，可显式进入 Advanced。
- `helix-v0.0.3-consumer-debug.apk`：渠道边界测试包，不包含上述 Runtime。
- GitHub 的 Source code 压缩包对应 v0.0.3 标签；`SHA256SUMS` 用于核对下载完整性。

两个 APK 均为 debug 签名的开发测试制品，versionName 为 0.0.3、versionCode 为 3。不是正式商店签名发布，不代表商店审核通过。安装要求 Android 10 / API29 及以上；developer 内置 PRoot 的运行边界以现有 arm64 支持为准。

## 本版本包含

- Workspace 会话绑定与恢复、Memory、本地模型安装和执行能力。
- 工具按操作类型授权、循环无进展检测、系统设置会话授权和滑块操作。
- 模型发布取消边界、SAF 来源刷新及 Goal 仅规划提示修复。

以上为已合入源码范围，详细验收边界以各任务证据为准。此发布不将历史定向验证扩展成全产品验收。
