# 授权、安全与发布验收

本页定义横向边界，决策细节见[会话授权](../adr/permissions/001-session-authorization.md)、[模式限制](../adr/permissions/002-review-modes.md)、[执行与审计](../adr/permissions/003-dispatch-and-audit.md)。已接受方案和已交付行为分别从[状态](../development/status.md)核对；HXA-209 未完成前不得声明新预设已经生效。

## 信任与权限

用户操作和用户建立的规则可以授予权限；模型、项目文本、Skill、MCP、网页与远端 Agent 不能自行授予。Android 权限、Root 授权等只满足相应能力条件。提示词排序不提高信任等级。

目标授权界面以工具启用/禁用和会话预设表达：FULL_ACCESS、WORKSPACE、READ_ONLY 都允许 Agent 工具联网，CUSTOM 可以进一步限制效果；禁止 Agent 工具联网不禁止模型 Provider 请求。工具禁用应从曝光和分派两处生效，直接构造调用不能绕过。

效果规则合并遵循 DENY > ASK > ALLOW；工作区模式仅自动允许所选范围内的符合条件操作。CUSTOM 禁写覆盖文件工具和 Shell 写入，无法可靠约束的执行不能伪装安全。特殊递归删除确认仅针对明确解析的 rm -rf dir；不扩大成所有等价删除的默认拦截。Chat/Plan 的只读边界仍独立有效，批准计划只绑定版本，不批准全部工具。

## 分派与证明

每次调用依次校验 schema、归一化效果、检查能力与 Policy、解析授权、排队准入和执行边界复检。审批卡绑定展示时的工具契约、参数与来源，审批等待中的设置变化不能悄悄改写已展示决定；开始前的新拒绝仍阻止执行。

仅真正需要询问的调用产生精确证明，绑定当前调用且在执行开始时一次性消费。拒绝、取消、失败和未知副作用都持久结算，未开始调用不能冒充已消费批准。Proof 不覆盖新 DENY，不向其他调用、工作区、版本或执行器转移。

并发由平台依据归一化效果判断，仅证明互不冲突的读可并行；结果按原调用顺序进入模型上下文。停止须覆盖排队、审批等待与执行中调用；恢复先对账，未知副作用不盲目重放。冷启动展示旧卡不等于复活旧等待槽或执行许可。

## 执行域和数据

[本地执行](../architecture/local-code-execution.md)区分 isolated QuickJS 与同 UID PRoot/Subscriptions。后者有进程崩溃边界，没有凭据、网络或文件安全隔离承诺。非导出组件、受限 API 与快照校验仍必要，但不能被描述成独立 UID 防护。

凭据与真实用户材料不进入日志、仓库或测试 fixture。工具输出、导入包、文件路径、WebView 与外部协议内容按不可信输入处理。下载、解包、导回与产物读取绑定真实 scope，拒绝逃逸与身份错配。依赖使用可追溯固定版本；发现兼容问题允许有意识升级并验证，不为保留锁版本而保留故障。

## 验收与发布

[公共验收规则](../development/verification-matrix.md)是命令和默认/外部测试边界的唯一入口，对应[任务规格](../development/roadmap.md)补充具体断言。至少覆盖成功、失败、拒绝、取消、排队竞态、设置变更、真实进程恢复和未知副作用。构建成功不能替代功能或安全验收。

每个切片报告源码版本、命令、实际数量、skip 与失败原因；既有红不得包装成全量通过。双 flavor、受支持 API、consumer 制品排除与真实 Runtime/账号项分别举证。测试不得为过门禁而删除、默默跳过或 suppress。

发布另核对渠道能力、权限与披露、签名与制品、第三方许可证、凭据清理、恢复与用户数据安全。功能完成记录不能自动证明发行可用；缺外部账号、设备或发行材料保持明确未验收状态。
