# 设备内本地模型

在 Provider 页面选择 **On-device**，输入模型显示名、直接 HTTPS 下载 URL、发布方提供的 SHA-256 和准确字节数，然后下载。仅支持单文件 GGUF；不会自动下载模型，也不把模型打包进 APK。使用模型前请确认其许可证及设备可用存储。

下载支持 Range 续传；重试须填写相同 hash/大小。首版不跟随重定向，不支持需要登录、Cookie 或认证 header 的 URL。只有大小、SHA-256 和 GGUF header 校验通过的文件会发布到 app 私有模型目录。下载及发布可能同时占用约两份模型空间；空间不足保留失败状态，不注册残片。

发布后执行连接测试，再显式检测能力。连接成功只说明资产能够加载；工具能力由合成 probe 判断，任务可靠性仍需针对该模型评估。通过测试后可像其他 Provider 一样选择为会话主模型。设备内推理不经过网络 endpoint；工具调用仍遵循会话权限、审批和审计，也可能产生其自身的网络效果。

首版限制：

- CPU backend，单个常驻模型、单个 generation；默认 4096 token 上下文、2 threads、greedy decoding。可在 Provider 上下文设置中手动选择 1024–32768，实际受模型上限和设备内存约束。模型内置 chat template 必须可用。
- 不支持图片、非零 temperature、自定义 stop sequences；输出在 native 生成结束后显示，暂非逐 token 流式输出。
- 单模型至多 8 GiB、总模型至多 12 GiB、最多 16 个。大小允许范围不等于设备一定能够加载；OOM/不兼容会失败，不自动改用远端。
- 内存预检失败时可降低上下文再试；不会自动吞掉用户配置。达到输出预算时保留用量并显示输出上限错误，不执行未完成的工具调用。工具格式约束不能保证计算正确，能力探测通过也不代表任务质量通过。
- “卸载”释放常驻权重，保留文件；“删除”卸载并删除资产及 Provider。模型运行中明确提示稍后重试，不删除活动模型。
- 开发期 Room v1 baseline 重建保留模型文件，启动时重新登记为未测试；名称和能力探测结果可能重置。卸载应用会删除私有文件。

已执行授权的 API36 模拟器真实 GGUF 推理及定向生命周期验证。Qwen3-0.6B/1.7B 的 CSV 任务存在错误计算；Qwen3-4B-Instruct-2507 Q4_K_M 在 8 GiB 模拟器、8K 上下文上完成固定任务并通过数值/回读断言，耗时约 14 分 46 秒。该结果不证明任意任务可靠，也不是手机性能保证。真机温升、持续负载与 OEM 行为 **not requested**。当前验收边界见 [HXA-222](../completion-records/HXA-222.md)及[收口证据](../evidence/development/hxa222-closeout-2026-09-28.md)。
