# v0.0.9 开发预览

[v0.0.9 开发预览](https://github.com/dollarser/helix-agent/releases/tag/v0.0.9) 已发布，版本名 0.0.9，versionCode 及自有内部版本保持 1。tag 与 APK 冻结源码：`93e813f2449d5d69a7f97a54d93673725870a001`。Standard 与 Advanced ARM64 均沿用既有开发预览签名，不是商店生产签名；历史发布保留。

## 本轮变化

- 加号只添加材料、引用内容或选择已有能力。会话管理、消息投递和全局配置各有入口；推理强度留在模型选择，预算为全局设置，上下文详情直接点击圆环。未裁剪现有产品能力，Agent 专用接口不强加界面。
- 会话引用读取真实目录，提供搜索、空态、错误重试和选中反馈。选择与异步回调绑定原会话，取消不改配置。
- 专家库在应用设置创建、编辑和严格 JSON 导入；会话只选择已有专家。选择复制为会话快照，之后编辑专家库不改已选快照或已受理 Turn。专家不会授予工具权限。
- 插件选择在单一面板暂存，明确应用才保存，取消不保存；配置与必要授权保持独立。统一面板间距、表面层级与选中态。
- 听写突出停止并识别，失败/空结果同面板重试，取消保留原草稿。重试等待旧资源释放，成功转写进入可编辑草稿、不自动发送。
- 官方服务仅配置 accounts 账号基址、包含 `/v1` 的 api 推理基址及不含 `/v1` 的 api WS 基址。HTTP ASR/TTS 与 WS ASR/TTS 统一派生，不回退旧语音域；用户自定义 provider/语音地址不改写。

## 升级与数据

专家目录改变了主库结构，内部数据库版本仍为 1。不兼容旧预览库启动时必须现场确认后重建：主库中的会话、消息及索引、任务、模型/插件配置、授权和专家目录等记录会清除，相关终端归属记录按确认页处理；未确认不会自动清理。旧运行尚未证实停止时先重启设备，再重新检查。此机制不等于全应用清数据。

共享知识文档、模型、Linux 环境/工作目录和账号凭据文件不在该主库重建范围。正文文件保留不等于其旧索引或会话可恢复；诊断导出不是全量可恢复备份。重要内容请另行保存。已安装 v0.0.7/code 2 的设备仍可能因降级限制需要另行授权卸载；删除旧 Release 不会改变设备规则，本轮不删除历史发布。

## 验证边界

此前 Debug 候选通过完整主机门禁及两台 Advanced 的限定入口回归。API36 日常模拟器的现有账号认证、真实 HTTP/WS ASR/TTS 使用固定合成语音通过；文件 ASR 真实结果进入输入组件后可编辑、不自动发送，取消保留草稿。无麦克风采集、扬声器播放、LLM推理或退出账号，不把客户端关闭连接当作服务端计算已回滚。

[冻结源码完整 CI](https://github.com/dollarser/helix-agent/actions/runs/40765900421) 通过，覆盖保留单测、双渠道 Release/R8 与制品边界。最终包签名、版本、ARM64 和 16KiB 对齐检查通过；两个公开 APK 均已匿名完整下载，SHA256 与发布值匹配。最终 Advanced 在 Helix_API_36/API36 保数据覆盖安装，installed hash、启动及七项入口检查通过。Standard 设备证据来自前序独立 R8 包（两渠道各 3/3），其运行负载与最终包逐项字节相同。PLC110 入口证据早于语音迁域，本发布阶段未更新真机。真实麦克风/耳机体验、长期稳定性、全部 OEM/内存压力及商店审核仍未验。当前不新增文本补全、Embedding 执行或 VibeVoice 专用入口。
