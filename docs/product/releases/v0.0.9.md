# v0.0.9 开发预览候选

本地候选，尚未创建标签、公开 Release 或上传附件。版本名 0.0.9，versionCode 及自有内部版本保持 1；沿用既有开发预览签名，不是商店生产签名。不替换已发布 v0.0.8 的标签或附件。最终源码提交、签名、APK 哈希与 CI 以获准发布后的正文为准。

## 本轮变化

- 加号只添加材料、引用内容或选择已有能力。会话管理、消息投递和全局配置各有入口；推理强度留在模型选择，预算为全局设置，上下文详情直接点击圆环。未裁剪现有产品能力，Agent 专用接口不强加界面。
- 会话引用读取真实目录，提供搜索、空态、错误重试和选中反馈。选择与异步回调绑定原会话，取消不改配置。
- 专家库在应用设置创建、编辑和严格 JSON 导入；会话只选择已有专家。选择复制为会话快照，之后编辑专家库不改已选快照或已受理 Turn。专家不会授予工具权限。
- 插件选择在单一面板暂存，明确应用才保存，取消不保存；配置与必要授权保持独立。统一面板间距、表面层级与选中态。
- 听写突出停止并识别，失败/空结果同面板重试，取消保留原草稿。重试等待旧资源释放，成功转写进入可编辑草稿、不自动发送。
- 官方服务仅配置 accounts 账号基址、包含 `/v1` 的 api 推理基址及不含 `/v1` 的 api WS 基址。HTTP ASR/TTS 与 WS ASR/TTS 统一派生，不回退旧语音域；用户自定义 provider/语音地址不改写。

## 升级与数据

专家目录改变了主库结构，内部数据库版本仍为 1。不兼容旧预览库启动时必须现场确认后重建：主库中的会话、消息索引、任务、配置与授权等记录会清除，相关终端归属记录按确认页处理；未确认不会自动清理。旧运行尚未证实停止时先重启设备，再重新检查。此机制不等于全应用清数据。

共享知识文档、模型、Linux 环境/工作目录和账号凭据文件不在该主库重建范围。正文文件保留不等于其旧索引或会话可恢复；诊断导出不是全量可恢复备份。重要内容请另行保存。已安装 v0.0.7/code 2 的设备仍可能因降级限制需要另行授权卸载；删除旧 Release 不会改变设备规则，本轮不删除历史发布。

## 验证边界

此前 Debug 候选通过完整主机门禁及两台 Advanced 的限定入口回归。API36 日常模拟器的现有账号认证、真实 HTTP/WS ASR/TTS 使用固定合成语音通过；文件 ASR 真实结果进入输入组件后可编辑、不自动发送，取消保留草稿。无麦克风采集、扬声器播放、LLM推理或退出账号，不把客户端关闭连接当作服务端计算已回滚。

最终 Release/R8、签名与安装结果须绑定本轮冻结提交和实际 APK；不把上述 Debug 结果冒称最终包实测。PLC110 的入口回归早于语音迁域；真实麦克风/耳机体验、长期稳定性、全部 OEM/内存压力及商店审核未由这些切片证明。当前不新增文本补全、Embedding 执行或 VibeVoice 专用入口，也不宣称普遍识别准确率。

第三方组件与分发材料沿用 [THIRD_PARTY_NOTICES](../../../THIRD_PARTY_NOTICES.md) 及锁定资产；最终附件校验与来源应在发布正文列明。源码、日志、mapping、私有凭据或重复归档不会因本地构建而自动上传。
