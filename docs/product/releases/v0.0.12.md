# v0.0.12 开发预览

[English](v0.0.12.en.md) · [更新日志](../../../CHANGELOG.zh-CN.md)

本版围绕账号体验、模型目录、附件读取与恢复，以及会话界面收尾。提供 Standard（consumer）和 Advanced（developer）ARM64 Release/R8 APK；versionName 为 0.0.12，versionCode 与内部版本保持 1，沿用开发预览证书。

Helix 尚未正式发布。新版本不保证可以覆盖安装；即使覆盖安装成功，也不保证保留历史数据。请先另存重要内容，卸载会删除应用私有数据。

## 主要变化

- 邮箱和密码登录，注册用户名选填；用户名同步服务器，修改无需密码。头像、用户名和账号信息统一到账号资料，注册成功提示后返回登录并保留邮箱。
- 注册、找回密码与绑定邮箱先完成人机验证，再发送验证码；验证网页直接呈现单张卡片，取消、过期与迟到回调保持隔离。账号通知采用五小时持久缓存，用量按服务器范围展示。
- 模型目录成功缓存五分钟；失败保留缓存，确认下架后保留历史已选模型并引导切换，不静默替换或重放。用量快照、嵌入能力和部分目录边界分别处理。
- 非图片附件默认仅提供元数据与稳定引用，由工具按需读取；图片按模型能力传递。修复 PDF/DOCX 引用，补强文档提取、终端/Python 输入快照、项目显式复制、备份恢复和引用感知回收。切换项目不会搬迁历史附件。
- 长会话标题不再挤压时间，列表移除内部路径；用户子页复用窗口，减少返回闪烁；相关禁用按钮保留轮廓，快速读取完成后再打开结果窗口。
- 补强 Binder 观察阻塞、取消与恢复，草稿/权限隔离、真实工具消费和文档验收记录。
