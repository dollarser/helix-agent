# Helix v0.0.7 development preview

[简体中文](v0.0.7.md) · [Release](https://github.com/dollarser/helix-agent/releases/tag/v0.0.7)

ARM64, Android 10+, Standard and Advanced. R8 optimized, non-debuggable, version 0.0.7 / code 2, retaining the existing development certificate. This is not a store-signed production release. The Release body records the exact source, CI, APK checksums and executed acceptance. Only two APKs and tagged source archives belong on the version page.

Install the matching edition over the existing app without uninstalling or clearing data. Incompatible preview databases require explicit foreground confirmation; cancellation preserves data. Arbitrary historical lossless migration is not promised.

## Changes

- Account-authenticated built-in models, removing standalone ClientID and embedded-key entry points. Custom APIs, channel-supported subscriptions and downloaded local models remain independent.
- Updated conversation, account, settings and Markdown knowledge interfaces. Editing a user message neither sends it nor creates a branch. Reading/editing preserves drafts without implicit saves.
- Cloud HTTP chunked speech and continuous WebSocket client support. Stop speech is separate from cancelling the Agent. Offline ASR/TTS weights download on demand with explicit removal.
- Advanced Linux executes in the authorized real workspace by default; generated files stay there. Controlled result/log reads replace mandatory whole-work-copy archives. Independent terminal creation and scoped environment recovery remain available.
- Tool discovery, failure/log references, technical recovery, deleted-provider feedback and sharing improvements. Updated architecture plans describe future work rather than claiming it is already complete.

## Acceptance limits

Use the Release body for the exact source/APK identity, complete host gates and executed emulator checks. A source commit is not publication or acceptance; earlier evidence is not automatically a new candidate pass. Physical devices, production signing and long-term migrations are outside this run. Natural model tool discovery/log consumption can still fail; synthetic ASR substitutions remain a server-quality limitation, without forced model steps or client word replacement.

Exact third-party sources and notices are provided through the existing [runtime asset Release](https://github.com/dollarser/helix-agent/releases/tag/runtime-assets-20260917), subject to verification against the actual packaged components. Helix Apache-2.0 does not replace third-party licenses.

The tagged [notices](../../../THIRD_PARTY_NOTICES.md), [speech dependency lock](../../../config/asr/dependencies.lock.json) and APK `asr-licenses/` / `tts-licenses/` directories describe the new speech components. The older runtime notice archive covers its original scope rather than every dependency in this version.
