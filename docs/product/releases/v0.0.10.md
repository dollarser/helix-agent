# v0.0.10 开发预览

[发布页与实际验收结果](https://github.com/dollarser/helix-agent/releases/tag/v0.0.10) · [English](v0.0.10.en.md) · [完整源码比较](https://github.com/dollarser/helix-agent/compare/v0.0.9...v0.0.10)

相对 v0.0.9，本轮重点是会话与项目的衔接、手机操作的持续使用体验，以及文件、资料和恢复流程。版本名为 0.0.10，versionCode 与 Helix 自有内部版本保持 1。提供 Standard（consumer）和 Advanced（developer）ARM64 两个开发签名 Release/R8 APK，不是商店生产签名版本。

## 主要变化

- **会话与项目**：新会话可以选择或创建项目；项目入口和文件问答统一为携带上下文的草稿，保留输入及附件。工作目录与会话私有存储分开，现有会话加入项目不会静默改目录。会话管理、输入选项与能力选择减少重复入口，成果归入现有管理入口。
- **手机操作**：默认全手机或指定应用范围；配置不足时选择后引导配置，返回再检查。语义观察、截图与输入按实际能力判断，任务屏无目标时不再等同于插件整体不可用。Root 后端、跨轮保留任务屏、预览缩放/清晰度及断连后的原 task 恢复改善；旧帧与节点需重新观察。近期失效 token 与未知 token 分开报告，并给出明确恢复步骤。
- **浏览器与文件**：改善搜索输入、页面归属及显式恢复；修正 SAF 授权保留，完善大文本阅读、写入回执、成果定位与分享。外部目录同步、原位执行及读取仍有各自的授权边界。
- **知识与表达**：所选来源按需检索、中文检索和扫描 PDF/视觉读取；引用包含来源定位。增加离线公式、Mermaid 与 SVG 预览。连续听写累加到可编辑草稿，回复朗读和客户端语音生命周期改善，不自动发送转写。
- **能力管理**：统一插件、技能与专家管理，专家可关联已有插件和技能；导入配置不自动安装或授权。技能资源路径、创作与安装引导更明确。
- **备份、启动与诊断**：专用本地应用备份按白名单恢复；中断恢复保留回滚材料，不自动重放外部操作。首次说明与初始化并行，数据库兼容预检先于旧数据消费者，权限列表可跳过；修复二次预检失败卡住和恢复清理窗口。增加有界诊断、执行记录搜索及客户端耗时信息。
- **开发流程**：提交前检查暂存快照，推送前检查实际推送提交；保留完整 CI、双渠道边界和 Release/R8 门禁。锁定第三方资源字节不因 whitespace 检查而改写。

## 升级前阅读

- **并非升级必然清库。** v0.0.9 与本版 Room 结构相同；不兼容主库才显示具体影响与独立确认，未确认不会删除。重建涉及主库会话、任务、配置与授权等记录，不等于全应用清数据；具体范围以现场提示为准。开发预览不承诺保留旧测试数据，请另存重要内容。
- **旧专家库格式不兼容。** v0.0.9 保存纯文本正文，本版保存闭合 JSON；Room 结构检查不能识别此载荷差异。升级前在旧版另存专家名称与指令，并删除旧专家库条目，升级后重新创建；否则专家列表可能读取失败，且相关备份会受影响。不会在 App 内静默转换、跳过或清除。已有会话快照是独立记录，不等于旧专家库已转换；不要通过清空整个应用来处理这一项。
- 专用本地备份可恢复其列明的会话、配置、附件和可选文件范围；静态凭据是独立、默认关闭的加密选项。账号/OAuth 登录、系统权限、外部目录授权、进程和运行中任务不转移，定时规则恢复后暂停，未知效果保留审阅。诊断导出不是应用备份。见[备份契约](../../adr/workspace/008-content-backup.md)。
- 沿用既有开发签名；此前 code 2 安装可能因 Android 降级规则被拒绝，不因此自动卸载或清数据。共享资料与私有数据的保留范围不同，正文保留不保证旧索引可恢复。

## 范围与限制

电脑 ADB helper 是 **Developer Debug / Android 12+ 原型**，不包含在本次 Release APK 中；不提供应用内无线 ADB、跨 Helix 进程重启恢复任务关联或纯无障碍独立任务屏。Root、Shizuku、无障碍各有系统限制，不保证所有应用和安全窗口可操作。

主机测试、模拟器实际制品检查和历史真机证据分开记录。最终源码 SHA、完整 CI 链接、两份 APK 的 SHA-256、签名及本次实际运行范围在发布页正文列明；未列明的设备/模型/OEM 不能视为通过。当前发布任务不使用真机，不证明长期运行、全部 OEM、真实麦克风/耳机质量或商店审核通过。第三方来源与许可见 [THIRD_PARTY_NOTICES](../../../THIRD_PARTY_NOTICES.md) 及发布正文。
