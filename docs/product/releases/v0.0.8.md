## 本版范围

- 知识、笔记、导入资料与附件以共享开放文件为正文权威，默认位于 `Documents/Helix/library/`；索引可重建。凭据、Agent 记忆、会话、审批与运行事实继续私有保存。旧共享库通过明确恢复入口和系统授权导入，不因同目录而取得其他应用文件权限。
- 知识库三分类与会话引用：显式保存、引用选择和范围、冻结历史内容；取消选择不发送、不丢草稿。共享可编辑状态不能授权启动时自动提取或删除。
- Advanced 手动新建终端不被历史 UNKNOWN 或停止记录阻挡。新 PTY 读取到实际 shell 提示符才视为就绪；不重放旧命令、不自动删除 Linux 环境，不承诺修复所有系统故障。
- 登录后的线上语音默认路线、显式离线使用和首次授权边界；离线 ASR 使用 ModelScope 固定制品按需下载，保留推理引擎，安装包不含模型权重。下载/取消/失败及资源管理反馈精简。
- 文件、Git、知识库、账号/语音等提示精简，保留权限、不可逆操作后果与准确错误分类。

## 候选身份与安装

所有者已确认版本名 0.0.8、versionCode 1，数据库及其他自有内部版本也保持 1。已安装 v0.0.7／code 2 的设备可能需要卸载重装；删除旧发布页不会改变设备降级限制。卸载会删除该包本地数据，必须匹配具体授权，不静默清理，也不为旧测试数据增加兼容迁移链。v0.0.7 由所有者自行处理，代理不删除其 Release、标签或附件。

沿用既有开发预览签名，不是商店生产签名。Standard 与 Advanced 分别准备 ARM64 R8、不可调试 APK；源码、签名、哈希、体积和可安装性以本轮候选记录为准。未经另行授权不创建标签、推送、Release 或上传附件。
