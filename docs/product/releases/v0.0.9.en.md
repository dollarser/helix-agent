# v0.0.9 development preview candidate

Local candidate only: no tag, public Release or asset upload has been created. Version name is 0.0.9; versionCode and Helix-owned internal versions remain 1. It uses the existing preview certificate, not a production store identity, and does not replace released v0.0.8 assets. The authorized publication must list the final source commit, signing identity, APK hashes and CI.

## Changes

- The plus menu adds materials, references or existing capabilities. Conversation management, message delivery and global configuration have separate destinations. Reasoning remains in model selection, budgets remain global, and the context ring opens context details. Supported features are retained; Agent-only interfaces do not require UI.
- Conversation references use the real directory with search, empty/error/retry and selection states. Async results remain bound to their originating conversation.
- Global settings create, edit and strictly import experts. Conversations select saved experts and retain independent snapshots; later library edits do not change selected snapshots or admitted Turns. Experts do not grant tool permissions.
- Plugin choices are staged in one panel, saved only on Apply, and discarded on Cancel. Configuration and necessary authorization remain explicit. Sheet spacing, surfaces and selection styling are unified.
- Dictation exposes Stop and transcribe, inline retry for failure/empty results, and cancellation that preserves the original draft. Retry waits for prior cleanup. Successful text remains editable and is never sent automatically.
- Official services derive HTTP/WS speech routes from the accounts base, the api inference base containing `/v1`, and the api WS base without `/v1`. There is no retired speech-host fallback. Custom providers and custom speech addresses remain independent.

## Upgrade and data effects

The expert library changes the main database structure while the internal version stays 1. Incompatible preview databases require explicit foreground confirmation before rebuilding. Main-database conversations, message indexes, tasks, configuration and authorization records are removed; related terminal ownership records are handled as disclosed. When old execution has not been proven stopped, reboot the device and recheck first. This is not a whole-app data reset.

Shared knowledge documents, models, Linux environments/workspaces and account credential files are outside that main-database reset. Preserved content files do not guarantee recovery of old indexes or conversations. Diagnostic export is not a restorable full backup. Save important content separately. Devices with v0.0.7/code 2 may still require separately authorized uninstall because of downgrade restrictions; deleting an old Release does not change device rules. Historical releases are retained.

## Validation boundaries

The preceding Debug candidate passed full host checks and bounded Advanced UI regressions on two devices. On the daily API36 emulator, an existing account completed real HTTP/WS ASR/TTS using one fixed synthetic utterance. Real file-ASR output was editable in the input components without automatic sending; cancellation preserved the draft. No microphone, speaker, LLM inference or logout was used. Client socket closure does not prove server-side execution rollback.

Final Release/R8, signing and installation evidence must identify the frozen source and actual APK. Debug results are not final-package acceptance. PLC110 UI evidence predates the speech-host change. Real microphone/headset quality, long-term stability, every OEM/memory-pressure case and store approval remain outside these slices. Dedicated text completions, embedding execution and a VibeVoice selector are not added, and broad recognition accuracy is not claimed.

Third-party obligations remain in [THIRD_PARTY_NOTICES](../../../THIRD_PARTY_NOTICES.md) and locked assets. Publication must identify final checksums and source. Local builds do not authorize uploading source, logs, mapping files, private credentials or duplicate archives.
