# v0.0.12 development preview

[简体中文](v0.0.12.md) · [Changelog](../../../CHANGELOG.md)

This preview improves accounts, model catalogs, attachment reading/recovery and conversation UI. Standard (consumer) and Advanced (developer) ARM64 Release/R8 APKs use versionName 0.0.12, versionCode/internal versions 1 and the existing development-preview certificate.

Helix is not formally released. In-place installation and historical data retention are not guaranteed, even when installation succeeds. Save important material separately; uninstalling deletes private application data.

## Changes

- Email/password login, optional registration display names and server-synchronized passwordless renaming. Avatar, name and account information share one page; successful registration shows a short confirmation and returns to login with the email retained.
- Registration, recovery and email binding complete human verification before sending a code. A single web challenge card preserves cancellation, expiry and late-result boundaries. Notices use a five-hour persistent cache; usage follows server scope.
- Successful model catalogs cache for five minutes. Failures retain cached data; confirmed removal preserves historical selections and asks for an explicit switch without silent replacement or replay. Partial catalogs, usage snapshots and embedding limits remain distinct.
- Non-image attachments provide metadata and stable references for on-demand tool reading; images follow model capability. PDF/DOCX references, extraction, terminal/Python snapshots, explicit project copying, backup/restore and reference-aware cleanup are strengthened. Project changes do not move historical attachments.
- Long conversation titles preserve readable timestamps and internal paths are removed. User subpages share a window; disabled controls retain outlines and fast reads finish before opening result dialogs.
- Added bounded Binder cancellation/recovery, draft/permission isolation and actual tool-consumption regressions.
