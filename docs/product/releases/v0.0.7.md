# Helix v0.0.7 开发预览版

[English](v0.0.7.en.md) · [发布页](https://github.com/dollarser/helix-agent/releases/tag/v0.0.7)

已于 2026-10-24 发布；构建来源为 `9965d2df`。验证范围与首次 CI 取消/有界重试见[发布记录](../../evidence/development/v0.0.7-publication-2026-10-24.md)。后续知识库新原型不在此版本。

## 分发与身份

ARM64 / Android 10+，Standard 完整基础产品与 Advanced 进阶能力，R8 优化、不可调试。版本 0.0.7 / code 2，沿用既有开发证书，非正式商店签名。版本页只提供两份 APK 与 GitHub 标签源码；精确提交、CI、SHA-256 和实际验证结果以发布正文为准。

同渠道覆盖安装，不先卸载或清库。预览数据库不兼容时须在前台明确确认删除范围，取消保留数据；不承诺任意历史版本无损迁移。账号令牌和用户资料不随发行材料上传。

## 本版变化

- 账号登录访问内置模型；单独 ClientID 与内置 key 入口已删除。未登录仍可使用自配 API、渠道允许的订阅或本地模型。
- 统一会话、抽屉、账号、设置及知识库交互；用户消息编辑不自动发送、不创建分支。紧凑输入区保留会话权限入口。
- 知识库分开管理原始资料、Markdown 笔记和资料问答；阅读/编辑显式切换，保留未保存草稿，不因切换自动保存。
- 云端语音支持已对齐的 HTTP 分段与 WebSocket 持续流客户端，停止朗读与停止 Agent 分开。离线 ASR/TTS 资源按需下载、显式删除，保留本地推理引擎。
- Advanced Linux 默认在已授权真实工作区原位执行，生成文件留在原处；结果与日志受控补读，不强制归档整个工作副本。终端提供独立新建和限定运行环境恢复。
- 工具发现、失败结果及日志引用、技术恢复、Provider 失效提示和系统分享路径收尾；更新后续架构分层计划，不将计划误记为已实现。

## 验证与限制

实际验收以发布页记录的提交、双渠道产物、完整主机门禁与模拟器证据为准；源码提交不等于已发布或已验收，既往结果不自动代表当前候选通过。真机/OEM、正式签名与长期升级承诺不在本轮范围。真实模型的工具发现/日志读取仍有波动，ASR 合成同样本替字保留为服务端质量问题；不以强制工具步骤或客户端改字规则掩盖。

第三方对应源码和许可由既有 [runtime 资源页](https://github.com/dollarser/helix-agent/releases/tag/runtime-assets-20260917) 提供；发布前核对与本版实际组件相符，Helix 的 Apache-2.0 不替代其各自许可。
