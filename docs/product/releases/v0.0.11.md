# v0.0.11 开发预览准备

[English](v0.0.11.en.md) · [中文更新日志](../../../CHANGELOG.zh-CN.md) · [本轮验收记录](../../evidence/development/v0.0.11-preparation-2026-11-13.md)

状态：UI 与更新检测整合候选已通过双渠道 Debug/R8 会话核心验收、更新/关于页专项、完整主机门禁及普通 ARM64 分发构建。应用预览尚未发布；最终分发签名、提交、CI 与附件身份以实际发布记录为准。

相对 v0.0.10，本轮重点是服务与模型设置、跨会话协作、网页与文件工具，以及长任务执行和恢复。产品版本为 **0.0.11**，Android versionCode 与 Helix 自有内部版本继续保持 **1**。计划提供 Standard（consumer）和 Advanced（developer）ARM64 Release/R8 APK。

Helix 尚未正式发布。开发预览不保证可以覆盖安装；即使覆盖安装成功，也不保证保留历史数据。升级前请另存重要内容。

## 主要变化

- **手动检查更新**：设置 → 关于 Helix → 检查更新，仅在用户点击后读取 ModelScope 元数据，按当前包名和设备 ABI 选择最高语义版本；另一次点击才交给浏览器下载。不新增后台检查、安装权限、自动安装或数据清理。
- **普通会话修复与必测**：修复生产 Room 拒绝有界 `tools.cost` 诊断、导致普通会话在模型请求前失败的问题，保留未知类型与长度限制。每次候选的核心验收覆盖实际会话、成功工具回填、进程重启后的持久历史、请求取消、不重放和继续会话。
- **工具详情**：会话内保留简洁摘要，详情按语义分组并支持复制；业务内容与内部诊断分开呈现，底层工具结果、模型记录及审计原值不被展示整理覆盖。
- **服务与模型设置**：自配 API 的连接字段和模型列表合并为单页，统一保存，取消保留原设置；支持连续添加模型和显示名。连接测试、逐模型生成测试与能力检测分别记录，不再把目录可达等同于模型能力通过。会话模型按服务分组，订阅登录继续使用独立管理入口。
- **跨会话协作**：可明确授予其他会话的历史读取、管理、创建及任务投递权限。支持查询、幂等创建、Queue 和指定活动 Turn 的 Steer；各权限独立，模型转发保留来源，不自动复制文件权限、创建 Goal 或绕过目标会话审批。
- **网页与搜索**：增加有界公开网页读取、浏览器搜索与表单操作，正文视图保留可追溯链接，减少不必要的结果分页。独立 API 搜索与支持的 Responses 原生搜索须显式启用，不自动注册或启用付费服务。
- **文件与授权目录**：补强真实系统 SAF 上的原生 glob / 字面量 grep、搜索后读回、授权撤销与取消边界；修复文件夹问答交接、长目录名称下的操作布局及刷新时的状态呈现。
- **MCP 与技能**：MCP Resources 支持有界文本及二进制产物；二进制通过宿主文件引用交付，不直接塞入模型正文。技能按插件安装归属管理，输入框支持原子技能标记与斜杠发现。
- **长任务与恢复**：调整上下文压缩预检、工具发现与 schema 投影，稳定缓存前缀并保留真实缓存计量；补强 Goal 协调、工具结算、进程恢复及未知效果处理。未知效果不会自动当作失败重放。
- **Advanced 媒体与手机操作**：FFmpeg 继续复用已有 PRoot/Job，可处理音视频、字幕、字体与多产物；修复 MediaCodec 编码初始化中的 encoder flush 问题。电脑 ADB helper 扩展到 Android 12+ 非 debuggable Advanced 构建，使用应用签发的一次性、进程绑定交接票据；Standard 不包含该入口。
- **文档**：中英文 README 聚焦核心功能、GitHub/ModelScope 下载入口和使用公开示例的真实截图；版本变化集中到双语更新日志，保留已核实的历史发布日期和明确的预览版升级风险。

## 升级前阅读

- 本版数据库结构与旧 v0.0.10 不同，新增跨会话授权和幂等回执记录。内部数据库版本仍为 1，这不表示结构兼容，也不构成无损升级承诺。
- 不兼容主库应先展示具体影响并由用户独立确认，取消不得清库。重建主库与清除全部应用数据不同；本次准备工作不代用户卸载或清理日常数据。
- 应用备份不是账号登录、OAuth、系统权限、外部目录授权或运行中任务的镜像。不要将旧格式备份的存在当作本版恢复兼容证明。
- versionCode 仍为 1，Android 可能拒绝覆盖历史 versionCode 更高的预览包；卸载会删除应用私有数据。不保证系统或商店自动提示更新。包名、签名、安装与数据保留结论仅以最终 APK 的实际验证为准。

## 检查更新与下载

- 固定使用 [ModelScope 仓库](https://modelscope.cn/datasets/dollars/Helix)的 `resolve/master/update-manifest.json`。按语义版本优先级和包名/ABI 匹配选择更新，不写死目标版本，也不把 README 上传时间作为依据。APK 使用 `releases/v<versionName>/` 路径。
- 新版本名对应的 versionCode 未递增时，界面提示可能无法覆盖安装，不引导卸载或清除数据。下载操作交给浏览器；安装及 Android 的包名/签名检查仍是独立步骤，Helix 不声称已校验下载文件或完成升级。
- 网络失败、清单未发布（HTTP 404）、清单无效和没有匹配安装包分别显示明确结果，提供重试或手动下载入口；GitHub Releases 和 ModelScope 下载入口同时保留。清单不存在不会显示为“已是最新”。
- 此功能需要已发布且有效的清单和对应 APK。本准备说明不表示两者已上线：须先上传并核验最终 APK，再发布包含其真实身份的清单。详见[分发契约](../../adr/platform/001-distribution.md#modelscope-更新发现)。

## 范围与限制

- 搜索服务、订阅、MCP 服务和模型能力依实际配置及提供方而定；已接入不等于所有服务、模型和账户都通过。
- FFmpeg MediaCodec 编码依设备实现；未包含 x264/x265/AV1 软件编码器，不承诺所有编码格式、硬件组合或性能。
- 跨会话功能不是远程电脑或生产子 Agent，也不自动授予目标会话的文件、设备或外部服务权限。
- 真机、模拟器、真实模型和主机检查分别列出。最终分发包须与下列证据核对，不能自动继承旧版本或不同候选的结果；不宣称全部 OEM、24 小时长稳、16 KiB 真机或真实麦克风/耳机质量通过。

## 最终核心验收与历史证据

下列当前结果是在合并更新检测、双语文档与截图后重新执行，先前仅含 UI 的候选、真机及媒体结果分别保留。精确源码、构建与安装制品身份见[验收记录](../../evidence/development/v0.0.11-preparation-2026-11-13.md)。

- 双渠道分别在独占 API36 模拟器上通过 40 个实际 Debug 方法：9 类真实 Room 会话核心共 35 项，加上更新 UI 3 项和关于页 2 项。失败、跳过和缺失均为零。此前工具详情 28 方法的隔离 UI 专项作为独立历史检查保留，不计入本轮方法数。
- 更新 UI 夹具核对主动检查与下载的独立点击、versionCode 提示、重试与错误呈现，以及取消后旧结果不得重新打开对话框；不证明线上已发布清单、浏览器实际下载或 Android 安装通过。
- 同一最终生产及 Release 测试输入构建双渠道非 debuggable、隔离包名、测试签名的 ARM64 R8 候选。按源码枚举的默认 smoke 各 4 个方法全部通过，其中会话旅程实际到达本机 HTTP Provider，执行真实只读工具并回填成功结果，验证进程退出及不同 PID 重启、历史进入下一请求、取消关闭连接、重启不重放以及再次继续。安装 APK 哈希与冻结件一致；精确隔离包清理及独占实例关闭均有回执。
- 门禁有效性使用同一强化测试 APK 对照：留存坏包在首次实际会话到达 Provider 前失败；已修复的中间包通过。中间正控仅证明门禁有效，不能替代上述最终双渠道结果。
- 最终完整 `check-all.sh --all` 主机门禁、普通 ARM64 双渠道分发构建及制品边界检查均退出 0，全部主机/设备阶段的全文件清单保持相同。四个独占实例均核对安装 APK 哈希、精确清理测试包并正常关闭。随后仅补充结果文档并重跑源码门禁；未将正常 Gradle 缓存复用描述成每个任务重新执行，也未替代真实设备验收。
- 较早候选的 ONEPLUS_A6013 / API34 / ARM64 / 4 KiB 页检查为 Debug 30 项及双渠道 R8 入口 8 项；真机与 API36 的媒体 3 项重跑是原集合子集。该批未覆盖普通会话生产 Room 链，未检测出后来实测发现的会话缺陷，不能称为最终候选核心验收。
- 历史媒体对照仅支持该 OnePlus 的 320×240/NV12 合成 H.264/HEVC sync/async 案例，核对 8 帧及解码；96×64/yuv420p 的失败保留，不外推所有 Qualcomm 或最低尺寸要求。媒体载荷不变的对应关系须由新制品逐项核对。
- 早期真机与日常模拟器的主应用保数据覆盖更新，只代表该次安装事实，不证明公开 v0.0.10 的无损升级。最终核心验收仅使用独占测试实例，没有操作日常前台或真机。
- 测试签名不是最终公开分发签名；16 KiB ZIP 对齐不是 16 KiB 真机执行。上述核心夹具不调用外部模型，仍未覆盖 API29、其他 OEM、真实模型媒体旅程、长稳、热压或真实麦克风/耳机质量。
