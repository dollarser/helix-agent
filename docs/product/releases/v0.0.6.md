**简体中文** | [English](v0.0.6.en.md)

## 2026-10-18 重发

本次在同一 v0.0.6 预览页替换附件和标签目标，按 Owner 最新要求，原版与新版内部编号均保持 1；精确构建提交及重发时刻写入 Release 正文。同渠道包名与开发证书保持，可覆盖原版，无需先卸载。需要手动下载本次 APK 并覆盖安装，不宣称相同 versionCode 会触发自动升级提示。插件/工具声明版本仍为 1；安装修订与运行实例身份独立，不清零授权或用户数据。随后附件整理保持本次 APK、签名、版本与标签目标不变。

## 安装包与升级

需要 Android 10+ 和 ARM64 设备。发布包从干净提交构建，精确提交记录于 Release 正文；两个渠道均使用 R8 优化、不可调试，`versionName=0.0.6`、`versionCode=1`，沿用现有开发证书。这不代表正式发行签名或长期升级承诺；已安装内部编号高于 1 的版本会受 Android 降级限制。

| 安装包 | 产品范围 |
| --- | --- |
| `helix-v0.0.6-consumer-arm64-v8a.apk` | Standard 完整基础产品：会话、API/设备内模型、文件及渠道允许的插件工具；不包含 PRoot 和第三方订阅 Runtime |
| `helix-v0.0.6-developer-arm64-v8a.apk` | Advanced：基础产品加 Linux 环境、终端及实验性第三方订阅适配；仍受当前模式、系统能力和会话授权约束 |

安装时核对发布页正文中的 APK SHA-256；匹配的 R8 mapping 与简要构建身份作为开发归档保留，不再上传到版本 Release。开发签名不表示 APK 可调试；相同版本编号也不表示数据库兼容。APK 不包含模型权重；可在对话选用免配置内置服务，也可配置自己的 API 或准备设备内模型。

预览版没有旧数据库迁移承诺。不兼容时，应用会在恢复任务和正常启动前要求确认：清空数据库内的会话、任务、配置和授权记录，保留数据库外文件；取消会保留旧数据并退出。诊断导出不是可恢复的全量备份。遇到签名冲突或不愿清空的数据，保留旧安装并先解决升级条件，不通过直接卸载绕过。

## 本版重点

- **内置模型：** 对话选模按动态目录显示 Helix 内置服务，无需 Key，不在 Provider 配置中显示；成功缓存、失败保留已选目标，不用打开弹窗触发推理探测。服务使用公开、可撤销的 Client ID，不是用户密钥；共享额度与服务可用性由网关管理。
- **选模与思考：** 模型与强度暂存后显式保存，取消不改设置；已知 Qwen 的低/中/高映射 low/medium/xhigh，默认省略参数。服务端接受请求不等于已验证各档效果。来源页和插件页统一自适应布局，会话不再显示内置传输提醒。
- **插件身份：** 无内容变化的原生启动与健康 repair 不重复写库或递增安装修订，进程工具投影仍重建；内容/启停/必要修复保持 CAS 保护。

- **插件与操作体验：** 已安装、市场、导入入口分工更清楚；配置与就绪提示统一，Skill 按需装载。外部包导入的可用内容与所需组件分开呈现，导入不自动赋予账号、脚本或设备操作权限。Mobile Use 保持插件边界，复用宿主授权与运行管理。
- **会话与文件：** 过程、工具和最终回答的展示更清楚，文件工具标题突出文件名，目录与完整信息在详情中查看。会话、项目和工作目录保留各自身份，显示路径不改变已经提交的调用目标。
- **可靠性：** 完善预览旧库重建确认、预算保存、调用恢复与待审查状态，修复 Linux 作业收取时标准输出未正确回填的问题。执行成功、结果保存和模型实际消费分别核验。
- **Linux 环境：** Advanced 内置资源在首次获准的新作业或手动终端启动时自动准备。打开设置、普通查询或恢复旧作业不会安装或重放命令；已有损坏/不匹配环境需明确修复或更新。
- **维护入口：** 用“Linux 运行环境”展示实际状态，检查、修复、重装、删除和开源许可按需进入。历史维护结果与当前状态分开；修复清理目录时沿符号链接误删外部文件的问题。
- **日常交互修复：** 浏览器页面布局恢复、被拒绝的外部应用跳转不再破坏原页面快照；自动标题尊重手动命名。输入保持语音、正文、添加、发送同排，完全访问仅文字变色，减少重复留白。短过程说明直接显示，空白不产生折叠入口。
- **手机手势：** 起手前核验 frame，执行中允许合法窗口变化，修复通知栏接管窗口导致取消；授权范围、显示坐标变化、锁屏、取消和未知结果边界保留。

内置云端服务接收消息、上下文、工具结果和所选图片，受共享额度与服务可用性影响；不宣称未知的留存或训练政策，可切换自己的模型。

PRoot 运行于非导出的私有进程，但与宿主共享 UID，不能视为对恶意代码的完整安全隔离。系统权限、会话授权和执行限制继续生效。

## 保留的边界

当前发布验收未覆盖实体手机、其他 API/OEM、x86 设备、2 小时/24 小时长稳、其他 Provider/账号，以及完整 FFmpeg/PRoot 媒体端到端。15 分钟浏览器资源检查不能替代这些范围。视觉识别与任务完成质量取决于模型及目标应用；模拟器通过不能推导所有手机后端通过。

第三方许可与精确来源统一在既有 [runtime 资产 Release](https://github.com/dollarser/helix-agent/releases/tag/runtime-assets-20260917) 提供：`helix-v0.0.6-third-party-notices.zip`、`alpine-corresponding-source.tar.gz`、`alpine-source-manifest.json` 和 `media-corresponding-source.tar.gz`。应用发布正文直接链接这些材料，原 Termux 源码和运行时附件保持，不另建资料 Release。Helix 的 Apache-2.0 不替代第三方各自许可证。

整体 Harness 重构、远程执行平台与逐调用变更审阅仍在后续规划中；本版没有把这些方案宣布为已实现功能。发布前的正式签名与渠道条件见[发行就绪条件](../../development/release-readiness.md)。
