# HXA-102 恢复和副作用（完成记录）

- 日期：2026-09-05
- 目标：收口模型流、审批与各副作用执行器的 kill/restart 不重放语义，并按 ADR-0004 为 Goal 增加原子 durable budget accounting 与明确最大未记账窗口。
- 前置任务/commit：HXA-101，`ec15fbb`。
- 修改文件：`core:storage` GoalRun checkpoint DAO/repository；app `GoalDurableUsageLedger`、恢复协调器与 API 29/36 进程重建测试。
- 实现的契约：模型与工具完成边界立即把 calls/tokens 写入 Goal lifetime 和当前 open run；活动运行每 5,000 ms 至少写一次 HEARTBEAT，故崩溃时墙钟最大未记账窗口为 5 秒，已完成模型/工具调用的最大未记账窗口为零。Goal、run 和 `goal.usage_checkpoint` 脱敏 audit 在同一 Room transaction 中提交，计数单调且使用 `Math.addExact` fail closed。达到任一预算时原子进入 `PAUSED` 并保存稳定 `BUDGET_EXHAUSTED(limit)`。恢复关闭 open run 时仅保留 durable usage；`endedAt` 可用墙钟夹紧，但离线时间与墙钟回拨不再增加 usage。现有统一 Turn/ToolCall 恢复继续把运行中的文件写、浏览器/UI 动作、MCP、A2A、PRoot 等停在 `INTERRUPTED/NEEDS_REVIEW`，不会自动重放。
- 未实现/明确排除：没有将 `INTERRUPTED` 或 `NEEDS_REVIEW` 猜成成功/失败，没有后台自动继续 Goal，没有改变 ADR-0004 的用户显式 continue 语义。5 秒内尚未 checkpoint 的纯运行时长在突然断电时仍可能丢失，这是明确上界，不伪称零窗口。
