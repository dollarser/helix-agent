# HXA-157：工具发现数量上限截断修复

Date: 2026-09-08
Status: completed

## 交付

修复 tools.search 和已搜索 MCP 工具可能落在 ModelRequest.MAX_TOOLS（64）之外的问题。对已通过 mode 准入的工具，先保留搜索入口及当前有效发现窗口，再按原顺序补充其他工具并按名称去重。16 项窗口、会话隔离、失效规则与实际执行审批保持不变。新功能暂停，ADR-0030/0031/0032 未接受、未实现。

## 验证

- 旧代码执行 `./gradlew :app:testConsumerDebugUnitTest --tests com.helix.app.mcp.McpToolDiscoveryTest --max-workers=1`：8 项中新增 2 项失败，分别复现大目录搜索入口和小目录已搜索结果被 64 项上限截断。
- 修复后 `./gradlew spotlessApply :app:testConsumerDebugUnitTest :app:testDeveloperDebugUnitTest :app:assembleConsumerDebug :app:assembleDeveloperDebug spotlessCheck detekt lintDebug --max-workers=1`：exit 0；consumer 336 项、developer 360 项，均 0 failures/errors，各 4 项既有 opt-in 外部测试跳过；8 项工具发现专项均通过。
- docs/ADR/secrets/diff 门禁通过。本次改动仅为模型工具列表排序，未重跑 Android 设备测试、真实服务或长稳，不引用历史设备结果作为本次测试。

决策记录：不适用：既有曝光契约内的 bug 修复，无新增协议、权限或持久化契约。根因与长期边界见 [Bug 记录](../bug-fixes/2026-09-08-mcp-discovery-model-limit.md)。
