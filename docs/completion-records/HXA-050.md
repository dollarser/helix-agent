## 关键能力证据（两台设备一致，除注明外）

- **evaluate**：`1 + 2 * 3` → `java.lang.Integer(7)`；`"a" + "b"` → `"ab"`；`"héllo 🚀 日本語"` 往返一致；`'a'.repeat(2 * 1024 * 1024)` → 长度 2097152 的 String；`JSON.stringify({a:1, unicode:"🚀"})` → `{"a":1,"unicode":"🚀"}`；`QuickJs.version` = `"2021-03-27"`。
- **memoryLimit**：限额 2 MiB 时 `new Array(4M)` 填充 → `app.cash.zipline.QuickJsException`（消息 `out of memory`）；默认 64 MiB 时 `new Array(32M).fill(1)` → 同一 `QuickJsException`；**API 29 上 64 MiB 用例消息为空字符串**（堆耗尽时 JS Error 对象分配失败；API 36 上为 `out of memory`）——两者均为 JS 级错误，进程存活，同实例后续 `6 * 7` = 42 正常。`memoryUsage.memoryUsedSize` 在分配后 > 0。
- **InterruptHandler**：`while (true) {}` 在 poll 计数 >1000（实测 1001 次）或 monotonic 截止 300 ms 时抛 `QuickJsException`（消息含 `interrupted`），中断后同实例 `1 + 1` = 2 / `2 + 2` = 4 正常。
- **`eval`/`Function`/constructor**：`typeof eval` 与 `typeof Function` 均为 `"function"`（Zipline 保留存根，不删除全局）；`eval('1+1')`、`new Function('return 1')()`、`Function('return 1')()`、`Object.constructor.constructor('return 42')()`、`String.constructor.constructor('return 7')()`、`[].constructor.constructor('return 3')()` **全部**抛 `QuickJsException`（消息 `eval is not supported`）。动态编译在引擎层封堵，但形式是“存根即抛错”，不是“全局不可见”——HXA-052 封装仍按架构文档 §3 实施并以攻击测试锁定。
- **大于 6 MiB 的调用线程 stack**：默认 `maxStackSize` = 524288（512 KiB），深度递归 `function r(n){return 1 + r(n-1)}; r(1e8)` → `QuickJsException`（`stack overflow`），实例存活（`3 + 3` = 6）；16 MiB native 栈线程（`Thread(..., 16L*1024*1024)`，可创建成功）上创建实例并设 `maxStackSize` = 8 MiB，同一递归 → 同样 `stack overflow` JS 错误、线程与实例存活（`4 + 4` = 8）——大于 6 MiB 的 JS 栈在大于 6 MiB 的调用线程上以 JS 错误结束而非进程崩溃。**关键约束**：实例在 A 线程创建、B 线程 evaluate 时立即 `stack overflow`（栈基线绑定创建线程）——HXA-051 必须在执行线程上创建实例。
- **`bindIsolatedService` 唯一实例回收**：唯一 instance name 绑定 → service PID ≠ 调用方 PID、service UID 99000 ≠ 调用方 UID 10252、进程名 `<pkg>:<serviceFQCN>:<instanceName>`；`unbindService` 后 20 s 内 PID 从 `ActivityManager.getRunningAppProcesses()` 消失（系统回收）；新 instance name 重绑 → 新 PID ≠ 旧 PID 且 info 事务正常。
- **16 KiB page**：本环境设备均为 4 KiB page（实测 4096），无 16 KiB 真机；替代证据 = AAR 四 ABI `libquickjs.so` PT_LOAD 对齐 0x4000（JVM 测试锁定 arm64-v8a/armeabi-v7a/x86/x86_64 全部 = 16384）+ 设备进程内对本 ABI `.so` 复核 + 4 KiB 设备全能力运行。**未把 4 KiB 设备当作 16 KiB 验证。**
