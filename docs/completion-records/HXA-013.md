# HXA-013 完成记录

- 目标：实现 Goal reducer 与预算（roadmap HXA-013）：Goal 状态、验收条件、模型/工具/token/时长/重试预算、checkpoint、`INPUT_REQUIRED`；首版只有用户显式继续创建新 run；WorkManager 只发可延迟提醒，不调模型/工具；预算耗尽不得完成；只有 verifier evidence 可满足 criterion；测试 Doze/强停/提醒延迟。

    - `ReminderPlan.kt`：纯函数提醒计划（null checkpoint → 跳过；过期 checkpoint → 延迟 0 立即排程；仅 RUNNING/PAUSED/INPUT_REQUIRED 需要提醒）。

- 实现的契约：
  - 架构 §5.1（Goal 模式行、WorkManager 只发可延迟提醒、UI 不显示精确定时器）、§5.3（预算合成 `stricterWith`）、§9.1（`goals`/`goal_runs` 字段语义：run 级 wakeReason/outcome，goal 级累计计数）；modes §6.1（Goal 结构、六项预算、首版只有用户显式继续创建新 `goal_run`、`wakeReason` 记录真实来源）、§6.2（状态图、verifier evidence 才能 COMPLETED、预算耗尽不是成功）。
  - run/wake 事件模型与预算耗尽取 PAUSED 的决定升级为 [ADR-0004](../adr/0004-goal-run-wake-budget-semantics.md)（**proposed**，Deciders pending）；HXA-014/015 依赖该语义。
  - 契约解释（已记录于 ADR-0004 第 2 条）：run 正常结束（`RunFinished`）→ PAUSED——§6.2 中唯一的非终态等待状态；PAUSED 同时承载“等下次唤醒/预算耗尽/进程死亡 park”，UI 与审计以最后效果区分。
  - 契约解释（已记录于 ADR-0004 第 3 条）：`GoalBudgets` 无 `ErrorCode` 预算专用值（HXA-010 的 12 值集不含预算码），耗尽语义由 `BudgetExhausted(limit)` 效果承载（limit 为预算字段名），错误码路径只用于 wake 失败（`HelixError`）。
