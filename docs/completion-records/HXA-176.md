# HXA-176：长 Turn / Goal 压缩实战强化

Date: 2026-09-09
Status: completed

## 实现

Harness 在每次模型调用前同步判断压缩，包含同 Turn 工具批次结算后的下一步和显式 Continue 的下一 Turn 第一次请求。不依赖空闲时间，不等待整个 Turn 结束，也不打断尚未结束的模型流或工具执行。

优先摘要较早历史，其次当前 Turn 较早已结算步骤；新轮没有可压缩步骤时可处理最近上一轮的较早步骤。保留当前输入、最新步骤及未结算批次；工具调用与全部结果整组。checkpoint 新增可选 preservedMessageIds，支持边界之前的必要原文与旧格式兼容；原消息、附件和审计不删除。ContextSegments 单独负责分组与来源映射，重排 retry 无法精确映射则拒绝规划。

最终请求增加协议/图像估算余量，结合当前 Turn 实际 input usage 校准和匹配的持久输入下限。发布摘要至少节省 max(32 tokens, 原请求估算的 5%)；每次普通模型调用之间最多两次摘要尝试。可恢复自动摘要失败仅重试一次，失败调用如实记账；无收益后按输入增长抑制重复尝试，仅当原文满足硬限制才继续。不可压缩的容量错误使 Goal PAUSED，不判完成，不增加 wake 或预算。

摘要使用结构化连续工作笔记；基础输出额度 2048，大上下文最多 4096，仍受现有配置/预算/窗口约束。确认支持推理时明确用 LOW，其他 Provider 保持 OFF 默认协议行为。普通对话推理设置不变，摘要不带工具或审批权。

决策记录：[ADR-0038](../adr/0038-step-boundary-context-compaction.md) 根据所有者明确授权接受并取代 ADR-0037；[ADR-0004](../adr/0004-goal-run-wake-budget-semantics.md) 的 Goal 显式继续/暂停/预算保持不变。长期不变式见 [Bug 记录](../bug-fixes/2026-09-09-long-turn-context-compaction.md)。

## 失败证据与修正

- 初始 Goal 夹具用 8192 窗口容纳完整工具目录，摘要后仍不可压缩；改为适合该工具集的 65536/10% 夹具，并单独保留硬容量与 Goal PAUSED 断言。
- 新增 503 用例发现错误码是 SERVER_ERROR，不能按 NETWORK 判断；现在同时要求 Provider retryable 标记和允许的暂态类别。
- 增加摘要预算后，摘要请求只能覆盖有界前缀；相关测试改为验证配对、末步保留、边界推进与真正减少原文，而非错误假定一次必然只剩一个批次。
- 真实模型最初 512 tokens 截断，恢复 2048 后在默认推理下仍耗尽额度。查明 OFF 省略参数不等于关闭推理；明确 LOW 后实机流程完成。截断摘要没有发布，没有放宽 TOKEN_BUDGET_LIMIT。
- 三轮 live 测试曾在 WAITING_MODEL 时提前断言，根因是只等列表长度和异步 UI isSending；修为同时等待持久 Turn 终态，保留完整回答断言。

原始失败与重跑日志保留在忽略的 build/phone-polish/hxa176-* 和 build/debug/2026-09-09/hxa176-*。最终机器证据为 hxa176-accepted-developer、hxa176-release-consumer；含 instrumentation、bounded logcat、制品冻结、owner/closed 记录。临时诊断和结果汇总脚本均先保存在 scripts/debug/2026-09-09。
