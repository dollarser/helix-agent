# HXA-039 完成记录

- 目标：消除 M1 串行 `TurnReducer` 与 HXA-037 批量并发 Tool Round 的生产语义冲突，在首个业务工具进入聊天工具表前建立唯一 batch-safe application coordinator，并关闭多轮 ModelCall、逐调用异常、事务终局和恢复一致性缺口。
- 决定：accepted [ADR-0010](../adr/0010-batch-turn-coordinator.md)取代 ADR-0002 的同响应串行生产决定。新 `TurnCoordinator` 驱动生产 Turn/ModelCall aggregate phase 和当前 stream checkpoint；旧 reducer 只保留历史测试与旧恢复行兼容，不接入新生产 Turn。
- 生产实现：
  - 新增 `TurnCoordinator.kt`：每轮模型调用开始前切换 ModelCall/`ModelStreamState` checkpoint；批内同时表达多个 pending/settled/unknown 调用；第二轮以后取消/失败终结当前调用并保留当前部分文本。
  - Turn start、assistant terminal text + Turn terminal + 当前 ModelCall terminal、model tool step close + assistant ToolCalls，以及固定顺序 ToolResult backfill + 下一 ModelCall + Turn 回环分别具有明确 Room transaction 边界；外部工具副作用保持事务外且不盲目重放。
  - `TurnRepository` 拒绝非法状态跳转并保留 process-death → `INTERRUPTED` 例外；生产 batch 使用 `RUNNING_TOOL` aggregate phase，每调用状态仍由 ToolCall 行记录。
  - `ToolScheduler.BatchResult` 改为逐槽 `Outcome/Thrown(cause)`，重复 `toolCallId` 在准入前失败关闭；修复 future completion 早于 slot release 造成等待线程漏唤醒的竞态。非审批取消的 contract throw 以 `NEEDS_REVIEW` 保存未知副作用。
  - `ModelStreamState` 补齐 262,144 字符文本、32 调用、单调用/聚合参数预算，以及重复 index/id、孤立 delta/finish、finish 后 delta 等协议失败关闭；发送前拒绝空/NUL/超长用户输入，ModelRequest 暂使用 4,096 token 硬输出上限。
- 测试：
  - `TurnCoordinatorTest` 覆盖第二轮 checkpoint、批内乱序结算、unknown 阻断下一模型调用、重复 identity 和终局当前调用。
  - `ModelStreamStateTest` 覆盖文本/聚合参数/调用数上限及重复、孤立工具事件。
  - `ToolSchedulerTest` 覆盖每槽独立异常、批内重复 id 和异常完成后的 slot 唤醒。
  - `TurnCoordinatorDeviceTest` 在 API 36 arm64-v8a 模拟器验证第二个 ModelCall 失败不会改写第一个已完成调用、部分文本持久化，以及 repository 拒绝状态绕行；既有 ProcessRecovery fixture 改为只通过合法 Turn 边构造数据。
