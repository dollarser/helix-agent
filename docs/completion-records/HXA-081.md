## 决策记录：构建期实现决定（无新 ADR）

1. **PRoot 组件来源 = termux 固定 deb（proot 5.1.107.92 aarch64）**：参考文档背书的路径（「构建期从 Termux package 获取固定组件，SHA-256 lock」）；deb 内含 proot、静态 loader 与 libtalloc/libandroid-shmem 依赖，loader 不另寻来源（`proot-loader` 组件与 `proot` 同 URL/同哈希，语义上分列两组件以便法律页按组件展示义务）。
2. **rootfs = Alpine 3.22.5 minirootfs + 5 工具固定 apk 版本**：基础镜像按 Docker digest 锁定（`sha256:143583…`），包按 `apk add name=version` 精确 pin（53 包全 pin）；可选 `ALPINE_MIRROR` 环境变量换镜像加速（本机用清华源），完整性与镜像无关（每 .apk 由镜像内 alpine-keys 验签 + 最终存档哈希入 lock）。
3. **rootfs 存档不含 /dev//proc//sys**（busybox tar 归档活容器虚拟文件系统必现确定性 short read；且运行时这三个目录由 PRoot 绑定挂载，归 HXA-084）；也不含 Docker 产物（`.dockerenv`、构建挂载点）。
4. **libtalloc 以单个常规文件 `libtalloc.so.2` 交付**（deb 内为 `libtalloc.so.2.4.3` + symlink；APK 资产不承载 symlink，重命名为 loader 期望的 SONAME 文件）。
5. **确定性存档参数**（`deterministic_tar.py`）：路径排序、uid/gid=0、uname/gname 空、mtime=1767225600（2026-01-01 UTC）、GNU 格式、gzip -9 mtime=0——lock 哈希因此可复现（generate 与 verify 两次构建逐字节一致已实测）。
6. **无新 ADR**：PRoot+Alpine 选型、lock 形态、ELF 对齐验证要求均为架构文档 local-code-execution §6.3/6.4 规范文本；本任务为其构建期实现，未触发 `docs/adr/README.md` ADR 触发器。

## 验证中缺陷

1. **（脚本）sh -c 单引号串内注释撇号**：注释中 `build's` 的 `'` 提前终止宿主侧单引号串 → 语法错误；该次运行表面 exit 0（管道吞码）实则 no-op。修复：措辞去撇号 + 脚本内注释警示；此后每次运行都核验真实产物（lock 哈希/资产 mtime）而非只看 exit code。
2. **（构建）busybox tar 归档活容器必现 short read**：`tar cf - /` 递归进 /sys 虚拟文件系统，在本机 Docker VM 上**确定性地**在 `./sys/kernel/warn_count` short read（5/5 复现，非随机 I/O）。修复：`-C / .` + 相对 exclude（proc/sys/dev/out/.dockerenv），并加宿主侧 `tar tf` 全量读回校验（截断即 fail-closed 整体重跑）。
3. **（构建）bind mount 自引用**：raw tar 输出目录 `/out` 在容器 `/` 下 → 存档把自身半成品 tar 打进 rootfs（274 MB 垃圾 + 不可复现）。修复：排除 `./out`。
4. **（平台）AGP 自动展开 `.gz` 资产**：源 `…tar.gz`（51 MB）在 APK 中变成 `…tar`（137 MB raw，deflate 56 MB）——设备端按 lock URL basename 直开必然 FileNotFoundException。修复：内嵌名规则「basename 去 .gz」在设备测试中实现并锁定；HXA-082 安装器沿用同一规则（已在本记录与测试注释中显式记录）。
5. **（测试）instrumentation context ≠ target context 资产**：测试 APK 只带自己的 fixture；读 app 资产必须 `targetContext.assets`。
6. **（测试）`readBytes(int)`/`readNBytes` 是 API 33+**：API 29 设备 NoSuchMethodError 风险 → 改用全版本可用的 `read(ByteArray)`。
7. **（代码）KDoc 内 `lib/*.so` 通配触发 Kotlin 块注释嵌套**（`/*` 未闭合）→ 改写注释措辞。
8. **（重构）fail-closed 检查顺序是契约**：checker 重构时一度把 `phNum==0` 检查挪到 `phOff>=size` 之后，`aZeroPhnumHasNoLoadSegment` 立即抓住（0 phnum 且 phoff 指向尾部的 ELF 应报「no PT_LOAD segment」而非「e_phoff out of bounds」）。顺序已恢复并注释锁定。
