# HXA-212：内置扩展市场与典型 Connector/Skill 目录

日期：2026-09-22。完成应用内内置精选扩展市场（Marketplace）浏览、按类型筛选与一键安装能力，提供典型免鉴权 MCP 服务、受保护 Connector 与本地只读审查/数据库 Skill。该能力运行在客户端，没有新增未授权网络外呼或模型重放。

## 交付与使用

打开“扩展”导航页面（`ExtensionsScreen`），顶部提供“发现市场”与“已安装与自定义”双 Tab 切换：
1. **分类浏览与搜索**：支持在“全部”、“Connectors”、“MCP”、“Skills”之间过滤，支持关键字检索与标签快速联动过滤，精选扩展扩充至 9 项；展示条目名称、简介、作者、类型标签及安全鉴权要求（免鉴权、需要 Token、需要 API Key、本地安全执行）；
2. **详细信息与展开**：支持展开查看各项目的详细功能说明及受保护端点的鉴权指引；
3. **一键安装、降级覆盖与生命周期**：
   - 未安装项展示“一键安装”按钮，内置安装防抖锁与“正在安装…”动态反馈；
   - 纯端侧安装：Connector/MCP 写入 `ConnectorService`，本地 Skill 导入并注册至 `SkillRepository`；
   - 支持降级覆盖与重新安装：系统不限制降级安装；当目标包哈希变化时先卸载再安装目标版本（成功路径）；本记录不证明替换途中失败保留或强杀安全，后续改进归 HXA-129；卡片展开后提供“重新安装”入口支持原地覆盖；
   - 原地停用与卸载：支持在展开卡片内直接停用/启用端点与技能，以及唤起带凭据清理提示的二次确认弹窗执行完整卸载；
   - 遵循默认未激活规范：新安装项呈现“未激活/待配置”标签，并提供“去配置”按钮一键平滑跳转至“已安装与自定义”管理页，由用户显式开启端点或配置 Secret；
   - 卸载联动：当用户删除 Connector 后，市场卡片状态自动精确恢复为未安装，支持安全重装。

决策记录：[ADR-CONNECTORS-005](../adr/connectors/005-curated-marketplace.md)。
