# HXA-172：归档列表、共享存储入口与上下文用量

Date: 2026-09-09
Status: completed

## 交付与边界

普通会话列表只显示未归档会话；“已归档会话”进入独立列表，支持打开历史、改名和返回，保留原数据，不新增自动删除。系统返回从归档列表回到普通列表。真机原有归档会话已核实只出现在归档列表。

文件首页在本地文件之后增加共享存储位置，集中列出已授权共享来源、SAF 添加入口和原权限页快捷链接；普通首页不再重复显示共享访问设置。两个 flavor 共用入口，未扩大所有文件访问权限或 Agent 根目录。现有共享来源仅支持浏览、预览与分享，未宣称全盘读写或 consumer 已取得 MANAGE_EXTERNAL_STORAGE。Google Play 文件管理用途有申报/审核条件，不能保证无上架影响。

对话输入选项栏增加可点击上下文圆环，继续单行横向滚动、每项独立胶囊。数据为当前 endpoint/model 最近一次请求的持久 inputTokens，不累计整个 Turn；未知窗口/usage 显示问号，超过上限仍保留超过 100 的数字，环形填充限于 0～1。详情说明不包含后续输出与草稿。真机旧会话成功读取历史 usage，未发送模型请求。

[现状核实与竞品参考](../development/context-window-and-shared-storage.md)记录：聊天尚未接入自动压缩或窗口设置；probe 返回未知上限；4096 输出限制和 128000 输入预算不是模型窗口。当前 SGLang get_server_info 实测 context_length=262144，但产品未读取该接口，未硬编码这个部署值。Codex、Claude Code、DeepSeek Harness 官方机制只用于后续设计建议，不当作本轮实现证据。
