- 实现的契约：
  - **字符串层（`PathSyntax`）**：拒绝 NUL、C0/DEL/C1 控制字符、超过 4096 字符输入、前导 `/`（正斜杠绝对路径）、前导 `\`（反斜杠绝对路径）、Windows 盘符形式（`C:\`/`d:/`）；`.`/`..` 用栈解析，`..` 越过根即拒绝；段数 ≤64、单段 1..255 字符、非空白。输出为唯一规范形式：正斜杠、无空段、无点段、相对路径。
  - **`WorkspacePath`**：构造即完成上述全部步骤；`value` 恒为规范相对路径（根为空串）。提供 `isRoot`/`parent`（单段路径的 parent 归到根）/`name`/`resolve`；`equals`/`hashCode`/`toString` 基于规范形式。模型只能看到 `value`，workspace 真实位置归平台适配层。
  - **`FileScopePath`**：`scopeId`（1..64，不含 `/` `\` `:` 与控制字符）+ 规范相对路径；`toModelReference()` 产出模型唯一可见形式 `scope:<scopeId>:<rel>`（根用 `.`）。模型引用的 512 字符上限（文档 13：有界输出）在**构造时**失败关闭（`init` 校验 `7 + scopeId.length + relativePath.length ≤ 512`），因此 `toModelReference()`/`toString()` 对任何已构造实例都**不会抛异常**——value object 不变量是“构造成功即 `toString` 安全”，否则字符串拼接/日志/require 消息会抛异常。`fromModelReference()` 对任何畸形/被篡改引用失败关闭并重新规范化，杜绝夹带绝对或逃逸路径。scopeId 不承载引用分隔符，长源 URI（如 SAF tree URI）由适配层映射为短 id。
  - **文件系统层（`PathResolution`）**：`resolveWithinRoot` 顺序执行 (1) `REJECT_SYMLINKS` 下拒绝 symlinked root；(2) candidate 必须 `startsWith(root)`——在任何段级遍历前证明，保证遍历不会爬出 scope 根（规避 macOS `/var`→`/private/var` 这类根外 symlink 误判）；(3) 解析 root 真实位置，symlinked root 下把 candidate 重基到真实根；(4) `REJECT_SYMLINKS` 下拒绝 root 到最终段之间的任何 symlink 段；(5) 要求每个已存在的严格祖先是目录（拦截 `a.txt/b`）；(6) 要求最终规范路径（最终段不解引用）等于或包含于真实根。全部违规以带固定、有界 `message` 的 `PathResolutionError` 失败关闭，不内嵌原始文件系统细节（文档 13）。`FOLLOW_ROOT` 只允许 scope 根本身是 symlink，后代 symlink 仍须落在真实根内。
  - **scope 边界**：`ScopeRootResolver` 把 scopeId 解析为真实根（只供执行层，绝不回传模型）；`resolveFileScopePath` 是模型规范路径到真实绝对路径的唯一收敛点。
- 未实现/明确排除：不注册 `read`/`write`/`edit` 生产工具（归 HXA-042）；不做 Artifact/配额/原子写（HXA-041）；SAF/All-files 适配层实现（HXA-044/045）只提供 `ScopeRootResolver` 契约位，真实根查找留到平台模块；不改变 Tool Dispatcher/Scheduler、Approval、Policy 或 Room schema。
