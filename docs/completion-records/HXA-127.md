# HXA-127：大 catalog 渐进工具发现

Date: 2026-09-08
Status: completed

## 交付

新增内置 `tools.search`，只搜索当前 registry 中由既有 MCP 启用流程注册的工具；按名称/描述匹配，默认 8、最多 16 个。小 catalog 保持直接暴露；大 catalog 的完整 schema 在搜索后进入下一次模型请求，每会话替换有限窗口，最多保留 128 个会话。进程重启清空发现窗口，可重新搜索；发现不是启用、授权或审批。

ChatService 的首次请求与 Tool Loop 请求都接入同一曝光筛选；mode 先筛选，最新完整 descriptor 不匹配、停用或移除即不再出现在窗口。工具契约 hash、Dispatcher、动态 Policy/Approval、实际执行前 bridge 校验保持原状；没有修改 core、存储、MCP transport 或依赖。

此优化控制模型 schema 上下文，不改变握手 tools/list 拉取边界；500 项为聚合 registry 合成夹具，不冒充真实厂商的大 catalog 验收。检索采用确定性文字匹配，不引入嵌入模型或远端搜索服务。
