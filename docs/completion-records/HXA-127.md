# HXA-127 完成记录：Codex 订阅最小模型 Smoke 与实验边界收口

日期：2026-09-06

## 结果

- 在 `com.helix.runtime.cli` 独立 UID 的可见 Codex 页面增加用户主动触发的极小模型测试。
- Runtime 从自己的 Keystore vault 读取凭据；主 App、Binder、UI、日志均不获得 token 或 account id。
- 先查询 `https://chatgpt.com/backend-api/codex/models?client_version=0.153.4`，再调用
  `https://chatgpt.com/backend-api/codex/responses`。请求只含固定 `Reply exactly HELIX_OK`、无 tools、
  `store=false`、streaming；客户端在 64 字符或 256 KiB 时立即失败并关闭流。
- API 36 arm64-v8a `emulator-5600` 使用 HXA-126 留存的真实 Codex 订阅 vault，模型目录选择
  `gpt-6-astra`，真实返回精确 `HELIX_OK`。这是少量真实订阅额度的正向模型调用证据。
- 第一次请求发现公开 Responses API 的 `max_output_tokens` 在该消费订阅 endpoint 返回 HTTP 400；
  移除该字段后仍因首个目录模型不接受 `reasoning.effort=minimal` 返回 `unsupported_value`；按参考
  adapter 的实际请求形状省略可选 reasoning 后成功。没有重放任何结果不明确的成功请求。

## 边界与决定

- 这不是 Provider/Tool/Job：不接受任意 prompt，不进入 Chat/Act/Goal，不提供跨 APK 模型事务，
  `agentBackendState` 仍为 `NOT_REGISTERED`。
- 后续生产 adapter 仍需独立 HXA 完成统一 `ModelEvent`、发送门控、Binder/PFD、持久 jobId 查询、
  取消/断连对账、Verification 与 Audit；在此之前不得把 smoke 宣称为订阅后端完成。
- Claude/Grok 没有付费订阅，付费模型调用暂记“未核实”，不是失败或成功。
- 官方 CLI/SDK Android/bionic 打包路线依 HXA-111/112/117 证据以低可行性停止，不用非官方重打包
  或兼容层伪造成功。
- 供应商未公开授权 Helix 分发第三方 OAuth identity/消费订阅接口；此功能仅存在于
  developer/Advanced 个人侧载实验，不进入商店发行。
- 本 HXA 落在 accepted ADR-0021 的个人侧载与 Runtime 凭据边界内，且未新增跨 APK Job/Provider
  架构，因此无需新 ADR。
- 决策记录：无需新 ADR；固定可见 UI smoke 不改变 accepted ADR-0021 的 Runtime-owned 凭据边界，
  也不改变 ADR-0007 的跨 APK Job 生命周期。生产 Provider/job 仍需后续独立 HXA。
