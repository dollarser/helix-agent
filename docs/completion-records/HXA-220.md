# HXA-220：Core Engine / TurnEngine 生命周期收敛

日期：2026-09-26。分支 `refactor/clean-slate-engine`，完成记录时工作树基线 HEAD `025af1ad852369ab3c1782f7bc345fca76ab570b`。本任务按项目尚未正式上线的 clean-slate 原则完成，不保留废弃 same-Turn 兼容路径。

## 交付

- TurnEngine 已成为 Turn durable + live execution owner：admission、cancel、review park/resolve、startup recovery、AgentLoop driver、terminal settlement、live registry、Goal timer/cancel signal 与 per-Turn observation 均从同一 Engine 边界进入。
- 新增 Engine-owned `TurnExecutionDriver`：负责 worker coroutine/start gate、AgentLoop 调用、异常分类、durable terminal/review settlement 与 live owner release。durable settlement 后的 UI/reminder/queue hook 异常被隔离，不再反向改写 Turn truth。
- 新增 Engine-owned `TurnObservationHub` + Room-backed `TurnRuntimeView`。late subscriber 以 Room durable state 兜底；Chat UI `StateFlow` 只做投影。
- 删除 `AgentTurnHost` 与 Chat-owned `TurnLiveFrames`；`AppAgentRuntime` 仅保留 core contract 到 command/runtime view 的薄适配。
- 删除旧 `core:agent` serial `TurnReducer/TurnEvent/TurnEffect/TurnState` 及其专属 tests；保留仍被当前模型预算使用的通用 token accounting，并独立为 `TokenAccounting.kt`。
- 删除 Turn-level `WAITING_APPROVAL`。审批等待只由 durable `ToolCallState.AWAITING_APPROVAL` 表达；Tasks/foreground/UI 从 ToolCall fact 派生 `awaitingApproval`，不再维护第二套 Turn approval phase。
- process death / review 采用 old Turn execution-terminal + successor Turn continuation；review 不创建 old Turn 的下一 ModelCall，Goal continuation 创建新的 GoalRun。
- `turn_runtime_records` 不再承载 same-Turn review receipt/old ModelCall identity；Turn review command 幂等由 immutable `turn_review_receipts` 承担，逐 ToolCall effect truth 由 `tool_call_reviews` 承担。
- 删除已失效的 parked `INTERRUPTED -> CANCELLED` device oracle；`INTERRUPTED` 现在是 execution-terminal，后续工作通过 successor Turn。

决策记录：本任务落实已接受的 [ADR-AGENT-001](../adr/agent/001-turn-coordination.md) 与 Goal 生命周期约束，没有新建替代 ADR；clean-slate 数据库历史重置被明确拆到 HXA-221，未混入 TurnEngine owner 收敛。
