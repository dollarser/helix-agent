# HXA-115 完成记录：独立 Runtime 凭据 vault

**日期**：2026-09-05

**状态**：完成。项目所有者明确接受 [ADR-0021](../adr/0021-third-party-subscription-protocol-adapter.md)
后，本任务只落实新的凭据所有权边界；订阅登录和模型后端仍不可用。

## 实现与边界

- access/refresh/id token 只写入 `com.helix.runtime.cli` 自己的 app-private 目录，使用该 UID 的
  Android Keystore AES-256-GCM key；每次写入随机 IV，文件权限固定为 `0600`，临时文件通过
  原子 rename 覆盖。
- schema 只接受 version 1、已知字段、非空 access/refresh token 和正 expiry；每个 provider
  独立 alias，明文上限 16 KiB。认证失败、未知字段与非法值均 fail closed。
- Runtime status 会实际解密并校验现有记录，只返回每个 provider 的 `LOGGED_OUT`、`LOGGED_IN`
  或 `CREDENTIAL_ERROR`；不返回 token、expiry 或账号标识。
- logout 幂等删除对应 provider 文件。未读取浏览器、Claude Code、DSH、主 App 或其他 CLI
  credential，未发起 OAuth、refresh、模型请求，也未注册 Provider/Job。

## 测试与设备证据

- JVM：5/5；保存/读取/覆盖、provider 隔离、幂等 logout、封闭 provider 集、未知 schema、
  超限、空 token 与非法 expiry。
- `Helix_API_29`：API 29、arm64-v8a，6/6 androidTest 通过。
- `Helix_API_36`：API 36、arm64-v8a，6/6 androidTest 通过。
- 设备测试覆盖 Keystore round-trip、原子覆盖、`0600`、密文篡改认证失败、redacted error、
  logout 删除，以及 Runtime APK 仍只有 `INTERNET` 权限。

## 决策记录：ADR-0021 与已知限制

[ADR-0021](../adr/0021-third-party-subscription-protocol-adapter.md) 已由项目所有者于 2026-09-05
明确接受。它不改变 accepted ADR-0007 的独立 UID、冷绑定和断连对账要求。供应商授权、固定
adapter 依赖/许可证闭包、OAuth 可见 UI、撤销、协议兼容、限额、模型流、Tool/Approval 转换和
jobId 恢复均未在 HXA-115 实现，必须由后续独立 HXA 验收；因此不得宣称订阅已可使用。
