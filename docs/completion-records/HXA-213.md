# HXA-213：按消息创建会话分支

日期：2026-09-22。完成 consumer/developer 共用的用户主动 fork、持久化与本任务主机/设备验收。独立分支 `codex/session-fork` 基于压缩补强 `5c2a11df`；未混入并行 marketplace 工作，未合并 main、推送或发布。

## 交付与使用

在已保存的用户或助手消息旁选择“从这里新建分支”，创建并打开独立新会话。继承截至该位置的完整历史、可适用的压缩摘要和附件引用，原会话不变；不自动发送模型请求。损坏后缀可以通过选择它之前的完整消息绕过。无法读取或验证所选前缀时明确失败，不伪称所有损坏都能自动恢复。

分支使用新的会话/消息 IDs，来源 session、请求/实际边界、消息身份映射及摘要来源持久保存为版本 1 的 `SYSTEM / SESSION_FORK` 元数据，并记录 `session.fork` 用户审计。来源元数据不进入模型上下文。页面说明权限使用新会话默认值、文件不复制/回滚、原会话任务独立运行。流式未落库文本没有分叉按钮。

这是应用能力，没有新增 Agent Tool、子 Agent、工作流服务或 Runtime。

决策记录：[ADR-AGENT-007](../adr/agent/007-session-fork.md)。

## 实现不变式

- 一次 Room 事务提交新会话、默认权限、历史引用、附件绑定、检查点与来源；失败或事务中取消没有半个可见分支。无需 schema 迁移。复制操作在 IO 上执行，有并发点击保护，切换会话后完成不会把用户强行跳回。
- 历史不携带新执行身份：`turnId` 为 null，不克隆 Turn/ModelCall/ToolCall 执行记录、Goal、Job、审批或用量。Provider/模型选择延续来源；权限与工作目录按新会话处理，不继承旧授权。
- 工具调用和全部结果保持完整配对，批内截点退到此前完整位置。损坏 JSON、缺失工具正文、跨会话目标明确拒绝；不能静默跳过坏记录。原任务的副作用及未结算工作不会被撤销或重放。
- 仅复用截点之前的最新检查点；重映射覆盖序号/保留 IDs，并保持它相对于历史消息的位置。嵌套分叉不丢掉已适用的摘要，后续摘要也不能泄漏未来消息。继承历史继续可压缩，最近完整工具批及其后续文本保留。
- 消息正文复用 ContentRef；绑定附件使用新会话拥有的 Artifact 元数据与同一文件路径/hash，绑定时 hash 保留。删除原会话不级联删除分支附件，已有全局引用计数保护共享正文/文件；后续物化仍验证可用性和 hash。
- 每页 256 条元数据，所选前缀最多 8192 行，活跃正文累计最多 8 MiB。超限不静默截断。已覆盖正文只复制引用；这些上限不是全应用内存峰值保证。
- UI 将无执行身份的继承历史置于新 Turn 之前；原工具执行详情仍属于原会话，不为分支伪造任务卡。

## 边界

继承的是持久历史，不承诺复现字节完全相同的旧网络请求；系统提示、工具与能力使用当前配置。文件仍共享，不提供独立工作目录快照或外部效果回滚。超限或所选前缀本身损坏时仍需选择更早位置；本次没有自动摘要救援、分支图或历史编辑。
