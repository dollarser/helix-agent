- 实现的契约：
  - **目录布局（`WorkspaceLayout`）**：`input/`、`work/`、`output/`、`.helix/`（`metadata.json`、`trash/`、`executions/`），与架构文档 §10 一致。`ensureLayout` 幂等地创建缺失目录、保留已有 `metadata.json`。region 归属是**规范相对路径首段**的逻辑判断（`regionOf`），不是真实路径前缀比较——后者在 scope 根本身是 symlink 的文件系统上（macOS `/var`→`/private/var`）会误判。
  - **原子写（`AtomicFileWriter`）**：目标同目录随机后缀 temp → 全量写入 → 文件 channel fsync → 目录 fsync（使 rename 在掉电后仍持久）→ `ATOMIC_MOVE + REPLACE_EXISTING` 发布。读者永不见半写文件；写中断只留下可回收的孤儿 temp。`cleanup`/`cleanupRecursively` 回收孤儿 temp；递归版从 scope 根走、**不跟随 symlink 子目录**（防经符号链接逃逸 scope），覆盖叶子之外目录（嵌套 `work/a/`、`.helix/metadata.json`）的 temp。
  - **前置 hash（乐观并发）**：`writeAtomic(target, bytes, expectedPreviousSha256)` 在动盘前比对目标现有 SHA-256；不匹配（含目标缺失，报 `missing`）以 `PreconditionHashMismatch` 失败关闭，不改任何文件、不留 temp。
  - **配额（`WorkspaceQuota`）**：递归统计 scope 下常规文件总大小（symlink 记 0、不跟随）。`ensureRoom` 在**动盘前**准入（拒绝时不建 temp）。对**串行写者**是硬保证：`usageBefore + bytes ≤ max` 推出原子替换后 `usageAfter = usageBefore − old + bytes ≤ max`；**跨会话并发写者**（文档 §12 仅按会话串行）可令总额超限，由下一次 pre-check 拒绝——超限被报告而非回滚（回滚=删除已持久化的成功写入，是数据丢失）。
  - **bounded MIME/encoding（`ContentProbe`）**：只读固定前缀（8 KiB），永不读全文件，杜绝把探测当 DoS 通道。分类 `UTF8/UTF16/BINARY/EMPTY`（BOM、NUL、严格 UTF-8 连续性校验）；MIME 由数据驱动 magic 表 + 少量文本启发式得出，未知回退 `application/octet-stream`。歧义即报 binary/octet，fail-closed 交由上层策略。
  - **Artifact 登记（`WorkspaceArtifactStore`）**：单一生产门面，编排 resolve→containment→region→配额 pre-check→前置 hash→原子发布→探测→登记。登记走调用方注入的 `ArtifactSink`（Room `artifacts` 表的 seam），顺序严格为**先写文件并算 hash，再登记**（架构文档 §9.2）。文件是权威，sink 失败不回删文件（登记可重试）。`resolveFileScopePath` 是唯一模型引用→真实路径收敛点，真实路径永不回传模型。
- 未实现/明确排除：不注册 `read`/`write`/`edit` 生产工具（归 HXA-042，`read` 的 offset/maxBytes 语义在那实现）；不做 Copy/Move/Delete/Trash 的冲突与恢复语义（归 HXA-043，本任务**不**暴露任何删除/移动 API，`WorkspaceArtifactStore` 无 delete/move）；SAF/all-files 真实根解析（归 HXA-044/045）仅由 `ScopeRootResolver` 契约位承接，生产实现在平台模块；不改 Tool Dispatcher/Scheduler、Approval、Policy 或 Room schema（`ArtifactSink` 是注入 seam，不在本任务接入 Room）。配额是**容量**上限（字节数），未做文件数上限——roadmap HXA-041 只要求"配额"，文件数约束归后续容量任务。
