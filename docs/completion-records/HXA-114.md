# HXA-114 完成记录：DSH subscription adapter 来源、凭据与条款 Spike

**日期**：2026-09-05

**状态**：**静态研究完成，生产实现未获准**。插件证明第三方 JavaScript adapter 可以直接把
消费订阅包装成模型 Provider，但它不是官方 CLI，且改变了 Helix 既有凭据所有权和服务端
接口边界。

## 实际证据

- 本地安装：`dsh-plugin-subscriptions@0.6.0`，package 声明 MIT。
- 2026-09-05 registry 查询：latest `0.7.0`，说明本地证据不能自动代表后续版本。
- 本地固定 SHA-256：
  - `package.json`：`63b91161fb4d2ef7fb4768539fa7525e0c4b07dd5107e82cc3957094339c506f`；
  - `LICENSE`：`1fcf4016009aa6dd0bd490f6fdaf0552424a1052ca8d2c59a09da3eb7e2cd722`；
  - `lib/auth/store.js`：`8dca713c60a3c9c5c2d2962e9ad4b2063c11e450e88499ccf9ae2b3673b16968`。
- 插件在自己的 `auth.json` 保存 access/refresh token；Claude 路线可读取并写回 Claude Code
  Keychain/credential 文件。Codex/Claude adapter 固定 CLI OAuth client identity 并直接调用
  subscription endpoint；Claude 还生成 CLI identity User-Agent。
- 插件工具通过 DSH `defineTool` 注册，README 明确 approval policy 在其他插件；相关 auth 和
  Codex/Claude provider 模块没有 Android Binder、durable journal、`jobId` 查询或
  `DeadObjectException` 恢复契约。
- 审计没有读取用户真实 `auth.json`，没有发起登录、token exchange、usage/model 请求或模型
  推理，也没有把第三方代码复制进 Helix。

不构成法律意见。MIT 只覆盖插件代码，不能替代服务端授权或依赖许可证闭包。
