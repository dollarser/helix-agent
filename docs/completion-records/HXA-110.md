## 交付

- `runtime/cli-app` 使用独立 applicationId `com.helix.runtime.cli`。manifest 只声明 `INTERNET`，无 All-files、Storage、Accessibility、Root、通知、前台服务或主 App 私有数据权限。
- exported bound Service 由 signature permission `com.helix.permission.BIND_CLI_RUNTIME` 保护；无 launcher、started-service、FGS、receiver 或自启动入口，`onUnbind()` 返回 false。事务侧按实时 Binder caller UID 复核唯一主 App package 与自身签名证书；API 30+ 使用精确 `<queries>`，不使用 `QUERY_ALL_PACKAGES`。
- 严格 `cli-runtime-lock.json` 拒绝未知/缺失字段、非固定版本、非 HTTPS、非法 SHA-256、重复/缺少基线 artifact，以及 HXA-111/112 前的 `bundled=true`；canonical encoding 与 SHA-256 可稳定复算。
- 有界状态查询只返回 protocol/runtime/ABI/lock 指纹、bundled artifact 数和真实的 `UNAVAILABLE_BEFORE_HXA_111`；不返回 token、cookie、路径、approval proof 或 CLI 输出。
