# HXA-072 MCP 动态 Tool bridge（完成记录）

- 日期：2026-09-05
- 前置任务：HXA-071（commit `d6136b3`）
- 状态：完成

## 交付范围

- 把用户启用的 MCP tool 注册为 `mcp.<server>.<tool>`，来源携带 server ID、协商协议版本、schema hash 与 server hints；服务端 `readOnly`/`idempotent` annotation 仅保留作提示，不能降低 NETWORK 风险或把调用变成可重放。
- 输入 schema 只接受 Helix 支持的安全子集；越界 schema 在注册前 fail closed。schema/hash 变化替换动态 contract，使旧审批绑定失效。
- MCP 结果块与 structured content 经有界 JSON 输出；调用走现有 Dispatcher/Policy/Approval/Audit 管线。
- 每次网络调用形成只含 origin/residence/类别/scope/参数 hash/字节计数的 `EgressSummary`；endpoint、schema、数据类别或 scope 变化触发 checkpoint。Advanced 长期规则继续精确绑定 server/origin/类别/scope/有效期。
- sampling、elicitation 与 roots 未开放。
