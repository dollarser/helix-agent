# HXA-104 隐私/诊断/删除（完成记录）

- 日期：2026-09-05
- 目标：提供无第三方 analytics 的本地脱敏诊断证据，并收口会话、Provider、MCP、A2A、Skill、Goal、Workspace、站点数据和 Root session 的显式永久删除语义。
- 前置任务/commit：HXA-103，`198e2f7`。
- 实现：进程启动安装 60 秒 heartbeat 与 uncaught handler；handler 仅保存异常类型和最多 32 帧 stack 的 SHA-256 后继续委托系统 handler。所有版本保存 allowlisted process state、最后 Turn/correlation/state；API 30+ 最多读取 8 条 `ApplicationExitInfo` reason/status/timestamp/importance。诊断预览为显式 allowlist JSON，编码上限 16 KiB，不包含 prompt、Tool 参数/结果、通知/文件正文或异常 message。
- 删除契约：普通会话移除仍是 archive。独立 `PrivacyDeletionService` 不进入 Tool Registry；活动 Turn 会阻止永久删除。Room 在事务中级联会话执行证据、receipt 与相关 audit，content-addressed 正文和 Workspace path 仅在无存活引用时物理删除。Provider/MCP/A2A 删除配置与 Secret alias；Skill 清理私有 trash；Goal 清理 run、audit 与无引用 Plan；站点数据清理 cookie/cache/history；Root 仅关闭当前 session。PRoot Runtime 保持 HXA-087 已有 companion 可见确认删除，不跨 UID 伪造擦除；CLI Runtime 的 credential logout/uninstall 仍由 M11 实现与验收。
- 自动测试：`./gradlew test spotlessCheck detekt --no-daemon` 最终 exit 0；解析全仓 XML 为 2,392 tests、0 failure、0 error、0 skipped。首次运行 exit 1，原因是 5 个 fake DAO 缺少新增删除接口实现；补齐精确 fake 后通过。`git diff --check` exit 0。
- 设备测试：`ANDROID_SERIAL=emulator-5554 ./gradlew :core:storage:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.helix.core.storage.PrivacyDeletionDeviceTest --no-daemon` exit 0，API 29 为 2/2；同命令 `emulator-5556` exit 0，API 36 为 2/2。`ProcessDiagnosticsDeviceTest` 在两台分别 4/4、0 skipped，覆盖正文排除、16 KiB 界限、非法状态/ID拒绝、handler 委托和 API 分支。
- 设备事实：`emulator-5554`，Android SDK built for arm64，API 29，arm64-v8a，4,096-byte page；`emulator-5556`，sdk_gphone64_arm64，API 36，arm64-v8a，4,096-byte page。一次并行 API 36 构建因两个 Gradle 进程竞争同一 dex/classpath snapshot 而 exit 1；串行重跑均 exit 0，不把该基础设施失败算作测试通过。
- 未验证边界：没有产生真实 crash/ANR/low-memory kill 的 `ApplicationExitInfo` 样本，没有 24 小时 instrumentation + logcat/ANR + exit-reason 联合证据，也没有物理设备或 16 KiB page-size 证据；这些仍是 release 阻断门禁，不能由短时 emulator suite 或 App 内 watchdog 替代。跨 Room 与文件系统的不可分割电源中断窗口仍按幂等重试/残留不可访问文件处理，不声称具备跨介质原子事务。
- 权限/依赖/网络/许可证：无新增权限、依赖、网络端点、analytics 或许可证；未升级依赖。
- 决策记录：不适用；实现遵循既有 archive、Secret 所有权、companion UID 与诊断边界，没有把 proposed ADR 当作 accepted。
- 后续：HXA-105 只能进行 ADR-0009 所述 developer/Advanced 有界只读 Spike；不得进入生产 Tool Registry。
