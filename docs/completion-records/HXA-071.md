## 交付范围

- `McpServerConfig` 保存规范化 endpoint、可选 SecretStore bearer alias，并始终以 disabled 状态创建；公开明文 HTTP 在配置阶段拒绝，loopback/LAN 仍须经过运行时 endpoint gate。
- `McpHandshakeService` 在读取凭据和发出请求前先执行网络门控；bearer 值仅存在于连接测试调用期，不进入配置、快照或日志。缺失、空、过长及含非法字符的 bearer 均 fail closed。
- 连接测试执行 initialize/协议协商，并保存规范 origin、residence、server identity、capability，以及 tools/resources/prompts 的有界 metadata/hash；不调用 `resources/read` 或 `prompts/get`，正文不进入 Context。
- metadata 对条目数、文本、schema、prompt 参数与总字节数分别设上限；超限拒绝。schema hash 使用规范 JSON，字段顺序变化不改变 hash。
- 首版只支持手工 bearer；未实现 OAuth/PKCE，也不把已配置 bearer 等同于高敏数据出网授权。
