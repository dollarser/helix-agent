# HXA-090 Accessibility Service 与权限中心（完成记录）

- 日期：2026-09-05
- 目标：实现由用户在系统设置中显式启用的 Accessibility Service、实时 service state、包 allowlist、限时 `AutomationSession` 与前台立即停止入口；先用自建 fixture App 验证，不接 Agent Tool Registry。
- 前置任务/commit：`main@acc8540`（`docs: record integration and device lessons`）。
- 修改文件：`tools/automation/**`；`app/src/main/kotlin/com/helix/app/capability/SystemCapabilityResolver.kt` 及其设备测试；根 `build.gradle.kts` 的 Android test 依赖版本目录；`tools/automation/gradle.lockfile`。
- 实现的契约：系统设置显式启用后才建立连接；service state 区分 `UNAVAILABLE` / `DISABLED` / `ENABLED_DISCONNECTED` / `CONNECTED`；allowlist 仅接受规范 Android package name，缩减 allowlist 会立即停止受影响会话；同时只允许一个 session，目标必须是 allowlist 子集，TTL 固定不超过 5 分钟、步骤硬上限 30，时钟回拨与到期均 fail closed；service 断连、用户停止、通知停止和用户撤销 service 都会同步清除会话；运行中使用 `specialUse` 前台服务及常驻通知停止动作；consumer 合并 manifest 不包含该能力，developer 合并 manifest 包含；App capability resolver 以 `GET_META_DATA` 读取 Accessibility service 元数据。
- 未实现/明确排除：不读取节点树，不生成 node token，不执行 click/type/scroll/global action，不接 Agent Tool Registry；这些分别属于 HXA-091/092。未新增坐标点击、脚本桥、Root 或新的 Maven repository。
- 自动测试：11 例 JVM 单测覆盖 package 校验、allowlist、单 session、TTL/到期、时钟回拨、显式停止和 allowlist 收缩；1 例综合 instrumentation 在每台专用设备上真实启用 service，并覆盖 manifest、连接状态、非 allowlist 拒绝、fixture session、通知广播立即停止、`disableSelf()` 撤销及原 enabled-service 集合恢复。
- 手工验证设备：`Helix_M9_API_29`（`emulator-5558`，API 29，arm64-v8a）与 `Helix_M9_API_36`（`emulator-5560`，API 36，arm64-v8a），均为 M9 专用 1080×2400 @ 420 dpi AVD；未使用 M8 设备。API 29 另以直接 `am instrument` 复核同一测试 APK，1/1 通过。
