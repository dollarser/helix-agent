# HXA-112 完成记录：Claude Code stream-json/SDK Spike

**日期**：2026-09-05

**状态**：**Spike 完成，Claude Code 打包路线停止**。官方 `linux-arm64-musl` native artifact 存在，但直接依赖 Android 不提供的 musl loader，且 Anthropic 未声明支持 Android/Termux；不使用 PRoot、兼容层或非官方重打包伪造成功。

## 结论与范围

- npm `@anthropic-ai/claude-code@2.1.260` 公开可选依赖 `@anthropic-ai/claude-code-linux-arm64-musl@2.1.260`；后者 metadata 明确 `os=linux`、`cpu=arm64`、`libc=musl`。
- native tgz 为 94,607,236 bytes，SHA-256 `b20054d917ac2faa1ed2d9cc2139924eeaed352d0193374886eb4eea6f1e7417`；其中 `claude` 是 AArch64 ELF，interpreter 固定 `/lib/ld-musl-aarch64.so.1`，许可证文件指向 Anthropic legal agreements。
- API 29/36 arm64-v8a 的 Android shell 直接执行均失败：`timeout: exec ...: No such file or directory`。这是 loader/用户态不匹配，不是网络、登录或主 App 实现错误。
- Anthropic 官方支持矩阵列 macOS 13+、Windows、Ubuntu 20.04+、Debian 10+、Alpine 3.19+ 与 x64/ARM64，没有 Android/Termux。公开 CLI 确有 `--print`、`stream-json`、`--max-turns`、`--max-budget-usd`、`--permission-prompts none` 等接口，但平台门禁先失败，未执行真实登录、凭据、取消或输出洪泛测试。
- 新增 native artifact 到 `cli-runtime-lock.json` 作为供应链证据，仍为 `bundled=false`；生产 APK 不含 Claude/Node executable。

官方资料访问日期均为 2026-09-05：[安装与支持矩阵](https://code.claude.com/docs/en/getting-started)、[CLI reference](https://code.claude.com/docs/en/cli-usage)、[legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)、[npm package metadata](https://registry.npmjs.org/@anthropic-ai/claude-code/2.1.260)、[native package metadata](https://registry.npmjs.org/@anthropic-ai/claude-code-linux-arm64-musl/2.1.260)。

## 验收结果

- `./gradlew :runtime:cli-app:testDebugUnitTest --no-configuration-cache`：严格 lock codec 回归，包括 native artifact 必需项与 `bundled=false` 门禁。
- `ANDROID_SERIAL=emulator-5580 ./scripts/verify-claude-android-spike.sh` 与 API 36 `emulator-5582`：固定 artifact 的 size/hash/tar 成员/metadata/ELF interpreter 通过；两台均只在观察到预期 loader 失败时成功退出。
- `ANDROID_SERIAL=emulator-5580 ./gradlew :runtime:cli-app:connectedDebugAndroidTest --no-configuration-cache` 与 API 36 `emulator-5582`：均 exit 0，3/3；回归四项 metadata、独立 UID/permission manifest 边界与 `bundled=false`。
- `./scripts/check-cli-runtime-lock.sh`：下载四个固定 artifact、重算 hash、核验法律 URL 与 APK 内 lock，确认无 executable/archive/`.so` 入包。
- 通用构建、文档、ADR、secret、lockfile 与 diff 门禁在提交前执行并记录实际结果。

## 缺失证据与限制

- 未执行真实物理设备、应用 UID、Claude 账号登录、凭据隔离、取消、输出限制、恶意工作区、工具拦截或进程死亡对账。平台前置门禁失败后停止打包路线，不能把这些项目写成通过。
- 未引入 `/lib/ld-musl-aarch64.so.1`、Alpine RootFS、PRoot 或 Node；它们可能让 Linux artifact 实验运行，但不会构成 Anthropic 官方 Android 支持，并会扩大供应链和攻击面。
- HXA-113 只能依据当前失败证据形成“不进入 Act/Goal Provider”的兼容性结论，不能补做隐藏 adapter。
