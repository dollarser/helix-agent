## 交付

- app-private `memory/global/` 与 `memory/projects/<project-id>/` Markdown 是唯一正文；不新增 Room 表或竞争性正文。元数据/search index 从文件重建，直接人工编辑在后续读取生效。
- `memory.list/search/read/write/edit/delete` 注册到现有工具管线，模型不能传入任意 Project ID 或访问 Memory root 外路径。写是 LOCAL_MUTATION，按外部文件修改判定，Chat/Plan 不允许；开关不授予权限。
- 使用记忆和自动维护默认关闭；开关由用户设置，模型不能更改。Project key 只由可信解析器提供，当前生产 resolver 返回不可用，不用目录 hash 或 Git remote 推导项目。
- 单文件 32 KiB、每 scope 128 文件/1 MiB；安全文件名、符号链接拒绝、凭据模式扫描、expectedHash 冲突保护、唯一匹配编辑、原子替换与确认删除。
- summary → index/search → topic 渐进披露；只有 session 明确 ALLOW 外部读取时自动注入 summary，总计最多 8 KiB。需要 ASK 时通过普通工具审批，不绕过授权。PromptSnapshot 将 Memory 记为 EXTERNAL_CONTENT / UNTRUSTED 并记录指纹。
- `+ → Reference → Memory` 提供 Markdown 编辑/搜索/删除、开关、系统文档导入/导出。失败保留草稿，导入先预览再保存，关闭记忆不删除文件或已进入历史的内容。
- HXA-227 host runner 支持显式 manifest，保留原默认 baseline；新增 Memory 固定 fixture 清单用于 off/on 与边界证据。
