## 交付

1. **一次发布的安全替换**：Room schema 26→27 保存唯一已提交安装事实，Skill 文件保持不可变。替换前不卸载旧包；准备、取消、空间/数据库写入失败保留旧安装和凭据。提交后只重试无引用内容清理，支持幂等重试与预期 revision 冲突检查。
2. **最小安装归属**：区分稳定安装身份、来源身份、内容 hash 和准确 SkillKey。保护两包共享、独立用户安装及准备中的快照；不按名称认领另一包。旧 JSON 一次性导入，未知旧 Skill 归属保守保留。卸载不删除其他来源或已发送调用仍持有的引用。
3. **会话独立选择**：聊天页的 Connector 面板选择本会话来源，并独立设置新会话默认集合。新会话复制默认值，fork 复制原会话快照；更新保持身份，卸载/同名重装不继承旧选择。组件配置入口继续留在扩展页，打开来源不提升权限或登录。
4. **曝光与执行一致**：Skill list/read/readResource 使用可信会话身份；MCP 目录、模型 schema、Dispatcher、连接前及 tools/call 前检查来源。关闭来源后旧审批不能放行，已发送调用继续结算。普通与 Goal Turn 复用同一工具管线，没有新增特殊调度器。
5. **更新与修复体验**：显示旧/新 hash、组件数量变化，以及包内有界版本标签和作者说明；缺说明时如实显示。URL 或认证配置指纹变化使用新端点身份重新配置，完全未变的绑定保留凭据。清理未完成可见并可重试；支持显式降级。

决策记录：[ADR-CONNECTORS-003](../adr/connectors/003-ownership-and-installation.md)。没有代码 Diff、多阶段通用 journal、历史版本浏览器、多层权限 scope 或新增 Agent 工具。

## 保留边界

- ENOSPC 为确定性故障注入，不是填满物理设备存储；进程强杀不是断电耐久性证明。
- MCP 协议 fixture 使用测试服务显式配置的 Advanced LAN permit，不证明 consumer 产品开放 LAN，不冒充真实 OAuth 账号。HXA-125/126 的真实外部服务验收继续独立。
- 无法证明专属的旧 Skill 保留独立来源，所以关闭旧 Connector 不保证撤销这些历史独立资产；组件开关仍可按原规则禁用它们。未知旧市场版本不按名字自动认领。
- 关闭来源保留历史；发送准入已经通过的调用按原配置结算，不保证网络层撤回远端请求。
- 本记录是本任务定向验收，不是全产品、OEM/Doze 或发行验收。后续工作见[当前计划](../development/next-work-plan.md)，217 仍需接受对应 ADR。
