## 交付与原因

文件、浏览器、扩展、权限、设置、审计使用 CompactPageHeader：同会话页的 48dp 菜单、titleMedium 标题、4dp 水平间距及页面底色，移除原 Material 大顶栏。菜单继续使用原三横线图标。权限目的页抽取为独立组合函数，避免继续增加 HelixApp 分支复杂度。

扩展导航此前仍落入早期 EmptyDestination，显示 M7 尚未实现；实际 Skill 创建/安装与 Connector 管理已接在设置页。新增 ExtensionsScreen 复用这些组件，提供 Skill 创建、ZIP/路径预览安装、Connector 导入、MCP JSON 及已安装端点管理。保留已有设置入口；进入页面不会启用或连接端点。未新增 M7 协议实现或改变凭据/授权路径。

已归档会话不能再次归档是原行为；禁用按钮现在显示“已归档”，不再显示容易误解的“归档”。没有修改真实会话的归档状态。

SAF 说明补充 Android 11+ 目录选择限制及 All files 入口。系统限制来自 [Android SAF 文档](https://developer.android.com/training/data-storage/shared/documents-files)；[All files 文档](https://developer.android.com/training/data-storage/manage-all-files)明确该权限不解除 SAF 限制，也不开放其他 App 私有目录。当前 developer All files 根目录目录表仍仅有 Download、Documents、Pictures、Music、Movies、Podcasts、DCIM，需 live 系统权限和当前 Advanced 状态；没有新增整个 sdcard 根目录能力。
