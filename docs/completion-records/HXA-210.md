## 交付

- 默认会话独立私有目录；稳定资源身份、可选显式项目归属、共享外部绑定、relative subdirectory/revision 与模型请求快照。Android Path 使用只读 allocation identity，无法证明身份时拒绝绑定；失效来源不自动替换为同名资源。
- 请求挂起、排队调用、审批、Job 和旧产物保留原目录；新模型请求读取新目录指令。当前 DENY、工具禁用、系统授权仍在执行前复检。Tool intent 仍先 strip，不参与业务权限和哈希。
- 文件管理、文件工具、项目指令、产物、受支持 Git/终端复用同一绑定。SAF 按实际能力原位访问；保留系统 picker flags 并持久化已授予权限，根查询使用 document URI；不伪造本地 cwd 或静默复制。
- 显式私有目录清理检查会话/请求/产物/备份/任务引用，先 fence、隔离再 purge；外部目录无清理入口。进程重开不自动重放，显式恢复检查身份与冲突。可恢复删除保留校验备份，部分写入不宣称回滚。
