# HXA-177：非阻塞任务列表与 Goal 阻塞恢复

Date: 2026-09-09
Status: completed

后续变更：本记录中的 Goal 强制绑定完成机制已由 [HXA-178](HXA-178.md) / ADR-0040 替代，以下保留当时验收历史。

## 实现与参考取舍

会话顶部和列表新增任务入口，按运行中、待回收、已回收分组；切换会话不停止任务，后台流不覆盖当前会话。结果按持久 Turn 读取，回收只写幂等时间戳，不重跑、不自动注入其他会话。未回收结果没有最近 200 条截断；已回收近期窗口之外的原消息仍保留在原会话。旧任务 ID 的停止操作不能取消同会话的新任务。

Goal 的用户暂停先持久请求再取消当前执行，结算后 PAUSED，可显式 Continue 开新轮。预算耗尽、不可压缩的上下文容量、未决副作用和需要用户配置的验收绑定进入 BLOCKED；不能直接 Continue，修复后显式重新检查转 PAUSED。检查不调用模型、不创建轮次、不重置预算，写用户操作审计。未知副作用优先于用户暂停。进程恢复不重放，预算结算产生的 BLOCKED 不被恢复流程覆盖。

前台服务改为观察全部传输任务，不再观察打开的会话；通知停止和系统超时取消真实任务，Goal 使用暂停路径。此服务不承诺强杀后持续执行或绕过 Android 后台限制。

数据库 v11 为 turns 增加可空回收和暂停时间，旧预算耗尽 PAUSED 迁移为 BLOCKED。原消息、工具结果、预算计数和完成验证权限保持。

决策记录：[ADR-0039](../adr/0039-background-results-and-goal-blockers.md) 记录授权和对 ADR-0004 的局部替代。已阅读所有者提供的 [Goal 使用参考](../references/goal-feature-guide.md) 并核对当前 DeepSeek 官方 round-driver：采用明确暂停、恢复不重放、阻塞原因与准入复查。指南的模型完成判断不替代 Helix 用户绑定证据与 Harness 验证。本 HXA 没有增加自动跨 Turn 续跑、生产子 Agent 或自动把任务结果交给另一个模型。

## 失败与修正记录

- 首次调用用了错误 instrumentation runner，未执行测试；后续改用项目 HelixAndroidJUnitRunner。
- UI 夹具首次在连接探测前启用纯文本回答，导致工具探测失败；移到探测成功后。
- 单线程本地 HTTP 夹具被第一个挂起请求占住，无法证明跨会话并行；使用两个独立 Provider fixture 后通过，不改产品网络语义来迁就测试。
- 两处旧预算恢复断言仍期待 PAUSED，按 ADR-0039 更新为 BLOCKED，保留计数/恢复不重放断言。
- 完成验证类曾误写 chat 包名，产生 initializationError；使用实际 goal 包名后两版本 57 项通过。
- live-schema 对照仍固定 v10，改为对照 v11，保留 v10→v11 和 v1→当前完整迁移链验证。
- 复用尚未退出或端口仍占用的模拟器地址被 runner 拒绝；等待自己进程关闭并使用空闲端口，没有借用其他模拟器。
- ADR 旧文件名触发密钥正则的 sk- 前缀误报；缩短文件名并修复引用，未放宽密钥扫描。
