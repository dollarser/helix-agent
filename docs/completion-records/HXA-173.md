# HXA-173：归档恢复与共享存储根目录

Date: 2026-09-09
Status: completed

## 交付与边界

归档仍保存在 App 私有 session/message 数据及内容文件中，仅设置 archivedAt。会话列表 → 已归档会话 → 恢复，清除归档标记并返回普通列表；不改标题、消息或工作目录，不删除历史。原始首句截取标题的规则保持不变。

共享存储入口直接打开外部共享存储根目录；没有权限时进入系统授权页，返回后重新验证并展示根目录。API30+ 使用所有文件访问，API29 保留 READ_EXTERNAL_STORAGE 与 legacy 兼容声明。两个 flavor 都声明手动文件管理权限；当前根目录浏览/预览/分享为只读，SAF 子目录入口保留。单独的 user-shared-storage resolver 不注册到 Agent 工具作用域。

模型选择和上下文圆环共用一个椭圆，继续保持单行横向滑动。窗口与压缩机制见 [HXA-174](HXA-174.md)。

## 验证

主机联合命令和 JVM 计数见 [HXA-174](HXA-174.md)，双 flavor 构建、完整 lintDebug、双 app lint、Spotless、Detekt、docs/ADR/i18n/secrets/diff 全通过。

独占 API36 arm64-v8a、1080×2400@420：Developer 联合回归 36/36（归档恢复、文件、输入区、导航、停止与压缩等）；Consumer 联合专项 16/16，含归档恢复和共享根目录。两包分别另测拒绝访问 1/1；Developer 授权根目录另测 1/1。共享根目录测试先由外部设置当前 package 与 UID 的 appops，再单独执行对应方法，避免 Android 撤销权限终止测试进程。

```sh
adb -s SERIAL shell cmd appops set --uid PACKAGE MANAGE_EXTERNAL_STORAGE allow
adb -s SERIAL shell cmd appops set PACKAGE MANAGE_EXTERNAL_STORAGE allow
adb -s SERIAL shell am instrument -w -e class com.helix.app.ui.SharedStorageDeviceTest#grantedRootNavigationKeepsFilesReadOnly PACKAGE.test/com.helix.app.HelixAndroidJUnitRunner
adb -s SERIAL shell cmd appops set --uid PACKAGE MANAGE_EXTERNAL_STORAGE deny
adb -s SERIAL shell cmd appops set PACKAGE MANAGE_EXTERNAL_STORAGE deny
adb -s SERIAL shell am instrument -w -e class com.helix.app.ui.SharedStorageDeviceTest#deniedRootHasNoReadableSource PACKAGE.test/com.helix.app.HelixAndroidJUnitRunner
```

PACKAGE 分别为 com.helix.agent.developer / com.helix.agent；只对独占测试模拟器使用，测试后恢复其原 appops。授权用例验证真实根目录文件列表、路径逃逸拒绝、只读来源，并直接调用生产 read 实现证明即使手动浏览已授权，Agent resolver 仍拒绝该 scope。这里的实现层测试不代替 Dispatcher/Policy 的独立验收。

Developer 另经真实系统 UI 验证：拒绝状态点击共享存储，前台进入 Settings$AppManageExternalStorageActivity，打开系统开关后返回 Helix 自动显示共享存储根目录。首次测试曾在进程内撤销权限导致 instrumentation 被系统结束；已改为上述外部控制，没有删除功能断言。

API34 真机覆盖安装保留原会话，归档列表显示 UX-check 的恢复按钮（未擅自恢复用户会话）；共享入口直接列出根目录 21 项；模型/圆环同椭圆和手动压缩入口均已检查。手机截图含真实信息，不入库。
