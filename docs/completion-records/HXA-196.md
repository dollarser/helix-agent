# HXA-196：有租期的独立后台命令 Job

日期：2026-09-24。实现已合入 main 并推送到远端。真机 HOME 键切后台存活、租期控制与主进程硬杀存活已在 OnePlus 6T 物理硬件上通过验收。证据与原始数据见[真机验收记录](../evidence/development/physical-oneplus-acceptance-2026-09-24.md)与[平台实现计划](../evidence/development/hxa-196-platform-plan-2026-09-18.md)。

## 交付与产品接线

- **异步工具套件**：面向 developer 渠道注册 `code.linux.job.start`、`code.linux.job.status`、`code.linux.job.cancel`、`code.linux.job.collect` 工具，复用统一 Dispatcher、209 会话授权预设（三预设与 CUSTOM）、L2 审批流与执行审计。
- **租期控制与独立进程**：后台命令运行在同 UID 独立进程 `:proot` 中，支持默认 300 秒、上限 1800 秒的不可续约租期；超时后由 Runtime 内部定时器强制终止进程树并转入 `TIMED_OUT` 终态。
- **执行准入与所有权管理（`ExecutionOwnership`）**：提交前在主进程持久化绑定 `(sessionId, turnId, toolCallId, executionId)`；严格限制仅原会话原调用可查询、取消或收取结果，防止跨会话越权。
- **主进程死亡与后台存活**：前台通知服务保障后台执行；真实主进程遭遇 SIGKILL 硬性强杀或 Activity 销毁退出时，`:proot` 独立进程保持运行不受影响，并在终态将输出哈希、退出码与执行证明落盘到 `record.json`。
- **Tasks 面板投影与结果导入**：接入任务管理页面，支持只读状态查询、用户手动停止与结果收取（Collect），安全将产物导入工作区；终态对账幂等，不会触发额外模型 Turn。

决策记录：[ADR-RUNTIME-001](../adr/runtime/001-execution-domains.md)、[ADR-RUNTIME-002](../adr/runtime/002-terminal-and-jobs.md)，均为 accepted。

## 验证

- **模拟器专项矩阵**：API29/36 覆盖租期收紧、重复提交幂等拒绝（`REPLY_JOB_DUPLICATE`）、预算耗尽拒绝、绑定中取消、Runtime 异常死亡对账及 PFD 文件描述符回收。
- **OnePlus 6T 物理硬件（`561e3b15` / API 34）全量验收**：
  1. `ProotDetachedJobDeviceTest`：10 项测试全部通过（包括前台运行发送 `KEYCODE_HOME` 挂起至后台、子进程持续执行并成功生成 `DETACHED_OK` 输出验证）；
  2. `ProotDetachedOwnerDeathDeviceTest` + `verify-196-owner-death.py`：真实非 instrumentation 主进程启动后台 Job 后向主进程发送硬性 SIGKILL，实测 `:proot` 原 PID 持续运行并在预算内到达 `SUCCEEDED` 终态，终态证明落盘；
  3. `DetachedJobTasksDeviceTest`：验证 Tasks 界面只读查询、手动取消、权限收紧保护及结果收取。

## 边界与后续

- consumer 渠道完全排除所有后台命令组件与 `:proot` 运行时。
- 后台 Job 终态只作为执行事实，不自动发起模型后续 Turn；长周期自主决策由 Goal 编排机制承载。
- 物理长稳挂机与 16 KiB 页面边界在 HXA-199 终端专项中独立记录。
