# HXA-218：会话工作台 UI 与交互重构

日期：2026-09-22。所有者授权在独立工作树开始重构。本记录仅覆盖第一批呈现层改造，基于 `645fa680`，分支 `codex/ui-interaction-refactor`。

## 交付与使用

- 会话头部保留导航、可重命名标题、返回会话和更多操作。新建与后台任务入口移到可滚动的会话详情 Bottom Sheet，沿用现有会话配置和导出能力。
- 输入区保留模式与模型，独立48dp回复选项按钮打开推理强度和上下文详情。运行锁、输入、发送、停止和上下文压缩仍调用原服务。
- 任务清单默认显示已完成/总数与阻塞数量，展开查看全部原始状态。关闭面板不修改任务或草稿。
- 工具行显示紧凑摘要与展开按钮，请求及结果仍可原地查看；待审批、命令详情和PRoot恢复入口保持可达。
- 全局抽屉按会话、工作、扩展、设置与管理分组，保留全部12个目的地和原导航回栈行为，短窗口可滚动。

共享面板最大内容高度560dp，标题和关闭按钮固定，正文可滚动；触控目标、大字体及完整工具输出通过行为测试验证。没有引入UI直连DAO、Provider或Runtime，也没有新增权限确认。

决策记录：未新增或修改ADR。本切片只调整呈现与导航分组，沿用现有服务和[ADR契约](../adr/README.md)，不改变授权、存储、运行或结果身份。
