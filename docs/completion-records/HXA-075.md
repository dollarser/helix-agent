## 目标

支持本地目录和 zip Skill 的有界导入，在安装前展示 scripts、resources 与内容 hash；拒绝 traversal、symlink、特殊文件和 zip bomb，并以内容寻址快照保证更新不会静默替换运行中固定的版本。

## 实现的契约

- 目录导入只接受普通目录、普通文件和根 `SKILL.md`，拒绝 symlink/特殊文件；复制和再次检查均使用 no-follow 读取，并限制文件数、单文件、总字节和相对路径长度。
- zip 导入接受根布局或唯一 wrapper 布局；拒绝绝对路径、`..`、反斜线、重复项、加密项、symlink/特殊 Unix 类型和多 Skill 根。
- 解包前限制 archive 字节与 entry 总数，解包过程中再次限制文件数、单文件/总展开字节和精确压缩比。entry 枚举达到上限即中止，不先物化无界 central-directory 列表。
- 安装前 preview 枚举 manifest/scripts/references/assets/other 的相对路径、大小、逐文件 SHA-256、总 snapshot hash、兼容性和声明工具；commit 前完整复算，review 后发生任何改变均 fail-closed。
- 安装路径为 `name/snapshotHash/name`。相同内容复用已有快照；内容变化生成新 hash 和新目录，旧快照及其固定引用保持存在，不静默替换。
- staging、安装 name/hash 容器均校验为非 symlink 私有目录；失败 staging 被清理，discard 只能处理当前 service 拥有的 staging 目录。

## 验证中修复

- 原压缩比门禁使用整数除法，实际比率仅略高于阈值时会被截断后放行；改为商和余数的精确比较，并覆盖非整数越界回归。
- 原实现只限制普通文件数，且先把全部 zip entries 物化为列表；大量空目录可绕过文件数门禁并放大内存/文件系统工作。新增独立 archive-entry 上限，并在枚举时有界收集。
- import limits 增加正值和单文件/总量关系校验，避免无效配置形成不清晰或意外放行的边界。
