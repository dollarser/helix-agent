# HXA-197：单个手动 PTY 终端

日期：2026-09-20。完成 developer 单手动终端及本任务要求的主机、API29/36 产品路径验收。终端是应用能力，没有新增 Agent 自动输入工具。

## 交付

- Workspace 文件目录可打开终端，显式启动/连接原会话；真实 PRoot PTY 支持中文 IME、REPL、cwd/env、resize、Ctrl-C/Tab/Esc/Ctrl-D。关闭页面仅 detach，停止会话后显式结算。
- 应用服务与 Agent 执行共享持久 admission；私有 `:proot` 前台服务维护真实 Workspace 映射、单写者、会话身份/generation 和独立租期。默认两小时、最大八小时，断开 idle 三十分钟；PRoot 共享 UID，不承诺目录或凭据隔离。
- Runtime 输出 256 KiB 环、8 KiB 分片和缺口游标；慢页面不阻塞进程。UI 输入按 32 KiB 总字节缓冲并合并碎片，修复短命令快速逐键输入丢字符；超限/不确定输入可见且不重发。
- 固定 termlib 0.2.1 制品，明确 Apache-2.0/MIT 许可证、close 补丁及释放顺序；compileSdk 37/Compose BOM 2026.09.00，targetSdk 36/minSdk 29 不变。consumer 排除页面、依赖、dex 和 native。
- 主进程死亡后连接原 shell；Runtime 死亡不重放，UNKNOWN 保留占用，实际设备重启提供停止证明后才显式结算。进程树关闭不以 EOF 或信号发送成功冒充完成。

决策记录：[ADR-RUNTIME-001](../adr/runtime/001-execution-domains.md)、[ADR-RUNTIME-002](../adr/runtime/002-terminal-and-jobs.md)。实现与演进见[原任务历史](../evidence/development/hxa-197-implementation-history-2026-09-20.md)、[会话接线](../evidence/development/hxa-197-product-session-2026-09-20.md)、[页面接线](../evidence/development/hxa-197-terminal-page-2026-09-20.md)和[最终收口证据](../evidence/development/hxa-197-recovery-closeout-2026-09-20.md)。

## 使用及后续边界

在 developer/Advanced 准备好 Runtime 后，从 Files 的 Local files 进入目录，选择“打开终端”并启动。退出页面后通过同一入口“连接原会话”；结束时先“停止会话”，确认已停止后“结算并关闭”。Runtime 死亡后的 UNKNOWN 不代表执行成功；同一启动周期不能确认停止时，重启设备后查询原会话，再显式结算。
