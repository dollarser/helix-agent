# HXA-198：手动终端多会话与重连

日期：2026-09-20。完成 developer 手动终端双会话并发、多标签切换、单写/只读观察模式降级、容量限制与逐会话独立生命周期管理。终端是应用能力，没有新增 Agent 自动输入工具。

## 交付

- Runtime 多会话管理与有界容量：`ProotTerminalHost` 支持最多 2 个 live 手动终端会话（`MAX_SESSIONS = 2`），超出以 `CAPACITY_EXHAUSTED` 显式拒绝，独立维护每会话进程、空闲追踪与环形缓冲。
- 应用层仲裁与双绑定：`DeveloperManualTerminal` 维护双会话绑定（`binding1`/`binding2`），持有 `ExecutionOwnership` 跨会话互斥锁；当会话 1 结束结算时，若会话 2 仍存活则自动提升并原子替换 admission 记录，严禁提前释放全局执行许可。
- 单写互斥与只读降级：`ManualTerminalConnection` 与 `ProotTerminalEndpoint` 在多连接接入时，首个接入获 `isWriter = true`，后续接入降级为只读观察者（`isWriter = false`），禁用输入写入与终端缩放；当写者 detach 后观察者或新连接可竞争提升。
- 多标签 UI 与零重开会话切换：`ManualTerminalViewModel` 与 `ManualTerminalScreen` 扩展多标签栏（Tab 1/Tab 2 与新建按钮）、当前会话切换（detach UI 订阅后 attach 目标会话，保持 Shell 进程零中断）、只读横幅提示、独立停止与结算交互，及完整多语言资源支持（base / en / zh-rCN）。
- 测试套件：新增 `ProotMultiSessionDeviceTest` 覆盖双会话并发隔离、第 3 会话拒绝、单写连接与只读降级、先结算会话 1 提升存活会话 2 并保持 admission。

决策记录：[ADR-RUNTIME-001](../adr/runtime/001-execution-domains.md)、[ADR-RUNTIME-002](../adr/runtime/002-terminal-and-jobs.md)。前序准备见[HXA-198 UI准备文档](../evidence/development/hxa-198-ui-preparation.md)。

## 使用及后续边界

在 developer/Advanced 准备好 Runtime 后，从 Files 的 Local files 进入目录，选择“打开终端”并启动。用户可在顶部标签栏新建第二个会话并在双标签间无缝切换，切换时后台 Shell 不中断。已达 2 个终端时拒绝新建并提示容量已满。每个终端支持单写多读模式，次要连接以只读观察模式展示。关闭并结算一个会话后，存活会话自动维持全局执行独占并可继续操作。
