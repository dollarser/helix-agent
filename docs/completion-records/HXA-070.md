- 日期：2026-09-05
- 前置任务/commit：HXA-069；M7 非设备实现基线 `acc85400ee79`

## 目标

固定 Android MCP Client artifact 和 Ktor OkHttp engine，在 API 29/36 与 R8 下验证
Streamable HTTP、取消、重连、大消息和 Activity 前后台切换，同时确保 SDK、Ktor、
OkHttp 与 wire DTO 类型不泄漏到 `core:*` 或 `tools:framework` 公开契约。

## 实现的契约

- 生产 MCP Client 底座固定为 `io.modelcontextprotocol:kotlin-sdk-client:0.15.0` +
  Ktor OkHttp engine `3.5.2` + OkHttp `5.5.0`；不携带 umbrella/server runtime。
- SDK/Ktor/OkHttp/JSON-RPC DTO 只活在 `:extensions:mcp`；对外只暴露 Helix 自有
  `McpClientFacade`、`McpClientSession` 和值类型。
- initialize 协议版本来自服务端响应，不硬编码；缺失、嵌套 decoy 或在
  64 KiB 有界前缀之外才出现均 fail closed，不接受 SDK 默认补齐。
- 非 SSE JSON 响应在 Ktor/SDK 缓冲前按 wire bytes 封顶 16 MiB；SSE 按单事件
  16 MiB 封顶，不对健康长连接施加累计上限。
- 认证 transport 仅向精确规范 origin 附加 bearer；DNS 只使用 endpoint gate
  产生的已审查地址集，不跟随 HTTP/HTTPS redirect。
- 关闭或取消不盲目重放；取消后同一 session 仍可用，关闭后可用新 facade
  重新 initialize，SSE 以 `Last-Event-ID` 继续同一连接语义。

## 未实现 / 明确排除

- 不开启 MCP sampling、elicitation 或 roots；不托管 MCP Server。
- OAuth/PKCE、MCP stdio/PRoot、动态 Tool 产品验收分别属于后续 HXA，不是本
  Android Client 底座 Spike 的完成证据。
- 本轮是 API 29/36 arm64-v8a 模拟器证据；签名 release、全 App SBOM/notice、
  多 ABI 与物理真机发布矩阵由 M12 统一验收。
