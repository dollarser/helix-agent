# HXA-091 UI snapshot/token（完成记录）

- 日期：2026-09-05
- 目标：在 HXA-090 的用户会话内读取有界 `AccessibilityNodeInfo` tree，生成绑定 package/window/generation/fingerprint 的短时 opaque node token，并对 null root、敏感界面、`FLAG_SECURE`/custom surface 和节点生命周期 fail closed；仍不接 Agent Tool Registry。
- 前置任务/commit：HXA-090（commit `851f574`）。
- 修改文件：`tools/automation/src/main/**` 的 snapshot model/engine/service bridge；`tools/automation/src/test/**` 的纯 JVM tree/token/recycle 测试；`tools/automation/src/androidTest/**` 的 normal/password/secure-custom fixture 与真实 service 验收。
- 实现的契约：snapshot 必须有 connected service 和 live `AutomationSession`；root package 必须在 session allowlist 且所有遍历节点保持同 package/window，否则拒绝；generation 在 Accessibility event 上递增并立即使旧 token 无法通过 generation 复验；每个 128-bit opaque token 仅保存在进程内，绑定 package/window/generation/128-bit SHA-256 fingerprint/path，30 秒到期，新 snapshot、event、stop、allowlist 收缩或 service 断开立即失效；tree 最多 200 nodes、深度 16、单字段 256 chars、总文本 16 384 chars，任何裁剪显式 `truncated=true`；password / API 34+ accessibility-sensitive 节点和固定系统权限/安装器/Root 管理包返回 `SENSITIVE_UI`；null root 与无法提供有效语义的 secure/custom surface统一返回 `UNSUPPORTED_UI`；不保留任何 live `AccessibilityNodeInfo`，root/已取得 child 在成功、拒绝和异常路径均进入同一 `finally` recycle 边界。
- 未实现/明确排除：不执行 click/long-click/set-text/scroll/back/home/wait，不提供坐标动作，不注册 `ui.snapshot`/`ui.find` Agent Tool；动作前重走 token path 并复验 fingerprint 属于 HXA-092。HXA-093 继续扩展完整敏感包/语义攻击矩阵。
- 自动测试：`:tools:automation:testDebugUnitTest` 共 20 例（HXA-090 11 + HXA-091 9）；新增覆盖完整四字段 token 匹配及每个独立 mismatch、TTL/new-snapshot 失效、200-node/16-depth/256-field/16 384-total-char 上限、package/window 变化、password/denied package、null/custom tree、遍历异常和所有已取得节点回收。
