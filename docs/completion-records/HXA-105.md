# HXA-105 有界只读委托与声明式 Workflow Spike（完成记录）

- 日期：2026-09-05
- 目标：在不进入产品 Tool Registry 的前提下，验证 proposed ADR-0009 的最小边界模型，并判断是否已有足够证据接受生产化。
- 前置任务/commit：HXA-104，`56b7a1f`。
- 修改范围：新增隔离 Android library `:spikes:bounded-orchestration` 及测试；更新 proposed ADR-0009 的事实性验证段；没有修改 `:app`、Dispatcher、生产 Tool Registry、Room schema 或 UI。
- Spike 契约：child depth=1、同时运行≤2、每父 Turn 总数≤4；model call/token/Tool/wall usage 累计到父预算且重建不归零；snapshot≤32 KiB、result≤16 KiB；child 工具必须 `READ_ONLY` 且动态风险≤L1。running 状态重建后进入 `NEEDS_REVIEW`，不自动 spawn/replay；completion 固定 source/trust/hash/evidence refs，并按父 call sequence 合并。Workflow 只接受最多 32 个封闭 node type 的无环 DAG，未知依赖、重复 node、环与超限均失败关闭；没有 JS/Starlark、plugin、Policy node。
- 自动测试：`./gradlew spotlessApply :spikes:bounded-orchestration:test spotlessCheck detekt --no-daemon` 最终 exit 0，6/6 JVM tests。首次 exit 1：构造 `ChildRecord` 漏传初始 `SPAWNED` 且存在 line-length 静态检查；修复后第二次因耗尽预算仍允许零成本 spawn 的边界测试失败，增加 exhausted admission guard 后通过。
- 设备测试：先执行 `./gradlew spotlessApply :spikes:bounded-orchestration:compileDebugAndroidTestKotlin --no-daemon` exit 0。随后 `connectedDebugAndroidTest` 指定 `BoundedOrchestrationDeviceTest`：`emulator-5554` API 29 为 2/2、`emulator-5556` API 36 为 2/2，均 0 skipped。设备均 arm64-v8a、4,096-byte page；API 29 型号 Android SDK built for arm64，API 36 型号 sdk_gphone64_arm64。
- 未验证门禁：没有真实模型/网络 child；没有固定研究/repo/verifier 场景相对单 Agent 的正确率、token、费用、网络字节、峰值内存、热量、电量与墙钟对照；没有真实 Room graph kill-point；没有代表性物理设备 30 分钟并发、后台和热限制证据。因此不能接受 ADR，也不能声称并行收益或生产恢复已验证。
- 结论：HXA-105 Spike 代码范围完成；证据不足以将 ADR-0009 从 `proposed` 改为 `accepted`。产品保持单 Agent，Spike 不进入生产 Registry。项目所有者后续可在补齐收益与真机门禁后接受，或因无明显收益将 ADR 标为 `rejected`。
- 权限/依赖/数据/许可证：无新权限、外部依赖、网络、持久 schema 或许可证；未升级依赖。
- 决策记录：[ADR-0009](../adr/0009-bounded-local-orchestration.md)，状态 `proposed`；本任务没有权限替项目所有者接受或拒绝。
