# HXA-111 完成记录：Codex app-server 登录 Spike

**日期**：2026-09-05

**状态**：**Spike 完成，Codex 打包路线停止**。官方 Linux arm64 artifact 可在 Android kernel shell 上实验启动，但 OpenAI 未声明支持 Android/Termux；按 roadmap 前置门禁未通过，不打包 executable，也不实现或宣称登录/退出/限额验收。

## 结论与范围

- 官方 Codex `0.153.3` release 提供 `codex-app-server-aarch64-unknown-linux-musl.tar.gz`（71,499,996 bytes；SHA-256 `149e20ca79f76eee578e402146910f78647881b33cf0bf146b23ab363e57a281`；Apache-2.0）。
- API 29/36 arm64-v8a 模拟器 shell 可运行 `codex-app-server 0.153.3`，并完成 JSONL `initialize`；返回 `platformOs=linux`。这是 Android kernel 的实验兼容证据，不是应用 UID、认证或厂商支持证据。
- OpenAI 官方 Codex CLI 安装页只列 macOS/Linux、Windows；未列 Android/Termux。故 `CodexBackendEligibility` fail closed 为 `UNSUPPORTED_ANDROID_PLATFORM`，生产 APK 的 lock 继续 `bundled=false`。
- 官方 app-server 文档公开 `chatgptDeviceCode`、`account/login/cancel`、`account/logout`、`account/read` 与 rate-limit 接口；由于平台前置门禁失败，本 HXA 不启动真实登录，不生成、不读取、不复制 `auth.json` 或 token。
- Codex 失败不阻止 HXA-112 对 Claude Code 做独立 Spike。

官方资料访问日期均为 2026-09-05：[CLI](https://learn.chatgpt.com/docs/codex/cli)、[认证](https://learn.chatgpt.com/docs/auth)、[app-server](https://learn.chatgpt.com/docs/app-server)、[release](https://github.com/openai/codex/releases/tag/rust-v0.153.3)、[源码/许可证](https://github.com/openai/codex/tree/rust-v0.153.3)。

## 验收结果

- `./gradlew :runtime:cli-client:testDebugUnitTest :runtime:cli-app:testDebugUnitTest --no-configuration-cache`：client eligibility 4 例与 CLI lock 5 例。
- `ANDROID_SERIAL=emulator-5580 ./scripts/verify-codex-android-spike.sh` 与 `ANDROID_SERIAL=emulator-5582 ...`：均 exit 0；API 29/36、arm64-v8a；archive size/hash、单一 tar member、AArch64/static ELF、`--version`、app-server `initialize`。
- `ANDROID_SERIAL=emulator-5580 ./gradlew :runtime:cli-app:connectedDebugAndroidTest --no-configuration-cache` 与 API 36 `emulator-5582`：均 exit 0，3/3；只回归 HXA-110 manifest/UID 边界，没有把它记作登录验收。
- 通用文档、ADR、lockfile、secret 与 diff 门禁在提交前执行并记录实际结果。

## 缺失证据与限制

- 未执行真实物理设备、应用 UID/SELinux executable、真实 ChatGPT 账号、登录取消、浏览器返回、token 过期、logout/uninstall 删除或账户限额错误。原因不是这些测试通过，而是官方 Android 支持前置门禁已失败，Codex 打包路线必须停止。
- shell 探针的 `/data/local/tmp` 不代表 `com.helix.runtime.cli` 私有目录；不得据此声称跨 UID、凭据隔离或 companion Activity 生命周期已通过。
- 没有新增 Maven repository、依赖、RootFS、兼容层或非官方重打包；下载内容只存在于临时目录和设备临时探针路径，脚本结束清理。
