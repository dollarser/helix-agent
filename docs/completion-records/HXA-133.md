# HXA-133 完成记录

- 目标：把 Runtime 私有固定 Codex smoke Job 作为首个跨 APK持久 Job 控制面开放给 developer App，并落实 submit/query/cancel/reconcile、同 jobId 幂等、断连只对账和空闲解绑。
- 前置任务/commit：HXA-132 / `988cc43`。
- 修改文件：`runtime:cli-client` 共享 Job record/codec、transaction 与 client；`runtime:cli-app` Service 生命周期、Binder dispatcher 和 HXA-128 runner 共享 record；App developer E2E；边界脚本和 M11 状态文档。
- 实现的契约：固定请求 manifest `fixed-codex-smoke-v1` 的 SHA-256 为唯一可首次提交 hash；同 jobId + 同 hash 返回原记录，不同 hash 拒绝。首次 submit 与轮询保持同一前台 cold binding，终态立即解绑；query/cancel/reconcile 每次重新冷绑定。Runtime 每事务重验 caller，未知/非法/busy/满额均为稳定状态。
- 生命周期修正：首轮设备测试发现 submit 后立即解绑会销毁纯 bound Service，`onDestroy()` 因而正确取消在途 Job。client 改为 `submitAndAwaitFixed` 在前台有界执行期间持有同一 binding；没有引入 started Service、FGS 或 wake lock。
- 数据边界：跨 APK只返回 jobId、request hash、状态、时间、模型 ID 与输出 hash；不传用户 prompt、响应正文、token、account id 或原始错误。journal 延续 128 条/1 MiB 门禁。
- 自动测试：`runtime:cli-client` 18/18，共享 record codec 覆盖终态 round-trip、未知字段/伪 token 字段拒绝、成功缺 proof 拒绝；`runtime:cli-app` 53/53，HXA-128 runner 原有成功、失败、取消、迟到结果、恢复、hash 冲突和容量测试继续通过。
- 设备证据：独占 `emulator-5602`（API 29，arm64-v8a）与 `emulator-5604`（API 36，arm64-v8a）各运行 `CliRuntimeHandshakeE2eDeviceTest#fixedModelJobIsDurableAndNeverBlindlyResubmitted` 1/1。无凭据形成持久 `FAILED`；重复提交返回同一 terminal record；未知 query/cancel 稳定；debug-only self-kill 后重新冷绑定 query 恢复同一 record，未 submit；最终无活动 binding。Runtime 私有 JSON 已检查不含 token/account/`HELIX_OK`。
