## 实现的契约

1. **URL 策略单一 choke point，fail-closed**：任何进 WebView 的 URL 只可能经 `BrowserTabController.navigate`（用户地址栏输入经 `normalizeInput` 后）或被拒策略错误页；页面发起的导航在 `shouldOverrideUrlLoading` 被**消费**（恒 `return true`）后回传同一策略——allowed 走 Load 命令，denied 只到错误页，WebView 永远不被要求加载被拒 URL。`doUpdateVisitedHistory` 对重定向/`location` 到达的 committed URL 再查一次（这些路径不走 `shouldOverrideUrlLoading`），被拒即 `stopLoading` + 错误页。策略不可解析的输入（含控制字符、相对 URI）= INVALID 拒绝，不交给平台解析器。
2. **加固设置可被设备验证**：`BrowserSecuritySpec.DEFAULT` 逐字段显式应用（JS 开、file/content 访问关、file URL 跨域关、混合内容 `NEVER_ALLOW`、Safe Browsing 开、domStorage/database 开、JS 不得自动开窗）；geolocation 在 API 36 无回读 getter（spec 刻意不含该字段），host 显式 `setGeolocationEnabled(false)`，设备测试以行为探针验证（页面请求必须被拒）。设备测试用 `specFromSettings` 从**活 WebView** 回读重建 spec 并 `assertHardened`——任何设置回归直接打掉门禁。
3. **无永久 JS 桥**：整个 feature 无 `addJavascriptInterface` 调用（AGENTS 硬规则、doc 09 §3.4）；设备测试行为探针：加载页面后 `typeof window.helix === "undefined"`。Safe Browsing 刻意**不**覆写 `onSafeBrowsingHit`——系统 interstitial 是既定行为（doc 09 §3.4「绝不由 Agent 自动 proceed」在本模块没有任何 proceed 路径可走）。
4. **错误页双通道 + typed 优先**：typed 通道（legacy 4 参 `onReceivedError`，`ERR_*`/`ERROR_*` 映射到六类 kind，双零/ABORTED = 非错误）与 codeless 通道（modern `onReceivedError(WebResourceRequest, WebResourceError)` 无数字码 → UNKNOWN，除非 typed 已先到或标签被用户 stop）；两通道都有 same-document 守卫（`isSameDocument(url, lastLoadUrl)` 剥 `#` 后比对），丢弃被新导航取代的 load 的 `ERR_ABORTED` 噪声。错误页期间 `error != null` 与 `isLoading` 互斥，UI 两视图不共存。
5. **用户 stop 不是错误**（codeless 通道的固有歧义）：stop 后 `stopped=true`，codeless 回调无法区分中止与失败，故 `stopped` 期间不产生 UNKNOWN 错误页；`stopped` 在下一个真实迁移（navigate/goBack/goForward/reload/onPageStarted/onPageFinished/onMainFrameError/onMainFrameUnknownError）清除。**刻意不以 `isLoading` 为门**——legacy 零码事件可能先清掉 `isLoading`，若以其为门会把真实失败吞掉（单测 `aCodelessFailureStillSurfacesWhenLegacyClearedLoadingFirst` 钉住）。
6. **设备固定的 2026 System WebView 行为（本任务 logcat 探针发现）**：主帧失败（DNS 等）时该 WebView **不**通过 legacy 回调提供码，而是 fire modern 无码回调，随后**还为内置错误页 fire `onPageFinished`**。状态机定型：`onPageFinished` 在 `error != null` 时 no-op（错误页的 finish 不提交任何东西——不清错误、不 bump generation；单测 `aFinishedEventForAnErrorPageDoesNotClearTheError` 钉住）。
7. **下载：无自动落盘、双重上限、执行期再验**：页面下载请求只进队列（`PENDING_CHOICE`）；策略拒绝（非 http(s) URL / 可执行后缀 / Android MIME / 超限 / 空名）直接 `DENIED`，一字节不动（设备测试 `anApkDownloadIsDeniedBeforeAnyBytesMove` 钉住）；保存唯一路径是用户在 SAF `CreateDocument` 里显式选位，之后才 `HttpURLConnection` 流式写入（30 s connect/read 超时）；声明长度**不是**信任边界——`copyWithCap` 逐字节查同一 100 MiB 上限；`saveDownload` 执行期对 URL 再验 `isHttpUrl`（队列不是信任边界，doc 09 §3.4）。
8. **清除入口**：Cookie/缓存/历史独立清除行（doc 09 §3.4「独立清除入口」）；设备测试 `cookiesRoundTripAndTheClearEntryRemovesThem` 证明 Cookie 能 round-trip 且清除入口真的清掉。页面正文是 UNTRUSTED_WEB_CONTENT：错误页/标签条只呈现脱敏 host，原始 URL 不进 UI 文案（doc 09 §3.4「指令不构成 Tool 授权」——本模块尚无任何 Tool 消费页面内容）。
9. **标签状态机守卫**：`maxTabs` 硬范围（越界构造即拒绝）；`reload` 拒绝空白标签与加载中；`goBack/goForward` 受历史与加载态守卫；`stop` 仅在加载中生效且只置状态+发 Stop 命令；关闭标签选邻居并销毁 host；选中标签不存在 = 编程错误（`requireTab` 抛错，不静默）。
10. **`navigationGeneration` 地基**：committed 页面自增（错误页 finish 不自增，见契约 6）——HXA-061/062 的 snapshot node token 将绑定（tab id + generation），页面导航后旧 token 可证明失效（doc 09 §3.3）。

## 风险或后续任务

- codeless 错误页固定为 `UNKNOWN`（modern 回调无码）：typed/legacy 通道保留为优先路径，若未来 System WebView 版本恢复提供码，自动回到 typed 语义；双通道顺序（typed 先到 / codeless 先到）均有单测钉住。
- 双回调行为（契约 6）基于 2026 年 System WebView 两台设备固定；WebView 版本漂移时设备测试（错误页 + 加固 spec 回读）会先于生产暴露回归。
- `stopped` 标志是唯一区分「用户中止」与「真实失败」的标记（codeless 回调无 ABORTED 信号）；若后续加入超时合成或预检失败路径，需保持「下一个真实迁移清除」语义（单测已钉两条关键顺序）。
- WebView 内存：标签状态 app-scoped、host 随 activity 生命周期；多标签长驻的内存上限（标签数上限/eviction）roadmap 未要求，留给 HXA-061 起按真实负载评估。
- HXA-061（Browser snapshot）开工时：snapshot 脚本必须走 doc 09 §3.4「固定、版本化 JS 片段」（`evaluateJavascript` 执行 Helix 自有脚本，模型不可提交任意脚本），node token 绑定 `navigationGeneration`。
