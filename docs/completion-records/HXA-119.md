# HXA-119 完成记录：GitHub Copilot Free 第三方侧载 Device Flow 登录生命周期

**日期**：2026-09-05

**状态**：代码与自动化设备验收完成；真实账号授权后 entitlement exchange 因网络失败未取得
`LOGGED_IN`，Copilot adapter 仍未注册。本结论不表示 GitHub/Microsoft 授权 Helix，也不表示
Copilot 模型可调用。

## 实现与边界

- CLI Runtime 固定使用 `Iv1.b507a08c87ecfe98`，依 GitHub Device Flow 请求 device/user code，
  严格固定 verification URL、响应大小与 15 分钟最大有效期；首次轮询至少等待 5 秒，
  `slow_down` 每次增加 5 秒。
- Device Code 生成后同时显示完整 `https://github.com/login/device` 并自动打开系统浏览器；保留
  手动打开按钮。拒绝、过期、取消和未知协议均 fail closed。
- GitHub token 必须先经 `https://api.github.com/copilot_internal/v2/token` 完成 entitlement/token
  exchange，成功后 GitHub/Copilot token 才同时写入 Runtime UID Android Keystore vault。exchange
  的 I/O 失败最多在内存中重试三次；HTTP 403 等确定拒绝不重试、不落盘。
- UI、异常、Binder status 只显示稳定状态，不返回 token。本 HXA 没有模型 endpoint、Provider、
  Tool、Job、外部 credential 导入或新的 Android 权限。
- client id 与 internal endpoint 仅是项目所有者接受的非官方个人侧载例外；它们可随时失效，且
  client id 公开不等于注册者或 GitHub/Microsoft 授权 Helix。商店/官方发行门禁未满足。

## 当前官方事实与第三方证据

- 访问日期 2026-09-05：GitHub 官方 Device Flow 文档要求注册 client id、按 `interval` 轮询，
  并规定 `slow_down` 增加 5 秒：
  https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/authorizing-oauth-apps 。
- GitHub 官方 Copilot SDK 文档支持 signed-in user 或项目自有 OAuth App，且用户订阅路线要求
  Copilot subscription：
  https://docs.github.com/en/copilot/how-tos/copilot-sdk/auth/authenticate 。
- 本地 `dsh-plugin-subscriptions@0.7.0` 只作为固定 client id、endpoint 与响应形态证据；Helix
  未复制其生产代码。MIT 许可证不授予服务端身份使用权。

## 真实尝试与已知限制

- API 36 上真实请求成功签发 device code，用户完成一次网页授权；随后 Runtime 显示
  `GitHub/Copilot network request failed`，vault 无 credential 文件。没有 HTTP 403，因此不能
  把它表述为账号无 Copilot 资格，也不能表述为登录成功。
- 该失败后已增加 exchange 有限重试，但新的真人授权尚未执行。重测时 API 36 被另一工作树的
  PRoot instrumentation 抢占前台；设备、端口和 Activity 不是 worktree 隔离资源，故停止交互
  验收，避免覆盖并行任务。
- 无真实 `LOGGED_IN`、真人 logout 或模型调用证据；adapter 保持 `NOT_REGISTERED`。

## 决策记录：ADR-0023 accepted

本 HXA 修改 accepted ADR-0021 的 Copilot 身份限制。项目所有者明确接受固定 client id 或其他已
注册 Device Flow identity 后，新增 accepted
[ADR-0023](../adr/0023-copilot-third-party-device-flow-identity.md)。该决定只允许个人侧载登录实验，
不改变 ADR-0007 隔离、不满足商店授权，也不把 proposed ADR-0022 的官方 SDK 平台负向结论改成
已实现。
