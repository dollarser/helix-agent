# HXA-095：Root 高层工具作用域与失权验收

日期：2026-09-17。状态：completed（Root 专项范围）。基线、物理设备、制品和集成限制与 [HXA-094](HXA-094.md) 相同。

## 决策记录：

复用 RootSessionManager、现有五个只读高层工具及 [ADR-RUNTIME-004](../adr/runtime/004-root-service.md)，没有新增任意 root.exec。真实系统 Root grant 只满足 Capability；工具仍进入生产 Dispatcher 与 [当前会话授权](../adr/permissions/README.md)，不以旧审批形态代替 HXA-209。

## 修复与验收

- 修复 `root.process.list` 扫描 `/proc` 时进程中途退出导致整项失败的问题。仅逐条跳过 IO、权限错误及无效字段；不将任意异常包装成成功。确定性 JVM 用例同时放入两个有效进程、消失记录、缺字段记录和非数字目录。
- `RootHighLevelToolsDeviceTest` 真机覆盖 status、scoped file.read、package.info、process.list、bounded log.read，越界拒绝，真实 RootService crash 后失权、旧 scope 调用拒绝及用户关闭不自动申请 Root；检查采样日志未出现未遮蔽的凭据形态，不宣称穷尽真实凭据/全部日志格式。
- `RootLifecycleDeviceTest.realAppDispatcherHonorsRootScopeAndToolDisable` 使用真实 AppContainer、Room、ChatService/Dispatcher、RootModule：UI 显式选 `/system/etc` scope 并开始会话；五工具成功，文件输出最多 64 bytes、进程/日志数量有界；`../build.prop` 越界失败；会话工具 DISABLED 返回 TOOL_DISABLED；点击断开后旧文件调用失败。FULL_ACCESS 测试配置通过生产设置服务写入，不由模型授权。
- RootSessionManager JVM 覆盖过期、scope 与失权；RootTools JVM 验证拒绝不触达 privileged port。该单测事实不冒充真实时间流逝的设备长稳。
