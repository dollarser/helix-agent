- 实现的契约（逐条对照任务书）：
  - 风险结合 mode/Safety Profile/scope/数据敏感度/规范 origin+residence/tool source/execution target/参数：`PolicyInput` 全字段 + 管线三级合成（mode→PLAN 只读拒绝与审计；profile→出网门与隔离运行时门；scope→规则匹配与 LAN scope 匹配；敏感度→三档门 + 源下限；origin/residence→从 `NormalizedEndpoint` 派生 + LAN/未知/保留端点分支；source/execution target→绑定变更因子与 ADVANCED-only 目标；参数→overwrite/codeChanged/bindingChanged/newOrigin 因子）。
  - Standard 高敏出网逐次确认：`evaluateEgressGate`——STANDARD 下 SENSITIVE 永不匹配规则（`ruleCovers` 要求 ADVANCED），`RequiresApproval` detail 带数据类别+Provider/MCP+origin+scope（ADR-0005 确认面四要素）。
  - Advanced 规则精确绑定 Provider/MCP ID + origin + 数据类别 + scope，可撤销：`isLiveFor` 四字段精确相等 + `target == egress.target`（value class 相等）+ `origin.full == endpoint.full`（规范化端点全量含 path）+ `scope` 强制相等；撤销=规则出集合，下一调用立即重新门控（测试证）。
  - 期限只允许 1h/24h/7d/30d，默认 24h、最大 30d、不得滑动续期：`RuleDuration` 四值封闭 + 构造期 TTL 精确匹配 + `withDefaultTtl`（24h）；规则不可变，引擎无扩展窗口路径，renewal 只能是新对象（测试证 expiresAt 不随调用移动）。
  - `createdAt/expiresAt` 到期或时钟回拨 fail closed：`!now.isBefore(createdAt) && now.isBefore(expiresAt)`——两个方向都回逐次确认（非 DENY：用户重新确认即可，与 ADR-0005“回到逐次确认”一致）。
  - Secret/凭据和未知工具/Capability/L3 默认拒绝：FORBIDDEN 恒拒（无 profile/规则例外）；`missingCapabilities` 非空→DENY（HXA-032 center 供给事实）；baseRisk L3 或动态风险达 L3→DENY；“未知工具”由注册表侧拒绝（HXA-030 子集门），引擎侧对已注册事实默认放行链无未知通道。
  - 模型/MCP/Skill 不能切换 Profile、创建 LAN scope 或降低 residence：API 形状——`profile`/`lanScopes`/`missingCapabilities` 是引擎输入（来自可信 app 层/用户设置），无任何工具参数路径可注入；residence 无字段可声明，只从 endpoint 派生；测试矩阵覆盖（STANDARD 带“Advanced 式”规则仍逐次确认；LAN 无 scope 必拒）。
  - 测试默认/上限、重启、撤销、到期、时钟回拨、绑定字段变化：25 引擎测试 + 6 规则测试逐条对应（重启=状态无关性测试；默认/上限=RuleDuration 构造测试 + L2/L3 决策测试）。
- 关键实现决策（均为可逆实现选择，不触发 ADR）：
  1. **`AgentMode`/`SafetyProfile` 迁入 core:model**：两者都是纯域枚举；core:policy 不能依赖 core:agent/app（模块图方向），core:model 是两者的合法公共落点（doc 02 §3：core/model=纯 Kotlin 域模型）；迁移是机械 import 更新，零行为变化（core:agent 165/0、app 单元 54+54/0 回归证）。
  2. **规则/门控类型落 core:policy**（HXA-032 已确立的模块语义延续）：出网规则、LAN scope、数据类别、引擎全是“风险、审批、授权作用域”（doc 02 §3 模块图 core/policy 定义）；复用 core:model 既有 `NormalizedEndpoint`/`ProviderResidence`/`ProviderId`/`McpServerId`/`SkillId`/`ExecutionTargetType`/`RiskLevel`/`ToolOperationClass`，零 build 变更。
  3. **规则持久化不在本 HXA**：verification-matrix 的 HXA-033 行只有 `:core:policy:test`（无存储行）；规则按“外部态按次传入”建模（引擎状态无关、重启不依赖内存），持久化存储与设置 UI 归后续 HXA（Advanced 设置与规则管理是独立任务面）；本 HXA 的“重启”测试验证的正是引擎不持有状态。
  4. **保留端点决策时白名单 + 连接时策略分层**：引擎只拒三个经典云元数据/平台保留字面 host（决策时可见）；doc 07 §7.9 的完整 SSRF 策略（A/AAAA、IPv4-mapped IPv6、DNS rebinding、重定向重验证）归网络层连接时执行——两层各自完整，KDoc 互指。
  5. **时钟回拨/到期回“逐次确认”而非 DENY**：ADR-0005 原文“回到逐次确认”——规则失效不升级为用户的拒绝，用户重新确认即可继续；DENY 保留给恒拒类（凭据/保留端点/能力/L3/PLAN 只读/隔离运行时 profile 门）。
  6. **BROWSER/ACCESSIBILITY 源下限抬升**：doc 10 §2.6 把“浏览器页面、Accessibility 内容”整体列为高敏示例——源即类别下限，防止调用方把页面内容标成 NORMAL 绕过门控；文件源不抬升（正文/元数据由调用方按实际携带判定，doc 02 §8 数据源列表不区分文件内容形态）。
  7. **detekt `@Suppress("TooManyFunctions")` 一处（PolicyEngine 类）**：单一管线拆成 11 个小 stage 函数（默认拒绝/出网门三 helper/风险因子/规则匹配/辅助），函数是管线阶段而非独立操作；项目先例（HXA-028 ToolSchema、HXA-031 ToolSchemaValidator）同型处理，注释在类 KDoc。

- 排障记录（真实证据，供后续参考）：
  1. **`residence` 是函数不是属性**：`NormalizedEndpoint` 的派生方法是 `fun residence(): ProviderResidence`（M2 既有 API），引擎初版按属性 `endpoint.residence` 调用 → 编译错 “Function invocation 'residence()' expected”（2 处），改 `residence()` 调用。
  2. **前缀替换损坏 import**：批量把 `import com.helix.app.profile.SafetyProfile` 替换为 core:model 路径时，`String.replace` 前缀命中了 `import com.helix.app.profile.SafetyProfileStore` → 3 个文件出现 `com.helix.core.model.SafetyProfileStore`（Unresolved reference），反向替换修复。教训：跨包迁移用整行锚点或 `\b` 边界，不用前缀替换。
  3. **测试 helper 默认值遮蔽类属性**：`rule(scope: UserScope = scope)` 的默认参数表达式里 `scope` 解析到参数自身（未初始化）→ “Parameter 'scope' is uninitialized here”，改参数名 `ruleScope`。
  4. **JUnit `assertTrue` 不做 smart cast**：helper 里 `assertTrue(cond is X)` 后返回 `decision` → 返回类型不匹配（assertTrue 返回 void，编译器不收窄），改 `if (!is X) error(...)`（detekt UseCheckOrError 合规）。
  5. **测试语义 bug（真失败两次）**：(a) 绑定字段变化用例里 `egress(endpoint = ...)` 丢掉了 helper 默认的 `sensitivity = NORMAL` → 调用实际是 NORMAL 类别，引擎正确地放行，断言失败；debug 打印证明 `full match=false` 但 `factors=[]`（SENSITIVE 分支根本没进）——类别才是关键。(b) 无滑动续期用例取 `later = now+23h`，恰好等于 expiresAt（created=now−1h，TTL 24h）→ 规则恰在边界外（`now < expiresAt` 不含端点）被判过期——引擎行为正确（ADR-0005“不早于 expiresAt 即过期”），测试时点改为 now+20h。
  6. **detekt 结构性指标**：`evaluate` 初版 147 行/复杂度 29/10 个 return → 拆为 `checkDefaultDenials`（when 表达式）+ `evaluateEgressGate`→再拆 `findMatchingLanScope`/`egressDenial`/`egressApprovalDetail` + `computeDynamicRisk`，全部 ≤2 return；`TooManyFunctions`（11/阈值 11）按项目先例 `@Suppress` + KDoc 说明；ktlint `no-consecutive-comments` 要求 KDoc 后不能直接跟 `//` 行注释（注解可以）——Suppress 说明并进 KDoc。
