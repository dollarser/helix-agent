日期：2026-09-28。完成范围：Provider contract、Room v1、private-process llama.cpp、模型资产与管理 UI、完整主机 gate，以及所有者授权的 API36 consumer 定向验证。真实 4B 固定多步任务通过；不代表任意 GGUF、真机性能或发行验收。工作树尚未提交。

决策记录：[ADR-PROVIDER-001](../adr/provider/001-models-and-connection.md) accepted；遵循 [ADR-AGENT-001](../adr/agent/001-turn-coordination.md) 的 durable lifecycle，不新增 Agent loop、Dispatcher 或权限路径。

## 交付

- provisioning、transport、auth、residence 正交建模。OnDeviceLocal 不含 endpoint/protocol/secret；Ollama/LAN/loopback 仍是 Network。Room 继续开发期 v1 baseline。
- LocalModelProvider 通过有界 Binder/PFD 请求非导出的 `:model_runtime`；llama.cpp JNI 为 CPU backend，不启动 HTTP server。单常驻模型、单 generation，资产只读 handoff；取消须确认 executor exit 或进程死亡，重启不重放旧调用。
- llama.cpp 固定 commit `7fe450e19305b828c199d602c23a8337aaa1f03b`，MIT 许可证随 APK；模型权重不打包。显式 HTTPS/hash/size 下载，Range 边界、配额、校验与原子发布，卸载/删除及 Room 重建后资产重新登记。
- 默认 4096 context、2 threads、greedy；上下文可调 1024–32768，受模型及可用内存约束。metadata/probe/generation 共用配置，加载失败可降低 context 重试。资源预检拒绝超预算；截断输出保留 Usage 并返回 LOCAL_OUTPUT_LIMIT，不执行部分 ToolCall。
- 模板 grammar 辅助语法，真实 text/tool probe 判断工具能力。工具调用仍由 Harness 校验、授权、执行及持久化；grammar、probe 与 COMPLETED 都不能替代业务正确性断言。
- opt-in 合成测试保存逐轮请求、JNI JSON、事件、Room 轨迹及产物，失败路径也保留证据；不增加生产会话 prompt 日志。修复重复清理 Provider 覆盖原始异常的夹具问题。

## 保留边界

- 0.6B/1.7B 的同类聚合任务失败仍有效；4B 的一次固定任务通过不证明泛化可靠性。首轮 4B 未在时限内结束，原始异常又被清理异常覆盖，完整保留失败记录。
- 旧 PROTOCOL 未保存原始 native reply，不声称唯一根因已经定位。当前取证不包含模板后 token 流或隐藏推理。
- 真机温升、长时间持续负载、OEM 行为、真实远端 Provider 同题对照均 not requested。模拟器内存预检不是通用容量保证；CPU 任务延迟仍高，首版为生成完成后缓冲返回。
- HTTP 续传边界、资产完整性有 host 测试；此次真实权重由 host 下载及 ADB 注入，未做 Android HTTP 下载端到端设备验收。
- 保留已有 Workspace/Memory/HXA-227 修改；未改动 Dispatcher/permission/effect owner，未 commit、push、merge 或发布，不代表 main/远端 CI 已通过。
