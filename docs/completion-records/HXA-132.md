# HXA-132 完成记录

- 目标：让 developer App 在用户主动验证时按需冷绑定独立 CLI Runtime，完成本地安装/状态/签名门禁、共享 status handshake 和空闲解绑，并以 API 29/36 跨 APK E2E 固化边界。
- 前置任务/commit：HXA-131 / `570f562`。
- 修改文件：`runtime:cli-client` status codec、Binder client、cold-bind supervisor 与 JVM 测试；developer manifest 的精确 package visibility/signature permission；App developer 设备测试；依赖锁、边界脚本和 M11 状态文档。
- 实现的契约：调用前检查 Runtime 已安装、启用、未 force-stop 且 APK 签名集合与主 App 相交；仅通过共享显式 `ComponentName` + `BIND_AUTO_CREATE` 绑定，20 秒内完成 16 KiB status transaction；严格校验 protocol v1、arm64-v8a、lock SHA-256 和 `NOT_REGISTERED`，所有已绑定路径均在 `finally` 解绑。未安装、禁用、force-stop、签名/绑定/超时/握手失败均为封闭原因。
- 未实现/明确排除：无模型 Job transaction、任意 prompt、Provider、Tool、token/account id/原始错误通道或登录 UI 启动；consumer 不接入 `cli-client`。
- 自动测试：`runtime:cli-client` 15/15（status codec 新增有效、协议不匹配、提前注册拒绝覆盖）；`runtime:cli-app` 53/53；完整 App developer unit/build/androidTest 与两模块 lint 命令 exit 0。
