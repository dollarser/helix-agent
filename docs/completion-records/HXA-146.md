# HXA-146 Copilot 订阅 Provider

日期：2026-09-06。

## 交付范围

developer/Advanced 受管理 `subscription-copilot` 通过既有 ModelProvider、ProviderService、ChatService 与 Runtime v2 PFD/job journal 接入文本对话。独立 Runtime UID 持有 GitHub/Copilot grant，预先交换短期 token，模型 POST 不自动重放；不改 Room schema、Policy/Approval、consumer 渠道或凭据所有权。固定账号入口补齐设备码和 URL 复制按钮，复用敏感剪贴板标记，授权结束后禁用。

复用 `SubscriptionHttpModel` 的网络时限、重定向禁止、错误和流大小限制及既有 Chat encoder/decoder；Copilot 专用编码把 `max_tokens` 映射为 `max_completion_tokens`，不修改 API Key Provider 的协议。仅加入现有内部 `provider:openai-chat` 依赖，无新增外部库/许可证，没有复制插件源码或打包 CLI。

决策记录：accepted ADR-0025/0026/0027 已覆盖渠道、固定身份、独立 UID 与平台 Job 路由，无需新 ADR。官方 CLI/SDK Android 路线仍停止；consumer/store 不包含订阅实现。

## 真实失败与修复证据

2026-09-06 查阅 [GitHub 套餐](https://docs.github.com/en/copilot/get-started/plans)、[认证](https://docs.github.com/en/copilot/how-tos/copilot-sdk/auth/authenticate) 及本地 [参考插件](https://github.com/V1ki/dsh-plugin-subscriptions) 0.7.0/MIT。官方 UI 的自动选模不证明第三方端点接受 `model=auto`；最初默认值有误。

首次探测在设备授权未完成时返回 AUTH；完成授权后返回 HTTP_ERROR。Runtime 内 opt-in 诊断确认 HTTP 400、错误涉及 model/invalid，而非网络超时或身份拒绝。诊断只输出状态码及固定布尔分类，不导出响应正文或凭据。账号 `/models` 目录没有 `auto`，但明确列出 `claude-haiku-4.5` 支持 `/chat/completions`。改用该模型并纠正输出预算字段后真实请求通过。只迁移未发布的受管理 `auto` 默认行，其他配置模型不覆盖。

参考插件还支持动态目录、Responses 模型与动态 editor version；本任务只验收上述固定 Chat 模型，不宣称全目录、所有免费账号或任意模型可用。固定 editor headers、非公开端点与 client identity 仍可能失效。
