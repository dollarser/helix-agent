## 交付

1. **新模块 `:runtime:proot-core`（纯 Kotlin JVM，无 Android 依赖）**：schema 与严格 codec 的单一实现，供构建期资产门禁（HXA-081）、设备端安装器（HXA-082）、主 App 握手（HXA-083）与法律页（HXA-087）共用——「唯一版本真相」由模块结构保证：所有版本/哈希/URL 的消费面都经过这同一份解析代码。
   - `RuntimeLock`（`lockVersion`=1 闭集、`abi` 闭集、`components[]` 唯一 id）；`RuntimeComponent`（id/version/abi/url/size/sha256/license/source/packages[]，packages 显式必填、可为空数组）；`RuntimeLicense`（spdx/name/textRef）；`RuntimeSource`（repository/ref/patches[]）；`RuntimePatch`（path/url/size/sha256）；`RuntimePackageInfo`（name/version/licenseSpdx）。
   - `RuntimeInstallManifest`（schemaVersion=1、installId=`inst_`+12hex、abi、installedAtEpochMs、**内嵌完整 lock** + `lockSha256`、可选 `smoke`{PASSED/FAILED+failures}）；`RuntimeActivation`（`active.json`/`rollback.json` 共享 schema）；`RuntimeAbi`（`arm64-v8a`/`x86_64` 闭集）。
   - `RuntimeLockSchemaException`（`IllegalArgumentException` 子类，可携带 parser cause）。
   - `RuntimeBaseline`：产品基线规则（必含 `proot` 与 `alpine-rootfs` 组件、rootfs 必含 bash/git/python3/nodejs/ripgrep、组件 ABI 与 lock ABI 一致）；`requireBaseline()` 为构建/安装/握手共用的单点强制。
2. **严格 codec 语义（fail-closed）**：未知 key 拒绝、缺失 key 拒绝、闭集类型；`sha256` 仅接受 64 位小写 hex（大写拒绝，防大小写翻转绕过比对）；URL 必须 https + 真实主机（拒绝 IP 字面量、userinfo、fragment）；嵌入引用（license 文本/patch）必须相对路径且无 `..`/`.`/反斜杠/空段；size ∈ [1, 1 TiB] 整数；`lockVersion`/`schemaVersion` 闭集（未知版本拒绝，不猜测）；manifest 解析时**重算内嵌 lock 的 canonical SHA-256** 与 `lockSha256` 比对，篡改内嵌 lock 即 schema 违规；smoke PASSED 必无 failures、FAILED 必有 failures。
3. **canonical 编码 + 指纹**：`encode` 固定 key 序（与输入 key 序无关，有测试锁定）、`sha256Hex` 为稳定文档指纹——HXA-082 安装器与 HXA-087 法律页复算同一指纹证明「APK 内嵌 lock = 构建锁定 lock」。
4. **接线**：`settings.gradle.kts` + 根 `build.gradle.kts`（jvmLibraries 条目 + pinned kotlinx-serialization-json 1.9.0 `api` 依赖，无新依赖版本）；`runtime/proot-app/build.gradle.kts`（`implementation(project(":runtime:proot-core"))` + androidTest 基线 + `testInstrumentationRunner`）；`scripts/check-lockfiles.sh`（29→30 个 lockfile，projects 表加入 `runtime:proot-core`）。
5. **设备验收面**：`proot-app` androidTest `ProotLockSchemaDeviceTest`（3 例）+ 自述测试 fixture `src/androidTest/assets/runtime-lock.sample.json`（URL/哈希为 fixture 值，**不是**真实资产锁定；真实 `runtime-lock.json` 归 HXA-081）。

## 验证中缺陷

1. **（测试）设备测试正则不容忍 pretty-print**：`aTamperedSampleLockHashIsRejectedOnDevice` 用 `"sha256":"…"`（无空格）正则匹配 pretty-printed 的 sample 资产（实际 `"sha256": "…"`），`find()` 返回 null 触发 NPE（API 36 设备首轮暴露）。修复：正则改 `\\s*:\\s*` 容忍空白。非生产代码缺陷（生产 codec 走 JSON 解析，与空白无关）。
