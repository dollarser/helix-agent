# HXA-211：按会话导出 JSONL 执行记录

日期：2026-09-20。完成 consumer/developer 共用的用户主动导出、独立格式消费与本任务主机/设备验收。该功能是应用能力，没有新增 Agent 工具，也不触发模型、工具重放或 Goal。

## 交付与使用

打开已有会话的会话设置，选择“导出会话 JSONL”，再通过系统文件选择器创建目标文件。包含消息、Turn、模型调用、工具调用及结果、执行/审批结论、附件/产物引用、压缩边界与已有用量；未采集的历史关联、顺序或结束原因明确 unknown，不猜测补齐。

格式 `helix.session-export` v1 保留源 ID、连续导出序号、引用状态、源/导出 hash 与完成尾。关系来自单次 Room 事务；每页最多 128 个排序键，正文逐条读取，避免 SQLite 整批排序大参数造成原生内存膨胀。ContentStore 在事务后校验。内联 32 KiB、单行 256 KiB、关系暂存含索引 128 MiB、最终输出 128 MiB、交付缓冲 32 KiB；大内容仅引用，文件不是自包含备份。

正文沿用已知凭据规则，不导出配置/Secret/授权证明，不宣称匿名。普通方括号业务说明不会误作损坏 JSON 整段删除。取消可打断打开目标或阻塞写入；写入/关闭/空间/授权失败不报告成功。完成或失败清理本次暂存及所属授权；进程死亡后再次打开导出入口清理旧操作，不自动重导出。云盘同步不在输出关闭保证内。

规范、合成样例与离线消费命令见[格式文档](../architecture/session-export.md)。独立 Python 校验器检查版本、身份、序号、引用、hash 与尾统计，重建消息和工具/结果/审批关联；材料缺失或变换明确降低完整度。
