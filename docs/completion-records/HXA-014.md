## 完成后安全加固（2026-08-31）

后续全面审查发现原始 `ApprovalDao.consume` 使用 `decision IS NOT NULL`，Repository 还接受任意非空字符串；这与后续已明确的“`DENIED` 只记录、不可消费”契约不一致。该问题在 Dispatcher/HXA-034 尚未实现时没有形成可执行 Tool 绕过，但存储原语本身不安全，已在本轮直接修复：

- `core:model` 新增封闭 `ApprovalDecision(APPROVED, DENIED)`；`ApprovalRepository.decide` 不再接收自由字符串。
- `ApprovalDao.decide` 在 SQL 层拒绝封闭集合外的值；`consume` 以单条原子 SQL 限定 `decision = 'APPROVED' AND consumedAt IS NULL`，pending、denied 和重复消费都返回 0 并由 Repository fail closed。
- `RoomGuardAndConfigTablesTest` 新增任意字符串决定被 DAO 拒绝、真实 denied 记录不可消费断言；既有 fixture 由 `ALLOWED` 迁移为 `APPROVED`。审批表字段未变化，因此该项不新增 migration/version。
- 同轮清除 Room KSP 的既有性能告警：为 `skill_snapshots.skillId` 外键补单列索引并重新导出未发布的 v1 schema；表和列契约不变，不新增数据库版本。

本次加固实测：`./gradlew :core:model:test :core:storage:testDebugUnitTest spotlessCheck detekt` → exit 0；`./gradlew :core:storage:connectedDebugAndroidTest` → exit 0（API 36 arm64 AVD，14 tests / 0 failures）。这不表示 HXA-034 已完成；approval hash、expiry、Proof、UI token 与端到端并发消费仍归 HXA-034/036。
