# HXA-134 完成记录

- 目标：在 HXA-133 的签名 Binder/jobId 控制面上增加通用、严格有界的 `ModelRequest`/`ModelEvent` PFD 载荷，并实现 Runtime 结果留存、hash 校验与对账后正文删除。
- 前置任务/commit：HXA-133 / `b693913`。
- 修改文件：`runtime:cli-client` 的请求/事件 codec、PFD channel、Job client/record；`runtime:cli-app` 的通用 Codex 执行适配、payload journal、Binder/Service 和依赖锁；developer App 跨 APK E2E；roadmap、status、verification matrix 与边界脚本。
- 实现的契约：请求 codec 上限 512 KiB，并拒绝图片引用与未知字段；结果 codec 上限 1 MiB/2048 events，要求唯一 terminal 且位于末尾。Binder 只传 PFD 和 redacted record；request/output 均以 SHA-256 对锁，8 MiB payload 配额计入待写请求。
- Runtime 行为：复用现有 OpenAI Responses request encoder/stream decoder，保留显式模型和工具 schema，强制 `store=false`；401 只在 Runtime 内刷新一次。凭据、account id 和 Authorization header 不跨 APK。
- 生命周期/恢复：首次 submit 与轮询沿用 HXA-133 同一前台 cold binding；query/cancel/reconcile 各自冷绑定。取消胜过迟到结果；成功结果先原子落盘，再写 terminal record。reconcile 校验结果 hash，成功交付后删除 request/event 正文并写 `reconciledAtEpochMillis`；断连不重放请求。
- 自动测试：codec 覆盖请求/工具 round-trip、未知凭据字段拒绝、事件 round-trip、缺失/重复 terminal 拒绝；payload runner 覆盖成功留存/对账删除、hash 不匹配、取消迟到结果和计入待写请求的配额门禁。`runtime:cli-client` 22 tests、`runtime:cli-app` 57 tests、developer App 271 tests，均通过。
- 设备证据：独占 `emulator-5602`（API 29，arm64-v8a）和 `emulator-5604`（API 36，arm64-v8a）均通过 HXA-133 回归及 `modelPayloadUsesPfdAndIsDeletedAfterReconcile`（各 2/2）。fixture 返回统一事件 `TextDelta`/`Usage`/`Completed`；设备文件检查只剩 `record.json`，request/event 文件不存在，record 不含 token/account/请求或响应正文；最终无活动 Service binding。
- 未实现/明确排除：不注册 Provider，不接对话 UI、Dispatcher、Policy、Approval、Verification 或 Audit；图片引用因跨 UID 无法按现有 Artifact 契约重验而 fail closed；本任务没有重新启用官方 CLI/SDK 打包路线，也没有新增 Claude/Grok/Copilot 模型 endpoint。
- 权限/许可证/供应链：无新增 Android 权限、Maven repository、可变版本或第三方源码；新增模块依赖均为仓库内现有模块及已锁定传递依赖。Runtime 仍为独立 APK/applicationId/UID 且只有 INTERNET。
