## 目标

M6 收尾：把 App 的**全部用户可见文案资源化为可切换的多语言**（简体中文 / English，外加"跟随系统"），并在 App 内提供语言切换、跨进程（含 ADR-0015 隔离的 QuickJS 进程）一致地生效、API 33+ 与系统"App 语言"双向同步——**同时保持纯 JVM 数据模型与工具/审计的稳定字段 locale-independent**（文案只活在 UI 边界的资源引用里，模型只带资源 ID + 参数）。这是 M6 的最后一项；完成后 M6 结束。

## 修改文件

**新增（核心）**

- `app/src/main/kotlin/com/helix/app/language/AppLanguageStore.kt`：`enum AppLanguage {SYSTEM, ZH_CN, EN}` + `object AppLanguageStore`。只把**选择**（locale-independent 值）持久化进 SharedPreferences；`effectiveLocaleList` 在每个进程（含隔离 QuickJS 进程）fail-closed 地算出生效 LocaleList（API 33+ 采纳系统语言变化）；`wrapForLocale` 用 `Context.createConfigurationContext`（fail-closed 回退未包装 base）；`applyChoice` 持久化并在 API 33+ 经 `android.app.LocaleManager.setApplicationLocales` 推到系统（App→系统）；`persistChoiceOnly` 只持久化、**不做异步推送**（测试 runner 用）；`systemLocaleFor` 在"跟随系统"时返回**空** list 以清除系统覆盖（不留陈旧 override）。

## 实现的契约（验收焦点）

- **资源化 + 三套键 parity**：App 全部用户可见文案进入 `values`（简体中文 base）/ `values-en` / `values-zh-rCN`；`check-i18n.sh` 强制三者**键集合完全一致**（573 键 parity）且生产源码无硬编码汉字（2 条 allowlist：模型可见注入 + pinned JS 脚本，均跨 locale 字节稳定）。
- **模型/工具/审计 locale-independent**：纯 JVM 数据模型（`ApprovalCardUi`、能力 chips、`EgressDisclosure`、Provider 模型等）只带 `res: Int` + 参数（`List<String>` 已解析或 `List<Int>` 嵌套 res-ID），**从不**持有 `Context`/locale 文本；UI 边界经共享 `localizedString` 解析。Provider/Tool/审计的**稳定字段**（代码、ID、原因码如 `DenialReason.code`）不受语言影响，`AppLanguageDeviceTest` 设备验证确认。
- **App 内切换 + 三值闭环**：`SettingsScreen` 的 `LanguageSection` 提供 `跟随系统 / 简体中文 / English`（选项标签为 endonym，各 locale 相同）；选择持久化后立即经 `wrapForLocale`（`createConfigurationContext`）重包 Context 生效。
- **跨进程一致（含隔离 QuickJS）**：`effectiveLocaleList` 在**每个进程**（含 ADR-0015 隔离的 QuickJS 进程，该进程不碰 SharedPreferences 以外的持久化）fail-closed 地生效。
- **API 33+ 双向同步**：`applyChoice` 经 `android.app.LocaleManager.setApplicationLocales` 把 App 语言推到系统（App→系统）；`effectiveLocaleList` 在 API 33+ 采纳系统语言变化（系统→App）；"跟随系统"通过 `systemLocaleFor` 返回**空 list** 清除系统覆盖，**不留陈旧 override**。
- **Activity / 进程重建保持**：切换后 Activity 重建、进程重启后语言选择保持（设备测试覆盖）。

## 未实现 / 显式边界

- 不做**运行时逐字面**的任意语言包动态下载/热更（语言集固定为 简体中文 / English / 跟随系统三值闭环）；新增语言需加对应 `values-*` 目录并在 `AppLanguage`/parity 闸门登记。
- 不用 `AppCompatDelegate.setApplicationLocales`——它需要活的 AppCompat delegate，而 Activity 是 plain `ComponentActivity`，会静默 no-op；改用公开的 `android.app.LocaleManager`（从任意 Context 可用）。
- `bundle.language.enableSplit = false` 是**有意**取舍：为支持 App 内切换而不产生 locale split APK（代价：base APK 携带全部 locale 字符串）。
- 测试 runner 用 `persistChoiceOnly`（**不**触发异步系统推送）是**有意**的：避免异步 `setApplicationLocales` 在不可预测时机以 config change 翻转 locale、销毁被测 Activity（见决策记录）；真实 UI 与双向同步测试仍走 `applyChoice`。
- 不在本任务内为 `feature/browser` 之外新增其它 feature 模块的资源目录——仅 browser 与 files-allfiles 因已有内联文案而需要。

## 决策记录：

- **(a) 模型带 res-ID + 参数，边界解析。** 纯 JVM 数据模型只带 `res: Int` + 参数，UI 边界经共享 `localizedString` 解析。模型不碰 `Context`/locale 文本，保证 Provider/Tool/审计稳定字段 locale-independent，也让众多调用点只读友好。
- **(b) 浏览器模块唯一 locale 边界 = `BrowserMessages.kt`。** 浏览器 feature 模块的用户措辞全部收敛到这一个 `Context.getString` 解析器文件，模块其余代码保持 locale-independent；`DenialReason` 的用户措辞在这里，对外 reason 是 locale-independent 的 `DenialReason.code`。
- **(c) `AppLanguage` 三值闭环，只持久化选择。** `enum {SYSTEM, ZH_CN, EN}`，SharedPreferences 只存选择值（locale-independent），不存解析出的文本，避免陈旧 locale 文本残留。
- **(d) 双向同步用 `android.app.LocaleManager`，不用 AppCompatDelegate。** Activity 是 plain `ComponentActivity`，`AppCompatDelegate.setApplicationLocales` 需活的 AppCompat delegate、会静默 no-op；`LocaleManager` 是公开的 per-app-locale API，从任意 Context 可用，API 33+ 生效、低版本 fail-closed 跳过。
- **(e) "跟随系统"不留陈旧 override。** `systemLocaleFor` 在跟随系统时返回**空** LocaleList 清除系统覆盖，避免用户切回跟随系统后仍残留上次的手动 override。
- **(f) `persistChoiceOnly` vs `applyChoice`。** 测试 runner 用 persist-only（不触发异步 `setApplicationLocales` 推送）——异步推送以不可预测时机触发 config change，曾在测试中途翻转 locale 并销毁被测 Activity（HXA-069 flake）。真实 UI 切换与双向同步测试仍用 `applyChoice`。
- **(g) `effectiveLocaleList` 全进程 fail-closed（含隔离 QuickJS）。** 每个进程（含 ADR-0015 隔离 QuickJS 进程）都经它 fail-closed 地算出生效 locale（任何 null/异常 → `LocaleListCompat.getAdjustedDefault()`），保证跨进程文案一致且不崩溃。
- **(h) `check-i18n.sh` 双检闸门。** 键 parity（三套 `values-*` 键集合完全一致）+ 无硬编码 CJK（生产源码，2 条 allowlist：模型可见注入 + pinned JS 脚本，均跨 locale 字节稳定），把 i18n 纪律固化进 CI 脚本。
- **(i) 静态/风格修复（不改行为）。** 共享 `localizedString` 收敛唯一 vararg 展开；`AppContainer` 把非 val 构造参数 `context` 捕获进 `appContext` 属性供成员函数使用（Kotlin 作用域规则）；`FileManagerService`/`FileManagerServiceTransfers` 针对性 `@Suppress`（LargeClass/LongMethod，cohesive facade 不拆分）；`BrowserMessages` 文件头 KDoc→`//` 注释（清 ktlint 悬空 toplevel KDoc）。均为**行为保持**的整理。
