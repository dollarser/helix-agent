# HXA-113 完成记录：工具与审批兼容性结论

**日期**：2026-09-05

**状态**：**完成，结论为不实现 Agent backend adapter**。HXA-111/112 均未获得厂商支持的
Android arm64 Runtime；因此不存在可诚实执行的 CLI Job，不能证明内置工具代理、断连后按
`jobId` 对账或未知结果不重放。

## 范围与生产结论

- `CliAgentBackendEligibility` 固定三个相互独立的门禁：厂商支持的 Android Runtime、CLI
  内置工具被禁用或代理为普通 Helix ToolCall、断连后按原 `jobId` 查询且不重放未知命令。
  任一门禁缺失都令 `mayRegisterForActOrGoal=false`。
- 当前 Codex/Claude Code 证据在第一项即失败，结果为 `METADATA_ONLY_UNSUPPORTED`，不是
  “可用但未接 UI”。CLI Runtime 状态明确为
  `UNAVAILABLE_UNSUPPORTED_ANDROID_PLATFORM` / `NOT_REGISTERED`。
- 未新增 Provider protocol、catalog template、Factory 分支、Dispatcher 绕行、Tool、登录、
  凭据、Job/journal 或 Binder 执行事务。生产 CLI APK 仍没有 Node 或 CLI executable。
- 若未来第一项通过而工具控制或恢复证据缺失，唯一允许的结果是
  `ISOLATED_CLI_SESSION_ONLY`，仍不得进入 Act/Goal Provider 列表。

## 测试与证据边界

- 单元测试覆盖：不受支持 Runtime 对后续声称 fail closed；工具控制缺失；对账缺失；两项
  同时缺失；三项全部有独立证据才产生 eligibility。
- developer App 回归固定当前生产 Provider surface 只有三个网络协议，内置 catalog 不含
  Codex、Claude Code 或 CLI template，并断言当前 M11 证据不可注册。
- API 29/36 设备测试只验证 Runtime metadata、独立 APK 权限边界及 `bundled=false`。由于无
  可执行 Runtime，内置工具、取消、断连、`jobId` 查询和不重放没有执行，不能报告通过。
- [ADR-0020](../adr/0020-cli-runtime-execution-base.md) 仍为 `proposed`；HXA-113 没有接受它，
  也没有把候选执行底座写成既定架构。

## 决策记录：ADR-0020（proposed）

HXA-113 仅把负向兼容性结论补入既有 proposed ADR-0020。项目所有者尚未接受该 ADR；
当前不新增或变更 accepted 决策，且不以 HXA 完成状态替代 ADR 接受。
