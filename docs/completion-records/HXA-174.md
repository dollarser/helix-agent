# HXA-174：上下文窗口配置与自动、手动压缩

Date: 2026-09-09
Status: completed

## 交付

Provider 按 ID、规范 endpoint 和 model 保存窗口与压缩设置：默认 200000 tokens，自动压缩默认开启、80% 触发，比例可设 10～95%。设置页支持选择后端模型。连接测试和设置页自动发现精确模型的数字窗口；本地单模型 SGLang 可读取 get_server_info，不跨模型借用、不按名字猜测。用户窗口与已知服务端上限取小值；元数据未知不让连接测试失败。

发送前按历史估算、匹配的最近真实输入及输出预留判断压力；达到阈值、输入预算或消息数边界时，对较早完整轮次生成无工具摘要。至少保留最近完整轮次和当前轮次，旧工具调用与结果整组覆盖，摘要是低信任历史资料。原消息和附件不删除；原子持久化独立 CONTEXT_CHECKPOINT_V1 消息和模型调用关闭，成功后才替换后续请求历史，不增加 Room schema。UI 隐藏 checkpoint JSON。

点击模型旁圆环 → 立即压缩，或显式输入 /compact，走普通用户 Turn 的停止与预算路径；自动压缩若属于 GoalRun，也计入绑定 Goal 的预算。摘要不创建/唤醒 Goal，不扩大权限。取消、拒绝、无完整结束事件、无效摘要和预算不足不发布半成品。成功 checkpoint 后进程恢复中断未完成的下一调用，不重放已结束摘要。过大且不可分割的当前轮次明确失败。

圆环显示匹配 endpoint/model 的最近实际输入；手动压缩后用 ≈ 标记缩减后估算，下一次请求再由真实 usage 更新。Provider 配置变化会刷新当前窗口投影。窗口不是累计计费或未发送文字的精确 tokenizer，也不替代已有 Turn/Goal 预算。
