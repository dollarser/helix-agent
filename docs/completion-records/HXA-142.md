- 目标：把官方 CLI/SDK Android 打包路线与未获供应商分发授权的第三方订阅 adapter Provider 路线明确停止，防止 HXA-140/141 的真实 smoke 与私有 journal 被误报成待接线的生产后端。

- 手工验证设备：无。本任务没有改变 APK 行为或 Android 生命周期；沿用 HXA-141 的 API 29/36 边界证据，本次以 JVM 注册门禁和 APK 静态边界为验收。
