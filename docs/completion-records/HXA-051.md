  - `JsExecutionWire.kt`：internal 事务编解码（execute 信封 = version + request + 3×(presence byte + PFD) + 尺寸 + flags + crashAfterMs；reply = version + result；INFO reply = Bundle{pid,uid}）；`writeFileDescriptor`/`readFileDescriptor`（SDK 36 已移除 `writeParcelFileDescriptor` 形态，显式 presence byte 不依赖 null-fd 语义）
  - `JsExecutionService.kt`：isolated Service + 单一 `ExecutionBinder`。槽位 `IDLE→RUNNING→DONE`（一次性实例：第二次 execute → `REQUEST_REJECTED already used`）；专用执行线程（16 MiB native 栈，ADR-0015：create/evaluate/close 同线程）新建 `QuickJs`（memoryLimit + InterruptHandler = 取消标志 ∨ monotonic deadline）；**deadline 优先**分类（deadline 已过 → TIMEOUT 压过 INTERRUPTED；显式取消带远 deadline → INTERRUPTED）；OOM 按消息形态（`out of memory` 或**空消息**——HXA-050 固定的 API 29 形态；`memoryUsage` 计数器在失败分配后回落基线（实测 ~94 KiB），不能作判别器，已在 KDoc 固定该事实）；Java 侧 `StackOverflowError`（引擎对环/过深结果的转换失败）→ OUTPUT_LIMIT；`finally` 关 PFD、置 DONE、关引擎。`onTransact` 防御性 catch → UNKNOWN（绝不成功）
  - `JsExecutionClient.kt`（主进程，HXA-053 直接可用）：同步有界 `execute(JsExecuteParams, JsCancellation?)`。preflight（未开始取消 → CANCELLED；空 executionId/非法 limits/超限 → REQUEST_REJECTED，不产生实例）→ 传输装配（>64 KiB 的 source/input 走 cacheDir 临时文件 + 只读 PFD；outputFile → 可写 PFD）→ `bindIsolatedService(intent, BIND_AUTO_CREATE, instanceName, mainExecutor, connection)`（15 s 有界连接；bind 期间取消 → CANCELLED）→ 等待循环（50 ms 轮询：结果 parcel / cancel → 发一次 interrupt + 2 s 宽限 → 合成 INTERRUPTED / deadline → 发一次 interrupt + 1 s 宽限 → 合成 TIMEOUT 并放弃 Binder 交互；DeadObject/RemoteException → CRASHED；其他异常 → UNKNOWN）→ SUCCESS 时若指定 outputFile 则读回全量字节并校验 size + SHA-256（不匹配 → UNKNOWN）→ finally 解绑（系统回收实例）、关 PFD、删临时文件。**不重试、不盲放**；并发由调用方负责

## 实现的契约

- 每执行：唯一 `bindIsolatedService` 实例（`js_` + 32-hex，由 executionId 确定性派生）、isolated UID、非导出、一次性槽位；执行 = 专用 16 MiB 线程上 create/evaluate/close 同一 `QuickJs`
- 传输：≤64 KiB inline；>64 KiB 走 PFD（source/input 只读、output 调用方可写）；PFD 显式 presence byte；跨 UID 依赖 Binder 继承 fd（不重新按路径打开）
- 时间：调用方发送 `deadlineNanos`（monotonic，跨进程可比）；服务端 InterruptHandler 与主进程 watchdog 同基；**deadline 优先**分类
- 控制面：interrupt 事务（主进程 watchdog/取消触发）；主进程 deadline+1 s 宽限后放弃 Binder 交互并解绑；取消 2 s 宽限；实例回收只靠解绑 + 系统回收（`binderDied` 为主观察信号）；**无 killProcess/System.exit 正常路径**
- 闭合状态集 11 项（wire 冻结顺序）；未知 wire 状态 → UNKNOWN；catch-all 绝不返回成功；detail ≤2048 字符
- 结果审计：`outputSha256Hex`/`inputSha256Hex` + `servicePid`/`serviceUid`
