# HXA-171：独立文件管理界面

Date: 2026-09-09
Status: completed

## 参考与交付

按所有者明确要求，将 main 工作树根目录的九张用户参考图统一移动到 docs/references/ui/screenshots，并同步至实现工作树；[索引](../references/ui/README.md)保留原名、归档名、SHA-256。七张会话图和两张文件图分类；不打包进 APK、不复制竞品代码、不依据截图宣称产品功能或性能。

文件页默认显示独立首页：本地文件、真实已授权来源、导入/工作/输出快捷位置、添加 SAF 文件夹、共享存储访问设置、导入。目录页采用来源选择/首页/搜索/更多单行工具栏、可点路径、当前列表数量与只读状态；把排序、视图、创建、回收站、授权、导入和刷新放入滚动弹窗，文件内容获得更多空间。移除失去引用的 AdaptiveFileControls，文件首页、位置栏与文件列表分开组织。

文件条目改用原生矢量图标和分层信息；平时不显示复选框，长按进入多选，底部操作可横向滚动。系统返回依次清除选择/搜索、退出回收站、返回父目录/首页。搜索只过滤已列出的当前目录文件名，不宣称全盘索引。切换目录先清除旧条目和选择，避免操作上一目录内容。

所有手动操作继续走既有 FileManagerService，不依赖 Chat、模型连接、Agent ToolCall 或审批。没有扩大文件工具权限。当前本地 Workspace 支持原有写入/整理；SAF 与 All files 来源的浏览/预览/分享及导入导出仍遵守既有能力，未实现的共享目录直接重命名/删除不伪装为可用。全盘媒体分类、磁盘分析、任意 sdcard 根目录管理均未由截图推定为已实现。
