# HXA-076 Skill 工具与首批内置 Skills（完成记录）

- 日期：2026-09-05
- 前置任务：HXA-075（commit `6a0e48b`）

## 目标

把 Skill discovery/activation/resource/enablement/removal 接入正常 Tool Pipeline，交付文件整理预览、网页研究、数据转换、repo inspection、notification digest 五个小型内置 Skill；Skill 脚本只能请求既有执行工具，不获得新执行器或权限。

## 实现和复核的契约

- `skills.list` 为 L0 read-only，分页返回最多 256 项的 name/description/source/snapshot hash/enablement；`offset`/`limit`、`nextOffset`/`eof` 允许完整继续发现，不加载正文或资源。
- `skills.read`、`skills.read_resource` 为 L1 read-only，只读取已启用的精确 hash 快照；导入内容标记 `untrusted`，内置内容标记 `built-in`。resource 仅限 `references/`/`assets/`、no-follow 普通文件和 512 KiB 上限。
- `skills.enable`/`disable` 为 L1 local mutation，精确绑定 snapshot，支持 session/global；global 原子持久化，session override 不改变全局状态。启用只允许读取指令，不注册工具、不授予 Capability/Approval/文件范围。
- `skills.remove` 为 L2 non-idempotent local mutation，只允许 user-imported snapshot，移动到 app-private recoverable trash；built-in/project 不可删除。
- 五个内置 Skill 精确为 `organize-files-preview`、`web-research`、`data-transform`、`repo-inspection`、`notification-digest`；全部 instruction-only，`android-ui-task` 未提前进入 M7。
- `AppContainer` 在 production Registry/ImplementationRegistry 注册六个 Skill 工具，统一经过 Dispatcher/Policy/Approval/Audit。

## 验证中修复

- `skills.list` 原实现无界返回全部快照，却声明 output `maxItems=256`；改为确定性分页，避免产生违反自身 schema 的 Completed 结果，也不通过静默截断损失可发现性。
- API 29 专项前字节码审计发现 `Stream.toList()` ×2 与 `Files.writeString()` ×1 会在 Android 10 运行时失败；改用 API 24+/26 可用路径，并新增真实设备链覆盖，详见 [bug 记录](../bug-fixes/2026-09-05-skill-java-apis-api29.md)。
