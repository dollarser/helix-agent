# HXA-092 UI actions（完成记录）

- 日期：2026-09-05
- 目标：只消费 HXA-091 已验收的 bounded snapshot/token，实现 `find`、`click`、`long_click`、`set_text`、`scroll`、`back`、`home`、`wait` 模块能力；每个节点动作重新取得当前 root 并复验 token 绑定，目标变化立即暂停，且不提供任何坐标动作或 blind click。
- 前置任务/commit：HXA-091（commit `0df3abe`）。
- 修改文件：`tools/automation/src/main/**` 的 find/action/wait、session pause/resume 和 service/controller bridge；`tools/automation/src/test/**` 的纯 JVM 查询、token 动作和有界等待测试；`tools/automation/src/androidTest/**` 的 button/edit/scroll fixture 与跨包、过期、停止设备验收。
- 实现的契约：`find` 只过滤当前有界 snapshot，支持 exact/contains 和最多 50 个结果；节点动作只接受 32-char opaque token，重新取得 `rootInActiveWindow`、沿 token path 重走节点，并逐次复验 package/window/generation/fingerprint、allowlist、password/data-sensitive 和固定敏感包；成功动作立即使全部旧 token 失效；`set_text` 限 2,000 chars；`wait` 最长 10 秒、轮询间隔 50 ms～1 秒且调用方必须离开 Android main thread；`back`/`home` 在执行前仍走当前 snapshot admission；当前活动 root 离开 session allowlist 后会话进入 `TARGET_CHANGED` 暂停态、token 清空，后续动作返回 `SESSION_PAUSED`，只有用户确认且当前 snapshot package 与预期 allowlisted package 相同才恢复。
- 无坐标不变量：公开 request 只有 token、枚举 action 和可选 text，没有 x/y、bounds、selector fallback 或 gesture 路径；节点动作只调用目标 `AccessibilityNodeInfo.performAction`，找不到 path、generation/fingerprint 变化或平台拒绝均返回稳定失败状态，不回退到屏幕坐标。
- 未实现/明确排除：本检查点不把 snapshot/find/actions 注册进普通 Agent Tool Registry，不新增自动批准或可复用授权，不实现连续动作预算扣减/攻击恢复矩阵；系统权限、安装器、Root 管理、支付/认证、锁屏、服务断连/强停、预算和快速批准攻击归 HXA-093。
- 自动测试：`:tools:automation:testDebugUnitTest` 共 31 例（HXA-090/091 20 + 当前新增/扩展 11）；覆盖 exact/contains/bounded/invalid find，token path 重走与节点回收，package/window/generation/fingerprint mismatch，unknown/expired token，password/data-sensitive/denied-package 动作期复验，不支持能力与平台动作失败区分，缺失/超长 set-text 参数，有界 wait 的成功、超时、非法预算和 snapshot refusal，以及 session 暂停/显式恢复。
