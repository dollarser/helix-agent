- **`JsAbiAssembly.kt`（新增）**：wrapper 装配（纯 JVM）。最终模板（verbatim，`<...>` 为装配点）：
  ```javascript
  ((__helixInputJson) => {
    "use strict";
    const stringify = JSON.stringify;
    const input = JSON.parse(__helixInputJson);

    function helixMain() {
  <userSource，原样，作为无参函数体；input 经闭包捕获>
    }

    let value;
    try {
      value = helixMain();
    } catch (e) {
      if (e === null) throw e;
      let m;
      try {
        m = (e !== null && e !== undefined && e.message !== undefined && e.message !== "") ? String(e.message) : String(e);
      } catch (_) {
        m = "";
      }
      if (m === "") throw e;
      throw "helixMain threw: " + m;
    }

    const out = stringify(value);
    if (out === undefined) return "null";
    if (out.length > <maxOutputBytes>) throw "helix output limit exceeded: " + out.length;
    return out;
  })(<input 字面量 | null>);
  ```
  与 doc §3.2 草图的唯一偏差：`helixMain` 为**无参**函数，`const input` 在外层经闭包捕获（草图将 input 作参数；无参 + 闭包使 `const` 不可重赋值——node 实测赋值即 strict-mode TypeError，且攻击套件固定该行为），wrapper 语义其余逐条对应。

- **`JsJsonDocument.kt`（新增）**：纯 JVM 严格 JSON 文档结构校验器（递归下降，深度硬上限 64，拒绝尾逗号/前导零/裸控制字符/无效转义）；客户端输入预检与输出复验共用

## 实现的契约

- **唯一生产路径 = wrapper**：client 侧 `JsAbiAssembly.build(userSource, inputLiteral, maxOutputBytes)` 装配；raw-evaluate 直跑不存在（测试源码全部以 `return` 形态书写 helixMain 体）
- **输入**：空 = 字面量 `null`（`JSON.parse(null)` → JSON null）；非空 = 恰好一个合法 JSON 文档（客户端 preflight + service 双侧校验），host 编码为不可闭合的 JS 字符串字面量，经 IIFE 参数 → 外层 `const input` 注入（闭包捕获，strict-mode 不可赋值）
- **输出**：恒为恰好一个 JSON 文档文本（`JSON.stringify` 语义：数字裸、字符串带引号、`undefined` → `"null"`）；wrapper 内保守 UTF-16 长度检查（上限分配跨越 Zipline bridge 之前）+ service 权威 UTF-8 字节检查（detail `output N exceeds maxOutputBytes M`）+ 客户端 `JsOutputContract` 复验（违约 = 客户端合成失败，不截断、不回退）
- **错误**：用户错误 → 前缀字符串 `helixMain threw: ` + 非空白消息（thrown string 而非 `new Error`——替换 Error 构造器无法置空白）；两条故意保持裸路径的捕获值 = 引擎无消息 OOM 表面形态：caught `null`（API 29 批量耗尽时引擎无法分配 Error 对象本身，异常以字面 null 到达 catch，原样重抛 → 宿主空消息形态 → OOM）与字符串化为空的值（用户 `throw ""`，原样重抛 → OOM）；**用户 `throw null` 与 API 29 OOM 不可区分，同样落 OOM——设备实测固定、文档化、接受**；`throw new Error("")` 歧义已消解（JS_ERROR）
- **限制**：§4.1 默认值/上限不变（10 s / 64 MiB / 256 KiB / 2 MiB / 256 KiB；30 s / 1 GiB / 1 MiB / 32 MiB / 2 MiB）；新增 `maxWrappedBytes` 组装上限（service 拒绝，defense-in-depth）；每执行新 isolated 实例（HXA-051 语义不变）
- **无 file/network/Android bridge**：隔离进程 + QuickJS 引擎本身无宿主对象注入；攻击套件对 7 个探针 global 全部固定 undefined
- `PROTOCOL_VERSION = 2`（wire 状态顺序 11 项冻结不变）
