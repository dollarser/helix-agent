# HXA-219：产物就地预览

日期：2026-09-22。基于已提交的第一批UI重构 `1c1b8ab7`，在 `codex/ui-interaction-refactor` 独立工作树交付。所有者明确将 `@`/`/`引用留到后续批次。

## 交付与使用

- 会话有工具产物时，在输入区上方显示产物数量；点击打开底部面板，按会话归属浏览，排除无生产Turn归属的输入附件，不受全局最近产物窗口截断影响。
- 同一面板内查看有界文本或图片，返回列表保留浏览位置；关闭面板不离开会话、不清空当前输入、不启动Turn。切换会话清除旧面板选择，取消旧查询。
- 工具状态、发送状态、前台恢复及打开面板触发只读刷新；每次选择/重新打开文件复用原可用性检查。变更、缺失、授权失效与截断提示沿用既有实现，不把登记记录当作实时文件状态。
- 共享面板支持内部按需加载的列表，长标题最多两行，关闭入口保持固定。原产物中心操作区改为换行布局，解决窄屏关闭按钮越界，见[修复记录](../bug-fixes/2026-09-22-artifact-dialog-action-overflow.md)。

允许模块内仅增加app/chat只读查询、UI及资源/测试，无数据库迁移或新增授权；UI不直接访问DAO。

决策记录：没有新增或修改ADR，继续遵循[工作目录](../adr/workspace/README.md)与[权限](../adr/permissions/README.md)契约。
