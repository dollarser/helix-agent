## 契约与交付

决策记录：产物可用性是打开时对真实文件的即时检查——行比文件长寿，打开即真实检查，缺文件（删除/移动）、scope 授权不可解析（SAF 授权已撤销，fail-closed）、其他 I/O 失败是三种不同的显示状态，不静默重读、不重试；尺寸/哈希与任务记录阳性不一致显示"内容已变化"横幅并渲染新内容（无法验证的哈希不声称变化）；文本预览限 64 KiB，"仅显示开头"标记置于预览正文之上保证可见；图片只渲染开头。应用内导出只提供给可导出区域的 workspace 文件，走与文件页同一管线（`FileManagerService.exportDocument`，取消按 chunk 轮询），对话框只发布管线自己的 TransferResult（成功为管线的已验证/尺寸核对措辞，取消为部分产物措辞）——点击本身从不声称结果；SAF 授权文件拒绝应用内导出（跨 scope），只提供"用其他应用打开"（先 stage 私有副本）。"用其他应用打开"用 `resolveActivity` 预检诚实报告"没有应用可打开该文件"（框架空 chooser 会谎称已打开），manifest 声明 `VIEW/*` queries 保证该检查在 API 30+ 包可见性下真实。对话框"查看任务"走独立 `tasks-turn` 路由落到该 turn 的结果对话框（落点即对话框、其返回为路由自身返回条），系统返回回到行打开来源页；任务页产物对话框按真实归属（turn/goal）读取，不以全局窗口代替。行显示名取 scope 相对路径的最后一段（SAF 引用自身无路径分隔符，直接切分会把整个引用泄漏成名字）。打开、预览、导出都不启动或继续任务。未改 Runtime IPC、授权、数据库 schema 或执行上限。
