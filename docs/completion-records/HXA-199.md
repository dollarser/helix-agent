# HXA-199：终端专项集成与交付

日期：2026-09-24。全场景测试、升级验证、模拟器真实默认时长及 OnePlus 6T 物理真机核心专项均已完成。实现经所有者授权合入 main。详见[199/206 验收记录](../evidence/development/acceptance-199-206-2026-09-21.md)与[2026-09-24 真机验收记录](../evidence/development/physical-oneplus-acceptance-2026-09-24.md)。

## 交付与体系收拢

- **终端与后台 Job 综合收敛**：集成单个手动 PTY 终端（HXA-197）、多会话重连与主进程死亡恢复（HXA-198）、有租期独立后台命令 Job（HXA-196）以及实时日志协议（HXA-195）。
- **生命周期与会话隔离**：最多支持两个活动手动 shell 终端与独立的后台命令 Job；共享文件系统工作区，持有独立的输入输出流、工作目录与环境变量。
- **跨版本升级与覆盖安装**：覆盖安装新 APK 时旧运行中任务自动标记为 `INTERRUPTED`，无状态重放与重复执行；历史结果依然支持按需查询、展示与显式结算。
- **构建渠道严格隔离**：consumer 变体完全排除 PTY、PRoot 二进制、`:proot` 服务与相关 UI/工具入口。

决策记录：[ADR-RUNTIME-001](../adr/runtime/001-execution-domains.md)、[ADR-RUNTIME-002](../adr/runtime/002-terminal-and-jobs.md)，均为 accepted。

## 验证

- **双 API 自动化矩阵**：API29 与 API36 模拟器上 144/144 项 Runtime、单/双终端与后台 Job 测试全部通过。日志首包延迟（API29: 41ms, API36: 39ms）、取消至终态延迟（API29: 633ms, API36: 117ms）均符合预期。
- **真实默认时长与脱离验证**：
  - API36 独占模拟器上无缩短地真实运行了 30 分钟脱离 idle（`IDLE / PROCESS_TREE_EXIT`）与默认 2 小时运行到期（`LEASE_EXPIRED / PROCESS_TREE_EXIT`，实际运行 7203.598s）；
  - 进程树退出后主进程与 Runtime 内存保持稳定，无 FD/线程泄露。
- **OnePlus 6T 物理真机（`561e3b15`，API 34）专项验收**：
  - 后台 Job 10 项核心用例全部通过（含 HOME 键后台挂起后持续执行生成输出）；
  - 主进程 SIGKILL 硬杀后 `:proot` 独立进程存活、执行完成至 `SUCCEEDED`、终态证明持久化全部通过；
  - 13 项连接器测试与 96 项底层存储全迁移链测试同步通过。

## 边界与物理保留

- **真实 16 KiB 页面**：受限于当前物理设备均为 4 KiB 页面，真实 16 KiB 硬件测试需在后续接入 Android 15+ 16 KiB 编译设备后执行。
- **无电源跨整夜 Doze 挂机**：深度 Doze 维护窗口与长时间无电源挂机作为长稳巡检项独立单列，不影响终端功能本身的集成验收与交付闭环。
