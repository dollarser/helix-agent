# HXA-150 MCP Installer 与 Connector 导入接线

日期：2026-09-08。

决策记录：accepted ADR-0029。三项助手均已实现；不扩展 Runtime、Room、核心授权、OAuth 或远程市场。

## 交付

内置 mcp-installer 与真实 connectors.preview/install。只接收 app Workspace 中的本地 JSON/ZIP；预览给出源、hash、端点、凭据待配置标记、Skill 文件清单、兼容诊断及相同 hash 的已安装 id。L2 安装经既有 Dispatcher 精确审批，重新捕获并校验内容，提交同一组内存字节，默认不连接、不导入源凭据。结果丢失可重新预览查已安装 id；源已变化时须在设置中按旧 hash 核对，不能盲目重放。

设置的 Connector 入口新增 JSON 粘贴和校验，复用文件导入、安装卡、独立凭据表单、连接测试与工具选择。Skill Creator 编辑保留全部 frontmatter，校验错误补文件/字段诊断；同一表单复用失败/取消处理。
