# HXA-191：深色主题与会话搜索

日期：2026-09-20。完成应用侧跟随系统的主题和会话/历史检索，以及本任务要求的双 API、双 flavor 验收。未增加 Agent 工具或改变会话权限。

决策记录：沿既有应用能力范围交付，无新增执行域、核心依赖或存储 schema 决策。主题统一跟随系统，不增加手动主题设置；不强制修改外部网页配色。

## 交付

- Compose 根显式使用 HelixTheme，窗口与系统栏使用 night 资源；真实页面、对话框和重建/进程恢复跟随系统模式。修正此前裸 MaterialTheme 固定浅色的问题。
- developer 原生订阅页面采用深浅资源配色，系统栏 LIGHT 标志按夜间模式更新，保留其他 decor 标志。大字体返回箭头完整显示；consumer 不包含该模块。
- 标题和现有正文的只读搜索，归档命中、片段、空态、清空、取消及打开会话。复用 Room 和 ContentStore，在工作线程有界扫描，显式显示扫描/跳过/截断，不静默宣称已检索全部历史。
- 搜索命中不注入模型上下文；主题/搜索操作不发起模型请求，不授予跨会话 Agent 权限。没有第二套会话状态源。
