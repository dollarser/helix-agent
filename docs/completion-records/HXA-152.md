# HXA-152：浏览器原生引用短时归因

Date: 2026-09-08
Status: completed（有界调查检查点；底层缺陷仍 open）

## 交付与证据

只扩展测试 APK 的 RawWebViewControlActivity，增加纯 Android Autofill 查询对照和每 100 轮的本地 Binder、代理及 GC 计数。未改生产浏览器、运行时或能力；不强制 GC、不放宽阈值、不启动 24h 长稳。

- API29/WebView91 与 API36/WebView133：原生 WebView 均复现 JNI 表溢出，最后日志 25500 轮，GC 304/403 次，本地 Binder 21/256。
- API29/36：不创建 WebView，仅重复两项 Autofill 查询，均因 Too many Binders sent to SYSTEM 被终止，最后日志 2900/3100 轮，本地 Binder 5810/6216，GC 均 6 次。
- 目标均为 30000 轮，四组运行均记录 FAIL；检查点完成指归因实验及证据交付，不是缺陷修复或测试通过。
- 原始 logcat、版本、APK SHA256、结果 JSON 位于忽略目录 `build/webview-diagnostic/`。最后日志轮数不冒充精确崩溃轮数。

决策记录：不适用：仅测试诊断与事实性证据记录；未选择新的生产运行策略或改变既有 ADR。

## 结论与后续

Binder 终止具有不依赖 WebView 的平台充分复现条件；JNI 溢出则在两台原生 WebView 对照中独立复现。不能据此把旧 Binder 失败唯一归因于 Autofill，更不能宣称 Helix 生命周期所有路径无缺陷。

JNI 的具体 native 槽位所有者、Autofill 回调与系统代理释放仍待进一步跟踪。应先取得可符号化 WebView/ART 引用创建和删除证据，再选择修复；未引入禁用 Autofill、Context 替换、周期重启或强制 GC 等未经证实的生产改动。真机与长稳继续后置。
