决策记录：accepted [ADR-AGENT-010](../adr/agent/010-request-context-manifest.md)。

## 交付内容

### 1. 轻量级请求清单与 Provenance 溯源 (HXA-217)
- **Room 27→28 存储演进**：
  - `ModelCallEntity` 增加可空字段 `requestManifest: String? = null`。
  - 实现 `MIGRATION_27_28`（`ALTER TABLE model_calls ADD COLUMN requestManifest TEXT`），注册于 `HelixDatabase` 与 `HelixStorage.ALL_MIGRATIONS`。
  - 生成并持久化 Room Schema `core/storage/src/androidTest/assets/com.helix.core.storage.HelixDatabase/28.json`。
- **请求捕获与不可变快照**：
  - 在 `AgentLoop.createRequestManifest` 中于最终组装、压缩、准入后、进入 Provider 前生成紧凑来源清单。
  - 清单包含 schema 版本（`1`）、模型调用 ID、有序历史消息引用（`id`、`role`、`inputId`）、关联的 `inputIds`（来自 `storage.sessionInputs.appendedForMessages`）、以及历史压缩检查点 `checkpoint`。
  - 通过 `TurnCoordinator.recordRequestManifest` 与 `ModelCallRepository.recordRequestManifest` 写入 `model_calls`，优先持久化来源记录再调用 Provider。
- **JSONL 导出与溯源追踪**：
  - 在 `SessionExportQuery` 的 `MODEL_CALL` 投影中引入 `requestManifest`，保持按行导出。
  - 严格限制单行大小与预算，遵循 `< 256 KiB` 单行与 100 次调用 `< 10 MiB` 边界，超限标记 `isTruncated: true`。
  - 不重复存储消息全文或工具调用输出，不采集 token、secret、auth headers 等机密，旧数据无清单时宽容处理为 null。
- **设备回归与故障恢复**：
  - `RequestContextManifestDeviceTest`：验证 27→28 数据库迁移、列存在性、256 KiB 边界守卫以及级联删除。
  - `RequestManifestExportDeviceTest`：验证 JSONL 导出格式投射、无敏感凭据泄漏与历史 null 兼容。
  - `RequestManifestRecoveryDeviceTest`：验证异常中断（INTERRUPTED Turn）恢复时，先前落盘的 requestManifest 完整保留且不破坏后续轮次。

### 2. UI 第二阶段体验优化（对标 Operit 等移动端标杆）
- **Thinking Accordion（深度思考折叠容器）**：
  - 新增 `ThinkingParser`，精准解析 `<think>...</think>` 标签，支持流式生成中未闭合标签与最终完成态识别。
  - 实现 `ThinkingAccordion`，支持点击展开/折叠长思考链，附带动态状态指示（思考中与已完成状态指示）。
  - 集成至 `ConversationMessage`，优化模型长推理输出排版，保持沉浸式交互。
- **工具执行内联预览**：
  - 在 `ToolTimelineItem` 中增加 `ToolResultInlinePreview`，折叠时提供 3 行等宽文本预览与快捷展开按键，减少冗长工具输出对主对话视角的挤占。
- **多语言（i18n）全量对齐**：
  - 针对 `chat_thought_process`、`chat_thinking_in_progress`、`tool_preview_expand`、`session_details_title` 等新增资源完成基准、英文、简体中文三套资源文件 100% 对齐（`./scripts/check-i18n.sh` 扫描 1639 键全部对应）。
