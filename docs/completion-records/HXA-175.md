## 范围与实现

临时调试/测试脚本先保存到 scripts/debug/YYYY-MM-DD，日志、APK、截图和真实数据留在忽略的 build。找回 140 份非运行中的历史脚本，按 mtime 日期脱敏归档为不可直接执行的源码快照，记录原始与归档 SHA-256；不把旧脚本视为当前可运行的验证工具。当前另一任务使用中的 EV-02 脚本和第三方报告资源不迁移。规则写入工作分支及 main 的 AGENTS.md，保留 main 其他任务的修改。

新 runner 拒绝已连接 serial，自行启动只读模拟器进程，冻结 APK、记录进程归属、验证非空 JUnit，在成功、失败、超时和信号中断时关闭自己创建的进程组。不得借用其他人的模拟器。

上下文圆环默认 28dp，按实际文字测量适配大字体/≈100%，保留点击目标。消息正文顶部 12→8dp、底部 12→0dp，复制按钮直接跟随正文；全文复制与长按选择不变。

非会话页面的自定义顶栏 Row 缺少系统 Insets。targetSdk=36，Android 15+ 强制边到边布局；API34 真机的传统窗口遮蔽了问题，因此不是模拟器专属。Scaffold 的 topBar 需自行处理顶部 Insets，现在外包 safeDrawing 的顶部和水平方向，内部 48dp 紧凑顶栏保持一致，不给会话重复加顶栏。

平台依据：[Android 官方边到边说明](https://developer.android.com/develop/ui/compose/system/setup-e2e)、[Insets](https://developer.android.com/develop/ui/compose/system/insets)。修复前独占 API36 用例实际失败：files header y=0，systemTop=136px；保留失败日志，未以“模拟器问题”忽略。

## 自动压缩说明

沿用 HXA-174/ADR-0037：Harness 在发请求前判断窗口压力、输入预算和消息数，自动压缩开启且满足任一条件才进入摘要。窗口默认 200000，默认比例 80%；压力包括估算输入、匹配的最近实际输入下界和输出预留。模型只生成较早完整轮次的摘要，不决定何时触发。手动按钮或 /compact 可主动触发。原历史不删除，近期轮次保留；本任务没有修改该逻辑。
