# HXA-195：有界日志协议与实时输出

日期：2026-09-18。完成范围为 developer 一次性 PRoot Job 的实时日志、详情页展示及资源/恢复边界；依据 accepted [ADR-RUNTIME-002](../adr/runtime/002-terminal-and-jobs.md)，未扩展后台 Job、PTY 或 Agent 工具。

决策记录：实现既有日志合同，新 IPC 事务及独立 v1 日志子协议；预览、最终归档和模型结果分别处理，无新增架构决定。

## 交付

- Job/输入 manifest hash/generation/游标绑定的只读分页；新事务号，重复字节读取幂等，跨 Job、过期游标及不支持协议拒绝。
- 独立有界 spool：8 KiB 数据分片、32 KiB Parcel 上限、每 Job 4 MiB/总 16 MiB；16 分片队列、4096 分片索引上限。队列背压、低存储或 IO 错误只截断预览，不阻塞真实 stdout/stderr drain。
- 分流增量 UTF-8，展示文本合计最多 256 KiB，不截断代理对。命令详情页在结束前显示输出，明确截断/不可用；最终归档及 hash 仍是结果依据。
- 观察只使用已批准提交的 Binder，不绑定/启动 Runtime、不 ACK、不重放。Activity 重建可重新读取；进程死亡后临时预览失效，最终结果沿用原有对账。
- 分片不写模型消息或工具结果，不增加模型请求；consumer 不包含 Runtime 日志类。没有修改 Claude Code 所有的 204 恢复流程。
- 压力测试发现并修复结果字节计数误用 1 MiB journal 上限的问题，见[缺陷记录](../bug-fixes/2026-09-18-proot-output-counter.md)。保留原有最大执行预算，未扩大默认预算或 journal 大小。

## 边界与后续

- 本次设备为 arm64 API29/36、4 核/4096 MiB 模拟器；不代表 OEM 真机、低内存、Doze 或长稳验收。
- 6 MiB 真实双流归档完整性已验证；64 MiB 上限只验证计数 codec，不冒充最大内存压力验收。
- Runtime 回归的订阅场景使用确定性 fixture；外部账号/profile、付费调用、远端 CI、签名发行不在本次通过范围。默认主机门禁的条件跳过不计为通过。
- 日志是可失效的有界临时预览，进程死亡后不恢复该字节流、不重放命令；持久最终结果继续使用原有恢复机制。
- 196～199 后台 Job/PTY/多会话、204→205 恢复/准备仍按各自任务与所有权推进。本记录不将完整终端标为已实现。
