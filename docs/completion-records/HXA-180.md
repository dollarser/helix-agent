# HXA-180: 独立文件管理变更能力

日期：2026-09-09。分支：`codex/phone-chat-polish`；未提交、推送或合并 main。

## 实现

- Workspace、独立共享存储和可写 SAF 支持新建文件夹、文件/目录重命名、同来源复制/移动、显式冲突处理和删除。跨来源继续使用既有导入/导出入口。
- 手动执行拆为 `ManualFileOperations`、`ManualFileTree`、NIO/SAF backend 和目录回收站；不增加 Agent 工具或扩大 Agent resolver。
- 流式复制、目标重读和源变化复核；覆盖先保留旧目标，发布失败恢复；移动在目标确认后处理源。取消、权限变化或清理失败返回实际失败/部分结果，不伪造成功。
- Workspace 文件和目录可回收、恢复与永久删除；共享/SAF 删除须明确确认。清空回收站只统计实际删除成功项。根目录、Workspace 内部状态、逃逸和符号链接保持不可变更。
- 两个 flavor 的 API29 写权限有版本限制；API30+ 重验 all-files。SAF 每次重验授权和文档能力，发布结果重新从父目录解析核对。Agent 仍不能读取手动共享根。
- 修复根目录改名/冲突自动命名的父路径计算，并提供单选目录改名入口。
- 本轮复现并修复异步预览停在初始态：单一状态、明确主线程发布、加载/失败展示、修复后重开，见 [缺陷记录](../bug-fixes/2026-09-09-file-preview-publication.md)。

决策记录：[ADR-0041](../adr/0041-manual-file-management-mutations.md)（accepted，所有者授权扩展独立手动文件管理；部分扩展 ADR-0036）。

## 边界

仅操作自己启动的只读 AVD 实例，使用后关闭；未使用他人模拟器或物理手机。SAF grant 的可控撤销使用 fixture，不能冒充所有云盘厂商账号验收。进程死亡可能留下可识别的临时/备份项，未实现持久传输队列或共享回收站；错误会提示需检查的位置，不承诺跨 Provider 原子事务。商店审核、系统 JNI/Binder 和长稳仍单列。
