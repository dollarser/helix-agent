# HXA-130：Connector 签名索引与来源验证

日期：2026-09-22。完成 Connector 签名索引格式、ECDSA P-256 分离签名解析与来源验证器（SignedConnectorIndexParser / SignedConnectorIndexVerifier）及全覆盖离线测试套件。该能力纯离线运行，遵循 ADR-CONNECTORS-004 契约，不引入在线下载或未受信任根。

## 交付与使用

在 `:extensions:skills` 模块中实现签名索引契约：
1. **严格规范数据模型** (`SignedConnectorIndex.kt`)：
   - `ConnectorIndexEntry`：固定版本 (SemVer，禁止 latest)、内容寻址 (`archiveSha256` 64 位十六进制)、HTTPS 来源、文件大小上限 16 MiB、声明许可证规范。
   - `ConnectorIndex`：包含 `schemaVersion` ("helix.connector.index/v1")、`publisherId`、`keyId`、单调严格递增 `sequence`、`issuedAt`/`expiresAt` 时间戳窗口及包列表（上限 1000）。
2. **严格 JSON 解析器** (`SignedConnectorIndexParser.kt`)：
   - 严格 RFC 8259 递归下降解析，拒绝重复键、浮点数与科学计数法、前导零、未转义控制字符。
   - 嵌套深度限制（最大 32 层）与索引大小限制（最大 1 MiB）。
   - 拒绝未知字段与不支持的 schema 版本。
3. **安全离线验证器** (`SignedConnectorIndexVerifier.kt`)：
   - 信任根校验：`keyId` 必须存在于调用方传入的受信任公钥表（`trustedKeys`）中，索引不得自带新 Key。
   - 降级与回滚策略：单调 `sequence` 校验；默认不限制降级安装（`allowDowngrade = true`，验证成功并携带 `isDowngrade = true` 审计标记）；调用方亦可指定 `allowDowngrade = false` 严格拦截 sequence 回滚。
   - 时钟窗口校验：可选时间戳校验，确保 `issuedAt <= currentTime <= expiresAt`。
   - 分离密码签名校验：使用 `SHA256withECDSA` 校验原始 JSON 字节与 DER 编码签名，任何字节篡改均导致验签失败。
4. **测试资产** (`ConnectorIndexTestFixtures.kt`)：
   - 隔离的合成密钥对 `TEST_FIXTURE_KEY`，明确标识为测试夹具，不进入生产信任根。

决策记录：[ADR-CONNECTORS-004](../adr/connectors/004-signed-index.md)。
