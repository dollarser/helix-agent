## Android 结论与证据边界

- glibc runtime 的 ELF interpreter 是 `/lib/ld-linux-aarch64.so.1`；musl runtime 是
  `/lib/ld-musl-aarch64.so.1`。API 29 与 API 36 arm64-v8a 均按预期 `No such file or directory`。
- API 29 证据设备为并行任务已占用的 `Helix_Connector_API29_20260905`（`emulator-5580`）。
  端口在启动检查与连接之间发生碰撞，测试安装实际落在该设备；未关闭该设备，只终止了本任务
  自己启动的 emulator 进程。结果有效但资源协调不理想，故如实记录。
- API 36 使用本任务独占的 `Helix_M9_API_36`（`emulator-5590`），执行前核对 AVD 名、API 与
  ABI，完成后只终止该进程。
- 两台设备 instrumentation 各 6/6；证明 lock codec 和“APK 不含 executable”边界，不证明
  OAuth、模型或工具行为。
- debug APK：3,333,911 bytes；SHA-256
  `1115eac3f6cb5429c9157a20188f281789e5827afe11e654f11155a6a7f3a47e`。
- 因平台前置门禁失败，登录/logout、plan/限额、模型流、取消、恶意工作区、内置工具代理、
  Binder jobId 对账与断连恢复均未执行，不得报告为通过。
