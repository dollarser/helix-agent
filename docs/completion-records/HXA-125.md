- 目标：在 CLI Runtime 独立 UID 中实现 Grok 官方 Device Code 登录，并让 Free、X Basic、未知套餐严格不落盘。
- 前置任务/commit：HXA-124 / `ea32beb`；accepted [ADR-0021](../adr/0021-third-party-subscription-protocol-adapter.md)。
