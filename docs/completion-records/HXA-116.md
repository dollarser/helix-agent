## 平台结论

- Codex、Claude：维持 ADR-0021 的非官方侧载实验边界，HXA-111/112 的官方 Android CLI
  失败结论没有被插件更新推翻。

  认证方式，并明确用户 Copilot subscription 可用于该 SDK。后续应优先 Spike 官方 SDK/OAuth
  App，不复用插件固定的 Copilot CLI client id 或 `copilot_internal` token endpoint。
- Grok：插件使用 xAI OIDC、Grok CLI identity/CLI proxy 与 consumer subscription。当前官方
  consumer terms 与 developer API 是不同边界，未找到允许 Helix 分发第三方 consumer subscription
  adapter 的明确授权；因此仅列为非官方侧载候选。
