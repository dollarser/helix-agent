## 范围与验收要求

1. 导入成功保留准确安装身份，配置及会话选用均定位该插件；不自动连接、执行或授予权限。
2. 本地与市场候选共用简洁组件/限制摘要，技术详情折叠；安装可读 Skill 不宣称业务可运行。
3. 导入失败提供固定、本地化的分类与恢复动作，不显示异常中的文件正文或凭据。
4. 更新预览展示实际 Skill/端点变化，保持现有端点身份与凭据重绑定规则；绑定预期 revision，拒绝陈旧替换。
5. 完全相同本地身份可复用；同名仅作候选，明确选择更新或独立安装，不跨来源自动认领。
6. 补正常、重复、失败、取消/并发及界面导航回归；完整主机门禁、两渠道 AndroidTest 编译。设备、真实模型/账号本轮 not requested；不启动完整重构、不提交推送发布。
