## 最终产品契约

- **可用工具**只有 ENABLED/DISABLED，不再有工具级 ASK/ALLOW。禁用工具从模型 schema、发现与曝光窗口移除，执行入口拒绝旧调用；启用只恢复可用性，是否询问由模式决定。
- **审批模式**为完全免确认、工作目录与联网、只读与联网、CUSTOM。三个预设与自定义编译为同一操作权限配置，统一 resolver，不实现四条执行链。
- **CUSTOM 操作权限**按类别与范围设置 ALLOW/ASK/DENY。禁止文件修改跨 write/edit/Shell/脚本/插件生效，不能通过单次批准绕过。操作 DENY 与工具禁用不是同一概念。
- **统一禁网已移出本轮范围**：按所有者条件决定及[isolated PRoot 验证](../../evidence/development/isolated-proot-feasibility-2026-09-16.md)，保留当前共享 UID Runtime，不提供 CUSTOM 工具联网 DENY/离线 Shell 开关，不为这项已撤下要求拒绝 Shell。具体工具禁用、原有网络策略、文件和远端写权限仍有效。
- **删除专项仅拦截显式 rm -rf dir**，按 ADR 的命令解析边界进入精确审批，不要求检测所有脚本/语言/原生工具的等价删除。其他删除服从普通文件修改权限；CUSTOM 文件修改 DENY 仍禁止所有途径的修改。
- **不保留旧授权兼容状态**：旧会话采用新 READ_ONLY，旧 DENY 可转换为 DISABLED，旧 ASK/ALLOW 不再参与判定。保留用户文件、会话、凭据和审计数据；不因不兼容授权语义而破坏用户内容。
- **默认设置**：安装初始 READ_ONLY，可由用户设置新会话默认模式；仅影响以后新会话。复制/导入不继承来源授权，采用用户当前的新会话默认。

## 实施顺序

### A：先验证执行域可行性

网络子项已完成可行性取证并按所有者选择撤下统一禁网要求；不是禁网功能验收通过。A 剩余工作目录/禁止修改及正常任务可用性仍须证明，不因网络取舍而降低。

A 切片进度（2026-09-16）：四域“可识别效果 / 可约束执行 / 无法保证”矩阵与证据索引见[执行域效果边界与证据矩阵](../../evidence/development/2026-09-16-hxa209-execution-domain-matrix.md)；rm 命令规则 `RmCommandRule`（argv/script 两形态）与 45 个契约测试已实现并通过；宿主侧 policy/workspace/quickjs/files/app 双 flavor 套件当日全绿新跑。工作目录限制：文件工具 lane 以逐操作重解析 seam + 副作用断言测试证明生效；Shell lane 证明 cwd 不是包含边界，fail-closed 拒绝契约的实现归属 Phase B。rm 规则的“至少精确一次性审批、任何模式不得豁免”接线与 CUSTOM DENY 的跨 lane 强制在 Phase B/C 完成。Phase A 不是新模式功能的验收记录。

分别对原生文件工具、Shell/PRoot、QuickJS、远端 MCP/A2A 建立“可识别效果 / 可约束执行 / 无法保证”的清单并提供可运行证据。

- 必须证明工作目录限制、CUSTOM 文件修改 DENY 能生效；cwd、命令名、MCP readOnlyHint 或提示词不构成证明。
- 无法约束且可能违反 DENY 的调用直接拒绝，不能转成 ASK 放行；同时证明正常只读与联网任务可用，不能全部拒绝后声称完成 Shell 支持。
- 删除专项只实现 ADR-PERMISSIONS-001 的 rm 命令解析与审批；脚本等价删除拦截不再是本任务依赖。这个例外不能用于减弱 CUSTOM 的跨工具禁止修改。
- 任意通用 HTTP 的远端效果不能靠 GET/POST 判定；可信适配器给出效果，无法确定且可能违反 DENY 时拒绝。

### B：实现单一授权配置与判定

工具二态、四模式、操作类别、范围与版本；预设和 CUSTOM 编译为同一种配置。多个效果先合并，DENY 优先于 ASK，全部 ALLOW 才免卡；rm 命令规则额外要求询问。网络许可不授予文件读取/保存或远端修改权限。

工具合法性、系统能力、Chat/Plan 边界与历史 L3/出网默认值分层。重构冲突 Policy 分支，不能让旧风险上限抵消新授权。配置修改与执行开始共用线性化边界；CAS 冲突或存储失败不显示保存成功。

旧授权结构转换/清理保持用户数据；无隐藏兼容模式。Provider 网络与工具网络保留明确调用来源；本轮不增加统一禁网配置，不将实验 seccomp/isolated Service 接入生产。

### C：工具二态与各执行入口接线

- 禁用使用可信来源加规范工具身份，别名统一；不同来源同名工具不串扰。
- schema、tools.search、MCP 会话窗口、缓存更新复用同一可用性判定；重新启用不恢复工具 ASK。
- pending/排队调用在禁用或规则收紧后拒绝并持久结算；旧 proof 不能覆盖新禁止，历史消息不删改。
- 文件操作合并源/目标效果，覆盖复制/移动/解压/保存；Shell 与脚本约束采用 A 已验证机制。
- Agent 后台进程及延迟 Job 绑定会话、任务、配置版本；尚未开始的工作复检。手动终端属人工操作，模型不能通过该入口逃逸。

### D：UI、审计、默认值与恢复

四模式选择、自定义复制预设、按范围设置操作权限、启用/禁用工具列表；不展示工具 ASK 或风险等级开关。CUSTOM 草案离开后不生效，切换模式不重新启用被禁工具。

持久化原会话配置；新会话默认独立管理；设置恢复不激活 Goal。规则收紧显示“后续操作已生效；仍有 N 个此前启动任务”并提供精确停止，不声称追溯撤销副作用。已启动进程延续行为与停止结果如实记录。

“切换并继续当前操作”重验原调用、结算旧等待，不重放未知副作用；命中 rm 命令规则仍审批。记录模式/规则版本、效果、授权来源及终态，不把自动放行伪装成用户点击批准。

### E：整合与文档收口

同步架构、安全、产品与 AGENTS 的授权要求，以当前主题 ADR 为唯一设计入口；删除失效表述，有用的替代方案理由归入 Alternatives，不保留历史正文或双轨规则。ADR-WORKSPACE-004 为独立 proposed，不修改或作为已接受依赖。

允许验证后具名本地提交，不 push/合并、不夹带并行改动。原 HXA-200/201 的已完成记录保持历史证据；新方案验收归 HXA-209，不改写历史测试结果。
