## 范围与验收要求

- 普通纵向滚动、LazyColumn 和横向溢出提供持续可见的滚条，复用原状态、键、原生滚动行为；覆盖 Provider 管理、模型选择、本地模型、设置、文件/产物/插件管理和长内容弹窗。短内容不绘制滚条，支持 RTL、窗口变化和单个超高列表项。
- Composer 区分会话恢复、附件恢复、模式切换、权限保存、发送中、历史编辑和缺失模型。附件恢复不阻止继续输入；恢复失败保留未确认的附件身份并提供既有移除入口，不让纯文本永久卡住。缓存失败可见但不要求先保存成功才能发送。
- 切换会话后旧模式协程不修改新输入；保留当前模型、权限和停止入口，键盘/短窗口减少输入框可见行，附件改为横向紧凑区域。
- Mobile Use 启动页校验整组选定包名，明确反馈无目标、格式错误、服务未连接和启动异常；非法输入不覆盖保存的选择，显示当前许可剩余时间和动作数。
