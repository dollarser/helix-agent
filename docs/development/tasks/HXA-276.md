# HXA-276：Browser 原生插件贡献与统一选择入口

日期：2026-10-11。状态：已排期，未开工。优先级：P2。依赖：HXA-272、HXA-274；HXA-275 为推荐前序，非 Browser 执行器前置。

Owner request：依据两份插件研究文档和当前代码更新开发计划；按单一合理目标实现设计，不兼容旧版。本轮只登记任务，未实施或验证功能。当前顺序由 [status](../status.md) 维护。

共同设计基线：直接替换所涉旧入口，不做旧版本、旧数据库、旧会话或旧批准迁移，不保留双写/双注册和兼容 adapter。开发期存储沿用现行 baseline 规则；历史证据保留原含义。原执行身份、权限、取消结算和渠道边界继续有效。

## 当前代码与缺口

[BrowserTools](../../../tools/browser/src/main/kotlin/com/helix/tools/browser/BrowserTools.kt) 仍从 [DefaultAppContainer](../../../app/src/main/kotlin/com/helix/app/DefaultAppContainer.kt) 直接注册 12 个内置工具；[BrowserController](../../../feature/browser/src/main/kotlin/com/helix/feature/browser/BrowserController.kt) 已有标签与 Activity-owned WebView 生命周期。此卡只改变贡献归属、内容和会话选择，执行与视觉能力复用当前实现。

## 范围与验收要求

1. 建立宿主已知的 Browser native contribution，目标模块 `:extensions:browser` 保存 manifest、工具贡献和网页任务 Skill；App composition root 注入现有 BrowserToolBridge 与 ToolVisualPreparation。插件不持有 Activity/WebView，不创建独立浏览器 server。
2. 将 12 个工具统一生成为 `ToolBinding` 并使用 Browser 的 `PluginOrigin`；替换直接 `BrowserTools.registerAll` 的 built-in 发布，只有一个 owner。公开 `browser.*` 名称可沿用当前领域契约，内部旧注册/批准身份不做转换。
3. Browser 作为双渠道捆绑能力进入已有插件目录和会话面板；新会话默认集合包含 Browser，用户可在现有入口取消选择。选择不拉起 WebView、不批准网站访问，也不强制其他插件使用 MCP。
4. 手动浏览、书签、历史和用户导航继续由浏览器功能负责；Agent 来源关闭只撤下其后续工具准入，不能关闭正在手动浏览的标签。
5. 接入 HXA-272 的 Skill 内容路径及 HXA-274 的 host/组件状态；无 Activity host、页面失效、取消和视觉不可用必须返回真实原因。
6. 直接删除旧发布入口和对应内置来源假设，更新 native 作者样例。旧版会话默认值、旧批准和旧数据库迁移不属于交付物。

## 契约与范围边界

2026-10-11 已同步 accepted [ADR-CONNECTORS-003](../../adr/connectors/003-ownership-and-installation.md) 的默认集合与贡献归属、[ADR-PLATFORM-002](../../adr/platform/002-browser-lifecycle.md) 的 Browser/Activity 边界及 [ADR-TOOLS-001](../../adr/tools/001-descriptor-contract.md) 的单一绑定；[Plugin 专项](../../architecture/plugin-platform-plan.md)保留模块说明。保留原 URL/origin、generation/token、目标范围、执行授权和图像披露；本任务不增加 tabs/close/wait 或 Playwright API，新增交互由 HXA-279 承接。

## 验证入口

实施时运行本卡涉及的现有主机回归、全仓 source/JVM/静态检查及双渠道 Debug lint、APK、AndroidTest APK 编译，具体命令沿用[公共验收](../verification-matrix.md)。下列设备/模型场景是后续验收要求，本次均为 **not requested**；只能在当轮明确授权后执行，缺少输入不伪报通过，也不阻塞无依赖的主机工作。

- 扩展 [BrowserToolsMappingTest](../../../tools/browser/src/test/kotlin/com/helix/tools/browser/BrowserToolsMappingTest.kt)、PluginRegistry/会话选择/请求曝光回归：12 个工具仅一个绑定，全部来源正确，未选择/撤销/旧审批不能执行。
- 新会话默认集合与用户修改相互独立；手动浏览不受 Agent 插件选择影响。
- 后续设备验收覆盖双渠道原 BrowserActions/Snapshot/Security/Owner 旅程及截图像素回流，新增会话选择→页面操作→停用→手动浏览场景。
- 生产不存在 built-in 与 plugin 双注册、旧批准转换或临时 MCP 回环调用。
