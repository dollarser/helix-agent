## 范围与验收要求

Antigravity 原始签名继续留在订阅私有进程，不进入模型业务参数或主进程。现有 129 条历史保留与 canonical args 修复保持有效，不恢复 LRU。以可信宿主传入的会话归属和实际保留历史引用判断可清理性；分支、压缩前和被替代但仍保留的历史也是引用。模型不能制造清理资格。

- 会话身份进入实际请求封装及 write-ahead 请求哈希，正常会话与短期探测分开。
- 只提供有界元数据清单和精确指纹删除；不返回原始 parts 或账号凭据。候选产生后新写入或变更的记录不能被旧候选删除。
- Runtime 活跃执行或未确认结果保留；清理不代替取消、ACK 或恢复。无法证明安全、历史损坏、来源离线及范围超限明确报告未清理。
- 永久删除会话后尝试清理无引用私有证据；只归档不删除。老版本缺归属的记录在仍有会话时保守保留，不推断其属于最后使用的账号。
- 存储占用、实际删除、保留和继续清理信息分别报告；磁盘失败不损坏有效记录。
