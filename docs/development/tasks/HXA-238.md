3. PRoot 支持四个独立 Job 与两个终端并存；前台服务按 Job 维护 admission，日志独立排空、单例 journal 有短同步。环境维护与在用进程互斥；逻辑超时/终态观察不提前释放仍活着的物理槽。
4. 新用户任务不因历史 UNKNOWN 全会话拒绝；自动只读核查不自动获得写权限，原未知事实保留，不自动重放。
5. Provider 表单溢出显示滚动条及更多提示；保存可触发缺项/协议/HTTP 确认反馈并定位字段，不把可选 API Key 当必填，内部存储失败不泄露密钥或异常正文。
