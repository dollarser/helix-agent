## 范围与验收要求

| 当前代码接缝 | 裁决 | 启动与退出条件 |
| --- | --- | --- |
| Dispatcher 识别 JobObservationExecutor/JobLaunchWaitExecutor；LaunchWait 解析 originalCallId | P2，局部契约候选，不是已证明故障。当前 internal 类型承担观察只读、等待与容量释放；解析后重核原 call ID | 当目标分层/代表性扩展验证需要明确执行角色，或重复解析形成真实成本时，用窄可信契约替换对应分支；保留 no-start、原执行身份、观察不执行、取消不提前释放、旧 generation 与 UNKNOWN 反例，不能让远端元数据自报资格 |
| ToolVisualFeedback 截图用途、FileHistoryPaths 路径投影 | P2，按消费者收益评估。当前截图特判还执行本地模型屏幕披露，路径是请求-only展示，不是第二身份权威 | 若改为现有产物用途/路径身份字段，须证明原持久身份与披露/授权完全保留；不把删除工具名条件本身当完成，不修改全部后端结果 JSON |
| 显式 snapshot 跨来源层级 manifest | 独立增强未交付，P2 | 仅在明确用户任务需要时实施，验证多根重名、嵌套 cwd、源变化、撤权、部分发布及重复收取；不成为默认原位或文件工具可用的前置 |

同一输出的 JSON、BoundToolResult、日志、文件登记承担不同层次，不因名字类似合并数据库或新建通用执行协议。当前类/JSON 不因已交付免改，亦不要求等待第二消费者；以目标分层、可信角色和代表性扩展反例裁决。若依赖与事实已符合目标则停止，不以 288 标题推动无需求的全域重建。

## 验证入口

沿[执行域 ADR](../../adr/runtime/001-execution-domains.md)和[Workspace ADR](../../adr/workspace/004-workspace-binding.md)，调用返回、实际退出、输出 EOF/截断、持久提交分别举证；进程 STOPPED 可与 outcome UNKNOWN 并存。取消受理不等于退出/回滚，晚到事实归原身份，原收取/ACK 不重执行。非进程 MCP/HTTP 不伪造 POSIX/Job 字段，持久日志按会话/调用授权补读，主机文件路径不直接冒充模型访问权。

只重跑受影响的 Dispatcher、Job/资源、视觉披露、文件身份、原位/显式副本与日志回归；真实 Runtime 退出/设备/模型另按当次授权验证。与 287 的联验仅覆盖实际改动的命令/执行接缝，不重建最小宿主后再证明原能力。
