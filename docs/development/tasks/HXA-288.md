## 范围与验收要求

1. 实现 286 定义的公共契约：调用返回、实际执行退出、输出收尽、结果落盘分别有判据，并关联原 Job 状态与产物发布。同步工具无需变成 Job；MCP/HTTP、原生回调与进程分别保留真实完成/错误/取消语义，不伪造 POSIX 退出码，手势派发不等于业务成功。
2. launch/observe/collect/cancel 绑定原 executionId/generation/session/turn/call；停止等待、取消执行、收取和 ACK 各自表达，不重发命令、不续租、不用同名工具重新绑定。
3. 类型化产物来源、用途与引用，区分内部观察、交付文件、模型视觉输入；保存、展示、实际发送分别留事实。替换所涉 toolName/JSON 字段推断，不建立第二产物库。
4. 288-A 先以受控同步、异步/观察实现验证执行核心；与 287-A 用现有文件/只读路径和最小 Room 共同验证生产接缝，再按 Mobile Use → 既有 PRoot Job 逐领域接线和验收，MCP/HTTP 适配按其真实语义验证。每条完成路径统一结果回填并删除重复 DTO、具体 executor 类型分支和旧完成入口；不以所有插件已迁完作为核心集成前置。
5. cancel requested/confirmed 与实际退出分开；取消/逻辑超时/Turn 终态不释放未退出物理槽或仍被使用的插件资源。原 owner 负责输出 drain/完整性，应用负责持久结算，资源 owner 与产物库各按引用完成清理；进程已退出但输出未收尽不可假报完整。原引用释放、未知效果、当前版本重启 reconcile 和 GC 保持现有事实来源，UNKNOWN 不盲重放。QuickJS/PRoot/Root 的真实隔离范围不变。

6. 调用身份与长期资源句柄、控制权和真实存活分离；按真实资源 owner 的期限/引用释放，不能一律随 ToolCall 或 Turn 结束销毁。不同消费者/项目的隔离由显式身份保证，不把句柄当授权。进程死亡可使句柄失效，不承诺自动恢复内存或重放输入。
7. Direct/Observation/Launch-then-observe 只描述当前接线；控制长期资源可走普通具名调用，不强迫持久终端/LSP 变成一次性 Job。保留按具体不可重入资源协调，禁止引入全局 Agent/终端互斥；本轮不新增终端输入或语言服务。

2026-10-16 接续 HXA-297：复用同 Turn 的 modelCallId/callIndex、持久 ordinal/时间与工具批次消息；保持拒绝/取消来源及非模型调用空来源。引用 GC 复用已有索引与单候选发布锁；类型化产物/执行完成语义仍需本任务完成。

## 验证入口

- 288-A 先验证取消请求已确认但 executor 未退出、迟到旧 generation、大输出/乱序/截断、进程退出但输出通道未收尽及结果落盘失败；共同集成时与 287 交叉验证 crash/reload、原 call/result 配对与无重复执行。每个领域适配重用适用反例，最终 294 汇总和回归已有证据。
- MCP/HTTP 等非进程调用明确不适用的 Job/退出字段，插件缺失或撤权保持原调用事实；不能为凑齐生命周期接口而创建空 Job 或将远端取消响应解释为副作用回滚。

- 用既有 Job/原生共享资源验证一次调用结束但资源仍被持有、关闭 A 不关闭 B、控制句柄失效、迟到旧 generation 和真实退出后回收；人工输入资格不能由模型调用继承。

- 复用 Dispatcher、ExecutionOwnership、Capacity、JobObservation/LaunchWait、NativeResource 及视觉/Workspace 测试，覆盖迟到退出、失败结算、乱序回填、重复 collect/ACK、撤权和 UNKNOWN 不重放。
- 验证图片已保存但未发送、跨会话/过期 hash 拒绝、活跃引用与 GC；PRoot/设备物理退出和真实图像请求按当次授权另验。
- 开始实施时定位现有测试入口并按改动选择回归；目标契约可替换旧实现镜像断言，权限、持久原子性、取消、真实退出与恢复反例不得丢失。设备/服务须核对当次授权与配置，本轮未执行。
