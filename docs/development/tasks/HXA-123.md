# HXA-123：选定渠道提交准备与审核证据

分类：发行队列。当前是否执行见[实施状态](../status.md)。

前置条件：121、122；外部提交另需授权。

本次复核：可先准备材料；提交、审核、通过分别记账，不把计划渠道都当当前开发阻塞。

核对依据：[源码或有效证据](../../adr/platform/001-distribution.md)。本轮只审查，不新增测试通过或完成声明。

## 范围与验收要求

完成 Google Play 与首批国内 Android 应用商店的真实提交准备和渠道决定。优先通过核心用途声明、显著披露、用户同意和审核保留 All-files、Accessibility、解释脚本等能力；只有明确条款或真实拒审才做最小渠道裁剪，并记录对应模块与替代路径。真实审核通过前状态只能是“准备提交/已提交/审核中/被拒”，不能写“可上架”或“已上架”。

### 分工与收口

准备材料属于本任务；实际外部提交/发布仍需用户明确授权。区分准备完成与渠道审核通过，未提交不伪造审核结果。
