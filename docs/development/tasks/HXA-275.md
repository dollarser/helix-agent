# HXA-275：插件组件兼容诊断与可执行作者样例

日期：2026-10-11。状态：已排期，未开工。优先级：P1。依赖：HXA-272、HXA-273；诊断展示接 HXA-274。

Owner request：依据 Agent 插件架构调研、Helix 优化方案与当前代码拆分开发任务并更新计划；所有者追加要求按合理目标架构设计，不兼容旧版。本卡登记未来实现范围，本轮只完成计划，不代表代码或功能验收。执行顺序由 [status](../status.md) 维护。

共同设计基线：单一目标实现，旧入口随对应切片直接替换；不做旧版本、旧数据库、旧会话或旧工具批准迁移，不留双写、双注册与兼容 adapter。开发期存储沿用现行 baseline 重建规则；历史证据仍按原版本解释。原执行身份、权限、取消结算和渠道边界继续有效。

## 当前代码与缺口

[PluginPackageReader](../../../extensions/plugin/src/main/kotlin/com/helix/extensions/plugin/PluginPackage.kt) 已区分标准根与外部格式，并诊断 stdio、host app、未知 native、hooks/agents/commands/dependencies 等；[PluginInstallationService](../../../app/src/main/kotlin/com/helix/app/plugin/PluginInstallationService.kt) 已固定预览 hash。此卡补完整、可解释的组件矩阵和规范化诊断，不重做安装与安全校验。

## 范围与验收要求

1. 按明确支持的当前包格式版本声明矩阵：Skill、HTTPS MCP、APK 已知 native、stdio/桌面脚本依赖、注册 app 映射、hooks、Agent 定义、命令、LSP、依赖、配置 schema 和 Skill 执行字段。
2. 用同一解析结果表达“可用、需配置、仅保留元数据、不支持”，附组件/字段路径、原因和现有操作；preview、安装摘要、组件 readiness 与模型结果共享该数据。
3. 保持恶意归档整体拒绝与可隔离组件局部失败的区别；可用 Skill＋未配置 MCP 仍可使用 Skill。不把未知执行字段悄悄展平为主 Agent 指令。
4. 必要/可选包依赖与运行时条件分别诊断。缺少依赖不自动下载安装，也不创建占位 server；同名工具和相似 URL 保留准确 owner/账号/endpoint。
5. 按现有归属处理内容快照、用户配置、SecretStore 和产物，明确更新保留与卸载清理范围；沿用现有安装/更新规则，不引入旧版本迁移。
6. 交付三种真实样例及 fixture：纯 Skill、宿主已知 native、远程 MCP（本地受控服务替身）。从作者说明、预览、安装、选择、首次调用到停用都使用生产解析器；文档随样例交付，不另造 SDK 或市场发布平台。

## 契约与范围边界

2026-10-11 已同步 accepted [ADR-CONNECTORS-003](../../adr/connectors/003-ownership-and-installation.md) 的组件支持与诊断规则、作者样例和 Decision history；[Plugin 专项](../../architecture/plugin-platform-plan.md)保留格式与实现说明。外部当前格式的互操作支持不等于兼容旧 Helix；不保留已退役内部模型或导入执行语义。HXA-125/126 的真实认证验证仍归原任务，本卡用受控 fixture 完成可执行部分，不消费真实账号。

## 验证入口

实施时运行本卡涉及的现有主机回归、全仓 source/JVM/静态检查及双渠道 Debug lint、APK、AndroidTest APK 编译，具体命令沿用[公共验收](../verification-matrix.md)。下列设备/模型场景是后续验收要求，本次均为 **not requested**；只能在当轮明确授权后执行，缺少输入不伪报通过，也不阻塞无依赖的主机工作。

- 扩展 [PluginPackageReaderTest](../../../extensions/plugin/src/test/kotlin/com/helix/extensions/plugin/PluginPackageReaderTest.kt)、[PortablePluginContractTest](../../../extensions/plugin/src/test/kotlin/com/helix/extensions/plugin/PortablePluginContractTest.kt)、[PluginCompatibilityTest](../../../extensions/plugin/src/test/kotlin/com/helix/extensions/plugin/PluginCompatibilityTest.kt) 与安装预览回归。
- 矩阵每行均有正例或明确拒绝 fixture，覆盖不支持字段、缺依赖、同名冲突、目录逃逸、凭据泄漏、取消与内容变化；可用组件不会被无关连接失败整体禁用。
- 样例端到端沿用既有 mock MCP/主机入口；设备上的安装、选择、修复和退出旅程在后续明确授权后验证。
- 完成时无“支持了格式即可执行所有组件”的声明；组件诊断只有一个生产来源。
