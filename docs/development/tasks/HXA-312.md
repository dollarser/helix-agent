# HXA-312：本地知识库检索问答

## 范围与验收要求

Owner 授权在 HXA-311 后推进检索问答，随后再做确认式自然语言提醒和最小定时 Agent。当前任务只实现知识库问答，不启动整套重构。保留真实用户资料、会话及设置；版本和工具声明不变，不 push/发布，真机手测按 Owner 选择延后。

- 问题先在本机按词检索原始来源；英文词与中文双字片段，有界候选与确定性排序，无结果不调用模型。不是语义搜索或完整性保证。
- 用户选择最多八份来源，核对命中附近的有界片段、来源时间/完整性和所选模型目标后显式发送。请求不包含其他来源、历史问答、笔记、人格记忆或原件。
- 问答记录独立于原始来源及用户笔记；只有显式保存才生成可编辑、未核对草稿。来源引用冻结，来源后续变化/删除不改变已生成证据；保存幂等。
- 模型需正常完成且引用至少一个真实所选来源 ID；伪造/缺失引用、拒答、截断、工具调用失败。引用有效不等于模型事实正确，用户需核对片段。
- 取消/失败/中断保留终态，不自动模型重试。确认前来源或 Provider 配置变化使发送失效。
