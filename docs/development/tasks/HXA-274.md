# HXA-274：插件就绪原因与配置生效状态统一投影

日期：2026-10-11。状态：已排期，未开工。优先级：P1。依赖：HXA-272；复用 HXA-271 已交付授权状态与恢复入口，HXA-273 为推荐前序而非接口硬依赖。

Owner request：依据 Agent 插件架构调研、Helix 优化方案与当前代码拆分开发任务并更新计划；所有者追加要求按合理目标架构设计，不兼容旧版。本卡登记未来实现范围，本轮只完成计划，不代表代码或功能验收。执行顺序由 [status](../status.md) 维护。

共同设计基线：单一目标实现，旧入口随对应切片直接替换；不做旧版本、旧数据库、旧会话或旧工具批准迁移，不留双写、双注册与兼容 adapter。开发期存储沿用现行 baseline 重建规则；历史证据仍按原版本解释。原执行身份、权限、取消结算和渠道边界继续有效。

## 当前代码与缺口

[PluginComponentReadiness](../../../app/src/main/kotlin/com/helix/app/plugin/PluginComponentReadiness.kt) 以组件布尔值和诊断前缀计数；[PluginService.sessionRows](../../../app/src/main/kotlin/com/helix/app/plugin/PluginService.kt) 已提供选择错误，[CapabilityReadiness](../../../app/src/main/kotlin/com/helix/app/readiness/Readiness.kt) 已有只读准备投影。HXA-271 阶段6/7 已实现 Mobile Use 配置/观察后端检查与授权恢复；并行阶段9又增加配置不足时先说明原因、再由用户进入设置的引导（主机交付，新增UI夹具仅编译）。本卡补跨组件的一致表达、生效时点及下述恢复投影承载接口。

同日系统分层复核补充：[ChatScreen](../../../app/src/main/kotlin/com/helix/app/ui/ChatScreen.kt) 将 `recoveryModelsNavigation` / `recoveryPermissionsNavigation` 写入 ChatService，服务保留页面回调。本卡在恢复投影的同一切片收敛这一依赖，属于现有功能的接口增量，不是已复现的泄漏或运行故障，也不重做 HXA-257/258。

## 范围与验收要求

1. 在现有投影中表达可核实的原因与动作：包/组件不支持、待配置、未连接、宿主不可用、会话未选择、本请求能力不可用。状态带具体来源，避免一个 ready 布尔值承担安装与可执行全部含义。
2. 区分安装内容 revision、已保存配置、实际加载/握手事实和当前请求绑定；显示“下一请求生效”“连接未重建”等有事实依据的反馈。底层身份放详情，不要求用户理解 hash。
3. 复用 Mobile Use 已有状态；补 portable Skill、MCP 连接和 Browser WebView host 的相同投影入口。Browser 的原生插件接线由 HXA-276 完成，当前可先用已有 Browser 能力事实。
4. UI 与模型使用同一只读快照及稳定原因；执行前仍由 Dispatcher 重新准入。只读检查不申请系统权限、连接 Root、发起 OAuth、运行模型或重启 Runtime。
5. 相似能力展示实际提供方、目标/后端及账号标识；不按同名或 URL 自动合并。用户选择、默认新会话集合、组件连接和 Stop 各保留原操作含义。
6. 删除重复的 UI 本地 ready 推导；新的结构化诊断直接替换所涉字符串推断，不保留旧版返回字段兼容层。
7. 恢复原因、目标类型及必要会话/来源身份由应用层以数据提供，当前 UI 在用户点击后解释目标并导航；替换上述服务持有页面导航回调的接线，迁移所有受影响消费者并删除旧入口。无页面订阅仍可产生准确状态，旋转/重订阅/切换会话不能自动跳转或让旧目标作用到新会话。保留 HXA-271 的“先说明、用户点击去设置、取消不选择/不保存”行为；不另建通用事件总线或全量 ChatService facade。

## 实施切片顺序

1. 核对现有原因与恢复入口，定义最小结构化目标及身份；先保留原权限、选择、提交门禁和状态 owner。
2. 应用服务提供同源快照，实际 UI/模型消费者切换到新投影；页面处理导航，执行仍走原命令/Dispatcher。
3. 同一切片删除旧导航回调、字符串推断和重复 ready 计算，不保留生产双通道。
4. 按下方场景核对生命周期与无被动副作用；HXA-275/276 消费此接口。其他应用入口提取保留条件，不成为本卡前置。

## 契约与范围边界

2026-10-11 已同步 accepted [ADR-CONNECTORS-003](../../adr/connectors/003-ownership-and-installation.md) 的就绪原因与生效投影；[Harness §17.4](../../architecture/harness-refactor-plan.md#174-最小用户闭环)保留交互接线说明。不恢复已取消的用户侧插件全局开关，不把已保存等同已连接，不重新开发 HXA-271 的授权中心。恢复后真实设备执行验收仍归原任务；它不阻塞本卡独立的投影实现。

应用命令、读模型与页面导航的边界同时归 [ADR-AGENT-001](../../adr/agent/001-turn-coordination.md)；本卡只承接恢复展示及接口替换，不提取完整 Turn 宿主、不改变原 Engine 事务。范围补充来源为[系统分层分析](../../research/modules/01-architecture-and-execution-engine.md#9-2026-10-11-分层复核与优化承接)。
