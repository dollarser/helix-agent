# HXA-126：Connector OAuth 登录层

分类：进行中。当前状态见[实施状态](../status.md)。所有者已授权修复 OAuth 候选并合入 main；accepted [ADR-CONNECTORS-002](../../adr/connectors/002-oauth.md) 是设计授权，不是两家真实服务验收通过。

## 范围与验收要求

`extensions/mcp`、`app/mcp/oauth` 与 Connector 原生界面实现预注册 public client 的 PKCE 浏览器登录、服务明确支持时的 Device Authorization，以及原有 bearer/PAT 路径。不使用其他宿主的账号、Cookie、Client ID 或 CLI token。

回调按安装包 scheme、完整路径、state 与 issuer 绑定；服务识别使用精确 HTTPS 主机。attempt 的元数据和加密 verifier 分离，一次性原子领取后才兑换 code。token 的 server/resource/issuer/client、过期时间和刷新中状态持久化于 SecretStore；实际 MCP handshake 和 tools/call 前检查绑定、刷新，遇到不明刷新结果要求重新登录。登录不自动启用工具。

缺陷根因与修复证据见[修复记录](../../bug-fixes/2026-09-21-connector-oauth-merge.md)；早期候选失败保留在[合并前复核](../../evidence/development/hxa-126-merge-review-2026-09-21.md)。

## 验证入口

所有 Gradle 和设备运行通过 `python3 scripts/with-host-slot.py --` 串行持有 host slot；配置本机 JDK17 与 Android SDK 环境。日志、APK 与设备 PID 留在忽略的 `build/`。

- `./scripts/check-all.sh --all`：全部 source/JVM/lint/Debug 与 Release 制品边界。
- `./gradlew :extensions:mcp:test :app:testConsumerDebugUnitTest :app:testDeveloperDebugUnitTest`：回调/路径/机密存储/资源绑定/并发刷新/未知结果/撤销回归。
- `./gradlew :app:assembleConsumerDebugAndroidTest :app:assembleDeveloperDebugAndroidTest`。
- `python3 scripts/debug/2026-09-21/accept-hxa-126-oauth.py --output build/oauth-device-acceptance`：API29/36 × consumer/developer 的独占实例；OAuth Keystore/回调/取消/过期/真正换 PID 恢复，加 Connector 回归。输出目录必须不存在；不复用别人的模拟器。具体通过数字只在实际结果生成后记录。

- `python3 scripts/run-acceptance-matrix.py --scope 206 --group extensions --group extensions-restart --output build/oauth-extension-regression`：扩展普通旅程与独立 seed/recover 阶段分别执行；consumer 专属限制和阶段不匹配的 skip 保持原样记录，不算通过。

## 未完成范围

- 两家真实独立服务的 App 注册、账号/组织准入、精确 redirect、公有客户端与 PKCE/Device Flow 配置；登录后只读 tools/call、拒绝、刷新、厂商撤销和重连。缺少真实条件不记通过。
- 动态客户端注册尚未实现；自有 HTTPS App Link/client metadata document 也未启用。预注册 public client 不等于任意服务都兼容。
- Device Flow 进程死亡后不自动后台轮询；用户重新发起登录。未知 token 交换/刷新结果不自动重放。
- 本轮真实进程恢复使用模拟器，不能替代 OEM/Doze/热压力、签名发行或商店审核。
