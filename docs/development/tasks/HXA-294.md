## 验证入口

- 权限链、原绑定/实例、持久结算、取消/迟到事实、原调用顺序、UNKNOWN 和有限技术恢复不因重构改变。正常进入终端/新 shell 与旧未知命令核查继续分离。
- 同一真实工作区 native write → exec → read、显式 snapshot 的来源/输出/引用是现行两条路径；不恢复“当前默认快照”的旧前提，不要求整工作副本 ZIP。
- 真实 Mobile Use 动作只证明平台派发，任务效果由新观察/独立事实验收；模型 OCR 质量和服务器语音问题不自动归因为客户端架构缺陷。
- 每包记录成功构建、实际输入和安装候选身份；主机、Room/模拟器、真实模型、真机/OEM、长稳、Release/签名分别结论。本轮文档工作不授权其中任何执行。
- 复用已有测试/runner，新增故障注入只针对已改变边界；不以接口数、删行数、固定测试总数或所有竞品功能作门禁。不降低失败断言，不无限追加模型轮次。
