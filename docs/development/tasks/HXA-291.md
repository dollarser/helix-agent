## 验证入口

- 完成标准：同一实际连接上列举/模板/读取的身份和分页一致，模型下一请求得到可核查正文或明确不可读事实；仅 `listResources` 成功不能通过正文验收。
- 不确定项：目标服务是否支持 Resources/templates、SDK 暴露的分页/通知行为以及二进制类型。先用可控协议夹具固定契约；缺少真实服务是待验输入，不标为已通过，也不重开 Notion/Linear 结案。

- 使用本地协议夹具覆盖空列表、cursor、模板、错误来源、断连/撤权、过大正文和二进制；验证实际下一请求拿到内容而非仅元数据。

## 2026-11-08 文本切片实施

已补 facade 的 list/templates/read 及 SDK 实际协议接线、每服务器宿主资源 descriptor、既有 MCP 执行/认证/egress/撤销生命周期与 Resources-only 启用。读请求同连接重验 URI 来源，文本带 URI/内容 hash/不可信标识；不把远端 URI 转成本机路径或指令。

分页以来源绑定的宿主 continuation 重连重放前序元数据，并校验 hash 后使用新连接 cursor；变化明确失败。每类最多16页、累计1 MiB发现元数据；每页128项/256 KiB；正文64块/256 KiB UTF-8。简单标量模板用有界 DP 匹配；更广 RFC6570 表达式不支持。二进制明确拒绝，不冒充已经物化或发布。

新增 HTTP 协议、宿主 descriptor、分页边界和恶意模板回归。初轮通过不代表后续修改；最终门禁结果由本轮统一收口补充。设备、真实 Resources 服务和实际模型下一请求消费仍未验证。本切片不重做 OAuth，不启动后续长期缓存优化。

模板匹配额外共享每次发现 16,777,216 个 DP cell 的计算预算，跨模板/页不重置；超额返回 `MATCH_BUDGET_EXCEEDED`。每8行重新检查来源/取消并 `yield`，让同事件循环的 deadline 生效，避免多模板累积 CPU 阻塞。新增累积模板页、排队取消、同循环 deadline 与处理中撤销回归，最终通过结果由统一门禁补录。

### 2026-11-08 简单标量模板来源校验补正

独立审查发现原通配匹配错误拒绝空值，并允许同名变量不同展开和原始 reserved 字符。改为保留变量身份的两阶段匹配：滚动 DP 支持空值及完整 ASCII unreserved / `%HH` 单元；含重复名称且形状匹配的模板再用显式栈搜索验证相同编码区间。相邻变量和相邻重复变量保留支持，不加入其他 RFC6570 运算符。

变量名维持 `[A-Za-z0-9_]+` 子集，明确不支持 RFC6570 点号/百分号编码名称；文字部分的 `%HH` 必须完整，不允许跨文字/变量边界拼接百分号编码。回归覆盖该子集、文字百分号邻接变量和重复空绑定。

DP、搜索分支和逐字符比较共用原 16,777,216 工作预算；搜索不声称多项式复杂度，达到预算明确失败，不继续无界回溯。搜索每1024工作单元检查撤销并让出协程，保留原 DP 每8行检查与跨模板累积预算测试。新增编码/空值/重复名称、小规模穷举及歧义搜索预算、取消、撤销、同事件循环 deadline 回归。当前为代码与回归补正，未运行 Gradle或设备验证，最终结果由统一门禁补录；不改变实际模型消费与真实 Resources 服务的未验状态。
