## 一手依据与取舍

- [Claude Code 会话命名](https://code.claude.com/docs/en/sessions#name-your-sessions)：首 prompt 后台摘要、尊重手动标题。[OpenHands 标题工具](https://github.com/OpenHands/software-agent-sdk/blob/main/openhands-sdk/openhands/sdk/conversation/title_utils.py)：模型失败/空结果使用有界文本回退。采用自动可辨认标题、手动优先和非阻塞路径；Helix 本轮采用已接受首条输入的有界文本标题，不额外发起模型请求：服务未统一提供廉价小模型，标题不应增加首轮延迟、费用或主任务失败点。未命名使用空值语义，显示层本地化占位；与输入受理同事务初始化，手动标题禁止空值且永不自动覆盖，因此无需为单次初始化引入异步修订状态或新表。历史占位标题不猜测归属、不批量替换。
- [Claude Code bypass 模式](https://code.claude.com/docs/en/permission-modes#skip-all-checks-with-bypasspermissions-mode)、[WCAG 颜色](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)、[Android 无障碍](https://developer.android.com/guide/topics/ui/accessibility/apps)：风险可辨认、颜色之外保留明确的模式文字、触控目标至少 48dp；不声称复刻 Codex 未核实的确切颜色。
- [WebViewClient](https://developer.android.com/reference/android/webkit/WebViewClient)、[WebView 调试](https://developer.android.com/develop/ui/views/layout/webapps/debugging)、[渲染进程终止](https://developer.android.com/develop/ui/views/layout/webapps/handle-termination)：原生导航回调、主文档/子资源错误分开和真实渲染证据。[Chrome 清理数据](https://support.google.com/chrome/answer/2392709)：清理动作及影响应清楚；不为本轮增加依赖或清理整个设备。
- [豆包手机助手官网](https://o.doubao.com/)：系统/设备集成有自身条件。Helix 以独立 Android 应用和插件交付已有能力，宣传不扩大支持边界。
- [Compose 默认无障碍行为](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)：缩减视觉内边距与重复间隔，同时保留可靠触控区域；不通过重叠的小点击目标换取紧凑外观。
