## 范围与验收要求

近期 P1，优先 Mobile Use 主打流程；两个切片可独立完成，均只依赖 286/288 已稳定的相关接缝，不要求全部宿主/插件先迁完。

| 切片 | 动机与非目标 | 完成标准、测试与不确定项 |
| --- | --- | --- |
| Mobile Use | 降低动作参数/坐标误用和无效观察往返；授权、范围多选、浮窗、后端重建、截图来源/返回和发现配套已有，不重做、不融入宿主业务规划器 | 合成页面覆盖原图/缩放/旋转、系统栏/IME/遮挡、旧 generation、接管后新观察与取消；实际动作/新观察/独立业务判分分开。Android/OEM 差异与模型遵循率需有界实测，不能从参数简化直接宣称提升 |
| Browser | 补网页表单实际缺口，沿原 WebView/节点绑定；不引入 Playwright 或永久 JS 权限桥 | replace/append/submit、按键/select/授权文件上传独立夹具通过；跨 origin、页面替换、撤权及文件来源拒绝保持。动态站点/网站限制列真实边界，不为页面成功硬编码流程 |

Mobile Use 运行可靠性按事实分三类：已知客户端缺陷有复现才修；未覆盖的进程死亡/后端/OEM 组合是验证项；Owner 已确认的 Qwen 图像误读是模型限制。302 最终 R8 图片 UI 与 301 抖音有提示复测分别保留，不升级为通用视觉/全自主成功；不靠扩大截图或自动重放动作掩盖不确定性。

1. Browser 补键盘提交/按键、选择控件及授权文件上传，明确输入替换、追加与提交；沿原页面/节点/目标绑定、权限和等待路径执行。
2. Mobile Use 简化常用点击/输入/滚动/滑动参数，frame、截图原始尺寸、缩放、旋转及坐标空间由宿主统一映射；不让模型猜单位或手算图像变换。
3. 输入注入与业务完成分开；失效目标、遮挡/隐藏确认失败、敏感 UI 与未知系统过滤继续如实反馈，不靠无界重试或跨后端重放动作。
4. 同步模型工具描述、内置 Skill 和用户可理解的结果/配置提示，保留展开诊断详情；不新增第二个观察平台或通用操作后门。

## 验证入口

- Browser 表单夹具核验替换/追加/Enter/select/upload、跨 origin 和授权撤销；Mobile Use 覆盖 frame 缩放旋转、旧 token、取消、悬浮窗及注入/效果区分。
- 按授权用合成界面和真实模型比较参数错误、发现往返、调用数及任务成功；不继承旧 R6 长稳或据短验声称普遍改善。
- 开始实施时定位现有测试入口并按改动选择回归；目标契约可替换旧实现镜像断言，权限、持久原子性、取消、真实退出与恢复反例不得丢失。设备/服务须核对当次授权与配置，本轮未执行。
