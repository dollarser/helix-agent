## 2026-10-24 历史裁决

历史裁决：当时 BrowserInteractionTools.browser.type 参数为 tabId/token/text，新增提交、选择、上传尚未交付。当前实现见下方 2026-11-15 核对，不沿用旧待实施结论。Mobile Use 已有原图/帧身份、授权/浮窗与 AutomationToolOutcome 的 DISPATCHED/UNVERIFIED 契约；具体失败需复现才修，OEM/生命周期未覆盖组合是待验，模型视觉误读是质量边界。

## 范围与验收要求

独立能力/验证队列 P2；按可复现客户端缺口与用户任务确定优先级，两个切片可独立完成，均只依赖 286/288 已稳定的相关接缝，不要求全部宿主/插件先迁完。

| 切片 | 动机与非目标 | 完成标准、测试与不确定项 |
| --- | --- | --- |
| Mobile Use | 降低动作参数/坐标误用和无效观察往返；授权、范围多选、浮窗、后端重建、截图来源/返回和发现配套已有，不重做、不融入宿主业务规划器 | 合成页面覆盖原图/缩放/旋转、系统栏/IME/遮挡、旧 generation、接管后新观察与取消；实际动作/新观察/独立业务判分分开。Android/OEM 差异与模型遵循率需有界实测，不能从参数简化直接宣称提升 |
| Browser | 补网页表单实际缺口，沿原 WebView/节点绑定；不引入 Playwright 或永久 JS 权限桥 | replace/append/submit、按键/select/授权文件上传独立夹具通过；跨 origin、页面替换、撤权及文件来源拒绝保持。动态站点/网站限制列真实边界，不为页面成功硬编码流程 |

Mobile Use 运行可靠性按事实分三类：已知客户端缺陷有复现才修；未覆盖的进程死亡/后端/OEM 组合是验证项；Owner 已确认的 Qwen 图像误读是模型限制。302 最终 R8 图片 UI 与 301 抖音有提示复测分别保留，不升级为通用视觉/全自主成功；不靠扩大截图或自动重放动作掩盖不确定性。

1. Browser 补键盘提交/按键、选择控件及授权文件上传，明确输入替换、追加与提交；沿原页面/节点/目标绑定、权限和等待路径执行。
2. Mobile Use 简化常用点击/输入/滚动/滑动参数，frame、截图原始尺寸、缩放、旋转及坐标空间由宿主统一映射；不让模型猜单位或手算图像变换。
3. 输入注入与业务完成分开；失效目标、遮挡/隐藏确认失败、敏感 UI 与未知系统过滤继续如实反馈，不靠无界重试或跨后端重放动作。
4. 同步模型工具描述、内置 Skill 和用户可理解的结果/配置提示，保留展开诊断详情；不新增第二个观察平台或通用操作后门。

## 验证入口

上传与路径接续（2026-10-17 计划；当前已有实现，见下方核对）：Browser 文件上传使用明确源 ResourceRef/版本、目标页面 origin 和原调用绑定；执行副本中的路径、Android 本机路径与产物引用不能仅靠同名互换。Mobile Use 截图仍是带原会话/frame/generation 的产物，不能由路径展示推导像素已发送。沿 [第 23.3.1 节](../../architecture/harness-refactor-plan.md#2331-目录资源与执行环境) 验证源切换/变化、撤权、目标页面替换、同名不同副本和未导入文件；上传受理与业务提交分别留事实。

- Browser 表单夹具核验替换/追加/Enter/select/upload、跨 origin 和授权撤销；Mobile Use 覆盖 frame 缩放旋转、旧 token、取消、悬浮窗及注入/效果区分。
- 按授权用合成界面和真实模型比较参数错误、发现往返、调用数及任务成功；不继承旧 R6 长稳或据短验声称普遍改善。
- 开始实施时定位现有测试入口并按改动选择回归；目标契约可替换旧实现镜像断言，权限、持久原子性、取消、真实退出与恢复反例不得丢失。设备/服务须按当前 AGENTS 核对范围与配置；实际执行见下方日期记录。

## 2026-11-15 当前实现核对与动态目标窄修

- 当前已有 `browser_type` 替换、`browser_type(mode=append)` 追加、`browser_select` 单选、`browser_press` 合成按键、`browser_submit` 原生 requestSubmit 与 `browser_upload` 有界授权文件附加；注册入口为 `BrowserTools`，不能再将这些功能统称待实施。合成 Enter 不承诺原生默认提交，上传附加不等于业务提交。
- 现有 `BrowserActionsDeviceTest` 覆盖追加、选项拒绝、按键、原生验证/submitter、敏感字段与失效页面；上传源与目标约束由 `BrowserUploadSupport` 的源版本核验、快照指纹预检与目标引用复核执行。本段为源码核对，不继承历史设备通过状态。
- 本轮发现普通 click/type/节点动作只校验缓存指纹，再按 live DOM 的旧索引查找，动态插入节点可错误指向新目标。窄修在同一次固定动作 JS 内对照宿主已观察的 tag/role/text/value/name/href；变化返回 stale-token，不自动重放，不另加 WebView 调用。投影函数与 snapshot 共用，保留原敏感字段及页面/TTL 校验。
- 固定节点动作遍历找到指定索引即结束当前层并退出祖先遍历，避免继续扫描后续节点；顺序、节点/遍历预算与未找到拒绝保留。上传仅复用此遍历提前退出，不接入新的语义 guard，其既有全快照预检及上传目标引用检查不变。
- 该检查保护已观察的有界语义，不宣称 DOM 对象永久身份：相同投影的替换、被截断字段尾部变化仍是边界。与目标无关的普通正文变化不强制刷新。上传已有独立预检/目标绑定，本轮不改其路径。
- 新动态设备夹具覆盖插入导致旧索引偏移、输入值/href 变化、无误点/无覆写、显式新观察后恢复，以及无关正文变化无需重复 snapshot。当次 API36 集中验证中的浏览器 12 项通过，后续当前契约清理候选又完成 12 项浏览器回归；分别见 `build/task-efficiency-20261115/` 与 `build/compatibility-audit-20261115/browser-device.xml`。这些是对应候选的定向回归，不代表所有网站、OEM 或自然模型通过。不把拒绝错误动作或减少调用数表述为端到端延迟改善。
