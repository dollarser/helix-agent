## 范围与验收要求

1. Browser 补键盘提交/按键、选择控件及授权文件上传，明确输入替换、追加与提交；沿原页面/节点/目标绑定、权限和等待路径执行。
2. Mobile Use 简化常用点击/输入/滚动/滑动参数，frame、截图原始尺寸、缩放、旋转及坐标空间由宿主统一映射；不让模型猜单位或手算图像变换。
3. 输入注入与业务完成分开；失效目标、遮挡/隐藏确认失败、敏感 UI 与未知系统过滤继续如实反馈，不靠无界重试或跨后端重放动作。
4. 同步模型工具描述、内置 Skill 和用户可理解的结果/配置提示，保留展开诊断详情；不新增第二个观察平台或通用操作后门。

## 验证入口

- Browser 表单夹具核验替换/追加/Enter/select/upload、跨 origin 和授权撤销；Mobile Use 覆盖 frame 缩放旋转、旧 token、取消、悬浮窗及注入/效果区分。
- 按授权用合成界面和真实模型比较参数错误、发现往返、调用数及任务成功；不继承旧 R6 长稳或据短验声称普遍改善。
- 开始实施时定位现有测试入口并按改动选择回归；目标契约可替换旧实现镜像断言，权限、持久原子性、取消、真实退出与恢复反例不得丢失。设备/服务须核对当次授权与配置，本轮未执行。
