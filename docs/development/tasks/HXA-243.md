# HXA-243：Mobile Use 全机授权与原生操作覆盖

分类：收尾验收。2026-10-02 所有者要求先提交 HXA-242，再收敛代码并尽量开放全手机操作，减少非系统稳定性所需的任意限制。前置提交 `ed5e1ef3`，不推送。本轮不运行模拟器或真机，不沿用 HXA-241 设备证据。

## 范围与验收要求

- 保留现有 Dispatcher、工具授权、Android 用户开启无障碍权限和可立即停止的会话；不创建独立自动化引擎。
- 提供用户显式选择的全手机范围与指定应用范围；模型不能扩大范围。默认不再限制 5 分钟/30 动作，用户可设置时间和动作预算；锁屏、停止与服务断开仍结束授权。
- 删除按包名/动作关键词猜测的永久拒绝，保留明确的目标授权、平台安全屏幕及身份校验。平台动作失败只报告真实结果，不伪装成功或自动重放。
- 接入实际支持的系统动作、应用发现/启动、坐标多点手势与无障碍截图，复用现有工具图像和会话产物管线。截图/手势绑定观察到的目标与坐标系；缺失或变化的目标明确返回诊断。
- 等待扩展为出现/消失/内容变化/稳定；有界单次等待与模型决策分工不变。
- 收敛共享实现、旧说明、死代码，补齐主机与制品回归；不使用真实账号，不承诺所有 OEM/安全窗口均可自动化。
