## 范围与验收要求

按 [ADR-WORKSPACE-002](../../adr/workspace/002-manual-files-and-recovery.md) 完善文件发现与使用流程：稳定文件位置、最近打开、收藏、文件作为附件交给当前/新会话、受支持目录开始任务、会话/任务成果定位与交付。

- 收藏和最近只存 scoped 位置，不复制文件、不授予工具权限；同名异位置不合并，撤权/缺失不自动换目录。
- 附件显式准备副本，经原附件分类/导入流程，用户检查后发送；目录绑定复用原工作目录验证，不改变原文件。
- 捕获交接目标；异步读文件或验证目录期间切换会话后不重定向。目录失败不替换原会话。
- 成果定位使用记录的原始 scoped 引用，实际分享文件与分享预览文本分别标明；复用原导出验证与失败反馈。
- 最近限 40、收藏限 100；写入失败不发布成功状态，版本/格式损坏不静默重写。
