## 当前代码与缺口

[BrowserTools](../../../tools/browser/src/main/kotlin/com/helix/tools/browser/BrowserTools.kt) 的实施前12工具没有标签列表或条件等待；[BrowserController](../../../feature/browser/src/main/kotlin/com/helix/feature/browser/BrowserController.kt) 已维护标签状态和生命周期。[MobileUsePlugin](../../../extensions/mobile-use/src/main/kotlin/com/helix/extensions/mobileuse/MobileUsePlugin.kt) 已提供 `ui.wait` 和语义/视觉工具，HXA-271 也已补齐部分拒绝原因及 URI 结果说明，不重建手机等待与授权。

## 范围与验收要求

1. 冻结六类最小旅程：已有标签识别、延迟页面条件、导航后旧 token、同名控件歧义、截图未披露、动作结果未知。复用现有 Agent Eval 与合成页面/App fixture，先保留原调用与结果基线。
2. 增加受 scope 约束的有界 Browser 标签发现，返回准确 tab ID、允许披露的标题/URL、选中与页面/host 状态；不把别的上下文内容或不可用页面假报为当前可操作。
3. 增加有界 Browser 条件等待，复用已有页面观察而不执行任意页面 JS；只支持首版明确的页面/目标条件、期限与取消，返回命中/超时/宿主失效事实。页面导航、owner 替换和停止释放等待引用。
4. 在已有 Browser/Mobile Use 观察结果中只补确实缺失的事实：匹配数量/歧义、截断、实际后端、观察过期、像素是否提供。字段来自执行器，不由模型推断为成功；已经存在的字段复用。
5. 超时或无变化不自动重发点击、发送、安装等动作；未知结果只读核查，拒绝不换后端绕行。
6. 更新领域 Skill 及两项新工具的 descriptor/schema/policy/绑定，纳入既有发现窗口；直接替换受影响的旧结果形态，不保留内部结果兼容层。
