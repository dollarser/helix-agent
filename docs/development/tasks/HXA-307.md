## 设计与参考

- [OpenCode 官方 FAQ](https://dev.opencode.ai/)区分免账号内置模型与用户自配来源；采用“无需配置起步、可自行切换”的交互。其免费模型数据政策不能继承为 Helix 政策。
- 内置来源新增独立 provisioning，仍使用 Network transport + None credential；公共标识由专用传输附加，不伪装成 SecretAlias/Bearer。生产请求锁定 HTTPS 主机、端口、目录 GET 与生成 POST 的准确路径，禁止重定向及连接自动重试。常规自配 API 保持现有行为。
- [OkHttp 5.5.0 重试源码](https://github.com/square/okhttp/blob/parent-5.5.0/okhttp/src/commonJvmAndroid/kotlin/okhttp3/internal/http/RetryAndFollowUpInterceptor.kt)显示 `503 + Retry-After: 0` 存在独立 follow-up 路径，因此仅关闭连接重试不够；内置生成请求体同时使用 one-shot 语义，阻止传输层再次发送，保留原始状态与响应头供上层处理。
- 目录按需 `GET /models`，成功缓存 30 分钟、失败缓存 1 分钟，手动刷新有短暂防连点；并发查询合并，取消不发布半份目录。失败保留已缓存目录，没有历史则为空。目录与推理可用性分开，不发送生成探测、不改变连接测试结果、选择或付费来源。只有已知 Qwen 契约保留项目声明能力；其思考档位按固定官方模板提供，新增模型不继承视觉/工具/思考支持，窗口保持未知。
- 来源管理采用同一行可横向滚动的 Material primary tabs，窄屏不再出现 2+1；聊天的配置来源动作使用等宽单列，插件页同样采用可滚动 tabs。保留 Composer 声音、文本、加号与发送同一行，以及完全访问仅提醒色文字。参考 [Android Compose Tabs](https://developer.android.com/develop/ui/compose/components/tabs) 和 [OpenCode 模型选择](https://opencode.ai/docs/models/)，只采用适合现有手机界面的导航方式，不照搬其运行时。
- 原生插件 durable revision 仅在内容/启用变化或实际投影 repair 时递增；内容相同的冷启动仍建立新进程绑定，健康 repair 不写库也不换绑定。4 个内置 package 及当前工具 API 声明统一为版本 1；内部 CAS/选择/授权计数不回退。持久工具来源按 pluginId/runtimeId 识别，启动事务一次性规范化旧版本键并保留明确禁用；不维持双轨读写。单次审批仍绑定原调用和执行实例，不扩展为未来批准。
- 按 Owner 最新要求，会话窗口不显示内置模型传输消息、上下文等至服务器的提醒；数据处理范围保留在 README，不承诺未知留存/训练政策。工具与敏感附件授权保持。
- 共享 ID 的 120 RPM、每日一千万 token、4 并发，以及网关整体 4 并发由服务端执行，不显示为每人额度。401 提示客户端未授权/停用；429 只说明可能的共享请求/额度/并发限制；502 服务异常、504 超时。未收到可信服务端字段时不推算剩余额度、精确原因或恢复时刻。失败由用户手动重试，不自动重放部分 SSE 或切到自配付费模型。
- 新草稿选模偏好属于 UI 设置，已有 Room 会话和 Turn 冻结目标仍为权威。错误文案使用原模型调用快照中的 Provider 身份，后续切换模型不改变历史错误归属。

契约维护在 [ADR-PROVIDER-001](../../adr/provider/001-models-and-connection.md)，不为当前接入增加后续重构前置条件。
