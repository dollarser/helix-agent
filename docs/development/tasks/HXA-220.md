# HXA-220：Core Engine / TurnEngine 生命周期收敛

分类：进行中。当前状态见[实施状态](../status.md)。本任务是代码/架构重构任务，当前长期契约以 [ADR-AGENT-001](../../adr/agent/001-turn-coordination.md) 与 [ADR-GOAL-001](../../adr/goal/001-lifecycle-and-completion.md) 为准。

## 范围与验收要求

把 Turn 的 durable + live execution ownership 收敛到单一 TurnEngine，并把进程死亡恢复从旧的 same-Turn rehydrate 迁移到 **old Turn execution-terminal + successor Turn continuation**。

必须保留的安全/正确性基础：

- batch-aware process recovery；
- PENDING/RUNNING execution-start boundary；
- immutable `tool_call_reviews` 与 no blind replay；
- requestId/fingerprint 幂等；
- ToolCall batch 原调用顺序；
- `ExecutionOwnership`：timeout/cancel 不等于 executor exited；
- `turn_runtime_records` 的 immutable execution config 与当前 Turn usage/audit；
- TurnEngine single owner；
- Queue/Steer、Regenerate 原子 replacement、Goal 累计预算。

不再作为最终目标：same-Turn review resume、same-open-GoalRun resume、old ModelCall/tool-round/budget control-state rehydrate。

## 已完成的代码基础

- batch-aware recovery、NEEDS_REVIEW/review storage、v29/v30 migration；
- live UNKNOWN fail-closed 与 review park；
- C5-B same-Turn review/resume 主机实现：**保留为迁移期正确旧实现，后续 R1 卡替换后删除，不继续扩展**；
- `turn_runtime_records` immutable provider/run-control snapshot 与 live usage checkpoint；
- DurableSessionGate、Engine-owned admission/cancel/review park/terminal/startup recovery；
- E1-B0 Regenerate admission ownership；
- E1-B1 Engine-owned submit receipt/admission transaction；
- E1-B2 `TurnLiveRegistry` / `LiveTurnHandle` contract 与 stale Job completion tests。

ChatService 仍可暂时作为 AgentLoop/live-frame process-local driver，但不得绕过 TurnEngine 改写 durable lifecycle。

不在本 HXA：Workspace binding、Git 产品化、UI/IA 大改、新工具、本地模型 Provider 实现、子 Agent、远端 worker、设备 CI、发布/push/真实账号消耗。

## 实施顺序

### E1-B3a — Active Job + RunControl owner migration（已完成并强审通过）

继续按已经下发的 B3a 卡执行：

- `SessionTurnAdmission` → `TurnEngine.liveExecution`；
- `inputTurnControls` → `LiveTurnHandle.control`；
- claim 必须发生在 worker 创建后、`startGate` 释放前；
- durable terminal/review settlement 先 commit，再 release live owner；
- 不碰 `turnCancels`、`goalTimes`、AgentLoop exception、TurnLiveFrames、Room state。

caller graph 目标：`sessionTurnAdmission` / `inputTurnControls` production refs = 0。

### E1-B3b — Cancel signal + Goal timer owner（强模型已完成）

- `turnCancels` / `goalTimes` 迁入 `LiveTurnHandle`；
- 涉及 `AgentLoop`、`ChatDispatchRequests`、`ChatToolCalls`、Goal detached budget；
- 保留 UNKNOWN > timeout/cancel/error 的 fail-closed 优先级；
- deadline callback 动态读取当前 timer；
- 不提前释放 effect/live owner。

### R1-A — Turn state / process-death cutover（强模型已完成）

目标：停止复活 old Turn。

- `TurnState.INTERRUPTED` 改为 execution-terminal，不再允许 `INTERRUPTED -> BUILDING_CONTEXT`；
- `NEEDS_REVIEW` 只表示旧 Turn execution stopped + effect review pending；review 完成后 `NEEDS_REVIEW -> INTERRUPTED`（显式 abandon 可 CANCELLED）；
- process death：RUNNING ToolCall -> INTERRUPTED；PENDING/AWAITING_APPROVAL -> CANCELLED + interrupted-before-execution；其他 nonterminal Turn -> INTERRUPTED；
- 删除/替换 `RecoveryCoordinator.canResumeTurn`、Turn reducer Resume/reconcile 事件和所有 old-Turn resume test oracle；
- recovery 重驱必须幂等，不创建新外部调用或 successor Turn。

### R1-B — Successor identity + RecoverySummary（强模型已完成 host contract）

新增 durable predecessor/recovery identity。优先方案：给 Turn 增加 nullable `recoveryFromTurnId`（或等价强类型 durable relation）；若采用 schema 变更则按下一 migration 版本实现并补 Room migration test。

`RecoverySummary` 是有界模型上下文段，不伪造旧 ToolResult，至少包含：

- predecessor Turn / interruption reason；
- 已完成 durable facts；
- interrupted/unfinished facts；
- uncertain ToolCalls 与 review decisions；
- 相关 Artifact/check/result identity；
- “do not blindly replay unresolved side effects” 指令。

RecoverySummary 从 durable facts 构造，不成为第二历史源；默认不把它持久成普通 USER/ASSISTANT 文本。

### R1-C — Review service 简化：记录事实，不 resume old Turn（强模型已完成）

修改当前 `ToolEffectReviewService` / `TurnReviewResolution`：

- review insert/idempotency/conflict 继续保留；
- 删除 review 后创建 old Turn next ModelCall / synthetic batch backfill / WAITING_MODEL rehydrate；
- review complete 只关闭 old NEEDS_REVIEW Turn 为 INTERRUPTED 并记录 reason；ACKNOWLEDGED_UNKNOWN 也只是 effect fact，不隐式取消任务；显式 abandon/cancel 走独立命令；
- 删除 `ReviewedTurnResumeTicket`、`resumeResolvedTurn`、`TurnCoordinator.rehydrateWaitingModel()` 及 review-specific ModelCall receipt 的生产调用；
- 原 ToolCall/ToolResult 绝不改写；
- 旧 schema 字段先通过 caller graph 判断是否还被其它用途使用，再决定 migration cleanup，不为了减字段立即重写历史数据。

### R1-D — Successor admission + unresolved-effect gate（强模型已完成）

用户点击“继续上次任务”或发送新消息时允许创建 fresh successor Turn：

1. exact request dedup 仍在所有 fresh side effect 前；
2. INTERRUPTED historical Turn 不再阻止 admission；
3. NEEDS_REVIEW historical Turn 不阻止 successor ModelCall / read-only inspection；
4. 未决 effect 存在时，side-effecting ToolCall fail closed；首版允许保守阻止该 successor Turn 的 side-effecting tools；
5. review 全部确定后恢复正常 policy；
6. ACKNOWLEDGED_UNKNOWN 允许继续，但可能重复原未知 effect 的新调用不能复用旧 approval/receipt，必须重新经过显式 policy/approval；
7. process recovery 不自动消费 Queue，也不自动创建 successor。

要补 UI/command seam，但本 HXA 只实现 Engine/application command 和最小可用投影；大规模 UI/IA 改动另行排期。

### R1-E — Goal continuation 改为 new GoalRun（强模型已完成）

- crash/review 结束当前 GoalRun 为 interrupted/blocked outcome；
- Goal 保留长期 intent、累计 usage 与用户预算；
- review 完成后 Goal 进入可重新准入的 PAUSED/READY 语义；
- successor Turn 启动新的 GoalRun，runCount 增加；
- 新 Turn budget 重新计算并受剩余 Goal budget clamp；
- 删除 `ReviewResolvedInRun` / same-run `BLOCKED -> RUNNING` 专用路径及对应测试。

### R1-F — same-Turn recovery clean-slate cleanup（强模型收口）

项目尚未正式上线，不为废弃实现保留生产兼容层：

- 删除无 production refs 的 review-resume adapter、rehydrate helper、synthetic same-Turn backfill formatter/encoder 及对应旧测试；
- `turn_runtime_records` 只保存 immutable execution config 与 live usage/audit checkpoint，删除 `reviewActionId`、`reviewActionFingerprint`、`reviewOutcome`、`reviewModelCallId` 当前 schema 字段；
- Turn 级 review 命令幂等独立为 immutable `turn_review_receipts`（`turnId + clientActionId + actionFingerprint`）；逐 ToolCall effect truth 仍只在 `tool_call_reviews`；
- v30 仅作为历史 migration fixture 保留旧 runtime receipt 列，v30→v31 在迁移中重建 runtime table 并物理删除这些列；生产代码不提供 legacy `RESUMED/ABANDONED` 读取分支；
- caller graph + 编译器 + tests 证明 old Turn 不再回到 active phase，review resolution 不再携带 old ModelCall identity。

### E1-B4 — AgentLoop execution boundary（强模型）

在 recovery cutover 后，把 `launchAndPublishTurn/runTurn` 中真正属于 execution owner 的 start gate、AgentLoop invocation、exception→terminal/review、live release 抽到 Engine-owned driver。UI frame、Goal reminder、queue drain 通过 projection/notification seam 消费结果；Engine 不反向依赖 ChatService。

### E1-B5 — Observation hub / adapter 收敛（小模型实现 + 强模型复核）

- per-Turn live frame ownership 迁到 Engine observation seam；
- late subscriber 仍以 Room durable state 为底；
- 删除不再需要的 `AgentTurnHost`；`AppAgentRuntime` 仅在仍有必要时保留极薄 core contract adapter；
- UI `StateFlow` 不成为 runtime truth。

### E2/E3 — Legacy cleanup

最终用 `rg` + 编译器 + tests 证明：

- ChatService 不再拥有 Turn durable/live execution state；
- old same-Turn recovery 没有 production caller；
- legacy serial reducer/settlement helper 仅在确有测试 oracle 价值时保留，否则删除；
- 没有第二套 submit/cancel/review/recovery 解释。

## 必须覆盖的 fault / production-path tests

- 多 RUNNING、RUNNING+PENDING/AWAITING_APPROVAL process death；
- old Turn process death 后 execution-terminal，不创建 next ModelCall；
- live UNKNOWN -> NEEDS_REVIEW；review 不 resume old Turn；
- successor Turn durable predecessor identity + RecoverySummary；
- successor 使用新 runtime snapshot/Turn budget，Goal usage 不退款；
- NEEDS_REVIEW 存在时模型/read-only 可继续，side-effecting call fail closed；
- ACKNOWLEDGED_UNKNOWN 后新危险调用不复用旧 approval/receipt；
- duplicate successor submit / regenerate 不产生第二 Turn/Goal/runtime side effect；
- Goal continuation 创建 new GoalRun；
- timeout/cancel 时 executor 未退出不释放 ExecutionOwnership；
- stale Job completion 不释放新 live owner；
- late observer / Activity recreate 从 Room 重建 interrupted/review/successor facts。
