## 范围与验收要求

- `extensions/mobile-use` 拥有悬浮窗口、状态文案、接管和返回原会话交互。宿主仅提供通用 `PluginTaskHost`，不新增规划循环、数据库或 Mobile Use 专属聊天页面。
- 复用用户已启用的 AccessibilityService 和原前台服务；状态窗口使用半透明背景、不可触摸/不抢焦点。独立小控制窗口接收点击，其余屏幕继续交给被控应用。
- 绑定可信工具调用的 Conversation/Turn；接管停止原任务后续操作，不撤销持久授权，不声称已发出的外部动作回滚。普通任务停止；Goal 使用已有暂停语义。
- 截图及物理手势前隐藏窗口并有界等待渲染；隐藏失败拒绝本次执行。重叠操作的隐藏状态不能被另一个完成回调提前释放。
- 服务关闭清理窗口；锁屏/运行态暂停隐藏窗口；重建不恢复旧节点/手势凭据。停用插件隐藏展示，授权仍由现有 Dispatcher 和权限中心判定。
