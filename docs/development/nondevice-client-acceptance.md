# 非真机客户端回归

承接 `9a1f2ded`，本轮只做 Debug 主机、独立模拟器包与既有授权模型验收，不操作真机、不部署云服务、不扩大账号权限。保留无关开发指南改动，按功能本地提交，不推送。

## 有界范围

- 自然语言发现：通过真实 AgentRuntime 和请求装配器执行中文/英文压缩任务，并加入禁止写入对照；以实际 ZIP 内容及源文件是否不变判定效果，保存查询、结果、错误选择与额外调用。ZIP 是该用户任务明确要求的产物，不是所有命令的强制归档。另保留自然语言失败日志任务，读取原始调用证据、退出码并核对原命令仅提交一次，不由测试逐步指定模型工具选择。
- 模型只接触独立包内合成资料。测试会话只允许对应工作区读写，其他操作拒绝；进一步收紧工具可用性，不使用全访问模式。每任务最多六次模型调用或 90 秒，达到边界停止并保存失败，不无界重复。
- 语音：复用既有故障注入及 UI 生命周期测试，补 ASR/TTS 单调时钟超时、断线/繁忙不重连、前台恢复不自动采集。默认生产时限不变；没有新增业务恢复状态机。fake PCM、合成音频不代表真实麦克风验收。
- 分享：不同 UID 的测试接收器实际读取已分享快照，源文件随后改变不影响快照；无写授权、不持久授权，接收 Activity 结束后的 URI 生命周期单独核验。系统选择器打开与取消不等于已送达任意真实 App。
- 终端：使用已有真实 PRoot/PTY、前台私有进程及实际 UI 测试，覆盖持续执行、detach/attach、旋转/重开和停止结算。重连不重放原命令，仅清理本轮私有会话。
- OAuth 只检查既有无网络本地测试的回调错误和取消，不请求新账号授权、不测试真实发布或外部分享。

分享修正后的 4 项独立复验已全部通过，随后进入有界真实模型阶段，没有新增测试框架。

首次真实模型阶段未启动自然任务即失败：测试在应用启动恢复账号前直接断言 signedIn，两个准备断言失败。同轮独立账号恢复/刷新/退出验证通过；这不是模型发现失败或服务器登录失败。改用应用已有 awaitAppContainer()，先完成正式初始化，再断言账号。保留原日志，只做一次有界复验，不修改账号/引擎或弱化断言。

合成语音服务观测：HTTP/WS 使用同一 PCM，ready/end、取消/重连及 1013 繁忙通过。但输入“你好，这是模拟器语音接入测试。”往返为“你好这是模拟器语音接助测试”，存在字词差异，不算文字质量通过。原始 WAV/PCM、帧与响应保留在本轮 ignored 证据；不能仅凭该样本区分 TTS 发音与 ASR 模型问题，未用客户端替换文字掩盖，需服务端配合定位。

自然语言首轮进入正式 Agent 后，两个写入样本均正确发现 files.archive，但资料使用 app scope、会话自动绑定私有 workspace，读取和归档均被权限正确拒绝，没有生成 ZIP。负向样本同样未写入。修正测试：通过现有 setSessionDirectory 显式绑定合成目录，并使用绑定后的资源身份；不放宽外部目录权限，不重放被拒绝的原调用。

同轮日志任务调用 tools.read_result 读到了 FAILED/exitCode=7，但结果正文没有原执行日志入口，模型如实表示拿不到 stderr 后结束，未达到诊断目标。补读页现在从经过会话校验的原调用类型附带 logRef/logReadTool，与首次执行结果的既有引用语义一致；不解析不可信正文生成路径，不自动读取或重新执行。新增 JVM 断言覆盖三个受管执行名称及普通工具不虚构日志引用。原失败和后续有界对照分别保留。

绑定修正后的样本仍有测试契约错误：指定 ZIP 位于绑定根目录，而现有 files.archive 明确限制输出在 work/。模型正确发现工具、在合法 work/ 位置完成归档，随后为满足非法目标尝试调用失败；两个写入任务到调用预算取消，不能算完成。最终样本改为 work/result.zip，不改变产品归档限制；各轮失败原样保留。

该轮日志任务已自主发现 read_log 并取回真实 stderr，但日志读取页缺少已持久化退出码，模型将错误标记中的 731 与退出码 7 比较，不能算准确诊断。补读页现在保留原记录中的 exitCode（仅 saved 捕获有权威记录时存在，live 预览不伪装终态）；read_result 也在长正文分页外保留已知执行的退出码与日志截断标志。强化验收：提示不预先提供退出码，回答必须带明确退出码标签与独立数字 7，不能靠错误标记包含数字 7 通过。未改变执行、权限或重试语义。
