## 4. 每个切片的交付格式

1. 开始：核对HEAD、工作区、暂存区、对应任务和已有完成记录，写清本切片范围及未完成验收。
2. 实施：复用现有状态所有者，UI经应用服务；不新造任务账本或绕过Dispatcher。
3. 验证：执行专项精确命令及矩阵追加要求；设备使用自建独占runner。报告实际测试数、失败/skip与fail-fast未达阶段。
4. 记录：同步status、roadmap、matrix及证据；只有整个HXA要求满足才创建完成记录。切片通过不等于HXA通过。
5. Git：已授权独立切片验证后本地commit；具名路径或hunk，检查cached diff与check，不夹带并行工作，不push/merge/release。
