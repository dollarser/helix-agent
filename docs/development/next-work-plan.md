## 下一批：HXA-217

遵循[HXA-217](tasks/HXA-217.md)轻量范围，先测量再确定存储形式。现有主机预评估不能作为Android成本验收。

1. **成本与格式。** 在Kotlin/Room测量典型会话、最大合法来源和至少100次调用的字节增长及读写耗时，确定有界条目/字节上限与省略语义。包含长Unicode ID；累计成本不可接受时先缩减范围，不引入配额服务或后台淘汰系统。
2. **采集与导出。** 最终组装、压缩、附件物化与准入后，在Provider前保存最小有序来源；关联不可变消息版本、真实Queue/Steer input身份及压缩边界。复用ModelCall、用量、附件与现有JSONL，不重复正文。
3. **失败与对照。** 三类Provider逻辑请求对照；覆盖修订、fork、摘要、工具批和真实Queue/Steer。区分完整、缺失、省略、旧版未采集和原内容不可用；诊断写失败不单独阻断合法请求。验证会话删除、格式兼容和进程中断，不把清单落盘解释为服务端收到。

首期不做详情页、完整HTTP归档、工具目录取证、详细诊断开关或新的Agent工具。

## 维护与验收规则

- **R4不先实现CAS。** 当前没有已确认的生产竞态；出现可重复写者交错时再确定修复，避免为旧探针重构全部状态写入。
- **R8做有界验证。** 验证持久终态不反转、结果/预算不重复、后继输入不静默丢失及恢复可继续；无故障证据则记录通过范围，不预设必须拆分ChatService。
- **孤儿正文先保留为已知边界。** Room不回滚已物化文件。只有测得明显积累或出现清理需求，才设计带引用保护的最小清理，不直接全盘GC。
- **基线按实际源码核验。** 本轮绿色只覆盖记录中的提交；开工前解决现存强制失败。代码改变后跑任务规定命令和受影响路径；文档整理只跑源/文档门禁，不反复运行无关设备套件。
- **本地与远端分开。** 每批按“切片实现 → 本地验收 → 复核 → 按授权合并”推进；远端CI本轮暂缓，恢复时核对确切SHA，不能用历史绿色替代。
