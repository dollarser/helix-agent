## 本轮实现边界

- 离线 ASR/TTS 资源集中在语音设置，显示模型状态、实际已下载文件占用、显式重新下载和确认删除。只操作模型锁中的文件；不删除聊天、账号、设置、另一模型或未知文件，不跟随目录重定向。TTS 由既有播放所有者停止并等待物理合成资源释放后删除，不以取消信号冒充退出。
- 重新下载先校验暂存，失败保留原先有效模型。固定不可变模型文件 GET 的连接/读取瞬态故障，应用层每文件最多一次恢复，短退避/抖动，沿用整次时间和字节上限；显示恢复次数。校验失败、超限、本地文件错误、证书错误和取消不作网络重试。没有跨进程自动续传或后台自动下载，不影响业务工具单次执行语义。
- 设置按离线资源/云端服务分组；先显式启用云端才展示协议、账号和地址字段，保存仍走原设置契约。下载或保存设置不会自动录音、上传或发送消息。
- OCR 复用既有图像附件及 documents.view 视觉反馈链，PDF 原生渲染、图片披露/权限/预算边界保持。图片/无可读文本资料在知识库中明确提示视觉读取路径，不把收藏或文本提取成功当作 OCR；不自动上传、索引或将模型输出标为审核知识。

## 服务端与设备交接

云端 ASR 定位继续使用同一原始 PCM 的 HTTP/WS 包 `build/log-context-closeout/asr-same-sample-repro.zip`：预期“你好，这是模拟器语音接入测试。”，实际两路“你好这是模拟器语音接助测试”。包内含原始响应、采样率、逐帧与结束记录，不含凭据。服务端需对比网关前后结果、原始识别与 final 刷新；客户端不改字、不掩盖失败。

TTS 服务端需确认队列上限、等待超时、取消后的物理容量释放，以及忙时 1013 的网关透传；文档有队列描述和既有 1013 成功观测，不能推断所有并发/取消压力条件均通过。当前仓库没有获授权的语音服务端部署目标，本轮不修改生产服务或防火墙。

本轮只模拟器及既有授权模型；真实麦克风、耳机、OEM/低内存与真机终端覆盖安装恢复留在明确待验范围。Release/R8 主机、签名检查和模拟器冒烟不替代真机或商店发布许可。具体结果在本轮验证完成后更新。

## 收尾验收发现并修复

TTS 取消故障注入在读取以 EOF 结束时复现 expected IDLE / actual FAILED。下载任务已取消后的校验异常现在保留取消语义、回到空闲并重新抛出取消，不把仍活动任务的真实错误转成成功；原失败与定向复验分别留存。等待 ASR 使用锁期间关闭页面也会取消删除等待，保留尚未删除的模型；已经完成的文件删除不承诺回滚。

独立 Release 初次三项 UI 冒烟通过，但升级用例准备阶段点击 English 标签无效，尚未执行覆盖安装。确认原语言选择只有圆点响应，已改为最小 48dp 的整行单选触摸目标，保留原语言保存、系统同步和 Activity 重建逻辑；新测试通过标签触发，而不是改查找方式绕过问题。修复后的 TTS EOF 取消与真实语言标签选择两项定向模拟器复验通过。最终同候选覆盖验证在修复后的 Release 包上重新开始，不复用原准备失败为通过。
