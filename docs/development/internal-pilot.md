# 小范围内测执行与反馈清单

状态：准备材料；实际试用尚未执行，不代表设备、模型或用户验收通过。当前进度见 [status](status.md)，依赖顺序见[剩余工作](release-readiness.md)。本清单不新增模型服务、权限、生产遥测或持续后台任务。

## 准备

使用明确版本的 APK，记录渠道、commit/APK hash、Android/API/设备及模型配置；为每位试用者准备空的专用 Workspace 和合成资料。未经单独授权，不使用真实账号、个人文件或敏感网页。保留当前模型与权限设置，不用 FULL_ACCESS 掩盖默认流程问题。

首次使用者独立操作；观察者记录介入，不替用户完成后记作成功。设备操作、应用安装和模型服务使用都按当前授权执行；不执行清理用户设备数据的命令。模型安装会下载大文件，先说明来源和空间需求。

## 固定任务与独立核验

| 任务 | 操作 | 通过条件 |
| --- | --- | --- |
| 配置与首次成功 | 从模型选择/配置进入空 Workspace，要求生成包含 3 行指定合成文本的文件 | 用户能找到配置及产物；独立检查文件内容，不能仅看模型说“完成” |
| 文件修改 | 提供数量 2、3、5 的合成 CSV，要求生成总数报告，再把中间值改为 4 并更新报告 | 首次总数 10，修改后 11；原文件只发生请求的修改，报告与文件一致 |
| 只规划 | 要求对三个合成文档提出三个检查点，明确本轮不执行 | 输出计划且无业务写入；不把计划文字宣称为底层工作完成 |
| 授权拒绝与恢复 | 在需审批的配置下请求向专用目录写一个合成文件，先拒绝，再明确发起新请求并批准 | 首次文件不存在，UI 显示拒绝；第二次仅按新审批执行，旧请求不复活 |
| 停止与重开 | 在可安全中断的合成任务中停止，然后正常重开；进程骤停用已有专用 runner 另验 | 状态来自持久结果，没有无授权重跑；未知副作用进入核查，不能计成普通成功或直接重试 |
| 目录失效与更换 | 仅对专用测试目录制造不可用条件，打开/fork，并显式更换目录 | 可以回退到新空目录；已存在文件不丢失，新请求使用新绑定，在途请求不被偷换 |
| 文件面板与支持 | 打开 SAF 来源、刷新、移除测试来源，再预览用户主动的诊断报告 | 来源与当前授权一致；移除后不再显示或使用；报告不泄露正文/凭据，失败能恢复 |

本地 4B 的安装与基础 write/read 可以作为单独旅程；不要求用它跑全部长程任务。网页/系统自动化属于追加场景，先指定可测试页面/应用与动作范围；不擅自操作账号、通知或系统设置。

## 记录口径

每项记录：成功/失败/未执行、首次是否独立完成、人工介入次数及原因、端到端耗时、实际产物是否正确、失败后是否保留输入、能否恢复、观察到的错误码和关联 ID。失败与未执行计入总表，不只报告成功样本。模型纯推理速度另测，不从端到端耗时反推。

反馈模板：

```text
版本 / APK hash / 渠道：
设备 / Android / 模型（不含 token）：
任务编号 / 合成输入说明：
预期结果 / 实际结果：
首次独立完成：是 / 否 / 未执行
观察者介入次数和原因：
耗时 / 是否产生正确产物：
恢复步骤及结果：
错误码 / Call ID 或 Turn ID（如有）：
可公开的复现步骤：
是否有经过用户预览的脱敏附件：
```

不要填写 API key、Cookie、账号密码、真实文件内容或原始请求全文；不默认上传任何数据。截图也需用户预览，发现敏感内容先移除再分享。

## 退出与后续

准备阶段的退出条件是：任务、独立判定、记录口径和已知限制清楚；不把材料准备完成记为内测完成。试用阶段每项必须有记录，并修复/重验可复现的数据丢失、授权绕过、错误成功状态及无法恢复的核心阻碍。模型偶发性问题保留轨迹；一次成功不足以关闭。

反馈决定后续优先级，不自动授权 R2/J1、Project Memory 或新工具。扩大人数、设备矩阵或对外发布之前，明确候选版本和剩余缺口；发行仍沿用 HXA-120 → 122 → 121 → 123。
