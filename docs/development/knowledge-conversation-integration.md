# 知识库与会话引用接入

日期：2026-10-25。范围是 Owner 已评审原型的 Android 接入；不改变 v0.0.7 发布，不引入新的聊天引擎、同步、向量服务或 OCR。

## 实现边界

- 知识、笔记、资料是内容类别；新问答使用现有会话，旧资料问答仅保留只读记录和显式保存。`KnowledgeNote.kind` 与保存/核对/模型生成状态分离，既有笔记保留内容与核对状态，默认 NOTE。
- 新建笔记先在可恢复编辑器中编辑，显式保存才入库；放弃不创建空记录。已保存笔记可整理为可编辑知识候选，取消不入库，保存创建独立未核对知识，保留原笔记和冻结来源。这不是自动模型总结，未新增模型调用。
- `KnowledgeReferenceService` 提供有界选择和版本核查；UI 不直接读 DAO。输入框沿用现有会话工具栏、＋菜单、模型/语音/发送，知识引用与会话引用分别可发现。阅读页通过应用命令写入原会话草稿，不自动发送，不改权限或 Agent 知识库开关。
- `KnowledgeReference` 固定类型、身份、正文摘要、实际文本、范围、完整性和显式保留版本状态。FULL 是实际全文，EXCERPT 是开头最多 1800 字符；八条、总正文 24000 字符上限，不是 token 保证，也不是任意文本选区。超限拒绝，不把关联原件递归发送。
- 草稿、发送确认与接受后的队列都复用既有 `ChatSubmission`/`SessionInput`。发送前和确认时检查变化；已接受输入交付固定快照，不以原文变化修改它。敏感文本确认和凭据检查沿用原入口。模型正文用明确不可信区块，不授予工具权限。
- 消息历史从已消费输入获取固定引用，原资料更新或删除不改历史。手动编辑仅修改用户正文，保留引用，不自动重发或建分支；本条引用发送后仍可能被后续会话历史使用，不承诺自动遗忘。

## 数据与删除旧路径

主库 v1→v2 增加输入引用 JSON；资料库 v2→v3 增加类别、原笔记快照及回答来源身份。使用 Room 加法迁移，不清聊天、账号或资料。精确的已发布 v1 身份通过现有启动检查后迁移；其他未知预览仍需原有显式确认，不能自动重置。

测试改为共享 `core/storage/src/androidTest/assets/` 的权威导出，删除 App 内独立的旧 schema 副本，避免错误地把历史同版本号 schema 当作已发布迁移基线。不保留旧字符串拼接式知识引用入口。

## 尚未支持

任意正文选区、资料批量智能总结、自动关联、同步、整库备份与新的模型检索平台不在本轮。原型提供交互参考，不是所有演示能力都已有后端。持续更新本记录的实际验收结果后才收口。

## 原型优先表现层收敛（2026-10-25）

Owner 指出旧版页面与原型在视觉、按钮和功能入口上差异过大，确认按融合原型重做且不兼容旧 UI。保留已经接通的数据与引用事实，不以旧控件复用为理由维持重复流程。

| 原型任务 | 当前 Android 落点 | 实际动作及边界 |
| --- | --- | --- |
| 搜索、三分类、简洁列表 | KnowledgeLibrary | 知识/笔记/资料，日期和状态为次要信息；行内引用，写笔记为主动作 |
| 导入与管理 | KnowledgeImportAction 的更多菜单 | 真实系统文件选择；多选来源、直接写知识和默认关闭的 Agent 访问设置，不常驻占用正文空间 |
| 阅读/编辑 | KnowledgeNoteEditor / KnowledgeDetail | 正文优先、固定返回与更多，编辑独立状态且顶部显式保存；笔记保存不要求核对 |
| 整理知识 | KnowledgeDraftDialog | 可编辑本机候选；取消不入库，保存独立未核对知识，来源变更拒绝；不是模型自动总结 |
| 提问 | 既有 ChatScreen / ChatService | 将引用交回原会话草稿，不自动发送；新问题不再进入独立知识库模型流程 |
| 引用选择/预览 | KnowledgeReferencePicker / Chips | 选中时冻结，跨搜索保留；取消不改原草稿，来源更新需明确处理；正文历史固定 |
| 保存回答 | ChatService.saveReplyAsNote | 仅终态实际 assistant 正文；显式存笔记，重复保存幂等且不覆盖用户改写，不追加模型请求 |
| 旧问答/生成建议 | KnowledgeQuestionHistory / 历史建议查看 | 数据仍可读，READY 旧问答可明确存笔记；删除独立问答及笔记生成服务，无第二套 Provider/发送确认 UI |

原生实现保留 Android 返回、系统分享/文件选择及无障碍触摸区域，不机械复制网页尺寸。未实现撤销删除、全版本浏览或任意正文选区，不呈现成可用按钮。原图/扫描文档仍是实际原件与已有视觉会话入口，不能把“已收藏”画成文字已提取。
